ABOUT

このサイトについて

目的

Java Silver SE 17 試験対策ノートは、Oracle 認定資格 Java Programmer, Silver SE 17（試験番号 1Z0-825）の合格を目的とした学習サイトです。次の2つでできています。

  • 教材 ── 試験範囲を全 {{chapters}} 章・{{sections}} 節・{{points}} 論点にまとめたもの。論点番号（2-3-4 など）・検索・索引で引けます。
  • 模擬試験 ── 本番と同じ 90 分・60 問の形式で {{examCount}} 回分（{{questions}} 問）。解説から教材の論点へ戻れます。

使い方は はじめての方へ で、実際の画面を動かしながら説明しています。

注意事項

  • このサイトは非公式の学習サイトで、Oracle 社とは関係ありません。Oracle と Java は、Oracle Corporation およびその関連会社の登録商標です。
  • 試験範囲は Oracle 公式の試験内容チェックリスト（1Z0-825-JPN）に沿っていますが、内容の正確さや、試験に合格できることは保証しません。試験の範囲・形式・合格ラインは変わることがあるので、受験の前に Oracle の公式サイトで最新の情報を確かめてください。
  • 模擬試験の合格ライン（65%）や「黒本より易しめ」などの難しさは、作者が決めた目安です。

問題と文章について

  • 教材の文章・図、模擬試験の問題と解説は、すべてこのサイトのために書いたオリジナルです。市販の問題集の問題は載せていません。
  • 模擬試験の説明にある「黒本」は、市販の問題集の通称です。難しさや論点の配分の目安として比べているだけで、その書籍の出版社・著者とは関係ありません。
  • 模擬試験の問題のコードは、すべて JDK 17 で実際にコンパイル・実行して、解説どおりの結果になることを確かめています。

記録の保存先

  • 模擬試験の受験記録・振り返りメモ・見直しマーク、教材の「続きから」の位置は、お使いのブラウザの中（localStorage）だけに保存されます。サーバーには送りません。アクセス解析も入れていません。
  • そのため、別のパソコンやブラウザとは自動では共有されません。模擬試験の「記録を書き出す」「記録を読み込む」（JSON ファイル）で移せます。
  • 記録を消したいときは、模擬試験のページの「削除」か、ブラウザの設定でこのサイトのデータを削除してください。
  • 文字の表示に Google Fonts を使っているため、ページを開くとフォントのファイルを Google のサーバーから読み込みます。

誤りを見つけたら

内容の誤りや分かりにくいところは、GitHub の Issues で教えてください。教材なら論点番号（2-3-4 など）、模擬試験なら「試験 5 の問 12」のように場所を書いてもらえると助かります。

ソースコード

このサイトのソースコードは GitHub（shoushinei/java-silver-se17-note） にあります。手元のパソコンで受験記録 API（Spring Boot と H2 データベース）を動かすと、受験記録をデータベースにも保存し、間違えた論点をまとめた「弱点レポート」を取り出せます。手順はリポジトリの README にあります。
