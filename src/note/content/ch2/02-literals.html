リテラルの書き方

基数の表記

4種類の書き方形
int a = 10;        // 10進数
int b = 0b1010;    // 2進数（0b または 0B）→ 10
int c = 012;       // 8進数（先頭の 0）→ 10
int d = 0xA;       // 16進数（0x または 0X）→ 10

012 は12ではなく 10 です。先頭に 0 が付いた整数リテラルは8進数として解釈されます。桁揃えのつもりで int a = 007; と書くと値が変わる、という引っかけがあります。

アンダースコアの位置

桁区切りに _ が使えますが、位置に厳しい制約があります。

数字と数字の間だけOK
int    a = 1_000_000;
long   b = 1_234_567_890L;
double c = 3.141_592;
先頭・末尾・記号の隣は不可NG
int    a = _1000;      // エラー: 先頭
int    b = 1000_;      // エラー: 末尾
double c = 1_.5;       // エラー: 小数点の隣
double d = 1._5;       // エラー: 小数点の隣
long   e = 100_L;      // エラー: 接尾辞の隣

数字と数字の間に挟まれているときだけ有効。これ以外は全部コンパイルエラーです。
