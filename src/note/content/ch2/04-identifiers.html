04

識別子の規則

識別子とは、変数・メソッド・クラス・インタフェース・パッケージ・ラベルなど、自分で付ける名前のことです。規則は1組しかなく、どの種類の名前にも同じものが当てはまります。

使える文字

位置使える文字
1文字目Unicode の文字（英字・日本語など）、_、$
2文字目以降1文字目に使えるもの ＋ 数字
すべて通る名前最重要
int _name  = 1;   // _ で始めてよい
int $price = 2;   // $ で始めてよい
int a_b$c9 = 3;   // 途中は数字も混ぜられる
int 変数    = 4;   // 日本語も Unicode の「文字」なので通る
int INT    = 5;   // 大文字小文字は区別される。予約語の int とは別物
int Class  = 6;   // class ではないので通る
int String = 7;   // String はクラス名であって予約語ではない

長さに制限はありません。$ も規則上は使えますが、コンパイラが自動生成する名前に使う文字なので、慣習として避けます。「$ は使えない」という選択肢は誤りです。

使えないもの

すべてコンパイルエラーNG
int 1a      = 1;   // 数字では始められない
int a-b     = 1;   // ハイフンは識別子の文字ではない
int my name = 1;   // 空白は入れられない
int goto    = 1;   // goto は予約語
int const   = 1;   // const も予約語
int true    = 1;   // 予約語ではないが、リテラルなので使えない
int null    = 1;   // 同上
int _       = 1;   // _ 単独は Java 9 以降キーワード扱い

true false null は予約語の一覧には載っていません。これらはリテラルで、文法上そちらの側から識別子として除外されています。「予約語は50語」と数えるとき、この3つは含まれません。

goto と const はJava に機能がないのに予約語です。他言語から来た人がうっかり名前に使わないよう、押さえてあります。「使われていないから識別子に使える」という選択肢は誤りです。

予約語ではないので、名前に使えるもの

var yield record sealed permits は文脈依存キーワードです。決まった位置に書いたときだけキーワードとして働き、それ以外では普通の識別子として扱われます。

変数名に使える頻出
int var     = 1;   // OK
int yield   = 2;   // OK
int record  = 3;   // OK
int sealed  = 4;   // OK
int permits = 5;   // OK

これらを「新しい予約語だから識別子に使えない」とする選択肢は誤りです。互換性を壊さないために、あえて予約語にしていません。
ただし var だけはクラス名とインタフェース名には使えません。詳しくは次の 05・06、第3章 09、第4章 10、第5章 11 で扱います。

命名規約は文法ではない

対象慣習例
クラス・インタフェース先頭大文字のキャメルケースStringBuilder
メソッド・変数先頭小文字のキャメルケースtoUpperCase
定数すべて大文字＋アンダースコアMAX_VALUE
パッケージすべて小文字java.util

これらは規約であって文法ではありません。守らなくてもコンパイルエラーにはなりません。「クラス名が小文字だからエラー」「定数が小文字だからエラー」という選択肢は誤りです。
