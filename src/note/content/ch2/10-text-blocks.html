テキストブロックとエスケープシーケンス

SE 11 Silver には存在しなかった項目です。11 の教材では一切カバーされていないので、ここは新規に固める必要があります。

""" で囲むと、複数行の文字列をそのまま書けます（Java 15〜）。ただし、書いた見た目がそのまま文字列になるわけではありません。コンパイラが次の順番で手を入れます。

順コンパイラがすること結果
1行ごとに分け、全行に共通する字下げを取り除く一番浅い行が左端に来る
2各行の行末の空白を取り除く目に見えない空白は残らない
3\n \t \s などのエスケープシーケンスを1文字に変えるここで初めて改行・タブ・空白になる

エスケープは最後、というのが大事です。1 と 2 の時点では \n も \s もただの2文字なので、\n を書いても行は増えず字下げの計算に影響しません。\s は行末の空白として消されずに残ります。

図の読み方

取り除かれる空白 文字列に残る空白 ↵ 文字列に入る改行（\n 1文字） \t エスケープシーケンス 字下げの基準。ここより左は消える

ソースの上の数字は、左端から何文字目か（0 から数える）の目盛りです。「できる文字列」の箱の数がそのまま length()、箱の下の数字は charAt で使う位置です。

基本形 ── 開始の """ の直後の改行は入らない

ソース
01234567890123
String s = """
Hello↵
World""";
基準は 4 文字目（赤い線）。閉じる """ は最後の行と同じ行にある
できる文字列 ── 箱1つが1文字
H0e1l2l3o4\n5W6o7r8l9d10length() = 11
System.out.println(s); の表示 ── 2 行
  1. Hello
  2. World

中身は Hello の行と World の行の2行です。改行（↵）が入るのは Hello の行末だけで、開始の """ の直後の改行は文字列に入りません。閉じる """ が World と同じ行にあるので、末尾にも改行は付きません。5 + 1 + 5 = 11 文字です。

ルール1 ── 開始の """ の後は改行が必須

同じ行に文字を書けないNG
String s = """Hello
    """;
// error: illegal text block open delimiter sequence, missing line terminator

閉じる """ は中身と同じ行に置けます。改行が必須なのは開始側だけです。

ルール2 ── 字下げの基準は「一番浅い行」

ソース
01234567890123
String s = """
Hello↵
World↵
""";
基準は 6 文字目（赤い線）。閉じる """ は独立した行にある
できる文字列 ── 箱1つが1文字
01H2e3l4l5o6\n7W8o9r10l11d12\n13length() = 14
System.out.println(s); の表示 ── 3 行
  1. Hello
  2. World
  3. （空行）

基準を決めるのは、中身のある行と閉じる """ の行のうち、一番浅いものです。この例では World の行（6文字）が一番浅いので、どの行も左から6文字が消えます。閉じる """ の行は8文字なので基準になりません。Hello の行は8文字字下げしていたので、差の2文字が空白として残ります。

閉じる """ を左に出すと、字下げが残る

ソース
01234567890123
String s = """
Hello↵
""";
基準は 0 文字目（赤い線）。閉じる """ は独立した行にある
できる文字列 ── 箱1つが1文字
0123H4e5l6l7o8\n9length() = 10
System.out.println(s); の表示 ── 2 行
  1. Hello
  2. （空行）

閉じる """ が0文字目にあるので基準が0になり、Hello の前の4文字の空白がすべて残ります。

閉じる """ を右に下げても、中身は削られない

ソース
01234567890123
String s = """
Hello↵
""";
基準は 4 文字目（赤い線）。閉じる """ は独立した行にある
できる文字列 ── 箱1つが1文字
H0e1l2l3o4\n5length() = 6
System.out.println(s); の表示 ── 2 行
  1. Hello
  2. （空行）

閉じる """ は、中身より左にあるときだけ基準を動かします。中身より右に下げても、一番浅い Hello の行（4文字）が基準なので結果は変わりません。

空白だけの行は、基準に数えない

ソース
01234567890123
String s = """
A↵
↵
B""";
基準は 4 文字目（赤い線）。閉じる """ は最後の行と同じ行にある
できる文字列 ── 箱1つが1文字
A0\n1\n2B3length() = 4
System.out.println(s); の表示 ── 3 行
  1. A
  2. （空行）
  3. B

真ん中の行は空白2文字だけの行です。こうした行は基準の計算に入らず（入れば基準が2になってしまう）、中身は空になって改行1文字だけが残ります。

ルール3 ── 末尾の改行は、閉じる """ の場所で決まる

ソース
01234567890123
String s = """
Hello↵
""";
基準は 4 文字目（赤い線）。閉じる """ は独立した行にある
できる文字列 ── 箱1つが1文字
H0e1l2l3o4\n5length() = 6
System.out.println(s); の表示 ── 2 行
  1. Hello
  2. （空行）

閉じる """ を独立した行に書くと、Hello の行末の改行が入り "Hello\n"（6文字）になります。基本形のように中身と同じ行に書けば、改行は付きません。

末尾に改行がある文字列を println すると、println 自身の改行と合わせて最後に空行が1つ見えます。「何行表示されるか」は、文字列の中の \n の数 ＋ 1 で数えます。

ルール4 ── 行末の空白は消える。残したいときは \s

ソース
01234567890123
String s = """
A ↵
B \s↵
""";
基準は 4 文字目（赤い線）。閉じる """ は独立した行にある
できる文字列 ── 箱1つが1文字
A0\n1B2345\n6length() = 7
System.out.println(s); の表示 ── 3 行
  1. A
  2. B
  3. （空行）

A の後ろの空白3文字は行末の空白なので消えます。B の行は末尾が \s（空白ではなく2文字の記号）なので、その手前の空白2文字は行末の空白ではなくなり、残ります。最後に \s が空白1文字になり、B の後ろには空白が3文字並びます。

ルール5 ── 行末の \ で、改行を消す

ソース
01234567890123
String s = """
Hello \
World""";
基準は 4 文字目（赤い線）。閉じる """ は最後の行と同じ行にある
できる文字列 ── 箱1つが1文字
H0e1l2l3o45W6o7r8l9d10length() = 11
System.out.println(s); の表示 ── 1 行
  1. Hello World

行末の \ は「ここで改行しない」という意味で、次の行とつながります。\ の手前の空白は行末の空白ではないので残ります。World の行の字下げは、ルール2 ですでに消えているので入りません。

エスケープシーケンス ── 2文字で書いて、1文字になる

\ で始まる書き方は、普通の文字列リテラル（"..."）でもテキストブロックでも使えます。ソースでは2文字ですが、文字列の中では1文字で、length() もそう数えます。

書き方文字長さ要点
\n改行1表示では次の行に移る
\tタブ1表示では次のタブ位置（多くの環境で8文字ごと）まで空くが、文字としては1つ
\""1"..." の中に " を書くとき
\''1char c = '\''; のとき
\\\1バックスラッシュそのもの
\s空白1Java 15〜。行末の空白を残すのに使う
\＋改行（なし）0テキストブロックだけ。改行を消して次の行とつなぐ

\t はタブ1文字

ソース
String s = "a\tb";
できる文字列 ── 箱1つが1文字
a0\t1b2length() = 3
System.out.println(s); の表示 ── 1 行
  1. a→b

\n で表示が2行になる

ソース
String s = "a\nb";
できる文字列 ── 箱1つが1文字
a0\n1b2length() = 3
System.out.println(s); の表示 ── 2 行
  1. a
  2. b

\\n は「\ と n」の2文字で、改行にならない

ソース
String s = "a\\nb";
できる文字列 ── 箱1つが1文字
a0\1n2b3length() = 4
System.out.println(s); の表示 ── 1 行
  1. a\nb

Windows のパスは引っかけになります。"C:\\temp" は C:\temp（7文字）ですが、\ を1つしか書かないと \t がタブになり、C:＋タブ＋emp の6文字になります。コンパイルエラーにならないので気づきにくいところです。

正しい書き方 ── バックスラッシュは2つ

ソース
String s = "C:\\temp";
できる文字列 ── 箱1つが1文字
C0:1\2t3e4m5p6length() = 7
System.out.println(s); の表示 ── 1 行
  1. C:\temp

1つしか書かないと、タブになる

ソース
String s = "C:\temp";
できる文字列 ── 箱1つが1文字
C0:1\t2e3m4p5length() = 6
System.out.println(s); の表示 ── 1 行
  1. C:→emp
決められていない組み合わせはコンパイルエラーNG
String a = "\q";          // error: illegal escape character
String b = "C:\users";    // error: illegal unicode escape  ← \u は Unicode の書き方として読まれる
char   c = '\t';          // OK。char にも使える（1文字）

テキストブロックの中の \n と \t

ソース
01234567890123
String s = """
A\tB↵
C\nD↵
""";
基準は 4 文字目（赤い線）。閉じる """ は独立した行にある
できる文字列 ── 箱1つが1文字
A0\t1B2\n3C4\n5D6\n7length() = 8
System.out.println(s); の表示 ── 4 行
  1. A→B
  2. C
  3. D
  4. （空行）

ソースの中身は2行ですが、\n は3番目の処理で改行になるので、行が1つ増えます。改行は、行末の ↵ が2つと \n が1つで合計3つ。println の表示は 3 ＋ 1 ＝ 4 行（最後は空行）です。\t は表示では広く空きますが、文字としては1つです。

クォートの扱い

ソース
01234567890123
String s = """
say "Hi"↵
\"""↵
""";
基準は 4 文字目（赤い線）。閉じる """ は独立した行にある
できる文字列 ── 箱1つが1文字
s0a1y23"4H5i6"7\n8"9"10"11\n12length() = 13
System.out.println(s); の表示 ── 3 行
  1. say "Hi"
  2. """
  3. （空行）

テキストブロックの中では、" を1つや2つ書くだけならエスケープは要りません。""" を3つ続けて書くと閉じる記号と区別できないので、\""" のように1つ目をエスケープします。

行数と文字数を数える手順

すること
1中身のある行と、閉じる """ だけの行のうち、一番浅い字下げを探す（空白だけの行は除く）。その左を全行で消す
2各行の行末の空白を消す（\s や \ の手前の空白は残る）
3中身の行の終わりごとに改行1文字。ただし最後の行の後ろに付くのは、閉じる """ が独立した行のときだけ。行末が \ なら付かない
4\n \t \s \" \\ を1文字として数える
5println の表示行数は、文字列の中の改行の数 ＋ 1
