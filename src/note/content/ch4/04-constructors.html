04

コンストラクタ

規則内容
名前クラス名と完全一致（大文字小文字も）
戻り値型書かない。void も書けない
呼び出しnew のときだけ。自分で呼べない
アクセス修飾子4種類すべて可。private にすると外部から new できない
継承されない
戻り値型を書いた瞬間にメソッドになる最頻出
class B {
    void B() { System.out.println("これはメソッド"); }    // コンストラクタではない
}

new B();          // 引数なしコンストラクタが呼ばれる（デフォルト）
new B().B();      // メソッドとして呼べてしまう

void B() はコンストラクタではなく、たまたまクラス名と同じ名前のメソッドです。コンパイルは通ります。
この場合クラスには明示的なコンストラクタが1つも無いのでデフォルトコンストラクタが自動生成され、new B() は成功します。「コンパイルエラー」を選ばせる引っかけです。

デフォルトコンストラクタ

1つでも定義すると自動生成されない最頻出
class A {
    A(int x) { }          // 引数ありを1つ定義した
}

new A(5);                 // OK
new A();                  // コンパイルエラー
                          // constructor A in class A cannot be applied to given types;
                          //   required: int

デフォルトコンストラクタ（引数なし・中身空）は、コンストラクタを1つも書かなかったときだけコンパイラが用意します。1つでも自分で書けば、自動生成は行われません。
引数なしでも使いたければ、A() { } を自分で書き足す必要があります。
