this と this()

this ── 自分自身への参照

同名の変数を区別する頻出
class Car {
    String name;
    Car(String name) {
        name = name;            // 何も起きない。引数に引数を代入しているだけ
        this.name = name;       // 正しい。左がフィールド、右が引数
    }
}

ローカル変数（引数を含む）とフィールドが同名のとき、近い方＝ローカル変数が優先されます（シャドーイング）。フィールドを指したいときは this. が必須です。
name = name; はコンパイルエラーにならず、フィールドは既定値のままになります。出力を問う問題で null や 0 が正解になるパターン。

this() ── 別のコンストラクタを呼ぶ

初期化処理をまとめるOK
class Car {
    String name;
    int year;
    Car() { this("無名", 2020); }        // 別のコンストラクタへ委譲
    Car(String name, int year) {
        this.name = name;
        this.year = year;
    }
}
3つの制約NG
Car() {
    System.out.println("x");
    this("A", 2020);          // エラー: call to this must be first statement
}

Car(int y) { this(y); }       // エラー: 自分自身は呼べない（再帰的呼び出し）

void m() { this(); }          // エラー: コンストラクタ以外からは呼べない

this() はコンストラクタの最初の1文でなければなりません。第5章で扱う super() も同じ制約なので、this() と super() は同時に書けません（どちらも先頭を要求するため）。
