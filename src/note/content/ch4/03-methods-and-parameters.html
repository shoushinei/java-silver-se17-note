メソッドと引数の渡し方

Java の引数の渡し方は値渡しだけです。参照型でも例外はありません。

基本データ型 ── 呼び出し元は変わらないOK
static void change(int x) { x = 100; }

int a = 1;
change(a);
System.out.println(a);       // 1（変わらない）
参照型 ── 中身は変わるが、差し替えは効かない最重要
static void modify(int[] arr) { arr[0] = 100; }     // 中身を書き換え
static void replace(int[] arr) { arr = new int[]{9}; }  // 矢印を差し替え

int[] x = {1, 2};
modify(x);
System.out.println(x[0]);    // 100 ← 変わる

int[] y = {1, 2};
replace(y);
System.out.println(y[0]);    // 1 ← 変わらない

渡されるのは矢印のコピーです。コピーした矢印でも指す先は同じなので、中身の書き換えは呼び出し元に伝わります。
一方、メソッド内で arr = ... と代入するのはコピーした矢印の向きを変えているだけで、元の矢印には何の影響もありません。この対比が必ず出ます。

可変長引数

実体は配列要注意
static void m(String... s) { System.out.println(s.length); }

m();                 // 0（null ではなく長さ0の配列）
m("a", "b");         // 2
m(new String[]{"a"});// 1（配列をそのまま渡せる）
2つの制約NG
void m(String... s, int x) { }      // エラー: 可変長引数は最後だけ
void m(int... a, String... b) { }   // エラー: 2つは書けない
void m(int x, String... s) { }      // OK

戻り値と return の規則

書き方結果理由
int m(){ x * 2; }×式だけでは文にならない（not a statement）。return x * 2; と書く
String m(boolean f){ if (f) return "y"; }×f が false の経路で値を返していない（missing return statement）
int m(boolean f){ if (f) return 1; else return 2; }○すべての経路で return している
int m(){ while (true) { } }○メソッドの終わりに到達しないので return は不要
int m(){ throw new RuntimeException(); }○同上。例外で抜ける
int m(){ return 1; System.out.println(); }×return の後ろは到達不能（unreachable statement）
void m(){ return; }○値なしの return はメソッドを終えるだけ。コンストラクタでも書ける
void m(){ return 1; }×void は値を返せない（unexpected return value）

戻り値は「戻り値型の変数に代入できるか」で判定します（第2章 03 型変換と同じ規則）。

戻り値の型変換要注意
long   a() { return 10; }      // OK。int → long は拡大変換
double b() { return 10; }      // OK。10.0 が返る
Object c() { return 1; }       // OK。Integer にボクシングしてから Object へ
byte   d() { return 10; }      // OK。範囲内の定数なら縮小できる
char   e() { return 65; }      // OK。'A'
int    f() { return 1.0; }     // コンパイルエラー: double → int は縮小
byte   g() { return 200; }     // コンパイルエラー: byte の範囲外
Integer h() { return 1L; }     // コンパイルエラー: long は Integer にならない
int    i() { return null; }    // コンパイルエラー: 基本データ型に null は入らない

「long のメソッドで return 10; は int だからエラー」は誤りです。return は代入と同じで、long x = 10; が通るなら return 10; も通ります。
メソッドが値を返すかどうかは、メソッドの最後まで流れ着く経路があるかで決まります。while (true) や throw で終わるなら return は要りません。
