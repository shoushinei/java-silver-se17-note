07

抽象クラス

実装を持てる「未完成のクラス」基本
abstract class Animal {
    String name;                          // フィールドを持てる
    Animal(String n){ this.name = n; }    // コンストラクタを持てる
    void breathe(){ }                     // 実装のあるメソッドも書ける
    abstract void cry();                  // 本体が無い。子に実装を強制する
}
規則内容
インスタンス化不可（A is abstract; cannot be instantiated）
コンストラクタ持てる。子の super() から呼ばれる
abstract メソッド0個でもよい
abstract メソッドに本体不可（abstract methods cannot have a body）
abstract + final不可（illegal combination of modifiers）
abstract + private不可（子から実装できないため）
abstract + static不可

abstract メソッドを1つも持たない abstract クラスは合法です。「インスタンス化させたくない」という意図だけで付けられます。
逆に、abstract メソッドを持つクラスは abstract でなければなりません。

継承する側の義務頻出
abstract class A { abstract void m(); }

class B extends A { }            // error: B is not abstract and does not
                                 //        override abstract method m() in A

abstract class C extends A { }   // OK。abstract なら実装を先送りできる

第4章 節01の「main は static なのでインスタンス不要」と組み合わせると、abstract クラスでも main を書いて java コマンドで起動できます。「abstract だから実行できない」は誤りです。

「インスタンス化できない」の正確な意味

禁止されているのは new 抽象クラス名() と直接書くことだけです。

型として使うのは自由最頻出
new AbstractSample();                       // error: is abstract; cannot be instantiated
new ConcreteSample();                       // OK ── 子は完成品
AbstractSample s = new ConcreteSample();    // OK ── 変数の型にするのは自由

abstract メソッドは本体を持たないので、実体を作っても実行すべきコードが存在しません。だから「未完成のものは実体化させない」。
子クラスが本体を書けば完成品になるので new できます。
abstract が禁じているのは実体を作ることであって型として使うことではありません。むしろ型として使うためにある構文です。

親の中から呼んだ抽象メソッドが子に飛ぶ頻出
abstract class AbstractSample {
    public void sample(){
        System.out.println("A");
        test();                          // 実装は子にある
        System.out.println("C");
    }
    protected abstract void test();
}
class ConcreteSample extends AbstractSample {
    protected void test(){ System.out.println("B"); }
}

AbstractSample s = new ConcreteSample();
s.sample();          // A B C

AbstractSample を書いた時点では test() の中身は決まっていません。決めるのは子クラス。
これはテンプレートメソッドと呼ばれる設計で、処理の骨組みを親が決め、具体的な一部だけを子に埋めさせる形です。abstract メソッドの本来の用途がこれです。
「test() は呼ばれない」と考えて A C を選ばせる選択肢が出ます。
