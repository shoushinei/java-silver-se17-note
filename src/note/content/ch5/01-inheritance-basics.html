継承の基本

extends は1つだけ基本
class Animal { }
class Dog extends Animal { }          // OK
class Cat extends Animal, Dog { }     // コンパイルエラー。クラスの多重継承は不可
規則内容
クラスの継承単一継承のみ。extends は1つ
インタフェースの実装複数可。implements A, B, C
インタフェース同士の継承複数可。interface C extends A, B
暗黙の親何も書かなければ java.lang.Object を継承
継承されないものコンストラクタ、private メンバ

クラスの多重継承が禁止されているのは同じ名前のフィールドやメソッドを2つ受け継ぐと、どちらか決められないからです（菱形継承問題）。
インタフェースが複数実装できるのは、元々実装を持たなかったためです。default メソッドで実装が入った SE 8 以降は、衝突したら書き手に解決させる方式にして回避しています（節10）。

継承しても使えるとは限りません。第1章 節07の到達範囲がそのまま効き、別パッケージのサブクラスからは修飾子なしのメンバが見えません。存在することと名前で呼べることは別レイヤーです。
