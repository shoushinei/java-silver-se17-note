比較演算子と等価性

boolean に大小比較は使えないNG
boolean a = true, b = false;
a > b;         // コンパイルエラー
a == b;        // OK ← 等価比較だけは可能

== は「参照」、equals は「中身」

基本データ型と参照型で意味が変わる最重要
int a = 5, b = 5;
a == b;                              // true  ← 値そのものを比較

String s = "abc";
String t = new String("abc");
s == t;                              // false ← 参照を比較
s.equals(t);                         // true

Integer x = 127, y = 127;
Integer p = 128, q = 128;
x == y;                              // true  ← キャッシュ範囲
p == q;                              // false

第2章の内容がそのまま出ます。Integer は -128〜127 だけキャッシュされる、文字列リテラルは定数プールで共有されるの2点を思い出してください。

片方が基本データ型ならアンボクシングされる要注意
Integer p = 128;
int q = 128;
System.out.println(p == q);    // true ← p がアンボクシングされ値比較になる

Integer a = 128, b = 128;
System.out.println(a == b);          // false ← 両方参照型
System.out.println(a.equals(b));     // true

instanceof

null は常に false要注意
String s = null;
System.out.println(s instanceof String);   // false ← 例外にはならない

Object o = "abc";
System.out.println(o instanceof String);   // true
