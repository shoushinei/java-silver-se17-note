算術演算子とインクリメント

整数除算と剰余

切り捨ての向きに注意要注意
System.out.println(5 / 2);     // 2   ← 四捨五入ではなく切り捨て
System.out.println(-5 / 2);    // -2  ← ゼロ方向に切り捨て（-3 ではない）
System.out.println(5 % 2);     // 1
System.out.println(-5 % 2);    // -1  ← 符号は左オペランドに従う
System.out.println(5 % -2);    // 1
System.out.println(5.0 % 2);   // 1.0 ← 小数でも剰余は使える
整数の0除算だけが例外実行時
System.out.println(1 / 0);      // ArithmeticException
System.out.println(1 % 0);      // ArithmeticException
System.out.println(1.0 / 0);    // Infinity ← 例外にならない
System.out.println(0.0 / 0);    // NaN

前置と後置 ── この章の最重要トピック

後置 i++ は「今の値を返してから増やす」。前置 ++i は「増やしてから返す」。増えるタイミングは同じで、式の値として何を返すかが違います。

返す値が違う最重要
int i = 5;
System.out.println(i++);   // 5 を表示してから i は 6 になる
System.out.println(i);     // 6

int j = 5;
System.out.println(++j);   // 6 になってから 6 を表示
System.out.println(j);     // 6
自分に代入すると増えない最重要
int i = 1;
i = i++;
System.out.println(i);     // 1 ← 増えない！

理由は分解すると分かります。i++ はまず今の値 1 を退避し、i を 2 にします。しかしその直後に i = 退避した1 という代入が走るので、上書きされて 1 に戻ります。

第6章の return val; と同じ構造です。値を退避してから後処理をするため、後処理の結果が失われます。

複合した式は1つずつ書き出す要注意
int i = 1;
System.out.println(i++ + ++i);   // 4

// ① i++     → 値 1 を返す。i は 2
// ② ++i     → i を 3 にして 3 を返す
// ③ 1 + 3   → 4

複合した式は左から順に、1つずつ値と変数の状態を紙に書くのが最も確実です。暗算しようとすると必ず間違えます。

リテラルには使えないNG
System.out.println(5++);     // コンパイルエラー: 変数でないと増やせない
final int x = 1;
x++;                          // コンパイルエラー: final は変更不可
