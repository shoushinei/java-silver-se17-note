三項演算子

基本形形
int max = (a > b) ? a : b;

// 条件 ? 真のときの値 : 偽のときの値

条件部分は必ず boolean でなければいけません。そして選ばれなかった側は評価されません（短絡評価と同じ）。

選ばれない側は実行されない要注意
int i = 0, j = 0;
int r = true ? i++ : j++;
System.out.println(i + " " + j);   // 1 0 ← j++ は実行されない

結果の型は数値昇格される

両辺の型が揃えられる最重要
System.out.println(true ? 1 : 2.0);      // 1.0 ← int と double なので double に昇格
System.out.println(true ? 'a' : 98);     // a   ← 定数が char の範囲内なら char
System.out.println(true ? 1 : 'a');      // 1

true ? 1 : 2.0 が 1 ではなく 1.0 になるのが引っかけです。実際に選ばれなかった側の型も、結果の型に影響します。

ネストは右から結合する

右結合要注意
String s = a ? "A" : b ? "B" : "C";

// 実際はこう解釈される
String s = a ? "A" : (b ? "B" : "C");
文は書けないNG
int x = (a > b) ? System.out.println("A") : 0;   // エラー: void は値ではない
(a > b) ? doSomething() : doOther();              // エラー: 式文として不正

三項演算子は値を作るための「式」です。結果を代入するか、値として使わなければいけません。
