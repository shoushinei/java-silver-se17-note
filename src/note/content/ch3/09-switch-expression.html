09

switch 式

Java 14 で正式導入された構文で、SE 11 Silver には存在しませんでした。11 の教材では一切カバーされていないので、この節が第3章で最も重要です。

アロー構文 ── フォールスルーしない

break が不要になる形
switch (x) {
    case 1 -> System.out.println("A");
    case 2 -> System.out.println("B");
    default -> System.out.println("D");
}
// x が 2 なら "B" だけ。下へ流れない

アロー構文では break を書きません。一致した1つだけが実行されます。case 1 -> System.out.println("A"); break; のようにアローの後ろへ続けて書くと、コンパイルエラーになります（switch 文で右側を { } のブロックにしたときは、その中に書くこともできますが、必要ありません）。

複数のラベルをまとめられるOK
switch (x) {
    case 1, 2, 3 -> System.out.println("小");
    case 4, 5    -> System.out.println("大");
    default      -> System.out.println("その他");
}

値を返す ── ここが「式」たるゆえん

代入できる最重要
String result = switch (x) {
    case 1, 2 -> "小";
    case 3    -> "中";
    default   -> "大";
};                              // ← セミコロンが必要！

switch 式は値を作る「式」なので、閉じ波括弧の後にセミコロンが必要です。switch 文には要りません。選択肢でここを削られると見落とします。

yield ── ブロックから値を返す

複数行書くときは { } と yield最重要
int result = switch (x) {
    case 1 -> 10;                 // 1行なら式をそのまま書く
    case 2 -> {
        System.out.println("処理");
        yield 20;                 // ← ブロックからは yield で返す
    }
    default -> 0;
};

yield は予約語ではなく文脈依存キーワードなので、変数名にも使えます（var と同じ扱い）。「予約語だから識別子に使えない」という選択肢は誤りです。

yield は switch 式だけを抜け、return はメソッドごと抜けます。役割が違うので流用できず、専用のキーワードが用意されました。

yield の後もメソッドは続く要注意
int m(int x) {
    int r = switch (x) {
        case 1 -> { yield 10; }    // switch 式を抜けて r に 10 が入る
        default -> 0;
    };
    System.out.println("続き");     // ← 実行される
    return r;
}
return は使えないNG
int result = switch (x) {
    case 1 -> { return 10; }      // コンパイルエラー
    default -> 0;
};

各 case が取れる3つの形

式・ブロック・例外OK
int result = switch (x) {
    case 1 -> 10;                            // ① 式だけ → そのまま値になる
    case 2 -> { yield 20; }                  // ② ブロック → yield で返す
    case 3 -> throw new RuntimeException();  // ③ 例外 → 値を返さなくてよい
    default -> 0;
};

網羅性 ── すべての場合をカバーする必要がある

default がないとエラー最重要
int x = 5;
String s = switch (x) {
    case 1 -> "A";
    case 2 -> "B";
};                    // コンパイルエラー: すべての値をカバーしていない

値を返す switch 式は、あらゆる入力に対して値を返せなければいけません。int や String では現実的に全部を列挙できないので、default が必須になります。

enum を全部書けば default 不要要注意
enum Color { RED, GREEN, BLUE }

String s = switch (color) {
    case RED   -> "赤";
    case GREEN -> "緑";
    case BLUE  -> "青";
};                    // OK。全定数を網羅しているので default は省略できる

ただし、アロー構文を使っていても値を返さない switch 文なら、網羅性は要求されません（default を省略できます）。default が必須かどうかを分けるのは、アローかコロンかではなく、値を返す switch 式かどうかです。

コロン構文とアロー構文は混在できない

どちらかに統一するNG
switch (x) {
    case 1 -> System.out.println("A");
    case 2: System.out.println("B"); break;   // コンパイルエラー: 混在は不可
}

従来のコロン構文でも yield を使って値を返せます（この形も出題されます）。

コロン構文 + yieldOK
int result = switch (x) {
    case 1: yield 10;
    case 2: yield 20;
    default: yield 0;
};

コロン構文の switch 式はフォールスルーする

yield に来るまで下へ流れる最重要
int n = 2;
int r = switch (n) {
    case 1:
        System.out.print("one ");
    case 2:
        System.out.print("two ");      // ← n が 2 なのでここから入る
    case 3:
        yield 30;                       // ← 流れてきて、ここで値を返して抜ける
    default:
        yield 0;
};
System.out.println(r);
// 出力: two 30

フォールスルーするかどうかは「文か式か」ではなく、「コロンかアローか」で決まります。コロン構文の case は、switch 式の中でも次の case へ流れ込み、yield に来たところで値を返して抜けます。「switch 式はフォールスルーしない」と覚えていると外します。
流れた先の最後まで yield が無いと switch expression completes without providing a value というコンパイルエラーです。また、switch 式からは break で抜けられません（attempt to break out of a switch expression）。

まとめ表

switch の規則は、ラベルの書き方（コロンかアローか）で決まるものと、文か式か（値を返すかどうか）で決まるものの2種類に分かれます。混ぜて覚えないのがコツです。

ラベルの書き方で決まるコロン（case 1:）アロー（case 1 ->）
フォールスルーする（switch 文でも switch 式でも）しない
複数ラベルcase 1: case 2: または case 1, 2:case 1, 2 ->
混在1つの switch の中ではどちらかに統一する
文か式かで決まるswitch 文switch 式
値を返す不可可能
抜け方break（アローなら不要）yield（アローの右が式なら、その値がそのまま返る）。break は書けない
末尾のセミコロン不要必要（式を含む文の終わり）
default省略可必須（enum の定数を全部書いた場合を除く）
null を渡すとどちらも NullPointerException。仕組みは 08 の「switch に null を渡すと落ちる」
