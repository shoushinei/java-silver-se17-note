演算子の優先順位

丸暗記は不要ですが、順位が問われる組み合わせは決まっています。上ほど先に評価されます。

順位演算子結合
1後置 i++ i--左→右
2前置 ++i --i ! ~ 単項 + -右→左
3キャスト (int)右→左
4* / %左→右
5+ -左→右
6< > <= >= instanceof左→右
7== !=左→右
8〜10& → ^ → |左→右
11&&左→右
12||左→右
13? :右→左
14= += -= など右→左

覚えるべきは3点です。算術 → 比較 → 論理 → 三項 → 代入の順。&& は || より先。そして代入と三項演算子だけが右から左に結合します。

代入は右から左OK
int a, b, c;
a = b = c = 5;      // c=5 → b=5 → a=5 の順。全部 5 になる
