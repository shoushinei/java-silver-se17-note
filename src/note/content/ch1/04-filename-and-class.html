ファイル名とクラス宣言の規則

public クラスはファイル名と一致必須NG
// ファイル名: Hello.java
public class Main { }      // コンパイルエラー
                           // class Main is public, should be declared in a file named Main.java

1ファイルに複数クラス

public でなければ何個でも書けるOK
// ファイル名: Main.java
public class Main {                       // public は1つだけ、ファイル名と一致
    public static void main(String[] a) {
        new Helper().hello();
    }
}
class Helper {                            // public を付けなければ同居できる
    void hello() { System.out.println("hi"); }
}
class Another { }                          // 何個でも可

// javac Main.java → Main.class, Helper.class, Another.class の3つが生成される

ルールは2つだけです。public なトップレベル型は1ファイルに1つまで、そしてその名前がファイル名と一致していること。public を付けないクラスは、いくつ書いても、名前が何でも構いません。
.class ファイルはクラスごとに1つ作られます。

public クラスが1つもない場合要注意
// ファイル名: Foo.java
class Main {
    public static void main(String[] a) { System.out.println("ok"); }
}

// javac Foo.java   → Main.class が生成される
// java Main        → 実行できる（java に渡すのはクラス名。ファイル名は無関係）

public がなければファイル名は自由です。実行時に指定するのはクラス名なので、ファイル名が何であっても java Main で起動します。
