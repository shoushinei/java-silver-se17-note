コマンドライン引数

args には、クラス名より後ろに書いた文字列が順に入ります。

添字は 0 から要注意
public class Main {
    public static void main(String[] args) {
        System.out.println(args.length);
        System.out.println(args[0]);
    }
}

// java Main red green blue
// 出力: 3
//       red

C 言語と違い、args[0] はクラス名ではなく最初の引数です。args.length にクラス名は含まれません。ここを間違えさせる問題が必ず出ます。

引数を渡さなかった場合

null ではなく空の配列実行時
// java Main   （引数なし）

System.out.println(args == null);     // false
System.out.println(args.length);      // 0
System.out.println(args[0]);          // ArrayIndexOutOfBoundsException

args が null になることはありません。引数がなければ長さ 0 の配列が渡されます。したがって args.length は安全に呼べますが、args[0] は例外になります。

中身はすべて String

数値も文字列として届く実行時
// java Main 10 20

int a = args[0];                          // コンパイルエラー: String は int に代入できない
int b = Integer.parseInt(args[0]);        // 正しい変換
System.out.println(args[0] + args[1]);    // "1020"（文字列連結）

// java Main abc
Integer.parseInt(args[0]);                // NumberFormatException

引数はすべて String です。+ は連結になり、数値として使うには Integer.parseInt が必要。変換に失敗すると NumberFormatException（第6章・非検査例外）になります。

引用符とエスケープ ── 引数の数え方

規則はこの3行がすべてです。
① 基本は空白で区切る
② ただし " と " に挟まれた区間の空白は無視する
③ \" は引用符ではなく " という文字

大事なのは、" は引数の区切りではないということです。空白を無効化するスイッチでしかありません。

数え方は3ステップ

この順に潰すと迷わない最重要
java Sample a \" a\" "a "b c

① \" を「" という文字」に確定させる（以後、区切り判定に関与しない）

   a ● a● "a "b c                     ● = " という文字

② " 〜 " の間の空白を無効化し、" 自体を消す

   a ● a● a_b c                       _ = 死んだ空白

③ 残った（生きている）空白で切る

   a / ● / a● / a_b / c               → 5個

結果は args[0]=a、args[1]="、args[2]=a"、args[3]=a b、args[4]=c です。

引っかかるのはここだけ

閉じた後に空白があるか頻出
"a "b     →  引用符を消すと  a_b   →  1個（args[0] は "a b"）
"a " b    →  引用符を消すと  a_ b  →  2個（"a " と "b"）

"a "b が1個になるのは、引用を閉じた直後の b が空白を挟まずに続いているからです。
引用符を「引数の袋」だと思うと2個に数えてしまいます。袋ではなく、空白を殺すマーカー。マーカーを消してから、生き残った空白で切る。

なお、これは Java の文法ではなく OS 側のコマンドライン解釈です。日本語環境の教材では \ が ¥ と表示されるので、¥" とあれば \" のことです。
