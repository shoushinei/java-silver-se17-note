try-catch-finally の構文

基本形形
try {
    // 例外が発生するかもしれない処理
} catch (ExceptionType e) {
    // 例外が起きたときの処理
} finally {
    // 起きても起きなくても必ず実行
}

構文ルール

  • try 単体は不可。catch か finally が最低1つ必要
  • try { } finally { }（catch なし）は合法
  • catch は複数書ける。finally は1つだけ、かつ最後
  • 波括弧は省略できない（if 文と違う）
try 単体 / 順序が逆NG
try { }                              // エラー: catch も finally もない

try { } finally { } catch (Exception e) { }   // エラー: 順序が逆
catch なしは合法OK
try {
    doSomething();
} finally {
    cleanup();
}

スコープの罠

try 内の変数は catch から見えないNG
try {
    int x = 10;
} catch (Exception e) {
    System.out.println(x);   // コンパイルエラー
}

try のブロック内で宣言した変数は、そのブロックを出た時点で消えます。catch や finally でも使いたいなら、try の外で宣言してください。
