オーバーライドと例外の制約

第5章（継承とインタフェース）とまたがる論点で、必ず出ます。

オーバーライドするメソッドは、検査例外を増やせない・広げられない。

親のメソッド前提
class Parent {
    void m() throws IOException { }
}
子クラスでの宣言判定理由
void m() throws FileNotFoundExceptionOKIOException の子なので、より狭い
void m()OK減らすのは自由
void m() throws RuntimeExceptionOK非検査例外は制約の対象外
void m() throws ExceptionNG親より広い
void m() throws SQLExceptionNG無関係な検査例外の追加

オーバーライドの3制約をまとめて確認しておいてください。向きが項目ごとに逆なのが引っかけの温床です。

項目変更できる方向
アクセス修飾子同じか、より広く
戻り値の型同じか、そのサブクラス（共変戻り値）
検査例外同じか、より狭く
