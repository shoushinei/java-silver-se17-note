08

カスタム例外の作成

自分で例外クラスを作るには、Exception か RuntimeException を継承します。

検査例外になるOK
class MyException extends Exception {
    public MyException(String message) {
        super(message);
    }
}
非検査例外になるOK
class MyRuntimeException extends RuntimeException {
    public MyRuntimeException(String message) {
        super(message);
    }
}

どちらを継承したかで、検査か非検査かが決まります。コードの見た目はほとんど同じで extends の後ろだけが違う、という形で出題されます。ここを見落とすと「catch が必要か不要か」の判断を全部間違えます。

第4章とつながります。コンストラクタは継承されないので、MyException(String) は自分で書く必要があります。書かなければ引数なしのデフォルトコンストラクタだけが使え、new MyException("msg") はコンパイルエラーになります。

super(message) を呼んでおくと、getMessage() でその文字列を取り出せます。
