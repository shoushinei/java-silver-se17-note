クラス階層と3つの分類

すべての判断はこの階層から派生します。まずこの形を覚えてください。

クラス階層図
Throwable
├── Error                        ← 非検査。捕まえない
└── Exception                    ← 捕捉の対象
    ├── RuntimeException         ← 非検査
    │   ├── NullPointerException
    │   ├── ArithmeticException
    │   └── ...
    └── IOException など          ← 検査例外
        └── FileNotFoundException

検査例外かどうかの判定は、次の1行がすべてです。

Exception の子孫で、かつ RuntimeException の子孫でないものが「検査例外」。それ以外（Error 系と RuntimeException 系）はすべて「非検査例外」です。

3分類の違い

検査例外非検査例外エラー
代表例IOException
SQLException		NullPointerException
ArithmeticException		OutOfMemoryError
StackOverflowError
原因外部要因（ファイル・通信）プログラムのバグJVM の異常
処理の義務必須任意事実上なし
書かないとコンパイルエラーコンパイルは通る通る

3分類の実質的な違いは 「処理を書かないとコンパイルエラーになるか」だけです。この一点を軸に選択肢を切っていけば、分類問題はほぼ落としません。

検査例外を投げるのに宣言がないNG
void m() {
    throw new IOException();   // コンパイルエラー
}
throws で宣言すれば通るOK
void m() throws IOException {
    throw new IOException();
}
非検査例外は何も要らないOK
void m() {
    throw new RuntimeException();   // 宣言も catch も不要
}
