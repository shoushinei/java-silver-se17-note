throw と throws

throwthrows
書く場所メソッドの中メソッドの宣言部
意味例外を実際に投げる投げる可能性があると宣言
対象インスタンス1つクラス名。カンマで複数可
両方を使った形OK
void m() throws IOException, SQLException {   // 宣言
    throw new IOException();                  // 実行
}

throw に渡せるもの

Throwable でないものは投げられないNG
throw new String("x");   // コンパイルエラー
throw null はコンパイルが通る実行時
throw null;   // コンパイルは通り、実行時に NullPointerException

呼び出す側の義務

検査例外を throws しているメソッドを呼ぶ側は、catch するか、自分も throws する必要があります。

何もせずに呼ぶNG
void caller() {
    m();   // コンパイルエラー: IOException が未処理
}
自分も throws すれば通るOK
void caller() throws IOException, SQLException {
    m();
}

main メソッドも例外ではありません。public static void main(String[] args) throws Exception は合法です。「main に throws は書けない」という選択肢は誤りです。
