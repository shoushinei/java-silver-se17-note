05

multi-catch 句

同じ処理を複数の例外に対して書きたいとき、| で並べられます（Java 7〜）。

基本形OK
try {
} catch (IOException | SQLException e) {
    e.printStackTrace();
}

ルール1 ── 継承関係にある例外は並べられない

親子を並べたNG
catch (IOException | Exception e) { }                // エラー
catch (FileNotFoundException | IOException e) { }    // エラー

親のほうで捕まえられるものを並べるのは冗長なので、文法として禁止されています。

ルール2 ── 変数は暗黙的に final

multi-catch の変数に再代入NG
catch (IOException | SQLException e) {
    e = new IOException();   // エラー: 実質的に final
}

単一の catch なら再代入できますが、multi-catch では禁止です。

ルール3 ── 変数名は最後に1つだけ

変数名が2つNG
catch (IOException e | SQLException e2) { }   // エラー

選択肢では 親子関係があるかどうかが焦点になります。IOException | FileNotFoundException を見て「別の名前だから OK」と判断すると落ちます。02 の親子関係表がここで効きます。
