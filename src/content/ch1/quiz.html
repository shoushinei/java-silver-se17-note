一問一答

答えを声に出してから開いてください。

Q1static public void main(String[] args) は実行できる？

できる。修飾子の順序に決まりはありません。public static でも static public でも同じです。final を足しても動きます。

Q2public static void main(String... args) は？

実行できる。可変長引数の実体は配列なので、シグネチャは String[] と同一になります。String args[] も同様に可。

Q3main に static を付け忘れた。いつエラーになる？

実行時。メソッドとしては文法上正しいのでコンパイルは通ります。java コマンドで起動しようとした瞬間に Main method not found になります。選択肢に「コンパイルエラー」があっても選ばないこと。

Q4java Main red green のとき args[0] は？

"red"。クラス名は含まれません。args.length は 2 です。C 言語と違う点。

Q5引数なしで実行したとき args は null？

null ではなく長さ 0 の配列。args.length は 0 で安全に呼べますが、args[0] は ArrayIndexOutOfBoundsException です。

Q6java Main.class は動く？

動かない。java に渡すのはクラス名です。Main.class は「Main パッケージの class クラス」と解釈されて失敗します。java Main が正しい形。

Q7java Main.java は？

動く（SE 11 以降）。シングルファイルソース起動といい、メモリ上でコンパイルして実行します。.class は生成されません。SE 17 の範囲なので「エラーになる」は誤り。

Q81つの .java ファイルに public クラスは何個書ける？

1個まで。しかもファイル名と一致が必須。public を付けないクラスは何個でも同居できます。.class ファイルはクラスの数だけ生成されます。

Q9package と import の順序は？

package → import → 型宣言。package は1ファイルに最大1つで、コメント以外の何よりも前。逆順はコンパイルエラーです。

Q10import java.util.*; で java.util.concurrent.TimeUnit は使える？

使えない。ワイルドカードはそのパッケージ直下のクラスだけを指し、サブパッケージには及びません。java.util.concurrent は別パッケージです。

Q11java.util.* と java.sql.* を両方インポートして Date を使うと？

コンパイルエラー（ambiguous）。解決策は、片方を単一型インポートする（ワイルドカードより優先される）か、完全修飾名で書くか。ただし import java.util.Date; と import java.sql.Date; の併記も不可です。

Q12static import java.lang.Math.max; は正しい？

誤り。正しくは import static。語順が逆だとコンパイルエラーです。この1点だけを問う問題が出ます。

Q13package com.example; の Main を実行するコマンドは？

java com.example.Main。完全修飾名をドット区切りで渡します。java Main でも java com/example/Main でもありません。クラスパスの起点は -cp で指定します。

Q23java はどうやって2つのモードを切り替えている？

引数が .java で終わっているかどうかだけ。終わっていればソース実行モードでその .java を読み、そうでなければクラス名として .class をクラスパスから探します。

Q24ソース実行モードはバイトコードを経由しない？

経由する。コンパイルは必ず行われ、バイトコードは作られています。違いはそれをファイルに保存しないことだけ。「コンパイルを飛ばしている」は誤解です。

Q25古い .class と書き換えた .java が同居しているとき、java Main.java はどちらを実行する？

.java の方。ソース実行モードは .class の存在を完全に無視します。java Main なら古い .class が実行されるので、同じディレクトリで出力が食い違います。

Q18javac が作る .class の中身は機械語？

機械語ではなくバイトコード。JVM という仮想的なコンピュータ向けの命令です。機種に依存しないので、同じ .class を各 OS の JVM がそれぞれ動かせます。これが Write Once, Run Anywhere の実体。

Q19.class が目の前にあるのに java Main.class が失敗するのはなぜ？

JVM がファイル名ではなくクラス名として解釈するから。ドットはパッケージの区切りにしか見えないので、「Main パッケージの class クラス」を探しにいって ClassNotFoundException になります。

Q20ソースコードが提示され「実行して sample と表示したい」とある。java Sample は正解？

不正解。まだコンパイルしていないので .class が存在せず、Could not find or load main class になります。正解は javac Sample.java → java Sample の2行か、java Sample.java の1行。問題文にソースが載っているかどうかで読み分けます。

Q21javap Sample を実行すると何が起きる？

クラスの構造が表示されるだけで、プログラムは実行されない。javap は逆アセンブラです。jmod はモジュール作成ツールで、これも実行はしません。

Q22java Sample "a "b の args.length は？

1。引用符は引数の区切りではなく空白を無効化するスイッチです。閉じた直後の b は空白を挟んでいないので同じ引数の続きになり、args[0] は a b。"a " b なら2個です。

Q14修飾子を何も書かないとどこまで見える？

同じパッケージまで。パッケージプライベートと呼びます。default というアクセス修飾子は存在しません。書くのは「何も書かない」ことです。

Q15別パッケージのサブクラスは protected メンバに必ずアクセスできる？

できない場合がある。アクセスできるのは this か、自分と同じ型の参照を通したときだけ。スーパークラス型の参照経由（Base x の x.prot）はコンパイルエラーです。

Q16トップレベルのクラスに private は付けられる？

付けられない。public か修飾子なしの2択です。protected も不可。ネストしたクラスなら4種類すべて使えます。

Q17ローカル変数に private は付けられる？

付けられない。スコープはブロックで決まるので、アクセス修飾子に意味がありません。ただし final は付けられます（アクセス修飾子ではないため）。
