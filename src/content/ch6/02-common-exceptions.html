02

名前を覚えるべき例外

出題される例外は限られています。名前と「どんな場面で出るか」をセットで。

非検査（RuntimeException 系）

例外発生する場面
NullPointerExceptionnull に対してメソッド呼び出し・フィールドアクセス。null のアンボクシングも
ArrayIndexOutOfBoundsException配列の範囲外アクセス
StringIndexOutOfBoundsException文字列の範囲外アクセス
IndexOutOfBoundsException上2つの親。ArrayList の範囲外はこれ
ArithmeticException整数の 0 除算。1.0/0 は例外にならず Infinity
ClassCastException不正なキャスト
NumberFormatExceptionInteger.parseInt("abc")。IllegalArgumentException の子
UnsupportedOperationExceptionList.of() に add した場合など

検査例外 / エラー

  • 検査例外 ── Exception / IOException / FileNotFoundException（IOException の子）/ SQLException
  • エラー ── OutOfMemoryError / StackOverflowError / NoClassDefFoundError

親子関係そのものが問われます。とくに FileNotFoundException は IOException の子、NumberFormatException は IllegalArgumentException の子、ArrayIndexOutOfBoundsException は IndexOutOfBoundsException の子。catch の順序問題と multi-catch 問題は、この関係を知らないと解けません。
