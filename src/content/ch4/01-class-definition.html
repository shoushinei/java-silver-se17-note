クラスの定義とインスタンス化

クラスは設計図、インスタンスはそれを元に作られた実体です。設計図をいくら書いてもメモリは使われず、new した瞬間に実体ができます。

クラスに書けるもの基本
class Car {
    String name;                      // フィールド（インスタンス変数）
    static int total;                 // static変数（クラス変数）

    Car(String name) { this.name = name; }   // コンストラクタ

    void run() { }                    // インスタンスメソッド
    static void info() { }            // staticメソッド

    { }                               // インスタンス初期化ブロック
    static { }                        // static初期化ブロック
}

new が行う3つのこと

1行で3段階図
Car c = new Car("A");

  ①  new Car(...)     ヒープ上に実体を作り、フィールドを既定値で埋める
  ②  Car("A")         コンストラクタが走り、初期化される
  ③  c =              できた実体への「参照」を変数 c に入れる

     c ──────→ [ name="A" ]        c は実体そのものではなく、実体を指す矢印

変数が持っているのは実体ではなく参照（矢印）です。第2章の配列と同じ構造で、代入は矢印のコピーになります。== が「同じ実体か」を、equals が「中身が同じか」を判定するのもこのためです。

参照のコピー要注意
Car a = new Car("A");
Car b = a;                    // 矢印をコピー。実体は1つのまま
b.name = "B";
System.out.println(a.name);   // B ← a から見ても変わっている
System.out.println(a == b);   // true（同じ実体）
