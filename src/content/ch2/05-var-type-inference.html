var（ローカル変数型推論）

右辺から型を推論して、宣言を省略できる仕組みです（Java 10〜）。動的型付けではありません。型はコンパイル時に確定します。

基本形OK
var i = 10;                          // int と推論される
var list = new ArrayList<String>();  // ArrayList<String>
var s = "hello";                     // String
型は後から変えられないNG
var i = 10;
i = "hello";     // コンパイルエラー: i は int で確定済み

使えない場所

宣言のパターンNG
var a;                   // エラー: 初期化が必須
var b = null;            // エラー: 型を推論できない
var[] c = {1, 2};        // エラー: 配列型の宣言には使えない
var d = {1, 2};          // エラー: 配列初期化子は不可
var e = 1, f = 2;        // エラー: 複数宣言は不可
ローカル変数以外NG
class Sample {
    var field = 10;              // エラー: フィールドは不可
    void m(var x) { }            // エラー: 引数は不可
    var n() { return 1; }        // エラー: 戻り値は不可
}

使える場所

ローカル変数の位置なら可OK
for (var i = 0; i < 3; i++) { }              // OK
for (var s : list) { }                       // OK（拡張for）
try (var r = new Res()) { }                  // OK（try-with-resources）

var は予約語ではない

変数名やメソッド名に使える最重要
int var = 10;            // OK。var は「予約型名」であって予約語ではない
System.out.println(var); // 10

var var = 10;            // OK。これも通る

「var は予約語なので識別子に使えない」という選択肢は誤りです。互換性のため予約語にはされておらず、変数名・メソッド名・パッケージ名に使えます（クラス名とインタフェース名には使えません）。これは狙われます。
