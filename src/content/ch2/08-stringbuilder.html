08

StringBuilder

String と違い、中身を変更できる文字列クラスです。この一点から、すべての挙動の差が生まれます。

String との決定的な違い

代入しなくても変わる最重要
StringBuilder sb = new StringBuilder("Hello");
sb.append(" World");
System.out.println(sb);   // "Hello World" ← 代入していないのに変わった

String s = "Hello";
s.concat(" World");
System.out.println(s);    // "Hello" ← こちらは変わらない
StringStringBuilder
オブジェクトの中身変えられない（不変）変えられる（可変）
メソッドの戻り値新しいインスタンス自分自身
代入が必要か必要不要
equals()中身を比較参照を比較
+ 演算子使える使えない
リテラルからの生成String s = "a";不可。new が必要

生成の形

引数の型で意味が変わる最重要
StringBuilder a = new StringBuilder();       // 空。容量16
StringBuilder b = new StringBuilder("Hi");   // "Hi" を保持。容量 16+2=18
StringBuilder c = new StringBuilder(16);     // 空。容量16 ← 数値は「容量」
StringBuilder d = new StringBuilder("16");   // "16" を保持 ← 文字列は「中身」

new StringBuilder(16) の中身は 空文字列です。「16」という文字列にはなりません。int を渡すと容量、String を渡すと初期値。

リテラルからは作れないNG
StringBuilder sb = "Hello";                       // コンパイルエラー
StringBuilder sb2 = new StringBuilder("Hello");   // OK

A. 追加するメソッド

append ── 末尾に追加最重要
StringBuilder sb = new StringBuilder("a");

sb.append("b");        // "ab"
sb.append(1);          // "ab1"        ← int も受け取れる
sb.append(true);       // "ab1true"    ← boolean も
sb.append('c');        // "ab1truec"   ← char も
sb.append(1.5);        // "ab1truec1.5"
sb.append((Object)null);  // "...null" ← null は "null" という文字列になる

append はあらゆる型を受け取れるようオーバーロードされています。渡した値を文字列にしてから末尾に足す、というのが動作のすべてです。

引数の中で計算が先に起きる要注意
StringBuilder sb = new StringBuilder();
sb.append(1 + 2);      // "3"  ← "12" ではない。引数が先に評価される
sb.append(1).append(2);    // "312" ← こちらは順に足される
insert ── 指定位置に挿入OK
StringBuilder sb = new StringBuilder("abcd");

sb.insert(0, "X");     // "Xabcd"  ← 先頭に挿入
sb.insert(3, "Y");     // "XabYcd" ← 位置3の「手前」に挿入
sb.insert(6, "Z");     // "XabYcdZ" ← 末尾の次の位置まで許される
insert の範囲外実行時
new StringBuilder("abcd").insert(5, "X");   // StringIndexOutOfBoundsException
// 0〜4 まで許される（長さ4なので、末尾の次は 4）

B. 削除するメソッド

delete / deleteCharAt要注意
StringBuilder sb = new StringBuilder("abcdef");

sb.delete(1, 3);       // "adef"  ← 位置1から、位置3の手前まで削除
sb.deleteCharAt(0);    // "def"   ← 1文字だけ削除

substring と同じで、delete の第2引数も「含まない」。範囲指定の作法は統一されています。削除される文字数は 第2引数 − 第1引数。

setLength ── 長さを変えるOK
StringBuilder sb = new StringBuilder("Hello");

sb.setLength(2);       // "He"  ← 短くすると切り詰められる
sb.setLength(4);       // "He\u0000\u0000" ← 長くすると null 文字で埋まる
sb.setLength(0);       // ""    ← 全消去のイディオム

C. 書き換えるメソッド

replace ── 範囲を置換最重要
StringBuilder sb = new StringBuilder("abcdef");
sb.replace(1, 3, "XYZ");    // "aXYZdef" ← 位置1〜2 を "XYZ" に置換

// 比較：String の replace は「文字を探して置換」
"abcdef".replace("bc", "XYZ");   // "aXYZdef"

名前は同じ replace でも、StringBuilder は位置指定（int, int, String）、String は文字指定（String, String）。引数の形がまったく違うので、選択肢で入れ替えられます。

setCharAt ── 1文字を書き換えるOK
StringBuilder sb = new StringBuilder("abc");
sb.setCharAt(0, 'X');       // "Xbc"
// 戻り値は void。チェーンできない
reverse ── 逆順にするOK
StringBuilder sb = new StringBuilder("abc");
sb.reverse();               // "cba"
System.out.println(sb);     // "cba" ← 元のオブジェクトが変わっている

// String には reverse がないので、逆順にしたいときはこう書く
String s = new StringBuilder("abc").reverse().toString();   // "cba"

reverse() は文字の並びをそのまま逆にするだけです。戻り値は自分自身なのでチェーンできます。String には reverse がないので、回文判定などの問題では StringBuilder を経由する形が出ます。

D. 調べるメソッド

String と同名のものが多いOK
StringBuilder sb = new StringBuilder("abcabc");

sb.length();           // 6
sb.charAt(1);          // 'b'
sb.indexOf("b");       // 1   ← なければ -1
sb.lastIndexOf("b");   // 4
sb.substring(2);       // "cdef" 相当 ← 戻り値は String！
sb.substring(1, 3);    // "bc"  ← 元の sb は変わらない
sb.toString();         // "abcabc" ← String に変換

sb.substring(...) の戻り値は StringBuilder ではなく String です。そしてこの操作だけは元のオブジェクトを変更しません。「StringBuilder のメソッドはすべて自分自身を返す」と覚えていると外します。

length と capacity は別物要注意
StringBuilder a = new StringBuilder();
a.length();            // 0   ← 実際の文字数
a.capacity();          // 16  ← 内部バッファのサイズ（初期値）

StringBuilder b = new StringBuilder("Hello");
b.length();            // 5
b.capacity();          // 21  ← 16 + 文字数

b.append(" World");
b.length();            // 11
b.capacity();          // 21  ← 余裕があるので変わらない

容量が足りなくなると 現在の容量 × 2 + 2 に拡張されます。setLength は capacity を変えません。

equals はオーバーライドされていない

中身が同じでも false最重要
StringBuilder a = new StringBuilder("abc");
StringBuilder b = new StringBuilder("abc");

a.equals(b);                          // false ← Object の equals のまま
a == b;                               // false
a.toString().equals(b.toString());    // true  ← String に変換すれば比較できる

String は equals() をオーバーライドして中身を比較しますが、StringBuilder はしていません。別インスタンスなら必ず false です。

メソッドチェーン

自分自身を返すのでつなげられるOK
StringBuilder sb = new StringBuilder("abc");
sb.append("d").insert(0, "X").reverse();
System.out.println(sb);   // "dcbaX"

// ① append("d")   → "abcd"
// ② insert(0,"X") → "Xabcd"
// ③ reverse()     → "dcbaX"

String のチェーンは毎回新しいインスタンスが生まれますが、StringBuilder のチェーンはすべて同じインスタンスを操作しています。結果として sb 自体が変わる、というのが String との違いです。

ただし setCharAt は戻り値が void、substring は String を返すので、この2つはチェーンの途中に置けません。

+ 演算子は使えない

連結演算子は String 専用NG
StringBuilder a = new StringBuilder("a");
StringBuilder b = new StringBuilder("b");
StringBuilder c = a + b;      // コンパイルエラー

String d = a + "x";           // OK ← String との連結なら toString() が呼ばれる
