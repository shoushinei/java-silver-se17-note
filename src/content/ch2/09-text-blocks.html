テキストブロック

SE 11 Silver には存在しなかった項目です。11 の教材では一切カバーされていないので、ここは新規に固める必要があります。

""" で囲んで、複数行の文字列をそのまま書ける構文です（Java 15〜）。

基本形形
String s = """
    Hello
    World""";
// "Hello\nWorld"

ルール1 ── 開始の """ の後は改行が必須

同じ行に文字を書けないNG
String s = """Hello
    World""";        // コンパイルエラー
改行してから書くOK
String s = """
    Hello
    World""";

終了の """ は同じ行に置けます。改行が必須なのは開始側だけ。

ルール2 ── インデントは「最も浅い行」を基準に除去される

付随的な空白の除去最重要
String s = """
        Hello
      World
        """;
// 最も浅いのは終了の """ の位置（6文字）
// → 各行から6文字ぶんのインデントが取り除かれる
// "  Hello\nWorld\n"

終了の """ の位置も判定に含まれます。これが最も左にあれば、その位置が基準になります。

終了位置を変えると結果が変わる要注意
String a = """
    Hello
    """;          // 終了が4文字目 → "Hello\n"

String b = """
    Hello
""";              // 終了が0文字目 → "    Hello\n"

ルール3 ── 末尾の改行

終了 """ の位置で改行の有無が決まる要注意
String a = """
    Hello""";     // "Hello"     ← 末尾に改行なし

String b = """
    Hello
    """;          // "Hello\n"   ← 末尾に改行あり

ルール4 ── 2つのエスケープ

行末の \ と \s要注意
String a = """
    Hello \
    World""";
// "Hello World" ← 行末の \ で改行を打ち消す（連結される）

String b = """
    Hello   \s
    World""";
// \s は空白1文字として扱われ、その手前の空白も保持される

通常のエスケープ（\n \t \"）も使えます。ただしダブルクォート1個は、そのまま書いてもエスケープ不要です。

クォートの扱いOK
String s = """
    彼は "Hello" と言った""";     // OK。エスケープ不要
