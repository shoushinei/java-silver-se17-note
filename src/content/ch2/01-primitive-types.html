8つの基本データ型

型サイズ既定値範囲・特徴
byte8bit0-128 〜 127
short16bit0-32768 〜 32767
int32bit0整数リテラルの既定の型
long64bit0LL が必要な場面がある
float32bit0.0ff は必須。有効桁数 約7桁
double64bit0.0d小数リテラルの既定の型。約15桁
char16bit'\u0000'符号なし。0 〜 65535
boolean未定義false数値との相互変換は不可

既定の型は int と double。これを外すには接尾辞が必要になります。

接尾辞の付け忘れNG
long  a = 10000000000;   // エラー: int として評価され範囲を超える
float b = 1.5;           // エラー: 1.5 は double なので float に入らない
接尾辞を付けるOK
long  a = 10000000000L;
float b = 1.5f;
long  c = 10;            // OK。範囲内なら L は不要（int → long は拡大変換）

char は符号なし

char の性質要注意
char a = 65;         // OK。'A' になる
char b = 'a' + 1;    // OK。定数式なので 'b'
char c = -1;         // コンパイルエラー: 負の値は不可

char と short はどちらも16bitですが、表現範囲が重ならないため双方向で明示キャストが必要です。「サイズが同じだから代入できる」と考えると落とします。

浮動小数点の特殊値

整数の 0 除算は例外実行時
System.out.println(1 / 0);      // ArithmeticException
浮動小数点の 0 除算は例外にならない要注意
System.out.println(1.0 / 0);    // Infinity
System.out.println(-1.0 / 0);   // -Infinity
System.out.println(0.0 / 0);    // NaN

System.out.println(Double.NaN == Double.NaN);   // false
// NaN の判定は Double.isNaN() を使う

第6章とつながります。整数の 0 除算だけが ArithmeticException。小数の 0 除算は例外を投げません。「実行時に例外がスローされる」という選択肢を選ばせる引っかけに使われます。
