一問一答

問題を解く前の自己確認用です。答えを開く前に、頭の中で言い切れるか試してください。

Q1float f = 1.5; はなぜエラー？

小数リテラルの既定の型は doubleだから。double → float は縮小変換なので、1.5f と書くか (float) でキャストする必要があります。

Q2int a = 012; の値は？

10。先頭に 0 が付いた整数リテラルは8進数として解釈されます。

Q3byte a=1,b=2; byte c=a+b; は？

コンパイルエラー。byte・short・char の演算結果は int に昇格します。(byte)(a+b) が必要。ただし a += b なら暗黙のキャストが入るので通ります。

Q4final int x=10; byte b=x; は通る？

通る。final なのでコンパイル時に値が確定し、範囲内の定数として縮小変換が許されます。final を外すとエラーになります。

Q5Long a = 5; は？

コンパイルエラー。int → long（拡大変換）→ Long（ボクシング）の2段階は許されません。5L と書けば通ります。

Q6int var = 10; は書ける？

書ける。var は予約語ではなく「予約型名」なので、変数名やメソッド名に使えます。クラス名・インタフェース名には使えません。

Q7String s="Hello"; s.concat("!"); の後、s は？

"Hello" のまま。String は不変なので、メソッドは新しいインスタンスを返すだけです。s = s.concat("!") と代入が必要。

Q8"Hello" == new String("Hello") は？

false。リテラルは定数プールで共有されますが、new は必ず別のインスタンスを作ります。中身の比較は equals() で。

Q9"abcdef".substring(2, 4) は？

"cd"。第2引数の位置は含みません。substring(2,2) は空文字列で、例外にはなりません。

Q10StringBuilder の equals() は中身を比較する？

しない。オーバーライドされていないので参照比較のままです。中身を比べるには toString().equals(...)。

Q11テキストブロックのインデントは何を基準に除去される？

最も浅い行の位置。終了の """ の位置も判定に含まれます。終了 """ を左端に置くと、インデントが除去されなくなります。

Q12List<Integer> に 10,20,30。remove(1) の結果は？

[10, 30]。引数が int なので remove(int)（インデックス指定）が選ばれます。値10を消すなら remove(Integer.valueOf(10))。

Q13int e[], f; のとき f の型は？

int（配列ではない）。角括弧を変数側に書くと、その変数だけが配列になります。int[] e, f; なら両方が配列です。

Q14new int[2][] と new int[][3]、通るのは？

前者だけ。後ろの次元は省略できますが、前の次元は省略できません。

Q15System.out.println(new int[3]) は何が出る？

[I@ で始まるハッシュ形式。配列は toString() をオーバーライドしていないためです。中身を出すには Arrays.toString()。char[] だけは専用オーバーロードがあるので中身が出ます。

Q16Item[] items = new Item[3]; の後 items[0].price は？

NullPointerException。箱を3つ用意しただけで、インスタンスは1つも生成されていません。参照型の配列は new Item() を別途書く2段階が必要です。

Q17String[][] a を for (String[] tmp : a) で回すとき、tmp.length は？

a[i] の要素数。tmp は取り出された1行そのものです。全体の行数が欲しいなら a.length と書きます。ドットの左の変数の型で決まります。

Q18int[] b = a; と int[] c = a.clone(); の違いは？

b は同じ配列を指し、c は別の配列。b を書き換えると a も変わりますが、c は独立しています。ただし clone は浅いコピーなので、2次元配列では中の行が共有されたままです。

Q19size 1 のリストに add(2, "X") は？

IndexOutOfBoundsException。add で許されるのは 0〜size まで。飛び地は作れません。set はさらに狭く 0〜size-1 です。

Q20拡張for文の中で remove して、例外にならないのはどんなとき？

最後から2番目の要素を削除したとき。削除後に cursor == size となり hasNext() が false を返してループが終わるためです。整合性チェックは next() の中にしかありません。ただし最後の要素は取りこぼされます。

Q21new ArrayList<Integer>(3) の size は？

0。3 は初期容量であって要素数ではありません。StringBuilder(16) と同じ意味で、いくらでも追加できます。

Q22List.of と Arrays.asList の違いは？

List.of は set も不可（不変）、Arrays.asList は set だけ可（固定長）。asList は元の配列を包んでいるだけなので、set すると元の配列も変わります。どちらも add / remove は UnsupportedOperationException。
