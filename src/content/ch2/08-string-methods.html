08

String の主要メソッド

メソッドを1つずつ暗記する前に、2つの共通ルールを頭に入れてください。この2つで大半の問題が判定できます。

ルール1：戻り値を代入しない限り、元の文字列は変わらない。
ルール2：位置を指定するメソッドは、すべて 0 から数える。

位置（インデックス）の数え方

2つの数え方がある前提
String s = "abcdef";

//  文字      a  b  c  d  e  f
//  文字位置  0  1  2  3  4  5      ← charAt が使う
//  区切り位置 0  1  2  3  4  5  6   ← substring が使う

charAt は 0〜5 まで、substring は 0〜6 まで許されます。2つのメソッドで境界が1つずれているのが引っかけの温床です。

A. 調べるメソッド（戻り値で情報を返す）

length / isEmpty / isBlankOK
"abcdef".length();     // 6   ← メソッドなので括弧が必要
"".length();           // 0
"  ".length();         // 2   ← 空白も1文字

"".isEmpty();          // true
"   ".isEmpty();       // false ← 長さ3なので空ではない
"   ".isBlank();       // true  ← 空白のみなら true（Java 11〜）
"".isBlank();          // true
"a".isBlank();         // false

isEmpty は「長さ0」、isBlank は「空白だけ」。isBlank のほうが true になる範囲が広いと覚えてください。

charAt ── 1文字を取り出すOK
String s = "abcdef";
s.charAt(0);           // 'a'  ← 戻り値は char
s.charAt(5);           // 'f'
charAt の範囲外実行時
"abcdef".charAt(6);    // StringIndexOutOfBoundsException（0〜5 まで）
"abcdef".charAt(-1);   // StringIndexOutOfBoundsException

戻り値が char なので、演算に使うと数値になります。System.out.println(s.charAt(0) + 1) は 'b' ではなく 98。char + int が int に昇格するためです（第3節）。+ "" を足すか (char) でキャストすれば文字になります。

indexOf / lastIndexOf ── 位置を探す最重要
String s = "abcabc";

s.indexOf("b");        // 1   ← 最初に見つかった位置
s.indexOf('b');        // 1   ← char 版もある
s.indexOf("b", 2);     // 4   ← 位置2以降から探す
s.indexOf("z");        // -1  ← 見つからない
s.lastIndexOf("b");    // 4   ← 後ろから探す
s.indexOf("");         // 0   ← 空文字列は必ず 0

見つからないときは 0 ではなく -1。「見つかったか」の判定は != -1 で書きます。

contains / startsWith / endsWithOK
String s = "Hello World";

s.contains("lo W");        // true  ← 戻り値は boolean
s.contains("");            // true  ← 空文字列は常に含まれる
s.startsWith("Hello");     // true
s.startsWith("World", 6);  // true  ← 位置6から判定
s.endsWith("World");       // true
s.endsWith("world");       // false ← 大文字小文字は区別される
equals / equalsIgnoreCase / compareToOK
"abc".equals("abc");                // true
"abc".equals("ABC");                // false
"abc".equalsIgnoreCase("ABC");      // true

"abc".compareTo("abd");             // 負の数（abc が前）
"abc".compareTo("abc");             // 0     ← 同じなら 0
"abd".compareTo("abc");             // 正の数
"abc".compareToIgnoreCase("ABC");   // 0

compareTo の戻り値は boolean ではなく int。同じなら 0 を返します。if (a.compareTo(b)) と書くとコンパイルエラーです。

B. 切り出すメソッド

substring はこの章で最も出るメソッドです。第2引数の扱いだけ正確に。

第2引数は「含まない」最重要
String s = "abcdef";

s.substring(2);        // "cdef"  ← 位置2から末尾まで
s.substring(2, 4);     // "cd"    ← 位置2から、位置4の手前まで
s.substring(0, 3);     // "abc"
s.substring(2, 2);     // ""      ← 始点と終点が同じ → 空文字列
s.substring(6);        // ""      ← 長さと同じ位置は許される
s.substring(6, 6);     // ""

切り出される文字数は 第2引数 − 第1引数。substring(2, 4) なら 4−2 = 2文字です。この引き算で数えると間違えません。

範囲外・逆順実行時
"abcdef".substring(7);       // StringIndexOutOfBoundsException
"abcdef".substring(4, 2);    // StringIndexOutOfBoundsException（始点 > 終点）
"abcdef".substring(-1);      // StringIndexOutOfBoundsException

substring(6) は通るのに substring(7) は落ちる。「長さと同じ位置」までは許されるという境界が狙われます。

↑ 早見表に戻る

C. 作り変えるメソッド（新しい String を返す）

concat ── 連結OK
String s = "Hello";
s.concat(" World");        // "Hello World" が返るが s は変わらない
s = s.concat(" World");    // "Hello World"

s.concat(null);            // NullPointerException（+ と違う）

+ なら "a" + null は "anull" になりますが、concat(null) は NullPointerException です。同じ連結でも挙動が違います。

replace ── 置換OK
String s = "abcabc";

s.replace("a", "X");       // "XbcXbc"  ← 該当箇所をすべて置換
s.replace('a', 'X');       // "XbcXbc"  ← char 版もある
s.replace("z", "X");       // "abcabc"  ← 該当なしならそのまま
"aaaa".replace("aa", "X"); // "XX"      ← 左から重複せず1回だけ走査
"aaa".replace("aa", "a");  // "aa"      ← 置換結果は再走査しない

関連メソッドが2つあります。replaceAll は第1引数を正規表現として解釈し、replaceFirst は最初の1つだけ置換します。「replace は1個目だけ」ではない、という点に注意してください。

replace と replaceAll の違い要注意
"a.b.c".replace(".", "X");      // "aXbXc" ← ピリオドそのもの
"a.b.c".replaceAll(".", "X");   // "XXXXX" ← 正規表現の「任意の1文字」
trim / strip ── 前後の空白を除去OK
String s = "  a b  ";

s.trim();              // "a b"   ← 間の空白は残る
s.strip();             // "a b"   ← Java 11〜。Unicode 空白にも対応
s.stripLeading();      // "a b  "
s.stripTrailing();     // "  a b"
大文字小文字 / 繰り返しOK
"Hello".toUpperCase();     // "HELLO"
"Hello".toLowerCase();     // "hello"
"ab".repeat(3);            // "ababab"（Java 11〜）
"ab".repeat(0);            // ""
"ab".repeat(-1);           // IllegalArgumentException

↑ 早見表に戻る

D. 分ける・つなぐ・変換する

split ── 配列に分割OK
String s = "a,b,c";
String[] arr = s.split(",");        // {"a", "b", "c"} ← 戻り値は String[]
arr.length;                          // 3

"a,,b".split(",");                   // {"a", "", "b"} ← 空要素も入る
"a,b,,".split(",");                  // {"a", "b"}     ← 末尾の空要素は削除される
"abc".split("");                     // {"a", "b", "c"}
join ── 連結（static メソッド）OK
String.join("-", "a", "b", "c");     // "a-b-c"
String.join("-", List.of("a", "b")); // "a-b"

join は String.join(...) とクラス名で呼びます。インスタンスメソッドではありません。

valueOf / parseInt ── 型の変換要注意
String.valueOf(10);          // "10"   ← 何でも String にする（static）
String.valueOf(true);        // "true"
String.valueOf(null);        // 曖昧でコンパイルエラーになる場合がある

Integer.parseInt("10");      // 10           ← int が返る
Integer.valueOf("10");       // Integer(10)  ← Integer が返る
Integer.parseInt("abc");     // NumberFormatException

第6章とつながります。NumberFormatException は IllegalArgumentException の子で非検査例外なので、catch も throws も義務ではありません。

toCharArray ── 文字の配列にするOK
char[] c = "abc".toCharArray();   // {'a', 'b', 'c'}
c.length;                          // 3 ← 配列なので括弧なし

↑ 早見表に戻る

E. 連結演算子 + の罠

左から順に評価される最重要
System.out.println(1 + 2 + "a");    // "3a"  ← 先に 1+2 が計算される
System.out.println("a" + 1 + 2);    // "a12" ← 先に "a"+1 が文字列になる
System.out.println(1 + 2 + "a" + 1 + 2);   // "3a12"

String が現れた時点から後ろは、すべて文字列連結になります。それより前は普通の算術演算です。

null と char の扱い要注意
String s = null;
System.out.println("a" + s);        // "anull"   ← 例外にならない
System.out.println("a" + 'b');      // "ab"
System.out.println('a' + 'b');      // 195       ← char + char は int！

↑ 早見表に戻る

チェーンして呼ぶ場合

左から順に評価される要注意
String s = "  Hello World  ";

s.trim().substring(0, 5).toUpperCase();
// ①  trim()            → "Hello World"
// ②  substring(0, 5)   → "Hello"
// ③  toUpperCase()     → "HELLO"

System.out.println(s);   // "  Hello World  " ← 元は変わらない

チェーンできるのは、各メソッドが新しい String を返しているからです。1つずつ結果を書き出せば必ず解けます。
