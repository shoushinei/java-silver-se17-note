04

宣言・初期化・スコープ

ローカル変数は初期化が必須

未初期化のまま使用NG
void m() {
    int x;
    System.out.println(x);   // コンパイルエラー: 初期化されていない
}
フィールドは既定値が入るOK
class Sample {
    int x;              // 0
    String s;           // null
    boolean b;          // false

    void m() { System.out.println(x); }   // OK。0 が出力される
}

ローカル変数には既定値がなく、フィールドにはある。この非対称が問われます。宣言だけして使わなければローカル変数もエラーにならないので、「使ったかどうか」が判定の分かれ目です。

分岐で初期化した場合

すべての経路で初期化されていないNG
int x;
if (flag) { x = 1; }
System.out.println(x);   // コンパイルエラー: flag が false の経路がある
else があれば通るOK
int x;
if (flag) { x = 1; } else { x = 2; }
System.out.println(x);   // OK

第6章の「到達不能コード」と同じ判定方法です。コンパイラは全経路を調べるので、1つでも初期化されない経路があればエラーになります。

ブロックスコープ

ブロックを出ると消えるNG
{
    int x = 10;
}
System.out.println(x);       // コンパイルエラー

for (int i = 0; i < 3; i++) { }
System.out.println(i);       // コンパイルエラー: i は for の中だけ

try { int y = 10; }
catch (Exception e) { System.out.println(y); }   // コンパイルエラー

同名の変数

入れ子のブロックで同名は不可NG
int x = 10;
{
    int x = 20;      // コンパイルエラー: 外側と重複
}
フィールドとローカル変数の同名は可OK
class Sample {
    int x = 10;
    void m() {
        int x = 20;              // OK。フィールドを隠す（シャドーイング）
        System.out.println(x);        // 20
        System.out.println(this.x);   // 10
    }
}
