一問一答

問題を解く前の自己確認用です。答えを開く前に、頭の中で言い切れるか試してください。

Q1int i = 1; i = i++; の後、i は？

1のまま。i++ が今の値1を退避してから i を2にしますが、直後に「i = 退避した1」の代入が走って上書きされます。

Q2int i = 1; i++ + ++i の値は？

4。i++ が1を返して i は2、++i が i を3にして3を返す。1 + 3 = 4。左から1つずつ書き出すのが確実です。

Q3-5 / 2 と -5 % 2 は？

-2 と -1。除算はゼロ方向に切り捨て（-3 ではない）、剰余の符号は左オペランドに従います。

Q4a *= 3 + 4 はどう展開される？

a = a * (3 + 4)。右辺全体が括弧で囲まれます。a*3+4 ではありません。

Q5if (false && i++ > 0) の後、i は増えている？

増えていない。&& は左が false なら右辺を評価しません。& なら評価されるので i は増えます。記号が2つなら短絡。

Q6boolean b = false; if (b = true) は？

コンパイルが通り、true 側が実行される。代入の結果が boolean なので条件として成立します。b も書き換わります。int なら同じ形でコンパイルエラーです。

Q7true ? 1 : 2.0 は何が出力される？

1.0。選ばれなかった側の型も結果の型に影響し、int と double が double に昇格します。

Q8switch に使えない型は？

long / float / double / boolean とそのラッパー。使えるのは byte・short・char・int とそのラッパー、String、enum です。

Q9case ラベルに変数を書けるのはどんなとき？

final でコンパイル時に値が確定するときだけ。非 final の変数はコンパイルエラーです。

Q10default は必ず最後に書く必要がある？

ない。どこに書いてもよく、そこからもフォールスルーします。「最後に書かなければいけない」という選択肢は誤りです。

Q11switch 式のアロー構文で break を書くと？

コンパイルエラー。アロー構文はフォールスルーしないので break は不要かつ不可です。

Q12switch 式で複数行の処理をして値を返すには？

{ } で囲んで yield で返す。return は使えません。1行なら case 1 -> 10; のように式をそのまま書きます。

Q13値を返す switch 式で default を省略できるのは？

enum のすべての定数を網羅したときだけ。int や String では default が必須です。値を返さない場合は網羅性を要求されません。

Q14switch 式の閉じ波括弧の後に必要なものは？

セミコロン。値を返す switch 式は「式」なので、代入文の一部として }; で終わります。switch 文には不要です。

Q15while (i < 3); と書くと？

本体が空文になり無限ループ。逆に do-while の末尾にはセミコロンが必須です。

Q16while の中で continue すると危険なのはなぜ？

更新処理を飛ばして無限ループになるから。for なら更新部が必ず実行されますが、while では自分で書いた i++ がスキップされます。

Q17break outer と continue outer の違いは？

break はそのループごと抜け、continue は外側のループの次の周へ進む。ラベルは抜けたいループの直前に置きます。

Q18String s = null; s instanceof String は？

false。例外にはなりません。null は常に false を返します。

Q19System.out.println(012) は何が出る？

10。先頭の 0 が8進数の印です。0b=2進数、0x=16進数、先頭の 0 だけ=8進数。出力は必ず10進数になります。

Q20int a=1, b=2; のとき a && b は？

コンパイルエラー。&& と || は boolean 専用です。& ならビット演算として動きます（結果は 0）。

Q21yield と return の違いは？

yield は switch 式だけを抜け、return はメソッドごと抜ける。だから switch 式の中で return は書けません。yield は予約語ではないので変数名にも使えます。
