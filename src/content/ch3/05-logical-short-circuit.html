論理演算子と短絡評価

演算子意味右辺の評価
&&かつ左が false なら評価しない
||または左が true なら評価しない
&かつ必ず評価する
|または必ず評価する
^排他的論理和（片方だけ true なら true）必ず評価する
!否定—

記号が2つなら短絡、1つなら必ず両辺を評価。これが判定の起点です。

&& と & で結果が変わる最重要
int i = 0;

if (false && i++ > 0) { }
System.out.println(i);     // 0 ← i++ が実行されていない

int j = 0;
if (false & j++ > 0) { }
System.out.println(j);     // 1 ← 右辺も評価された
|| も同じ構造要注意
int i = 0;
if (true || i++ > 0) { }
System.out.println(i);     // 0

int j = 0;
if (true | j++ > 0) { }
System.out.println(j);     // 1

短絡評価は副作用があるコードと組み合わされて出題されます。i++、メソッド呼び出し、代入などが右辺にあるとき、それが実行されたかどうかが答えを分けます。

短絡評価は null チェックにも使われる実行時
String s = null;

if (s != null && s.length() > 0) { }   // OK。左が false なので右辺は評価されない
if (s != null &  s.length() > 0) { }   // NullPointerException！

第2章の「null にドットを付けたら例外」がここで効きます。& を使うと右辺が必ず評価されるので落ちる、という形で出題されます。

整数には && を使えないNG
int a = 1, b = 2;
a && b;        // コンパイルエラー: boolean でないとダメ
a & b;         // OK ← ビット演算として動く（結果は 0）

& | ^ は boolean にも整数にも使えます。&& || は boolean 専用です。
