if 文

条件は boolean のみ

整数は条件にできないNG
int i = 1;
if (i) { }          // コンパイルエラー（C言語と違う）
if (i = 1) { }      // コンパイルエラー: 代入の結果は int
if (i == 1) { }     // OK
boolean の代入は通ってしまう最重要
boolean b = false;
if (b = true) {            // 代入の結果は boolean → 条件として成立
    System.out.println("実行される");
}
System.out.println(b);     // true ← b が書き換わっている

== と = の書き間違いは、boolean 変数のときだけコンパイルが通ってしまいます。しかも常に true 側が実行され、変数も書き換わる。選択肢を読むときはイコールの数を数えてください。

波括弧を省略すると次の1文だけ

インデントに騙されない要注意
if (false)
    System.out.println("A");
    System.out.println("B");   // ← if とは無関係。必ず実行される

// 出力: B
セミコロンだけの空文要注意
if (true);                        // ← ここで if は終わっている
    System.out.println("A");      // 常に実行される

int i = 0;
while (i < 3);                    // 無限ループ！本体が空文
    i++;

if (...) や while (...) の直後のセミコロン1個が、コード全体の意味を変えます。行末のセミコロンを目で確認する癖をつけてください。

波括弧なしで宣言はできないNG
if (true)
    int x = 10;      // コンパイルエラー: 宣言は文ではあるが、ここには置けない
