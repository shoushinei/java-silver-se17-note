代入演算子と複合代入

複合代入演算子（+= -= *= /= %=）には、暗黙のキャストが組み込まれています。

意味は同じでも結果が違う最重要
byte a = 1;
a += 2;        // OK。(byte)(a + 2) と同じ扱い
a++;           // OK。同じ理由
a = a + 2;     // コンパイルエラー: a + 2 は int

第2章の数値昇格とセットで問われます。byte・short・char の演算結果は int なので、そのままでは代入できません。複合代入だけが例外的に通ります。

右辺全体が先に評価される要注意
int a = 2;
a *= 3 + 4;    // a = a * (3 + 4) = 14 ← a*3+4 = 10 ではない

a op= b は a = a op (b) と展開されます。右辺全体が括弧で囲まれると覚えてください。

文字列にも使えるOK
String s = "a";
s += 1;        // "a1"
s += 'b';      // "a1b"
s += null;     // "a1bnull"
