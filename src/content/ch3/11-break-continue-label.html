break と continue

動作使える場所
breakループや switch を抜けるループ / switch
continueその周を飛ばして次の周へループのみ
continue は switch では使えないNG
switch (x) {
    case 1: continue;      // コンパイルエラー（ループの中にあれば別）
}
for の中の switch なら continue も使えるOK
for (int i = 0; i < 3; i++) {
    switch (i) {
        case 1: continue;      // OK。for の次の周へ
    }
    System.out.println(i);
}
// 出力: 0 2

continue と for の更新部

更新部は実行される要注意
for (int i = 0; i < 3; i++) {
    if (i == 1) continue;      // i++ は実行される
    System.out.println(i);
}
// 出力: 0 2

int i = 0;
while (i < 3) {
    if (i == 1) continue;      // 無限ループ！ i++ に到達しない
    System.out.println(i);
    i++;
}

for では更新部が必ず実行されますが、while で continue すると更新処理を飛ばして無限ループになることがあります。この対比が出題されます。

ラベル付き break / continue

多重ループを一気に抜ける最重要
outer:                                   // ← ラベルはループの直前に置く
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) break outer;         // 外側のループごと抜ける
        System.out.println(i + "-" + j);
    }
}
// 出力: 0-0 だけ
continue にもラベルを付けられるOK
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) continue outer;      // 外側の次の周へ
        System.out.println(i + "-" + j);
    }
}
// 出力: 0-0 1-0 2-0

break outer はループごと抜ける、continue outer は外側の次の周へ進む。この違いで出力が大きく変わるので、選択肢を読むときはbreak か continue かを最初に確認してください。

ラベルとは何か

ラベルは文に付ける名札で、構文は 識別子 : 文 だけです。用途は break と continue の行き先を指定すること、その一つしかありません。

Java には goto が予約語として存在するのに使えません。無制限なジャンプは制御フローを壊すという合意がある一方、多重ループを一気に抜けたいという需要は残る。そこで「ジャンプ先はループの入口か出口だけ」という制限付きの goto として用意されたのがラベル付き break / continue です。goto が予約語のままなのは、うっかり変数名に使わせないためです。

ラベルを付けられる対象

ループ以外にも付けられる要注意
OUT: {                            // ブロックにラベルを付けられる
    System.out.println("A");
    break OUT;                    // ブロックから抜ける
}
System.out.println("B");
// 出力: A B

L: if (true) { break L; }         // if にも付けられる
continue はループにしか使えないNG
B: { System.out.println(1); continue B; }
// コンパイルエラー: not a loop label: B
変数宣言には付けられないNG
L: int i = 5;
// コンパイルエラー: variable declaration not allowed here

break は任意の文（ブロックや if を含む）から抜けられますが、continue はループに付いたラベルにしか使えません。この非対称が出題されます。
また、ローカル変数の宣言文だけは例外的にラベルを付けられません。

ラベルの有効範囲と名前空間

ラベルの外からは飛べないNG
for (int i = 0; i < 3; i++) {
    outer: System.out.println(i);
    break outer;                  // コンパイルエラー: undefined label: outer
}

break ラベル が使えるのは、そのラベルが付いた文の内側だけです。上の例では outer: が付いているのは println の1文だけで、break outer; はその外側にあるため、ラベルが見つかりません。

変数と同名でも衝突しないOK
int foo = 10;
foo: for (int i = 0; i < 2; i++) {
    System.out.println(foo + i);
    continue foo;
}
// 出力: 10 11

ラベルと変数は別の名前空間にあるので、同名でも問題ありません。「同じ名前だからコンパイルエラー」という選択肢は誤りです。
慣習として OUT や LOOP のように大文字で書きますが、これは規約であって文法上はただの識別子です。outer という決まった名前があるわけでもありません。
