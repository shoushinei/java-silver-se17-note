繰り返し文

for 文

3つの部分はすべて省略できる要注意
for (int i = 0; i < 3; i++) { }

for (;;) { }              // 無限ループ。セミコロン2つは必須
for (int i = 0; ; i++) { }   // 条件省略も無限ループ
初期化部・更新部はカンマで複数書けるOK
for (int i = 0, j = 10; i < j; i++, j--) { }   // OK
型は1つだけNG
for (int i = 0, long j = 0; ; ) { }   // コンパイルエラー: 型を2つ書けない
for (int i = 0; i < 3; i++, j = 1) { }   // 更新部に代入は OK

ループ変数のスコープはfor 文の中だけです。第2章で扱った通り、外では使えません。

while と do-while

do-while は最低1回実行される要注意
int i = 10;

while (i < 5) {
    System.out.println("A");     // 一度も実行されない
}

do {
    System.out.println("B");     // 1回は実行される
} while (i < 5);                 // ← セミコロンが必須

do-while の末尾にはセミコロンが必須です。無いとコンパイルエラー。逆に while 文の while (...) の直後にセミコロンを書くと本体が空文になり、無限ループになります。

拡張for文

配列とコレクションで使えるOK
int[] arr = {1, 2, 3};
for (int n : arr) { }

List<String> list = new ArrayList<>();
for (String s : list) { }

for (var s : list) { }        // var も使える
インデックスは使えないNG
for (int n : arr) {
    System.out.println(n);    // 値は取れる
    // i のような添字は存在しない
}

for (int i = 0 : arr) { }     // コンパイルエラー: 初期値は書けない

第2章の内容を再確認してください。ループ変数はコピーなので代入しても元は変わらず、走査中にコレクションを変更すると ConcurrentModificationException になります。

拡張for文で2次元配列を回す

取り出される型に注意最重要
int[][] array = {{1, 2}, {2, 3, 4}};

for (int[] row : array) {          // ← 外側が取り出すのは int ではなく int[]
    for (int n : row) {
        System.out.print(n + " ");
    }
}
// 出力: 1 2 2 3 4
型を間違えるとコンパイルエラーNG
for (int n : array) { }        // コンパイルエラー: int[] を int に代入できない
for (var row : array) { }      // OK。var なら int[] と推論される

2次元配列を拡張for文で回すとき、外側のループ変数は「行」の型になります。int[][] から取り出されるのは int[]。ここで int と書いた選択肢は必ず誤りです。var を使えば正しく推論されます。

多重ループと2次元配列

この組み合わせが第3章の実質的な山場です。まず2次元配列の実体を正しく捉えます。

2次元配列は「配列を指す参照の配列」図
int[][] array = {{1, 2}, {2, 3, 4}};

array ──┬──→ [ 1 ][ 2 ]                array[0].length は 2
        │
        └──→ [ 2 ][ 3 ][ 4 ]           array[1].length は 3

array.length は 2   ← 矢印の本数（行の本数）

Java の2次元配列は、メモリ上の長方形ではありません。行ごとに独立した配列があり、それを指す参照が並んでいるだけです。だから行ごとに長さが違ってよく（ジャグ配列）、長さを聞く相手も行ごとに変わります。

書き方意味使う場所
array.length行の本数外側ループの条件
array[i].length今いる行の要素数内側ループの条件
array[j].lengthj 番目の行の要素数誤り。列カウンタで行を選んでいる
内側の条件を array[j] にすると落ちる実行時
for (int i = 0; i < array.length; i++) {
    for (int j = 0; j < array[j].length; j++) {   // ← 誤り
        total += array[i][j];
    }
}
// i=0, j=0 → array[0].length は 2   0 < 2 で続行
// i=0, j=1 → array[1].length は 3   1 < 3 で続行
// i=0, j=2 → array[2] は存在しない
// ArrayIndexOutOfBoundsException: Index 2 out of bounds for length 2

例外メッセージの for length 2 は行の本数を指しています。内側の要素数の話ではありません。
覚え方は単純で、array[i][j] の左の添字と、条件式の添字を一致させる。読む場所と長さを聞く相手が同じ行になっていれば間違えません。

内側の開始位置をずらす形

黒本では、内側ループの初期化部に仕掛けを入れた空欄問題が出ます。

j を i から始める頻出
int[][] array = {{1, 2}, {2, 3, 4}};
int total = 0;

for (int i = 0; i < array.length; i++) {
    for (int j = i; j < array[i].length; j++) {   // ← j = 0 ではなく j = i
        total += array[i][j];
    }
}
System.out.println(total);

// i=0 → j は 0,1     array[0][0]=1, array[0][1]=2
// i=1 → j は 1,2     array[1][1]=3, array[1][2]=4   ← array[1][0] の 2 を飛ばす
// 出力: 10（全部足すと 12 なので、2 が1つ落ちている）

この型の解き方は逆算です。
① まず全要素を足していくつになるか出す（ここでは 12）
② 目標値との差を見る（12 − 10 = 2）
③ 「2 を1つだけ落とす選択肢はどれか」で絞る
選択肢を1つずつトレースするより速いので、必ずこの順序で。
