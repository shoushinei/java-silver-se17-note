switch 文（従来の形）

使える型・使えない型

byte short char int

int より大きい整数型（long）と、小数、boolean は使えません。「int に収まる整数系＋String＋enum」と覚えると確実です。

case ラベルは定数でなければならない

final の有無で結果が変わる最重要
final int A = 1;
int b = 2;

switch (x) {
    case A:  break;      // OK。コンパイル時に確定する定数
    case b:  break;      // コンパイルエラー: 変数は使えない
    case 1 + 2: break;   // OK。定数式
}

第2章の縮小変換や String の定数プールと同じ判定基準です。コンパイル時に値が確定するかが問われています。

重複と範囲外NG
byte x = 1;
switch (x) {
    case 1: break;
    case 1: break;       // コンパイルエラー: 重複
    case 200: break;     // コンパイルエラー: byte の範囲外
}

break がないとフォールスルーする

一致した位置から下へ流れる最重要
int x = 2;
switch (x) {
    case 1: System.out.println("A");
    case 2: System.out.println("B");
    case 3: System.out.println("C");
    default: System.out.println("D");
}
// 出力: B C D ← break がないので下まで流れる

一致した case から下のすべてが実行されます。break があればそこで抜けます。

default は最後でなくてもよい要注意
int x = 5;
switch (x) {
    default: System.out.println("D");
    case 1:  System.out.println("A");
}
// 出力: D A ← default から下へ流れる

default はどこに書いてもよく、そこからもフォールスルーします。「default は最後に書かなければいけない」という選択肢は誤りです。

switch に null を渡すと実行時
String s = null;
switch (s) {                 // NullPointerException
    case "a": break;
    default: break;
}

SE 17 の switch 文では case null は書けません。null が来ると実行時に落ちます。
