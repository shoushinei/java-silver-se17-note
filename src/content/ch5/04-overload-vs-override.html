オーバーライドとオーバーロードの区別

オーバーライドオーバーロード
場所親子関係の間同じクラス内でもよい
引数リスト完全一致違う
戻り値型同じかサブ型無関係（区別に使われない）
どれが呼ばれるか実行時の実体型で決まるコンパイル時の宣言型で決まる
引数を1文字変えるとオーバーロードになる最頻出
class A { void m(int x){ System.out.println("A"); } }
class B extends A {
    void m(long x){ System.out.println("B"); }     // 引数が違う → オーバーロード
}

A a = new B();
a.m(5);        // A ← オーバーライドされていないので親のものが動く

オーバーライドのつもりで引数の型を書き間違えると、静かにオーバーロードになります。コンパイルは通り、出力だけが変わる。
@Override を付けていればここで止まります。黒本はこの引っかけを多用します。
