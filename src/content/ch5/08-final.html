final

付ける先意味
クラス継承できない（cannot inherit from final）
メソッドオーバーライドできない
変数再代入できない
final 変数は「参照が固定される」だけ要注意
final int[] arr = {1, 2};
arr[0] = 100;              // OK。中身は変えられる
arr = new int[]{3};        // error: cannot assign a value to final variable arr

final StringBuilder sb = new StringBuilder("a");
sb.append("b");            // OK
sb = new StringBuilder();  // error

参照型の final が固定するのは矢印であって、指す先の中身ではありません。「final なら中身も変えられない」は誤りで、選択肢に出ます。
本当に中身も不変にしたければ record や不変クラスを使います。

final クラスの例は String、Integer などのラッパークラス、そして record（暗黙）。
abstract とは正反対の意味なので同時には付けられません。「継承を強制する」と「継承を禁止する」は両立しません。
