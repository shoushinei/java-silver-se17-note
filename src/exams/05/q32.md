次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Team {
    private final int[] scores = {1, 2};
    int[] getScores() {
        return scores;
    }
    int total() {
        return scores[0] + scores[1];
    }
}
public class Main {
    public static void main(String[] args) {
        Team t = new Team();
        int[] s = t.getScores();
        s[0] = 10;
        s = new int[] {0, 0};
        System.out.println(t.total());
    }
}
```

- A. 「3」と表示される
- B. 「12」と表示される
- C. 「0」と表示される
- D. 「10」と表示される
- E. final の配列の中身を変えているため、コンパイルエラーが発生する

## 解説
1. `getScores()` は Team の中の配列そのもの（への参照）を返すので、s は Team の scores と**同じ配列**を指す
2. `s[0] = 10` で、その共有している配列の中身が {10, 2} になる。scores は final ですが、final が禁止するのは scores に別の配列を入れ直すことだけで、中身の変更は許されます（E は誤り）
3. `s = new int[] {0, 0}` は、ローカル変数 s に別の配列を入れ直しただけ。Team の scores は {10, 2} のまま

total() は 10 + 2 で「12」です。
