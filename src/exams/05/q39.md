次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println(0b11 + 010 + 0x10);
    }
}
```

- A. 「29」と表示される
- B. 「27」と表示される
- C. 「21」と表示される
- D. 「331」と表示される
- E. コンパイルエラーが発生する

## 解説
| リテラル | 進数 | 10進数の値 |
|---|---|---|
| `0b11` | 2進数 | 3 |
| `010` | 8進数（先頭が 0） | 8 |
| `0x10` | 16進数 | 16 |

どれも int なので足し算になり、3 + 8 + 16 = 27 です。A は 010 を 10 と読んだ場合、C は 0x10 を 10 と読んだ場合の値です。
