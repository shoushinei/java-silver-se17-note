次のコードは、Circle クラスでコンパイルエラーになります。

```java title=Shape.java
interface Shape {
    double area();
    String name();
}
abstract class Base implements Shape {
    public String name() {
        return "base";
    }
}
class Circle extends Base {
}
```

コンパイルを成功させる方法として、正しいものを選びなさい。

- A. Circle に `public double area() { return 3.0; }` を追加する
- B. Circle に `double area() { return 3.0; }` を追加する
- C. Circle に abstract を付ける
- D. Base の name() を削除する
- E. Circle に `public String name() { return "circle"; }` を追加する

## 解説
Base は Shape の name() だけを実装し、area() は残しています。Circle は abstract が付いていないので、残っている **area() を実装しなければなりません**。

- A: area() を public で実装するので OK。
- B: インタフェースのメソッドは暗黙に public です。修飾子なしは狭くなるのでエラー。
- C: Circle を抽象クラスにすれば、area() を実装しないままでかまいません。OK。
- D: name() も実装されていない状態になり、エラーが増えるだけです。
- E: name() は Base で実装済みです。area() が無いままなのでエラーは消えません。
