次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        try {
            String s = null;
            System.out.print("1");
            s.length();
            System.out.print("2");
        } catch (NullPointerException e) {
            System.out.print("3");
        } catch (RuntimeException e) {
            System.out.print("4");
        } finally {
            System.out.print("5");
        }
    }
}
```

- A. 「1345」と表示される
- B. 「135」と表示される
- C. 「12345」と表示される
- D. 「15」と表示される
- E. 「1」と表示されたあと、NullPointerException がスローされる

## 解説
1. 「1」を表示
2. null の s で `length()` を呼ぶので NullPointerException。try の残り（「2」）は飛ばされる
3. catch は上から順に調べ、最初に合った `catch (NullPointerException e)` だけが実行されて「3」。NullPointerException は RuntimeException の子でもありますが、2つ目の catch は実行されません
4. finally で「5」

よって「135」です。
