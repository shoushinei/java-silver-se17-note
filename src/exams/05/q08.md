次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String s = "Java";
        System.out.println(s.charAt(1) + s.length());
        System.out.println("" + s.charAt(1) + s.length());
    }
}
```

- A. 「a4」「a4」と表示される
- B. 「101」「101」と表示される
- C. 「101」「a4」と表示される
- D. 「a4」「101」と表示される
- E. コンパイルエラーが発生する

## 解説
- 4 行目: `s.charAt(1)` は char の 'a'、`s.length()` は int の 4 です。String が出てこないので、char と int の**足し算**になります。'a' の文字コード 97 に 4 を足して「101」。
- 5 行目: 先頭の `""` が String なので、左から順に**連結**されます。"" + 'a' で "a"、そこに 4 をつないで「a4」。
