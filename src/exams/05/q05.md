次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
interface Greeter {
    String name();
    default String greet() {
        return "Hi " + name();
    }
}
class Base {
    public String greet() {
        return "Hello";
    }
}
class P extends Base implements Greeter {
    public String name() {
        return "P";
    }
}
class Q implements Greeter {
    public String name() {
        return "Q";
    }
    public String greet() {
        return Greeter.super.greet() + "!";
    }
}
public class Main {
    public static void main(String[] args) {
        Greeter p = new P();
        Greeter q = new Q();
        System.out.println(p.greet() + "," + q.greet());
    }
}
```

- A. 「Hello,Hi Q!」と表示される
- B. 「Hi P,Hi Q!」と表示される
- C. 「Hello,Hi Q」と表示される
- D. 「Hi P,Hello!」と表示される
- E. P クラスで greet が衝突するため、コンパイルエラーが発生する
- F. Q クラスの `Greeter.super.greet()` の書き方が誤っているため、コンパイルエラーが発生する

## 解説
- **P**: 親クラス Base の `greet()` と、Greeter の default の `greet()` を両方受け継ぎます。**クラスから受け継いだメソッドが常に勝つ**ので、エラーにはならず Base の greet が使われ「Hello」。
- **Q**: 自分で greet をオーバーライドし、`Greeter.super.greet()` で Greeter の default を呼んでいます（直接 implements しているインタフェースの default は、この書き方で呼べます）。default の中の `name()` は、実体の Q の name() なので "Hi Q"。そこに "!" を足して「Hi Q!」。

よって「Hello,Hi Q!」です。
