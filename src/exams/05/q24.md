次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int[] codes = {1, 2, 3, 2};
        int total = 0;
        for (int c : codes) {
            total += switch (c) {
                case 1 -> 10;
                case 2 -> {
                    int t = total;
                    yield t + 1;
                }
                default -> -total;
            };
        }
        System.out.println(total);
    }
}
```

- A. 「1」と表示される
- B. 「0」と表示される
- C. 「22」と表示される
- D. 「43」と表示される
- E. コンパイルエラーが発生する

## 解説
1周ずつ total を追います。

| c | switch 式の値 | total |
|---|---|---|
| 1 | 10 | 0 + 10 = 10 |
| 2 | t = 10 なので 11 | 10 + 11 = 21 |
| 3 | default で −21 | 21 − 21 = 0 |
| 2 | t = 0 なので 1 | 0 + 1 = 1 |

よって「1」です。アローの switch 式は一致した case の値を1つ返すだけで、下へ流れません。ブロック `{ }` の中では yield で値を返します。
