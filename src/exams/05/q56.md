javac コマンドと java コマンドについての説明として、正しいものを選びなさい。

- A. java コマンドには、クラス名に拡張子 .class を付けて渡す
- B. javac でコンパイルすると、.java ファイルが .class ファイルに置き換えられ、.java ファイルは残らない
- C. javac コマンドには、ファイル名を拡張子 .java まで付けて渡す
- D. java コマンドの -d オプションで、クラスファイルを書き出す場所を指定する
- E. `java Hello.java` のように .java のファイルを渡すと、クラスファイルを作らずにそのまま実行できる

## 解説
- A: 誤り。java にはクラス名だけを渡します（`java Hello`）。`java Hello.class` は「Hello.class というクラス」を探して失敗します。
- B: 誤り。.class ファイルが新しく作られるだけで、.java ファイルはそのまま残ります。
- C: 正しい。`javac Hello.java` のように拡張子まで書きます。`javac Hello` ではエラーです。
- D: 誤り。-d はクラスファイルの書き出し先を指定する **javac** のオプションです。
- E: 正しい。ソースファイルモードと呼ばれ、メモリの中でコンパイルしてそのまま実行します。.class は作られません。

## 検証
@case C: javac は .java まで付ける（付けないと失敗）
@file Hello.java
public class Hello { public static void main(String[] args) { System.out.println("hi"); } }
@sh javac Hello
@fails
@sh javac Hello.java
@sh java Hello
@stdout
hi
@end

@case A は誤り: java Hello.class は失敗する
@file Hello.java
public class Hello { public static void main(String[] args) { System.out.println("hi"); } }
@sh javac Hello.java
@sh java Hello.class
@fails

@case E: ソースファイルモードで実行でき、.class は作られない
@file Hello.java
public class Hello { public static void main(String[] args) { System.out.println("hi"); } }
@sh java Hello.java
@stdout
hi
@end
@sh java -cp . Hello
@fails
