  - c2-s11 配列の変数には配列への参照が入る。b = a とすると、同じ配列を2つの変数が指す。a に別の配列を入れ直しても、b は元の配列を指したまま
---
次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        int[] b = a;
        b[0] = 9;
        a = new int[] {4, 5, 6};
        b[1] = a[1];
        System.out.println(a[0] + "" + b[0] + b[1]);
    }
}
```

- A. 「445」と表示される
- B. 「945」と表示される
- C. 「18」と表示される
- D. 「495」と表示される
- E. 「995」と表示される

## 解説
| 行 | 処理 | a が指す配列 | b が指す配列 |
|---|---|---|---|
| 3・4 | b は a と**同じ配列**を指す | {1, 2, 3} | 同じもの |
| 5 | b[0] = 9（共有している配列が変わる） | {9, 2, 3} | 同じもの |
| 6 | a に**新しい配列**を入れ直す | {4, 5, 6} | {9, 2, 3}（元のまま） |
| 7 | b[1] = a[1] | {4, 5, 6} | {9, 5, 3} |

最後の行は、先頭の a[0] と "" をつなぐので文字列の連結になり、4・9・5 をつないで「495」です。
