次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Box {
    int size;
}
public class Main {
    static void update(Box b) {
        b.size = 5;
        b = new Box();
        b.size = 9;
    }
    public static void main(String[] args) {
        Box x = new Box();
        x.size = 1;
        update(x);
        System.out.println(x.size);
    }
}
```

- A. 「5」と表示される
- B. 「9」と表示される
- C. 「1」と表示される
- D. 「0」と表示される

## 解説
update には、x が指している Box への参照のコピーが渡ります。

1. `b.size = 5`: b は x と同じ Box を指しているので、x.size も 5 になる
2. `b = new Box()`: 引数 b に別の Box を入れ直す。x は元の Box を指したまま
3. `b.size = 9`: 新しい Box の size が 9 になるだけ

よって「5」です。
