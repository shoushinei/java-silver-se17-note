次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int n = 7;
        String r = n % 2 == 0 ? "even" : n > 5 ? "big" : "small";
        System.out.println(r);
    }
}
```

- A. 「big」と表示される
- B. 「even」と表示される
- C. 「small」と表示される
- D. コンパイルエラーが発生する

## 解説
`n % 2 == 0 ? "even" : (n > 5 ? "big" : "small")` と読みます。

1. 7 % 2 は 1 なので `n % 2 == 0` は false。後ろの式へ
2. `n > 5` は true なので "big"

よって「big」です。
