次のコードの `// insert code here` の位置に記述したとき、コンパイルが成功するものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        try {
            System.out.println(Integer.parseInt(args[0]));
        }
        // insert code here
    }
}
```

- A. `catch (RuntimeException | IllegalArgumentException e) { }`
- B. `catch (IllegalArgumentException | IllegalStateException e) { }`
- C. `catch (IllegalArgumentException | IllegalStateException e) { e = null; }`
- D. `catch (IllegalArgumentException e | IllegalStateException e) { }`

## 解説
- A: IllegalArgumentException は RuntimeException の子です。継承関係のある型は multi-catch に並べられません（親だけで足りるため）。エラー。
- B: 親子関係の無い2つの型を並べた正しい形。OK。
- C: multi-catch の変数は暗黙に final なので、代入できません。エラー。
- D: 変数は最後に1つだけ書きます。型ごとに変数名は書けません。エラー。
