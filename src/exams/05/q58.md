次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String[] names = {"A", null, "C"};
        for (String n : names) {
            System.out.print(n + ",");
        }
    }
}
```

- A. 「A,C,」と表示される
- B. 「A,,C,」と表示される
- C. 「A,null,C,」と表示される
- D. 「A,」と表示されたあと、NullPointerException がスローされる

## 解説
配列の2つ目の要素は null です。null を文字列と + でつなぐと "null" という文字になり、例外にはなりません（例外になるのは、null に対してメソッドを呼んだときなどです）。拡張 for 文も、null の要素を飛ばさずに取り出します。

よって「A,null,C,」です。
