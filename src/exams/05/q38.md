次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class A {
    int x = init("F");
    {
        System.out.print("B");
    }
    A() {
        System.out.print("C");
    }
    int init(String s) {
        System.out.print(s);
        return 1;
    }
}
public class Main {
    public static void main(String[] args) {
        new A();
    }
}
```

- A. 「CFB」と表示される
- B. 「BFC」と表示される
- C. 「FBC」と表示される
- D. 「FCB」と表示される
- E. コンパイルエラーが発生する

## 解説
new A() では、コンストラクタの本体より先に、インスタンス変数の初期化と初期化ブロックが**書いた順に**実行されます。

1. `int x = init("F");` で init が呼ばれて「F」
2. 初期化ブロックで「B」
3. コンストラクタの本体で「C」

よって「FBC」です。フィールドの初期化式からメソッドを呼ぶこともできます。
