次のプログラムを、あとに示すコマンドで実行したときの結果として、正しいものを選びなさい。

```java title=Calc.java
public class Calc {
    public static void main(String[] args) {
        int sum = 0;
        for (String a : args) {
            try {
                sum += Integer.parseInt(a);
            } catch (NumberFormatException e) {
                sum += 100;
            }
        }
        System.out.println(args.length + ":" + sum);
    }
}
```

```console
> javac Calc.java
> java Calc 3 "4 5" x
```

- A. 「4:112」と表示される
- B. 「3:103」と表示される
- C. 「3:7」と表示される
- D. 「4:12」と表示される
- E. 「3:203」と表示される
- F. 実行時に NumberFormatException がスローされる

## 解説
`"4 5"` は引用符で囲まれているので、空白を含めて**1つの引数**です。args は {"3", "4 5", "x"} で、args.length は 3 です。

| 引数 | parseInt | sum |
|---|---|---|
| "3" | 3 | 3 |
| "4 5" | 空白があるので NumberFormatException → catch で 100 | 103 |
| "x" | 数字ではないので NumberFormatException → catch で 100 | 203 |

よって「3:203」です。例外はループの中の catch で処理されるので、外には出ません（F は誤り）。A は、引用符を無視して4つの引数と考えた場合の結果です。
