次のクラスの `// insert code here` に挿入したとき、コンパイルが成功するコードを選びなさい。

```java title=Item.java
public class Item {
    int x;
    // insert code here
}
```

- A. `public Item(int x) { this.x = x; }`
- B. `Item(int x) { return x; }`
- C. `static Item() { }`
- D. `Item() { this(0); }`
- E. `private Item() { }`
- F. `final Item() { }`

## 解説
- A: 正しいコンストラクタ。OK。
- B: コンストラクタは値を return できません。エラー。
- C: コンストラクタに static は付けられません。エラー。
- D: `this(0)` は int を受け取るコンストラクタを呼びますが、このクラスにはそのコンストラクタがありません（挿入するのはこの1つだけ）。エラー。
- E: コンストラクタは private にもできます（クラスの外から new させたくないとき）。OK。
- F: コンストラクタに final は付けられません。エラー。
