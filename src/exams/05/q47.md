次のうち、「B」と表示されるコードを選びなさい。

- A. `System.out.print('A' + 1);`
- B. `System.out.print((char) 66);`
- C. `System.out.print("A" + 1);`
- D. `System.out.print((int) 'B');`
- E. `System.out.print((char) ('A' + 1));`

## 解説
- A: char と int の計算なので int になり、65 + 1 で「66」。
- B: 66 を char にキャストすると、文字コード 66 の「B」。
- C: String と int の連結で「A1」。
- D: 'B' を int にキャストすると、文字コードの「66」。
- E: 括弧の中の 'A' + 1 は int の 66。それを char にキャストして「B」。
