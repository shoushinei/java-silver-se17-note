次の2つのクラスがあります。

```java title=Timer.java
public class Timer {
    private int seconds;
    protected String label = "timer";

    public Timer(int seconds) {
        this.seconds = seconds;
    }
    public void tick() {
        if (seconds > 0) {
            seconds--;
        }
    }
    public int left() {
        return seconds;
    }
    @Override
    public String toString() {
        return label + ":" + seconds;
    }
}
```

```java title=Alarm.java
public class Alarm extends Timer {
    private boolean rang;

    public Alarm(int seconds) {
        super(seconds);
        label = "alarm";
    }
    @Override
    public void tick() {
        super.tick();
        if (left() == 0) {
            rang = true;
        }
    }
    public boolean rang() {
        return rang;
    }
}
```

これらのクラスについての説明として、正しいものを選びなさい。

- A. `Timer t = new Alarm(1); t.tick();` を実行したあと、`t.toString()` は "alarm:0" を返す
- B. Alarm のメソッドの中から、seconds フィールドを直接読める
- C. `new Alarm(2)` を作って tick() を1回だけ呼んだとき、rang() は false を返す
- D. Alarm に引数なしのコンストラクタが無いため、`new Alarm(5)` はコンパイルエラーになる
- E. `Timer t = new Alarm(1);` のあとで `t.rang()` と書いても、コンパイルできる
- F. Alarm のコンストラクタから `super(seconds);` の行を消すと、コンパイルエラーになる

## 解説
- A: 正しい。実体は Alarm なので Alarm の tick() が動き、super.tick() で seconds が 0 になります。label は Alarm のコンストラクタで "alarm" に変わっているので "alarm:0"。
- B: 誤り。seconds は Timer の private フィールドなので、子の Alarm から直接は使えません（left() を通して読みます）。
- C: 正しい。2 → 1 になるだけで 0 ではないので、rang は false のままです。
- D: 誤り。`Alarm(int)` があるので、`new Alarm(5)` は問題ありません。
- E: 誤り。変数の型は Timer で、Timer に rang() はありません。呼べるメソッドは変数の型で決まります。
- F: 正しい。消すと暗黙の `super()` が入りますが、Timer には引数なしのコンストラクタが無いのでエラーです。
