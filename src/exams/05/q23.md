次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        var x = 10;
        var y = x / 4.0;
        var z = 'A' + 1;
        var w = x / 4;
        System.out.println(y + " " + z + " " + w);
    }
}
```

- A. 「2.5 B 2」と表示される
- B. 「2 66 2」と表示される
- C. 「2.5 66 2.5」と表示される
- D. 「2.5 B 2.5」と表示される
- E. 「2.5 66 2」と表示される
- F. コンパイルエラーが発生する

## 解説
var の型は、右辺の式の型で決まります。

- `y = x / 4.0`: int と double の計算なので double。10 / 4.0 = 2.5
- `z = 'A' + 1`: char と int の計算なので **int**。'A' の文字コード 65 + 1 = 66（char の 'B' にはならない）
- `w = x / 4`: int 同士なので int。10 / 4 = 2（切り捨て）

よって「2.5 66 2」です。
