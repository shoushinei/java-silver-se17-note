次のプログラムの `// insert code here` の位置に記述したとき、コンパイルが成功するコードを選びなさい。

```java title=Main.java
public class Main {
    static final int MAX = 3;
    public static void main(String[] args) {
        int n = Integer.parseInt(args[0]);
        int k = 5;
        switch (n) {
            case 0:
                System.out.println("zero");
                break;
            // insert code here
                System.out.println("other");
        }
    }
}
```

- A. `case k:`
- B. `case 1, 2:`
- C. `case "1":`
- D. `case MAX:`
- E. `case 3L:`
- F. `case 1 + 4:`

## 解説
case のラベルには、コンパイルの時点で値が決まる**定数**しか書けません。また、switch に渡した値（int）と合う型でなければなりません。

- A: k は final の付いていないふつうの変数なので、定数ではありません。エラー。
- B: カンマで複数の値を並べられます。OK。
- C: "1" は String で、int の switch には書けません。エラー。
- D: MAX は `static final` で、定数で初期化されているので定数です。OK。
- E: 3L は long です。long は switch に使えず、int のラベルにもなりません。エラー。
- F: `1 + 4` はリテラルだけの計算（定数式）なので、5 という定数として扱われます。OK。
