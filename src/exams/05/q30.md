次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Res implements AutoCloseable {
    private final String id;
    Res(String id) {
        this.id = id;
        System.out.print("O" + id + " ");
    }
    public void close() {
        System.out.print("C" + id + " ");
    }
}
public class Main {
    public static void main(String[] args) {
        try (Res a = new Res("1"); Res b = new Res("2")) {
            System.out.print("B ");
            throw new IllegalStateException();
        } catch (IllegalStateException e) {
            System.out.print("E ");
        } finally {
            System.out.print("F");
        }
    }
}
```

- A. 「O1 O2 B C1 C2 E F」と表示される
- B. 「O1 O2 B E C2 C1 F」と表示される
- C. 「O1 O2 B C2 C1 E F」と表示される
- D. 「O1 O2 B E F C2 C1」と表示される
- E. 「O1 O2 B C2 C1 F」と表示される

## 解説
1. ( ) の中で a、b の順に作られる。「O1 O2」
2. 本体で「B」を表示し、例外を投げる
3. try ブロックを抜けるときに、**作ったのと逆の順**（b → a）に閉じる。「C2 C1」
4. 閉じたあとで catch へ。「E」
5. 最後に finally。「F」

よって「O1 O2 B C2 C1 E F」です。閉じる処理は catch や finally より先です（B・D は誤り）。
