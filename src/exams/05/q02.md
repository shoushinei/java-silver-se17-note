次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String s = "Java";
        String t = s;
        s = s.toUpperCase();
        t.concat("SE");
        t = t + s.charAt(1);
        System.out.println(s + " " + t + " " + (t == s));
    }
}
```

- A. 「JAVA JAVAA false」と表示される
- B. 「JAVA JavaSEA false」と表示される
- C. 「Java Javaa false」と表示される
- D. 「JAVA JavaA false」と表示される
- E. 「JAVA JavaA true」と表示される

## 解説
| 行 | 処理 | s | t |
|---|---|---|---|
| 3・4 | t は s と同じ "Java" を指す | "Java" | "Java" |
| 5 | toUpperCase は新しい "JAVA" を返し、**s だけ**に入れ直す | "JAVA" | "Java"（元のまま） |
| 6 | concat の戻り値を代入していないので、何も変わらない | "JAVA" | "Java" |
| 7 | s.charAt(1) は 'A'。"Java" + 'A' | "JAVA" | "JavaA" |

t と s は別の String なので `t == s` は false。よって「JAVA JavaA false」です。

- A: t が s と一緒に大文字になると考えた誤りです。String は不変で、s に入れ直しても t は元の "Java" を指したままです。
- B: concat の戻り値を代入していないことを見落とした誤りです。
