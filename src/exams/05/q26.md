---
次のクラスがあります。

```java title=Item.java
public class Item {
    int id;
    String name;
    Item(int id) {
        this.id = id;
    }
    Item(String name) {
        this.name = name;
    }
}
```

同じパッケージの別のクラスのメソッドに記述したとき、コンパイルが成功するコードを選びなさい。

- A. `new Item("a");`
- B. `new Item();`
- C. `new Item(1L);`
- D. `new Item(1, "a");`
- E. `new Item(1);`

## 解説
- A: `Item(String)` に合うので OK。
- B: コンストラクタを書いているので、引数なしのデフォルトコンストラクタは作られません。エラー。
- C: 1L は long です。long は int に暗黙では変換できないので、`Item(int)` には渡せません。エラー。
- D: int と String の2つを受け取るコンストラクタはありません。エラー。
- E: `Item(int)` に合うので OK。
