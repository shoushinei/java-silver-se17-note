次のプログラムを `java Main`（引数なし）で実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int x;
        if (args.length > 0) {
            x = 1;
        } else {
            x = 2;
        }
        System.out.println(x);
    }
}
```

- A. 「1」と表示される
- B. 「2」と表示される
- C. 「0」と表示される
- D. x が初期化されていない可能性があるため、コンパイルエラーが発生する
- E. 実行時に例外がスローされる

## 解説
ローカル変数 x は宣言しただけで値が入っていませんが、if と else の**両方**で代入しているので、どちらを通っても代入済みになります。コンパイラもそう判断するので、コンパイルエラーにはなりません（else が無ければエラーです）。

引数なしで実行すると args.length は 0 なので、else 側で x に 2 が入り「2」と表示されます。
