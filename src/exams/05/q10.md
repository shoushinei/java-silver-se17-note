次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int a = 5, b = 0;
        boolean r = (b != 0 && a / b > 1) || a > 3;
        System.out.println(r + " " + b);
    }
}
```

- A. 実行時に ArithmeticException がスローされる
- B. 「false 0」と表示される
- C. コンパイルエラーが発生する
- D. 「true 0」と表示される

## 解説
1. 括弧の中の `b != 0` は false です。`&&` は左が false なら結果が false に決まるので、右の `a / b > 1` は**評価されません**。0 で割る計算は実行されないので、例外は起きません（A は誤り）。
2. 括弧の結果は false なので、`||` の右の `a > 3` を評価します。true。
3. r は true、b は 0 のままです。

よって「true 0」です。
