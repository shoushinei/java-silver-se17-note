次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static int f(String s) {
        int r = 0;
        try {
            r = Integer.parseInt(s);
            return r;
        } catch (NumberFormatException e) {
            r = -1;
            return r;
        } finally {
            r = 100;
            System.out.print("F");
        }
    }
    public static void main(String[] args) {
        System.out.println(f("7") + f("x"));
    }
}
```

- A. 「6FF」と表示される
- B. 「FF200」と表示される
- C. 「FF6」と表示される
- D. 「FF99」と表示される
- E. 実行時に NumberFormatException がスローされる

## 解説
- `f("7")`: r は 7 になり、`return r;` の時点で戻り値 7 が決まる。そのあと finally で r を 100 にして「F」を表示するが、戻り値は 7 のまま。
- `f("x")`: parseInt で NumberFormatException が発生し、catch へ。r を -1 にして `return r;` で戻り値 -1 が決まる。finally で「F」。

main の println は、引数の `f("7") + f("x")` を計算し終えてから表示します。計算の途中で「F」が2回表示され、そのあと 7 + (−1) = 6 が表示されるので「FF6」です。

- B・D: finally で r を 100 にしても、すでに決まった戻り値は変わりません。
- E: 例外は f の中の catch で処理されています。
