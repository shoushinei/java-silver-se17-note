次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder("abcdef");
        sb.delete(1, 3).append("X");
        System.out.println(sb + " " + sb.length());
    }
}
```

- A. 「adefX 5」と表示される
- B. 「aefX 4」と表示される
- C. 「adef 4」と表示される
- D. 「abcdefX 7」と表示される

## 解説
1. `delete(1, 3)`: 位置 1 から、位置 3 の**手前**まで（b と c）を削除して "adef"
2. `.append("X")`: delete は自分自身を返すので、続けて "adefX" になる

StringBuilder は自分自身を書き換えるので、戻り値を代入しなくても sb は "adefX"、長さは 5 です。B は終了の位置まで含めて削除した場合、D は StringBuilder が変わらないと考えた場合です。
