次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
import java.util.List;

class Item {
    String name;
    Item(String name) {
        this.name = name;
    }
    @Override
    public String toString() {
        return "Item:" + name;
    }
}
public class Main {
    public static void main(String[] args) {
        List<Item> list = List.of(new Item("a"), new Item("b"));
        System.out.println(list);
    }
}
```

- A. 「Item:a Item:b」と表示される
- B. 「[a, b]」と表示される
- C. 「[Item@1b6d3586, Item@4554617c]」のような形で表示される
- D. 「[Item:a, Item:b]」と表示される
- E. コンパイルエラーが発生する

## 解説
List を println すると、`[要素, 要素]` の形で表示されます。各要素は toString() で文字列にされ、Item は toString をオーバーライドしているので "Item:a" と "Item:b" になります。よって「[Item:a, Item:b]」です。

C の形になるのは、Item が toString をオーバーライドしていない場合です。
