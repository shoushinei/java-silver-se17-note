次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static {
        System.out.print("S");
    }
    {
        System.out.print("I");
    }
    Main() {
        System.out.print("C");
    }
    public static void main(String[] args) {
        System.out.print("M");
        new Main();
    }
}
```

- A. 「SMIC」と表示される
- B. 「MSIC」と表示される
- C. 「SICM」と表示される
- D. 「MIC」と表示される
- E. コンパイルエラーが発生する

## 解説
1. main を実行するために Main クラスが準備され、そのときに static 初期化ブロックが動く。「S」
2. main の中で「M」
3. `new Main()` で、インスタンス初期化ブロック「I」、コンストラクタの本体「C」

よって「SMIC」です。static 初期化ブロックは main より先に動きます（B・D は誤り）。インスタンス側は new したときに初めて動きます（C は誤り）。
