次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
interface A {
    void a();
}
interface B extends A {
    void b();
    default void c() {
        a();
        b();
    }
}
class X implements B {
    public void a() { System.out.print("a"); }
    public void b() { System.out.print("b"); }
}
public class Main {
    public static void main(String[] args) {
        B x = new X();
        x.c();
        A y = x;
        y.a();
    }
}
```

- A. 「ab」と表示される
- B. 「aba」と表示される
- C. 「abab」と表示される
- D. X が A を直接 implements していないため、コンパイルエラーが発生する
- E. `A y = x;` でコンパイルエラーが発生する

## 解説
B は A を extends しているので、B を実装する X は、A の a() と B の b() の両方を実装する必要があり、実際に実装しています。X は B を通して A の子でもあるので、A を直接書かなくてもかまいません（D は誤り）。B 型の x を A 型の変数に入れるのも、子から親への代入なので OK です（E は誤り）。

- `x.c()`: default メソッド c() の中で a() と b() を呼ぶ。実体は X なので「a」「b」
- `y.a()`: 実体は同じ X なので「a」

よって「aba」です。
