次のクラスがあります。

```java title=TextReader.java
import java.io.*;

class Reader {
    void read() throws IOException {
    }
}
public class TextReader extends Reader {
    // insert code here
}
```

`// insert code here` の位置に記述したとき、コンパイルが成功するコードを選びなさい。

- A. `void read() throws Exception { }`
- B. `void read() { }`
- C. `private void read() { }`
- D. `void read() throws FileNotFoundException { }`
- E. `int read() { return 0; }`

## 解説
親の read() は IOException を throws に書いています。オーバーライドするメソッドの throws には、**親と同じか、その子の検査例外**しか書けません。

- A: Exception は IOException の親なので、広げることになりエラー。
- B: throws を書かない（例外を投げない）のは自由です。OK。
- C: 修飾子なし → private とアクセスを狭めているのでエラー。
- D: FileNotFoundException は IOException の子なので OK。
- E: 引数が同じで戻り値の型だけが違う（void と int）のでエラー。
