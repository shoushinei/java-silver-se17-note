次のプログラムをコンパイルしたとき、コンパイルエラーになる行を選びなさい。

```java title=Main.java
public class Main {
    static void m(final int x, int[] arr) {
        final int[] a = arr;
        a[0] = x;
        final int y = 10;
        int z = y + 1;
        x++;
        a = new int[1];
        System.out.println(z);
    }
}
```

- A. 4 行目
- B. 6 行目
- C. 7 行目
- D. 8 行目
- E. 9 行目

## 解説
- 4 行目: a は final ですが、変えているのは配列の**中身**（a[0]）なので OK。
- 6 行目: final の y を読むだけなので OK。
- 7 行目: 引数 x は final です。`x++` は x への再代入なので**エラー**。
- 8 行目: a に別の配列を入れ直そうとしているので**エラー**。final の参照型は、指す先を変えられません。
- 9 行目: OK。

（javac は、8 行目のようなエラーを先に見つけると、7 行目のエラーを同時には表示しないことがあります。どちらもコンパイルエラーです。）
