作業ディレクトリの下に、次のファイルがあります。

```java title=src/app/Main.java
package app;

public class Main {
    public static void main(String[] args) {
        System.out.println(args.length);
    }
}
```

作業ディレクトリで `javac -d out src/app/Main.java` を実行し、コンパイルは成功しました。続けて実行したとき、「2」と表示されるコマンドを選びなさい。

- A. `java -cp out app.Main x y`
- B. `java -cp out Main x y`
- C. `java out.app.Main x y`
- D. `java app.Main -cp out x y`
- E. `java -classpath out app.Main x y`
- F. `java -cp out app.Main "x y"`

## 解説
クラスファイルは out/app/Main.class にできています。-cp で起点の out を指定し、パッケージ名付きの `app.Main` を渡します。

- A: 正しい形。引数は x と y の2つで「2」。
- B: クラス名はパッケージ名付き（app.Main）で書く必要があります。実行できません。
- C: out はパッケージ名ではありません。実行できません。
- D: java のオプションは**クラス名より前**に書きます。クラス名の後ろの `-cp out` は引数として扱われ、-cp が無いのでカレントディレクトリから app.Main を探して見つかりません。
- E: `-classpath` は `-cp` の長い書き方です。「2」。
- F: `"x y"` は1つの引数なので「1」と表示されます。
