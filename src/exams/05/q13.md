次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int[] a = new int[3];
        String[] s = new String[2];
        boolean[] f = new boolean[1];
        System.out.println(a[1] + " " + s[1] + " " + f[0] + " " + a.length);
    }
}
```

- A. 「0  false 3」と表示される
- B. 「null null null 3」と表示される
- C. 「0 null false 3」と表示される
- D. 「0 null false 2」と表示される
- E. コンパイルエラーが発生する

## 解説
new で作った配列の要素には、型ごとの既定値が入ります。int は 0、String（参照型）は null、boolean は false です。null を文字列につなぐと「null」と表示されます（空文字にはなりません）。a.length は作ったときの要素数 3 です。
