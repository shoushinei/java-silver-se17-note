次の2つの例外クラスがあります。

```java title=Errors.java
class AppException extends Exception {
}
class AppError extends RuntimeException {
}
```

同じパッケージの別のクラスに記述したとき、コンパイルが成功するメソッドを選びなさい。

- A. `void a() { throw new AppException(); }`
- B. `void b() throws AppError { throw new AppException(); }`
- C. `void c() { throw new AppError(); }`
- D. `void d() { try { throw new AppException(); } catch (AppError e) { } }`
- E. `void e() throws AppException { throw new AppException(); }`

## 解説
AppException は Exception の子なので**検査例外**、AppError は RuntimeException の子なので**非検査例外**です。

- A: 検査例外を投げるのに、catch も throws もありません。エラー。
- B: throws に書いた AppError は AppException の親ではないので、AppException を任せたことになりません。エラー。
- C: 非検査例外は throws なしで投げられます。OK。
- D: catch の AppError では AppException を捕まえられません。エラー。
- E: throws AppException と書いているので OK。
