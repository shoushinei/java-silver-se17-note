次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>(List.of("a", "b", "c"));
        for (String s : list) {
            System.out.print(s);
            if (s.equals("b")) {
                list.remove(s);
            }
        }
        System.out.println(" " + list);
    }
}
```

- A. 「abc [a, c]」と表示される
- B. 「ab [a, c]」と表示される
- C. 「ab」と表示されたあと、ConcurrentModificationException がスローされる
- D. 「abc」と表示されたあと、ConcurrentModificationException がスローされる
- E. コンパイルエラーが発生する

## 解説
拡張 for 文は、裏で「次の要素があるか（今の位置 < 要素の数）」を確かめながら進みます。

1. "a" を表示
2. "b" を表示し、"b" を削除。リストは [a, c]（要素数 2）になる
3. 次の周に進む前の確認で、今の位置（2 つ取り出したので 2）と要素数（2）が同じなので、「もう次は無い」と判断して**ループが終わる**

"b" は**最後から2番目**の要素だったので、例外にならずに静かに終わり、"c" は表示されません。最後に「 [a, c]」を表示して「ab [a, c]」です。

最後から2番目以外（たとえば "a"）を削除すると、次の周で ConcurrentModificationException がスローされます。
