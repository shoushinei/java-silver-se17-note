次の2つのクラスは、同じパッケージ shop にあります。

```java title=shop/Item.java
package shop;

public class Item {
    public String name = "pen";
    protected int price = 100;
    int stock = 5;
    private String code = "X1";
}
```

```java title=shop/Main.java
package shop;

public class Main {
    public static void main(String[] args) {
        Item item = new Item();
        // insert code here
    }
}
```

`// insert code here` の位置に記述したとき、コンパイルが成功するコードを選びなさい。

- A. `System.out.println(item.name);`
- B. `System.out.println(item.price);`
- C. `System.out.println(item.code);`
- D. `System.out.println(item.stock);`
- E. `System.out.println(Item.name);`

## 解説
Main は Item と**同じパッケージ**にあります。同じパッケージからは、public・protected・修飾子なしのメンバをすべて使えます。

- A: public。OK。
- B: protected は「同じパッケージ ＋ 別パッケージのサブクラス」から使えます。同じパッケージなので OK。
- C: private は Item の中からしか使えません。エラー。
- D: 修飾子なしは同じパッケージから使えます。OK。
- E: name はインスタンスのフィールドなので、クラス名では使えません。エラー。
