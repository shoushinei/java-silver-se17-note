次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
interface Shape {
    double area();
}
class Sq implements Shape {
    public double area() { return 4; }
}
class Rect implements Shape {
    public double area() { return 6; }
}
public class Main {
    public static void main(String[] args) {
        Shape[] shapes = { new Sq(), new Rect() };
        double sum = 0;
        for (Shape s : shapes) {
            sum += s.area();
        }
        System.out.println(sum);
    }
}
```

- A. 「10」と表示される
- B. 「0.0」と表示される
- C. 「10.0」と表示される
- D. インタフェースの配列は作れないため、コンパイルエラーが発生する
- E. 実行時に例外がスローされる

## 解説
インタフェースは new できませんが、インタフェース型の**配列**は作れ、実装クラスのインスタンスを入れられます（D は誤り）。各要素の area() は実体のクラスのものが動くので、4.0 + 6.0 = 10.0 です。sum は double なので「10.0」と表示されます。
