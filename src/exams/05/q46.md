次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
abstract class A {
    abstract String a();
    String run() {
        return a();
    }
}
abstract class B extends A {
    String b() {
        return "b";
    }
}
class C extends B {
    String a() {
        return "c" + b();
    }
}
public class Main {
    public static void main(String[] args) {
        A x = new C();
        System.out.println(x.run());
    }
}
```

- A. 「b」と表示される
- B. 「c」と表示される
- C. 「bc」と表示される
- D. 「cb」と表示される
- E. B が抽象メソッド a() を実装していないため、コンパイルエラーが発生する

## 解説
B は抽象クラスなので、A の抽象メソッド a() を実装しなくてかまいません（E は誤り）。最初の具象クラスである C が a() を実装しています。

`x.run()` は A の run() で、その中の `a()` は実体の C のものが動きます。C の a() は "c" に b() の "b" をつないで「cb」です。
