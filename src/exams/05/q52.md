次のコードは、Laser クラスでコンパイルエラーになります。

```java title=Printer.java
interface Printer {
    void print(String s);
}
class Laser implements Printer {
    void print(String s) {
        System.out.println(s);
    }
}
```

その理由として、正しいものを選びなさい。

- A. Printer の print に public が付いていないため
- B. Laser の print の戻り値が void のため
- C. インタフェースを implements するクラスは、abstract でなければならないため
- D. インタフェースのメソッドを、static を付けずに実装しているため
- E. Printer の print は暗黙に public なので、修飾子の無い print では、アクセスを狭めることになるため

## 解説
インタフェースの抽象メソッドは、書かなくても**暗黙に public** です。実装はオーバーライドの一種なので、アクセスを狭められません。Laser の print は修飾子なし（public より狭い）なので、エラーになります。`public void print(String s)` と書けば通ります。

- A: Printer の print は public を書かなくても public です。Printer の側は正しく書けています。
- B: 戻り値の型は Printer と同じ void なので問題ありません。
- C: 抽象メソッドをすべて public で実装すれば、ふつうのクラスにできます。
- D: インタフェースのメソッドの実装に static は付けません。
