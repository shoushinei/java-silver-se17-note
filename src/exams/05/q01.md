次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class A {
    A() {
        System.out.print("A");
    }
}
class B extends A {
    B(int n) {
        super();
        System.out.print(n);
    }
}
class C extends B {
    C() {
        super(5);
        System.out.print("C");
    }
}
public class Main {
    public static void main(String[] args) {
        new C();
    }
}
```

- A. 「C5A」と表示される
- B. 「A5C」と表示される
- C. 「5AC」と表示される
- D. 「AC」と表示される
- E. コンパイルエラーが発生する

## 解説
`new C()` から、各コンストラクタの先頭で親のコンストラクタへさかのぼります。

1. C() の `super(5)` で B(int) へ
2. B(int) の `super()` で A() へ。「A」
3. B(int) に戻って「5」
4. C() に戻って「C」

親のコンストラクタが先に終わるので、表示は「A5C」です。B には引数なしのコンストラクタがありませんが、C は `super(5)` で B(int) を呼んでいるので問題ありません。
