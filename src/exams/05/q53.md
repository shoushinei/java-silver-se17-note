次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int[][] m = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
        int found = -1;
        search:
        for (int i = 0; i < m.length; i++) {
            for (int j = 0; j < m[i].length; j++) {
                if (m[i][j] % 4 == 0) {
                    found = i * 10 + j;
                    break search;
                }
            }
        }
        System.out.println(found);
    }
}
```

- A. 「10」と表示される
- B. 「21」と表示される
- C. 「-1」と表示される
- D. 「4」と表示される
- E. コンパイルエラーが発生する

## 解説
4 で割り切れる最初の要素を探します。行 0 の {1, 2, 3} には無く、行 1 の最初の 4（i = 1, j = 0）で見つかります。found は 1 × 10 + 0 = 10 になり、`break search;` で**外側のループごと**抜けます。

B の「21」は、break が内側のループだけを抜けると考えた場合です。そのときは行 2 も調べ、8（i = 2, j = 1）で found が 21 に上書きされます。
