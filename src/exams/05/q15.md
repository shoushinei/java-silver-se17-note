次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
abstract class Base {
    int n = 1;
    Base() {
        n = 10;
    }
    int value() {
        return n;
    }
    abstract int value(int add);
}
class Sub extends Base {
    int n = 2;
    Sub() {
        n = 20;
    }
    int value(int add) {
        return n + add;
    }
}
public class Main {
    public static void main(String[] args) {
        Base b = new Sub();
        System.out.println(b.value() + " " + b.value(1) + " " + b.n);
    }
}
```

- A. 「20 21 20」と表示される
- B. 「10 11 10」と表示される
- C. 「20 21 10」と表示される
- D. 「1 3 1」と表示される
- E. 「10 21 10」と表示される
- F. コンパイルエラーが発生する

## 解説
Sub のインスタンスには、Base の n と Sub の n の**2つのフィールド**があります。

1. `new Sub()` で、まず Base() が動き、Base の n が 10 になる
2. 次に Sub のフィールド初期化と Sub() が動き、Sub の n が 20 になる

- `b.value()`: value() は Base にしかありません。Base のメソッドの中の n は Base の n なので「10」。
- `b.value(1)`: Sub がオーバーライドした value(int) が動き、Sub の n（20）+ 1 で「21」。
- `b.n`: フィールドは変数の型（Base）で決まるので、Base の n で「10」。

よって「10 21 10」です。
