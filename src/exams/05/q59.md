次のコードがあります。

```java title=App.java
interface Config {
    int MAX = 10;
    static int twice(int x) {
        return x * 2;
    }
}
public class App implements Config {
    void run() {
        // insert code here
    }
}
```

`// insert code here` の位置に記述したとき、コンパイルが成功するコードを選びなさい。

- A. `MAX = 20;`
- B. `int a = MAX;`
- C. `int c = Config.twice(MAX);`
- D. `int d = twice(1);`
- E. `Config.MAX++;`

## 解説
- A・E: MAX は暗黙に final の定数なので、代入も `++` もできません。エラー。
- B: インタフェースの定数は、実装クラスから名前だけで読めます。OK。
- C: static メソッドをインタフェース名で呼ぶ正しい形。OK。
- D: インタフェースの static メソッドは実装クラスに受け継がれないので、名前だけでは呼べません。エラー。

## 検証
