次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Counter {
    static int total;
    static void reset() {
        total = 0;
    }
    Counter() {
        total += 2;
    }
}
public class Main {
    public static void main(String[] args) {
        new Counter();
        new Counter();
        Counter.reset();
        Counter c = new Counter();
        System.out.println(Counter.total + " " + c.total);
    }
}
```

- A. 「6 6」と表示される
- B. 「2 2」と表示される
- C. 「2 6」と表示される
- D. 「0 2」と表示される

## 解説
total は static フィールドで、クラスに1つしかありません。

1. 2回 new して total は 4
2. `Counter.reset()` で total は 0
3. もう1回 new して total は 2

`Counter.total` も `c.total` も同じ1つの total を読むので、「2 2」です。
