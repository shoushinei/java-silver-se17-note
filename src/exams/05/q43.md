次のプログラムをコンパイルしたとき、コンパイルエラーになる行を選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Object o = "text";
        String s = (String) o;
        Integer i = (Integer) o;
        Integer j = (Integer) s;
        Object p = (Object) s;
    }
}
```

- A. 4 行目
- B. 5 行目
- C. 6 行目
- D. 7 行目
- E. コンパイルエラーは発生しない

## 解説
- 4 行目: Object から子の String へのキャスト。コンパイルは通り、実体も String なので実行時も OK。
- 5 行目: Object から Integer へのキャスト。Object は Integer の親なので**コンパイルは通ります**（実行すると、実体が String なので ClassCastException）。
- 6 行目: String と Integer は親子関係の無いクラスどうしです。String 型の値が Integer であることはありえないので、**コンパイルエラー**。
- 7 行目: 子から親へのキャストは、書かなくてもできるので OK。
