次のコードが Pay.java に書かれており、コンパイルは成功します。

```java title=Pay.java
public sealed abstract class Pay permits Cash, Card {
}

final class Cash extends Pay {
}

sealed class Card extends Pay permits Credit {
}

final class Credit extends Card {
}
```

このコードについての説明として、正しいものを選びなさい。

- A. Cash の final を abstract に変えても、コンパイルできる
- B. Pay は abstract なので、`new Pay()` とは書けない
- C. sealed を付けたクラスには abstract を付けられないので、Pay の宣言は特別に許されている
- D. Credit を継承したクラスは作れない
- E. Card を直接継承できるのは Credit だけである
- F. Credit の final を消しても、コンパイルできる

## 解説
- A: 誤り。sealed クラスの子には final・sealed・non-sealed のどれかが必要です。abstract はその代わりになりません。
- B: 正しい。抽象クラスは new できません。
- C: 誤り。sealed と abstract はふつうに組み合わせられます（「子は限定するが、親自身は new させない」）。
- D: 正しい。Credit は final なので、継承できません。
- E: 正しい。Card は `permits Credit` なので、Card を直接継承できるのは Credit だけです。
- F: 誤り。Credit も sealed クラス Card の子なので、final・sealed・non-sealed のどれかが必要です。
