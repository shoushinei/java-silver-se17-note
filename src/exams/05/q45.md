次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int x = 0, count = 0;
        do {
            x++;
            if (x % 3 == 0) {
                continue;
            }
            count += x;
        } while (x < 7);
        System.out.println(count);
    }
}
```

- A. 「28」と表示される
- B. 「12」と表示される
- C. 「21」と表示される
- D. 「13」と表示される
- E. ループが終了せず、何も表示されない
- F. 「19」と表示される

## 解説
x を 1 増やしてから、3 の倍数のときは `continue` で足し算を飛ばし、末尾の条件 `x < 7` へ進みます。

| x | 3 の倍数か | count | 条件 x < 7 |
|---|---|---|---|
| 1 | いいえ | 1 | true |
| 2 | いいえ | 3 | true |
| 3 | はい（飛ばす） | 3 | true |
| 4 | いいえ | 7 | true |
| 5 | いいえ | 12 | true |
| 6 | はい（飛ばす） | 12 | true |
| 7 | いいえ | 19 | false で終了 |

よって「19」です。x を増やす処理は continue より前にあるので、無限ループにはなりません（E は誤り）。A は 3 の倍数も足した場合（1〜7 の合計）です。
