抽象クラスについての説明として、正しいものを選びなさい。

- A. 抽象クラスは、new でインスタンスを作れる
- B. 抽象クラスには、抽象メソッドを1つ以上書かなければならない
- C. 抽象クラスを継承したクラスは、必ず抽象クラスになる
- D. 抽象クラスは、コンストラクタを持てる

## 解説
- A: 誤り。抽象クラスは new できません。
- B: 誤り。抽象メソッドが1つも無いクラスにも abstract を付けられます（new させたくないときなど）。
- C: 誤り。受け継いだ抽象メソッドをすべてオーバーライドすれば、ふつうのクラス（具象クラス）にできます。
- D: 正しい。抽象クラスもコンストラクタを持てます。サブクラスのコンストラクタの先頭の super() から呼ばれ、フィールドの初期化などに使います。

## 検証
@case D: 抽象クラスのコンストラクタは子の super() から呼ばれる
@file Main.java
abstract class Shape {
    Shape() { System.out.print("S"); }
}
class Box extends Shape {
    Box() { System.out.print("B"); }
}
public class Main {
    public static void main(String[] args) { new Box(); }
}
@javac
@run Main
@stdout
SB
@end

@case A は誤り
@file Main.java
abstract class Shape { }
public class Main { Shape s = new Shape(); }
@javac-error abstract

@case B は誤り: 抽象メソッドが無くても abstract にできる
@file Shape.java
abstract class Shape { void show() { } }
@javac
