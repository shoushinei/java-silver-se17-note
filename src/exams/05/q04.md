次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String codes = "abd";
        int n = 0;
        for (int i = 0; i < codes.length(); i++) {
            switch (codes.charAt(i)) {
                case 'a':
                    n += 1;
                case 'b':
                    n += 2;
                case 'c':
                    n += 3;
                    break;
                default:
                    n += 4;
            }
        }
        System.out.println(n);
    }
}
```

- A. 「7」と表示される
- B. 「11」と表示される
- C. 「15」と表示される
- D. 「19」と表示される
- E. コンパイルエラーが発生する

## 解説
文字ごとに、一致した case から `break` まで下へ流れます。

| 文字 | 実行される case | 足す数 | n |
|---|---|---|---|
| 'a' | a → b → c（break） | 1 + 2 + 3 | 6 |
| 'b' | b → c（break） | 2 + 3 | 11 |
| 'd' | 一致なし → default | 4 | 15 |

よって「15」です。A の「7」は、フォールスルーせずに一致した case だけを実行すると考えた場合（1 + 2 + 4）です。
