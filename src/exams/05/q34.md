次のコードがあります。

```java title=Main.java
import java.util.ArrayList;
import java.util.List;

class Animal { }
class Dog extends Animal { }

public class Main {
    public static void main(String[] args) {
        List<Animal> animals = new ArrayList<>();
        List<Dog> dogs = new ArrayList<>();
        // insert code here
    }
}
```

`// insert code here` の位置に記述したとき、コンパイルが成功するコードを選びなさい。

- A. `animals.add(new Dog());`
- B. `dogs.add(new Animal());`
- C. `List<Animal> x = dogs;`
- D. `Animal first = dogs.get(0);`
- E. `Dog g = animals.get(0);`

## 解説
- A: Dog は Animal の子なので、`List<Animal>` に入れられます。OK。
- B: Animal は Dog ではないので、`List<Dog>` には入れられません。エラー。
- C: `List<Dog>` は `List<Animal>` の子ではありません（型引数が違うと親子にならない）。エラー。
- D: dogs から取り出すのは Dog で、Dog は Animal に代入できます。OK（実行するとリストが空なので例外になりますが、コンパイルは通ります）。
- E: animals から取り出すのは Animal です。親から子への代入にはキャストが必要です。エラー。
