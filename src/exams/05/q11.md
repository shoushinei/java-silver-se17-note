次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static String f(long x)    { return "L"; }
    static String f(Integer x) { return "I"; }
    static String f(Object x)  { return "O"; }
    static String f(int... x)  { return "V"; }

    public static void main(String[] args) {
        byte b = 1;
        System.out.println(f(b) + f(1.5) + f(Integer.valueOf(1)) + f() + f('c'));
    }
}
```

- A. 「LOIVL」と表示される
- B. 「IOIVI」と表示される
- C. 「LOIVV」と表示される
- D. 「VOIVL」と表示される
- E. どれかの呼び出しがあいまいなため、コンパイルエラーが発生する

## 解説
| 呼び出し | 引数の型 | 選ばれるもの | 表示 |
|---|---|---|---|
| `f(b)` | byte | byte → long の拡大変換で `f(long)` | L |
| `f(1.5)` | double | long には広げられない。Double にボクシングして `f(Object)` | O |
| `f(Integer.valueOf(1))` | Integer | `f(Integer)` に完全一致 | I |
| `f()` | 引数なし | 0個で呼べるのは可変長の `f(int...)` だけ | V |
| `f('c')` | char | char → long の拡大変換で `f(long)` | L |

拡大変換はボクシングより先に試されるので、byte や char は Integer ではなく long のほうへ行きます（B は誤り）。よって「LOIVL」です。
