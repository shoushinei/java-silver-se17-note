次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
record Range(int min, int max) {
    Range {
        if (min > max) {
            throw new IllegalArgumentException("bad");
        }
    }
    int width() {
        return max - min;
    }
}
public class Main {
    public static void main(String[] args) {
        try {
            Range r = new Range(2, 5);
            System.out.print(r.width());
            new Range(5, 2);
            System.out.print("!");
        } catch (IllegalArgumentException e) {
            System.out.print(e.getMessage());
        }
    }
}
```

- A. 「3bad」と表示される
- B. 「3!」と表示される
- C. 「3!bad」と表示される
- D. 「bad」と表示される
- E. コンパイルエラーが発生する

## 解説
`Range { ... }` は引数リストを省略したコンパクトコンストラクタで、new のたびに動きます。

1. `new Range(2, 5)`: min ≤ max なので問題なく作られ、width() は 5 − 2 = 3。「3」
2. `new Range(5, 2)`: min > max なので IllegalArgumentException("bad") が投げられる。try の残り（「!」）は飛ばされる
3. catch でメッセージ「bad」を表示

よって「3bad」です。record にもコンストラクタの処理やメソッドを書けるので、コンパイルエラーにはなりません。
