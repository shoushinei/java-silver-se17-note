次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Animal { }
class Dog extends Animal { }
public class Main {
    public static void main(String[] args) {
        Animal a = new Dog();
        Animal b = new Animal();
        Dog d = new Dog();
        System.out.println((a instanceof Dog) + " " + (b instanceof Dog) + " "
                + (d instanceof Animal));
    }
}
```

- A. 「false false true」と表示される
- B. 「true true true」と表示される
- C. 「true false true」と表示される
- D. 「true false false」と表示される
- E. コンパイルエラーが発生する

## 解説
instanceof は、変数の型ではなく**実体**がその型（またはその子）かを調べます。

- `a instanceof Dog`: a の型は Animal ですが、実体は Dog なので true。
- `b instanceof Dog`: 実体は Animal です。Animal は Dog の子ではないので false。
- `d instanceof Animal`: Dog は Animal の子なので true。

よって「true false true」です。
