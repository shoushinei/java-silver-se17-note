次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        for (int i = 10; i > 0; i -= 3) {
            System.out.print(i);
        }
    }
}
```

- A. 「10741」と表示される
- B. 「1074」と表示される
- C. 「107410」と表示される
- D. 「741」と表示される

## 解説
i は 10 から始まり、本体のあとで 3 ずつ減ります。

- i = 10, 7, 4, 1 のときは `i > 0` が true なので表示
- 1 − 3 = −2 で `i > 0` が false になり終了

表示は 10・7・4・1 をつないで「10741」です。
