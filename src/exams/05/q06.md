次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Point {
    int x, y;
    Point(int x, int y) {
        this.x = x;
        y = y;
    }
    void move(int dx) {
        x += dx;
    }
}
public class Main {
    public static void main(String[] args) {
        Point p = new Point(1, 2);
        p.move(3);
        System.out.println(p.x + "," + p.y);
    }
}
```

- A. 「4,2」と表示される
- B. 「1,2」と表示される
- C. 「1,0」と表示される
- D. 「3,2」と表示される
- E. 「4,0」と表示される

## 解説
- `this.x = x;`: 左はフィールド、右は引数なので、フィールドの x は 1 になります。
- `y = y;`: this が無いので、左も右も**引数**の y です。フィールドの y には何も入らず、既定値の 0 のままです。
- `move(3)`: move には引数 dx しかないので、x はフィールドです。1 + 3 = 4。

よって「4,0」です。
