次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class A {
    static {
        System.out.print("S");
    }
    {
        System.out.print("I");
    }
    A() {
        System.out.print("C");
    }
}
public class Main {
    public static void main(String[] args) {
        new A();
        new A();
    }
}
```

- A. 「SICSIC」と表示される
- B. 「ISCIC」と表示される
- C. 「SCIIC」と表示される
- D. 「SICIC」と表示される
- E. コンパイルエラーが発生する

## 解説
- `static { }`（static 初期化ブロック）は、クラス A を最初に使うときに**1回だけ**動きます。「S」
- `{ }`（インスタンス初期化ブロック）は **new のたび**に、コンストラクタの本体より先に動きます。「I」
- そのあとコンストラクタの本体。「C」

1回目の new で「SIC」、2回目は static が動かないので「IC」。合わせて「SICIC」です。
