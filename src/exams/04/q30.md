次のクラスの `// insert code here` に挿入したとき、コンパイルが成功するコードを選びなさい。

```java title=Child.java
class Parent {
    Object get() {
        return null;
    }
}
public class Child extends Parent {
    // insert code here
}
```

- A. `String get() { return ""; }`
- B. `int get() { return 0; }`
- C. `void get() { }`
- D. `private Object get() { return null; }`

## 解説
オーバーライドするメソッドの戻り値は、親と**同じ型か、そのサブクラス**にできます（共変戻り値）。

- A: String は Object の子なので OK。
- B: int は基本データ型で、Object の子ではありません。エラー。
- C: void は Object の子ではありません。エラー。
- D: 修飾子なし → private とアクセスを狭めているのでエラー。

## 検証
@case 正解 A
@file Child.java
class Parent { Object get() { return null; } }
public class Child extends Parent { String get() { return ""; } }
@javac

@case B は CE
@file Child.java
class Parent { Object get() { return null; } }
public class Child extends Parent { int get() { return 0; } }
@javac-error

@case C は CE
@file Child.java
class Parent { Object get() { return null; } }
public class Child extends Parent { void get() { } }
@javac-error

@case D は CE
@file Child.java
class Parent { Object get() { return null; } }
public class Child extends Parent { private Object get() { return null; } }
@javac-error weaker access
