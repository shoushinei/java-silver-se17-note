次のクラスの `// insert code here` に挿入したとき、コンパイルエラーになるものを選びなさい。

```java title=B.java
class A {
    void show(int x) {
        System.out.println("A");
    }
}
public class B extends A {
    // insert code here
}
```

- A. `@Override void show(int y) { }`
- B. `void show(long x) { }`
- C. `@Override public void show(int x) { }`
- D. `@Override void show(long x) { }`

## 解説
`@Override` は「このメソッドは親のメソッドをオーバーライドしています」という印です。オーバーライドになっていないと、コンパイルエラーになります。

- A: 引数の型が親と同じ int なので、オーバーライドです。引数の名前（x と y）は関係ありません。OK。
- B: 引数の型が long で親と違うので、オーバーロード（新しい別のメソッド）です。@Override が無いので問題ありません。OK。
- C: 引数が同じ int で、アクセスを広げている（修飾子なし → public）だけなので、オーバーライドです。OK。
- D: 引数が long なのでオーバーライドではありません。それなのに @Override を付けているのでエラー。

## 検証
@case A・B・C は通る
@file B.java
class A { void show(int x) { System.out.println("A"); } }
public class B extends A {
    @Override public void show(int y) { }
    void show(long x) { }
}
@javac

@case 正解 D は CE
@file B.java
class A { void show(int x) { System.out.println("A"); } }
public class B extends A { @Override void show(long x) { } }
@javac-error method does not override
