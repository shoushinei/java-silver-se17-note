メソッドの中に記述したとき、コンパイルエラーになるものを選びなさい。

- A. `Integer a = 5;`
- B. `Object b = 5;`
- C. `long c = Integer.valueOf(5);`
- D. `Long d = 5;`

## 解説
- A: int → Integer のボクシング。OK。
- B: int → Integer に包んでから、親の Object として扱う。OK。
- C: Integer → int にほどいてから、long に広げる。OK。
- D: int を Long にするには「long に広げてから包む」の2段階が必要で、これはできません。エラー。`Long d = 5L;` なら OK です。

## 検証
@case A・B・C は通る
@file T.java
class T { void m() { Integer a = 5; Object b = 5; long c = Integer.valueOf(5); } }
@javac

@case 正解 D は CE
@file T.java
class T { void m() { Long d = 5; } }
@javac-error incompatible types
