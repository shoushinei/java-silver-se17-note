次のプログラムをコンパイルしたとき、コンパイルエラーになる行を選びなさい。

```java title=Main.java
import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        var count = 0;
        var name = "Java";
        var list = new ArrayList<String>();
        count = "10";
        list.add(name);
        System.out.println(list + " " + count);
    }
}
```

- A. 5 行目
- B. 6 行目
- C. 7 行目
- D. 8 行目
- E. コンパイルエラーは発生しない

## 解説
var で宣言した変数は、初期化の右辺から型が決まり、そのあと変わりません。

- 5 行目: count は int に決まる
- 6 行目: name は String に決まる
- 7 行目: list は `ArrayList<String>` に決まる
- 8 行目: int の count に String の "10" は入らないので**エラー**

var は「何でも入る型」ではなく、「型を書く手間を省くだけ」です。
