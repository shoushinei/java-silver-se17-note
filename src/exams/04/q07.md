次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        try {
            System.out.print("A");
            int x = 1 / 0;
            System.out.print("B");
        } catch (ArithmeticException e) {
            System.out.print("C");
        } finally {
            System.out.print("D");
        }
    }
}
```

- A. 「ACD」と表示される
- B. 「ABCD」と表示される
- C. 「AD」と表示される
- D. 「ACBD」と表示される
- E. 「A」と表示されたあと、例外で終了する

## 解説
1. 「A」を表示
2. `1 / 0` で ArithmeticException が発生。try の残り（「B」の表示）は**飛ばされる**
3. `catch (ArithmeticException e)` が捕まえて「C」
4. 最後に finally で「D」

よって「ACD」です。例外は catch で処理されたので、プログラムは例外で終了しません。
