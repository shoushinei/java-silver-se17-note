次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Animal {
    String type = "A";
    String getType() {
        return type;
    }
}
class Dog extends Animal {
    String type = "D";
    String getType() {
        return type;
    }
}
public class Main {
    public static void main(String[] args) {
        Animal a = new Dog();
        System.out.println(a.type + a.getType());
    }
}
```

- A. 「AA」と表示される
- B. 「DD」と表示される
- C. 「AD」と表示される
- D. 「DA」と表示される
- E. コンパイルエラーが発生する

## 解説
- `a.type`: **フィールド**はオーバーライドされません。どちらの type を使うかは変数の型（Animal）で決まるので「A」。
- `a.getType()`: **メソッド**はオーバーライドされます。実体の Dog の getType() が呼ばれ、その中の type は Dog のフィールドなので「D」。

よって「AD」です。「フィールドは変数の型、メソッドは実体の型」と覚えておきましょう。
