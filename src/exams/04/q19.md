次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        for (int i = 0; i < 6; i++) {
            if (i == 2) {
                continue;
            }
            if (i == 4) {
                break;
            }
            System.out.print(i);
        }
    }
}
```

- A. 「0134」と表示される
- B. 「01」と表示される
- C. 「013」と表示される
- D. 「01345」と表示される
- E. コンパイルエラーが発生する

## 解説
- i = 0, 1: そのまま表示
- i = 2: `continue` で表示を飛ばし、次の周（i = 3）へ
- i = 3: 表示
- i = 4: `break` でループを抜ける。4 は表示されない

よって「013」です。
