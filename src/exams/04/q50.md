次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
abstract class Shape {
    abstract double area();
}
class Square extends Shape {
    double side = 2;
    double size() {
        return side * side;
    }
}
public class Main {
    public static void main(String[] args) {
        Shape s = new Square();
        System.out.println(s.area());
    }
}
```

- A. コンパイルエラーが発生する
- B. 「4.0」と表示される
- C. 「0.0」と表示される
- D. 実行時に例外がスローされる

## 解説
Square は抽象クラス Shape を継承していますが、抽象メソッド `area()` をオーバーライドしていません（`size()` は名前が違う別のメソッドです）。abstract の付いていないクラスは、受け継いだ抽象メソッドをすべて実装しなければならないので、Square でコンパイルエラーになります。
