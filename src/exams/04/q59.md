次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String[] days = {"SAT", "MON", "TUE"};
        int total = 0;
        for (String d : days) {
            total += switch (d) {
                case "SAT", "SUN" -> 0;
                case "MON" -> 1;
                default -> 2;
            };
        }
        System.out.println(total);
    }
}
```

- A. 「1」と表示される
- B. 「3」と表示される
- C. 「5」と表示される
- D. コンパイルエラーが発生する
- E. 実行時に例外がスローされる

## 解説
アロー形式の switch 式は、一致した case の値を1つだけ返し、下へ流れません。

- "SAT" → `case "SAT", "SUN"` に一致して 0
- "MON" → 1
- "TUE" → どれにも一致しないので default の 2

合計 0 + 1 + 2 = 3 です。switch 式は値を返す式なので、`total +=` の右辺に書けます。
