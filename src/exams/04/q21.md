次の抽象クラスの `// insert code here` に挿入したとき、コンパイルが成功するコードを選びなさい。

```java title=Shape.java
public abstract class Shape {
    // insert code here
}
```

- A. `void move();`
- B. `abstract double area();`
- C. `abstract void draw() { }`
- D. `void show() { }`
- E. `private abstract void hide();`
- F. `static Shape create() { return null; }`

## 解説
- A: abstract が付いていないメソッドには本体 `{ }` が必要です。エラー。
- B: 抽象メソッド（abstract 付き・本体なし）。OK。
- C: 抽象メソッドに本体は書けません（空の `{ }` でも不可）。エラー。
- D: 本体のある具象メソッド。抽象クラスにも書けます。OK。
- E: private メソッドはサブクラスでオーバーライドできないので、abstract と組み合わせられません。エラー。
- F: static メソッドも書けます。OK。

「本体なしなら abstract が必要、abstract なら本体なし」の組み合わせを確かめるのが基本です。
