次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int i = 10;
        do {
            i -= 3;
        } while (i > 5);
        System.out.println(i);
    }
}
```

- A. 「7」と表示される
- B. 「4」と表示される
- C. 「1」と表示される
- D. ループが終了せず、何も表示されない
- E. コンパイルエラーが発生する

## 解説
| 回 | 本体のあとの i | 条件 `i > 5` |
|---|---|---|
| 1 | 10 − 3 = 7 | true（続ける） |
| 2 | 7 − 3 = 4 | false（抜ける） |

ループを抜けたときの i は 4 です。
