次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
record Point(int x, int y) {
}
public class Main {
    public static void main(String[] args) {
        Point p = new Point(1, 2);
        System.out.println(p.x() + p.y() + " " + p);
    }
}
```

- A. 「12 Point[x=1, y=2]」と表示される
- B. 「3 Point[x=1, y=2]」と表示される
- C. 「3 Point@1b6d3586」のような形で表示される
- D. コンパイルエラーが発生する
- E. 実行時に例外がスローされる

## 解説
- record には、コンポーネントと同じ名前のアクセサ `x()`・`y()` が自動で作られます（getX() ではありません）。
- `p.x() + p.y()` は int 同士なので先に足し算され 3。そのあと " " と p をつなぎます。
- record の toString は自動で作られ、`Point[x=1, y=2]` の形になります（C は普通のクラスの場合）。

よって「3 Point[x=1, y=2]」です。
