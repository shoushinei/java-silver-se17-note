次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Base {
    void show() {
        System.out.print("B");
    }
}
class Sub extends Base {
    void show() {
        System.out.print("S");
        super.show();
    }
}
public class Main {
    public static void main(String[] args) {
        Base b = new Sub();
        b.show();
    }
}
```

- A. 「BS」と表示される
- B. 「B」と表示される
- C. 「S」と表示される
- D. 「SS」と表示される
- E. 「SB」と表示される

## 解説
変数の型は Base ですが、実体は Sub なので、オーバーライドした Sub の show() が動きます。

1. Sub の show() で「S」
2. `super.show()` で親の Base の show() を呼び「B」

よって「SB」です。
