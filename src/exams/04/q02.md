次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String s = "java";
        s.toUpperCase();
        s.concat("!");
        System.out.println(s + s.length());
    }
}
```

- A. 「JAVA!5」と表示される
- B. 「JAVA4」と表示される
- C. 「java4」と表示される
- D. 「java!5」と表示される
- E. コンパイルエラーが発生する

## 解説
String は**不変**です。`toUpperCase()` も `concat("!")` も、変換した**新しい文字列を返すだけ**で、s そのものは変わりません。戻り値をどこにも代入していないので、s は "java" のままです。

最後の行は "java" と長さ 4 をつないで「java4」です。s を変えたいときは `s = s.toUpperCase();` のように代入します。
