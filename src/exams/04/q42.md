次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Base {
    public String toString() {
        return "Base";
    }
}
class Sub extends Base {
}
public class Main {
    public static void main(String[] args) {
        System.out.println(new Sub());
        System.out.println("[" + new Sub() + "]");
    }
}
```

- A. 「Sub」「[Sub]」と表示される
- B. 「Sub@1b6d3586」のような文字列が2行表示される
- C. 「Base」「[Base]」と表示される
- D. コンパイルエラーが発生する

## 解説
println にオブジェクトを渡したときも、文字列と + でつないだときも、そのオブジェクトの **toString()** が呼ばれます。

Sub は toString を書いていませんが、親の Base でオーバーライドした toString を受け継いでいます。そのため、どちらも "Base" が使われ、「Base」「[Base]」と表示されます。

B の「クラス名@…」の形は、どのクラスも toString をオーバーライドしていない（Object の toString が使われる）場合です。
