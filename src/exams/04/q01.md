次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Parent {
    Parent() {
        System.out.print("P");
    }
    Parent(String s) {
        System.out.print(s);
    }
}
class Child extends Parent {
    Child() {
        super("X");
        System.out.print("C");
    }
}
public class Main {
    public static void main(String[] args) {
        new Child();
    }
}
```

- A. 「PC」と表示される
- B. 「XC」と表示される
- C. 「PXC」と表示される
- D. 「CX」と表示される
- E. コンパイルエラーが発生する

## 解説
Child() の先頭に `super("X");` が書かれているので、引数が String の `Parent(String s)` が呼ばれて「X」、そのあと Child() の残りで「C」と表示されます。

super(...) を自分で書いたコンストラクタには、暗黙の `super();` は入りません。そのため引数なしの Parent() は呼ばれず、「P」は表示されません（A・C は誤り）。親のコンストラクタは子より先に動くので、D の順にもなりません。
