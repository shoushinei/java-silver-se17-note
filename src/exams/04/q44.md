次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static int count() {
        int n = 10;
        try {
            n++;
            return n;
        } finally {
            n = 0;
            System.out.print("F");
        }
    }
    public static void main(String[] args) {
        System.out.println(count());
    }
}
```

- A. 「F0」と表示される
- B. 「11F」と表示される
- C. 「F10」と表示される
- D. 「F11」と表示される
- E. コンパイルエラーが発生する

## 解説
1. try の中で n は 11 になり、`return n;` の時点で返す値 11 が決まる
2. メソッドを抜ける前に finally が実行される。n を 0 にして「F」を表示
3. 決まっていた 11 が返り、main で「11」を表示

よって「F11」です。finally で n を変えても、すでに決まった戻り値は変わりません（A は誤り）。「F」は count() の中で、main の println より先に表示されます（B は誤り）。
