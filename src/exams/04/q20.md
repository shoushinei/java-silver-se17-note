次のうち、RuntimeException のサブクラス（非検査例外）を選びなさい。

- A. NullPointerException
- B. IOException
- C. Exception
- D. ClassCastException
- E. ArithmeticException
- F. FileNotFoundException

## 解説
| 例外 | 親 | 種類 |
|---|---|---|
| NullPointerException | RuntimeException | 非検査例外 |
| ClassCastException | RuntimeException | 非検査例外 |
| ArithmeticException | RuntimeException | 非検査例外 |
| IOException | Exception | 検査例外 |
| FileNotFoundException | IOException | 検査例外 |
| Exception | Throwable | 検査例外（RuntimeException の親） |

Exception は RuntimeException の**親**であって、子ではありません。

## 検証
@case 正解 A・D・E は RuntimeException に代入できる
@file T.java
class T {
    RuntimeException a = new NullPointerException();
    RuntimeException d = new ClassCastException();
    RuntimeException e = new ArithmeticException();
}
@javac

@case B は RuntimeException ではない
@file T.java
class T { RuntimeException b = new java.io.IOException(); }
@javac-error incompatible types

@case C は RuntimeException ではない
@file T.java
class T { RuntimeException c = new Exception(); }
@javac-error incompatible types

@case F は RuntimeException ではない
@file T.java
class T { RuntimeException f = new java.io.FileNotFoundException(); }
@javac-error incompatible types
