次の2つのファイルがあります。

```java title=p1/Item.java
package p1;

public class Item {
    public int a = 1;
    protected int b = 2;
    int c = 3;
    private int d = 4;
}
```

```java title=p2/Main.java
package p2;

import p1.Item;

public class Main {
    public static void main(String[] args) {
        Item item = new Item();
        System.out.println(item.a);
        System.out.println(item.b);
        System.out.println(item.c);
        System.out.println(item.d);
    }
}
```

Main.java でコンパイルエラーになる行を選びなさい。

- A. 7 行目
- B. 8 行目
- C. 9 行目
- D. 10 行目
- E. 11 行目

## 解説
Main は Item と**別のパッケージ**にあり、Item を継承してもいません。この位置から使えるのは public のメンバだけです。

| 行 | フィールド | 修飾子 | 判定 |
|---|---|---|---|
| 8 | a | public | OK |
| 9 | b | protected | エラー（同じパッケージか、サブクラスの中からしか使えない） |
| 10 | c | 修飾子なし | エラー（同じパッケージからしか使えない） |
| 11 | d | private | エラー（Item の中からしか使えない） |

7 行目の `new Item()` は、public クラスのデフォルトコンストラクタ（public）を呼ぶので問題ありません。
