次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static void change(int x, int[] arr) {
        x = 10;
        arr[0] = 10;
    }
    public static void main(String[] args) {
        int x = 1;
        int[] arr = {1};
        change(x, arr);
        System.out.println(x + " " + arr[0]);
    }
}
```

- A. 「1 1」と表示される
- B. 「10 10」と表示される
- C. 「10 1」と表示される
- D. 「1 10」と表示される
- E. コンパイルエラーが発生する

## 解説
Java の引数は、すべて**値のコピー**が渡されます。

- `int x`: 数値 1 のコピーが渡されます。change の中で x を 10 にしても、main の x は 1 のまま。
- `int[] arr`: 配列への参照（どの配列かという情報）のコピーが渡されます。main と change の arr は**同じ配列**を指しているので、`arr[0] = 10` は main からも見えます。

よって「1 10」です。
