次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static void m(int x)    { System.out.print("I"); }
    static void m(double x) { System.out.print("D"); }
    static void m(Object x) { System.out.print("O"); }

    public static void main(String[] args) {
        m(5);
        m(5.0f);
        m("x");
        m('a');
    }
}
```

- A. 「IDOO」と表示される
- B. 「IOOI」と表示される
- C. 「IDOD」と表示される
- D. 「IDOI」と表示される
- E. コンパイルエラーが発生する

## 解説
| 呼び出し | 引数の型 | 選ばれるメソッド | 表示 |
|---|---|---|---|
| `m(5)` | int | `m(int)` に完全一致 | I |
| `m(5.0f)` | float | float → double の拡大変換で `m(double)` | D |
| `m("x")` | String | String は Object の子なので `m(Object)` | O |
| `m('a')` | char | char → int の拡大変換で `m(int)`。ボクシング（Character → Object）より拡大変換が先 | I |

よって「IDOI」です。

## 検証
