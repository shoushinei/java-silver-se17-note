次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Box {
    int size;
    Box(int size) {
        this.size = size;
    }
}
public class Main {
    public static void main(String[] args) {
        Box a = new Box(1);
        Box b = new Box(1);
        String s = new String("x");
        String t = new String("x");
        System.out.println(a.equals(b) + " " + s.equals(t));
    }
}
```

- A. 「true true」と表示される
- B. 「false true」と表示される
- C. 「false false」と表示される
- D. 「true false」と表示される
- E. コンパイルエラーが発生する

## 解説
- `a.equals(b)`: Box は equals をオーバーライドしていないので、Object の equals が使われます。これは == と同じく「同じインスタンスか」を比べるので、別々に new した a と b は false。
- `s.equals(t)`: String は equals を「中身が同じか」を比べるようにオーバーライドしているので true。

よって「false true」です。
