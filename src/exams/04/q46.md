次のメソッドの定義のうち、コンパイルが成功するものを選びなさい。

- A. `int f() { return; }`
- B. `void g() { return 1; }`
- C. `void v() { return; }`
- D. `int h(boolean b) { if (b) return 1; }`
- E. `int k() { return 'a'; }`

## 解説
- A: 戻り値の型が int なのに、値を返していません。エラー。
- B: void のメソッドは値を返せません。エラー。
- C: void のメソッドで、値なしの `return;` は書けます（そこでメソッドを抜ける）。OK。
- D: b が false のときに return が無いので、「missing return statement」のエラー。
- E: char の 'a' は int に拡大変換できる（97 になる）ので OK。

## 検証

    void v() { return; }
    int k() { return 'a'; }
}
