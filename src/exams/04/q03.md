次のプログラムを、あとに示すコマンドで実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i < args.length; i++) {
            System.out.print(args[i]);
        }
    }
}
```

```console
> javac Main.java
> java Main x y z
```

- A. 「yz」と表示される
- B. 「xyz」と表示される
- C. 「xy」と表示される
- D. 「Mainxy」と表示される
- E. 実行時に例外がスローされる

## 解説
`java Main x y z` の args は {"x", "y", "z"} です。クラス名の Main は args に入りません（D は誤り）。

for 文は i = 1 から始まるので、args[1] の "y" と args[2] の "z" を表示し、i が args.length（3）になったところで終わります。よって「yz」です。添字は 0 から始まるので、args[0] の "x" は表示されません。
