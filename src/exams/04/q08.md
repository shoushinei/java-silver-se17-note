メソッドの中に記述したとき、コンパイルが成功するコードを選びなさい。

- A. `int i = 10L;`
- B. `long l = 10;`
- C. `float f = 1.5;`
- D. `double d = 3;`
- E. `byte b = 200;`
- F. `int x = 3.0;`

## 解説
- A: `10L` は long 型です。long から int へは縮小になるのでエラー。
- B: int の 10 を long に入れるのは拡大変換なので OK。
- C: `1.5` は double 型のリテラルです。double から float へは縮小になるのでエラー（`1.5f` なら OK）。
- D: int の 3 を double に入れるのは拡大変換なので OK（3.0 になる）。
- E: byte に入るのは -128〜127 です。定数でも範囲外の 200 は入らずエラー。
- F: `3.0` は double 型です。小数点以下が 0 でも、double から int へは縮小なのでエラー。
