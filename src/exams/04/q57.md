次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    int value = 5;

    void print() {
        System.out.println(value);
    }

    public static void main(String[] args) {
        Main m = new Main();
        m.print();
        print();
    }
}
```

- A. 「5」が1回表示される
- B. 「5」が2回表示される
- C. コンパイルエラーが発生する
- D. 実行時に例外がスローされる

## 解説
main は static メソッドなので、「どのインスタンスの」という情報（this）がありません。

- `m.print();`: インスタンス m を通して呼んでいるので OK。
- `print();`: インスタンスを指定せずにインスタンスメソッドを呼んでいるので、**コンパイルエラー**です。
