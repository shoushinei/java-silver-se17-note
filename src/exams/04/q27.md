次のインタフェースがあります。

```java title=Printer.java
public interface Printer {
    void print(String s);
}
```

Printer を実装したクラスの宣言として、コンパイルが成功するものを選びなさい。

- A. `class MyPrinter implements Printer { void print(String s) { } }`
- B. `class MyPrinter implements Printer { public void print(String s) { } }`
- C. `class MyPrinter implements Printer { public void print(Object s) { } }`
- D. `class MyPrinter implements Printer { public String print(String s) { return s; } }`
- E. `abstract class MyPrinter implements Printer { }`

## 解説
- A: インタフェースのメソッドは暗黙に public です。修飾子なしは public より狭いのでエラー。
- B: public で、引数も戻り値も同じなので OK。
- C: 引数が Object なので別のメソッド（オーバーロード）です。print(String) を実装していないのでエラー。
- D: 引数が同じで戻り値の型だけが違う（void と String）のでエラー。
- E: 抽象クラスは、インタフェースのメソッドを実装しないままでかまいません。OK。
