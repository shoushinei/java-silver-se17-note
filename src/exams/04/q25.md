次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int x = 0;
        if (x > 0 && ++x > 0) { }
        if (x == 0 || ++x > 0) { }
        if (x == 0 | ++x > 0) { }
        System.out.println(x);
    }
}
```

- A. 「0」と表示される
- B. 「1」と表示される
- C. 「2」と表示される
- D. 「3」と表示される
- E. コンパイルエラーが発生する

## 解説
- 4 行目（`&&`）: 左の `x > 0` が false なので、右の `++x` は評価されない。x は 0
- 5 行目（`||`）: 左の `x == 0` が true なので、右の `++x` は評価されない。x は 0
- 6 行目（`|`）: `|` は短絡しないので、左が true でも右の `++x` が**評価される**。x は 1

よって「1」です。記号が2つ（`&&`・`||`）なら短絡、1つ（`&`・`|`）なら両方を評価します。
