次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder("abc");
        sb.append("d");
        String s = sb.toString();
        sb.deleteCharAt(0);
        System.out.println(s + " " + sb);
    }
}
```

- A. 「abcd bcd」と表示される
- B. 「bcd bcd」と表示される
- C. 「abc bc」と表示される
- D. 「abcd abcd」と表示される
- E. コンパイルエラーが発生する

## 解説
1. `append("d")` で sb は "abcd" になる（StringBuilder は代入しなくても自分が変わる）
2. `toString()` で、その時点の中身 "abcd" を String として取り出し、s に入れる
3. `deleteCharAt(0)` で sb は "bcd" になる。s は別の String なので "abcd" のまま

よって「abcd bcd」です。
