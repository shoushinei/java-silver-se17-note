次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        for (int i = 0; i < 3; i++) {
            int sum = i * 2;
        }
        System.out.println(sum);
    }
}
```

- A. 「4」と表示される
- B. 「6」と表示される
- C. 「0」と表示される
- D. コンパイルエラーが発生する
- E. 実行時に例外がスローされる

## 解説
sum は for 文のブロック `{ }` の中で宣言したローカル変数なので、使えるのはブロックの中だけです。ブロックの外の 6 行目では sum が見つからず、コンパイルエラーになります。

ループの外で使いたいときは、for 文より前に `int sum = 0;` と宣言しておきます。
