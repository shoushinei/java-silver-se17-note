次のコードが Vehicle.java に書かれています。

```java title=Vehicle.java
public sealed interface Vehicle permits Car, Bike {
}

final class Car implements Vehicle {
}
```

Vehicle.java の末尾に追加する Bike の宣言として、コンパイルが成功するものを選びなさい。

- A. `class Bike implements Vehicle { }`
- B. `non-sealed class Bike implements Vehicle { }`
- C. `final class Bike implements Vehicle { }`
- D. `abstract class Bike implements Vehicle { }`
- E. `final class Bike extends Vehicle { }`

## 解説
sealed インタフェースを実装するクラスも、sealed クラスの子と同じく **final・sealed・non-sealed のどれか1つ**を付けなければなりません。

- A: 何も付いていないのでエラー。
- B: non-sealed（ここから先は自由に継承できる）で OK。
- C: final で OK。
- D: abstract は3つのどれでもないのでエラー。
- E: クラスがインタフェースを受け継ぐときは `implements` です。`extends` は書けないのでエラー。
