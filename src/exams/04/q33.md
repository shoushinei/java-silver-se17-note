メソッドの中に記述したとき、コンパイルが成功する宣言を選びなさい。

- A. `char c1 = 'a';`
- B. `char c2 = "a";`
- C. `char c3 = 65;`
- D. `char c4 = 'ab';`
- E. `char c5 = -1;`
- F. `char c6 = 'あ';`

## 解説
- A: シングルクォートで囲んだ1文字なので OK。
- B: ダブルクォートで囲むと String になり、char には入りません。エラー。
- C: int の定数 65 は char の範囲（0〜65535）に入るので OK。文字コード 65 の 'A' になります。
- D: シングルクォートの中に書けるのは1文字だけです。エラー。
- E: char は負の数を持てません。範囲外なのでエラー。
- F: 日本語の文字も1文字なら char に入ります。OK。
