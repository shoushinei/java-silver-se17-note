次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Vehicle {
    void move() {
        System.out.print("move");
    }
}
class Car extends Vehicle {
    void honk() {
        System.out.print("honk");
    }
}
public class Main {
    public static void main(String[] args) {
        Vehicle v = new Car();
        v.move();
        ((Car) v).honk();
    }
}
```

- A. 「move」と表示される
- B. 「honk」と表示される
- C. 「movehonk」と表示される
- D. コンパイルエラーが発生する
- E. 実行時に例外がスローされる

## 解説
変数 v の型は Vehicle なので、`v.honk()` と書くとコンパイルエラーです（呼べるメソッドは変数の型で決まる）。

しかしこのプログラムは `((Car) v).honk()` と、**v を Car 型にキャストしてから**呼んでいます。キャストした結果は Car 型なので honk() を呼べます。v の実体は Car なので、実行時の例外も起きません。よって「movehonk」です。

`(Car) v.honk()` と括弧を付けずに書くと、`v.honk()` を先に評価しようとしてコンパイルエラーになります。
