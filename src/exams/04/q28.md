次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int[][] a = {{1, 2}, {3, 4, 5}};
        System.out.println(a[1].length + a[0][1]);
    }
}
```

- A. 「4」と表示される
- B. 「6」と表示される
- C. 「5」と表示される
- D. 「32」と表示される
- E. 実行時に ArrayIndexOutOfBoundsException がスローされる

## 解説
- `a[1]` は2行目の配列 {3, 4, 5} なので、`a[1].length` は 3。
- `a[0][1]` は1行目 {1, 2} の位置 1 なので 2。

どちらも int なので足し算になり、3 + 2 = 5 です。文字列が入っていないので「32」のような連結にはなりません。
