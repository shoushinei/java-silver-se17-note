次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Item {
    static String last;
    String name;
    Item(String name) {
        this.name = name;
        last = name;
    }
}
public class Main {
    public static void main(String[] args) {
        Item a = new Item("pen");
        Item b = new Item("cup");
        System.out.println(a.name + " " + a.last + " " + b.last);
    }
}
```

- A. 「pen pen cup」と表示される
- B. 「pen pen pen」と表示される
- C. 「cup cup cup」と表示される
- D. 「pen cup cup」と表示される
- E. コンパイルエラーが発生する

## 解説
- `name` はインスタンスごとのフィールドなので、a.name は "pen" のままです。
- `last` は static フィールドで、クラスに1つしかありません。a を作ったときに "pen" が入り、b を作ったときに同じ last が "cup" で上書きされます。a.last も b.last も、同じ1つの last を読むので "cup" です。

よって「pen cup cup」です。インスタンスを通して static フィールドを読むのは勧められない書き方ですが、エラーにはなりません。
