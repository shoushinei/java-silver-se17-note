次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Object[] items = {"apple", 10, "kiwi"};
        for (Object o : items) {
            if (o instanceof String s && s.length() > 4) {
                System.out.print(s.toUpperCase());
            }
        }
    }
}
```

- A. 「APPLEKIWI」と表示される
- B. 「APPLE」と表示される
- C. 何も表示されない
- D. コンパイルエラーが発生する
- E. 実行時に例外がスローされる

## 解説
`o instanceof String s` は、o が String のときだけ true になり、そのとき s に String として入ります。`&&` の右側は左が true のときだけ評価されるので、そこで s を使えます（D は誤り）。

| 要素 | String か | 長さ > 4 | 表示 |
|---|---|---|---|
| "apple" | はい | 5 なので true | APPLE |
| 10 | いいえ | 評価しない | なし |
| "kiwi" | はい | 4 なので false | なし |

よって「APPLE」です。
