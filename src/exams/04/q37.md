次のコードを確認してください。

```java title=Sample.java
interface A {
    default void hello() {
        System.out.println("A");
    }
}
interface B {
    default void hello() {
        System.out.println("B");
    }
}
public class Sample implements A, B {
    // some code
}
```

Sample クラスについての説明として、正しいものを選びなさい。

- A. hello をオーバーライドしなければ、先に書いた A の hello が使われる
- B. hello をオーバーライドしなければ、コンパイルエラーになる
- C. オーバーライドした hello の中で `super.hello();` と書くと、A の hello を呼べる
- D. オーバーライドした hello の中で `A.super.hello();` と書くと、A の hello を呼べる
- E. 同じ default メソッドを持つ A と B を、同時に implements することはできない

## 解説
A と B から同じ hello() を受け継ぐと、どちらを使うか決まらないので、**Sample で hello() をオーバーライドしなければコンパイルエラー**です（B が正しい、A は誤り）。implements すること自体はできます（E は誤り）。

オーバーライドした中でインタフェースの default を呼ぶには、`インタフェース名.super.メソッド()` と書きます（D が正しい）。クラスの中の `super.hello()` は親クラス（ここでは Object）を指すので、A の hello は呼べません（C は誤り）。
