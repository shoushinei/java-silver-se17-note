次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String s = "abcde";
        System.out.println(s.substring(1, 3) + s.indexOf('d') + s.charAt(4));
    }
}
```

- A. 「bcd3e」と表示される
- B. 「bc3e」と表示される
- C. 「bc4e」と表示される
- D. 「abc3e」と表示される
- E. 実行時に例外がスローされる

## 解説
"abcde" の位置は a=0, b=1, c=2, d=3, e=4 です。

- `substring(1, 3)`: 位置 1 から、位置 3 の**手前**まで → "bc"
- `indexOf('d')`: 'd' の位置 → 3
- `charAt(4)`: 位置 4 の文字 → 'e'

つなげて「bc3e」です。A は substring の終了位置を含めた誤り、C は位置を 1 から数えた誤りです。
