次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int count = 0;
        outer:
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                if (j == 1) {
                    continue outer;
                }
                count++;
            }
        }
        System.out.println(count);
    }
}
```

- A. 「6」と表示される
- B. 「9」と表示される
- C. 「3」と表示される
- D. 「1」と表示される
- E. コンパイルエラーが発生する

## 解説
内側のループは j = 0 のときに count++ し、j = 1 になると `continue outer;` で**外側のループの次の周**へ進みます。内側の j = 2 は実行されません。

外側は i = 0, 1, 2 の3周あり、1周につき count++ は1回だけなので、count は 3 です。

A の「6」は、`continue outer` を内側のループの continue（j = 1 だけ飛ばす）と考えた場合の値です。
