次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String a = "hi";
        String b = "hi";
        String c = new String("hi");
        System.out.println((a == b) + " " + (a == c) + " " + a.equals(c));
    }
}
```

- A. 「true false true」と表示される
- B. 「true true true」と表示される
- C. 「false false true」と表示される
- D. 「true false false」と表示される
- E. コンパイルエラーが発生する

## 解説
- `a == b`: 同じ内容のリテラルは、定数プールにある**同じインスタンス**を指すので true。
- `a == c`: `new String("hi")` は新しいインスタンスを作るので、a とは別物。false。
- `a.equals(c)`: String の equals は中身を比べるので true。

よって「true false true」です。
