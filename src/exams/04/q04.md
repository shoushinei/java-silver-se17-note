次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int n = 2;
        String s = "";
        switch (n) {
            case 1:
                s += "A";
            case 2:
                s += "B";
            case 3:
                s += "C";
                break;
            default:
                s += "D";
        }
        System.out.println(s);
    }
}
```

- A. 「B」と表示される
- B. 「BC」と表示される
- C. 「BCD」と表示される
- D. 「ABC」と表示される
- E. コンパイルエラーが発生する

## 解説
n は 2 なので `case 2:` から実行が始まります。

1. `case 2:` で「B」を足す。break が無いので、下の case 3 へ流れる（フォールスルー）
2. `case 3:` で「C」を足し、`break;` で switch を抜ける

よって「BC」です。break で抜けているので、default の「D」は足されません（C は誤り）。一致した case より上の `case 1:` は実行されません（D は誤り）。
