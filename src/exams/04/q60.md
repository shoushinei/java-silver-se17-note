シールクラス（sealed クラス）についての説明として、正しいものを選びなさい。

- A. permits に書いたサブクラスには、final・sealed・non-sealed のどれかを付けなければならない
- B. permits に書いていないクラスでも、同じパッケージにあれば継承できる
- C. non-sealed を付けたクラスは、ほかのクラスから継承できない
- D. sealed クラスには abstract を付けられない

## 解説
- A: 正しい。sealed クラスの子は、final（これ以上継承させない）・sealed（さらに限定する）・non-sealed（制限を外す）のどれかを宣言します。
- B: 誤り。継承できるのは permits に書いたクラスだけです。同じパッケージでも、書いていなければエラーです。
- C: 誤り。non-sealed は「ここから先は自由に継承してよい」という意味です。
- D: 誤り。`abstract sealed class` のように組み合わせられます。

## 検証
@case A: 修飾子の無いサブクラスは CE
@file Shape.java
sealed class Shape permits Circle { }
class Circle extends Shape { }
@javac-error

@case B は誤り: permits に無いクラスは継承できない
@file Shape.java
sealed class Shape permits Circle { }
final class Circle extends Shape { }
final class Square extends Shape { }
@javac-error

@case C・D は誤り: abstract sealed にでき、non-sealed の子は継承できる
@file Shape.java
abstract sealed class Shape permits Circle { }
non-sealed class Circle extends Shape { }
class SmallCircle extends Circle { }
@javac
