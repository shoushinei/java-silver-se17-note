次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int a = 3;
        int b = a++ + 2;
        int c = ++a * 2;
        System.out.println(a + " " + b + " " + c);
    }
}
```

- A. 「5 6 10」と表示される
- B. 「4 5 8」と表示される
- C. 「5 5 8」と表示される
- D. 「5 5 10」と表示される
- E. コンパイルエラーが発生する

## 解説
1. `b = a++ + 2`: a++ は今の値 3 を使ってから a を 4 にする。b は 3 + 2 = 5
2. `c = ++a * 2`: ++a は a を 5 にしてから 5 を使う。c は 5 × 2 = 10

最後の a は 5 なので「5 5 10」です。
