次の2つのファイルがあります。

```java title=p1/A.java
package p1;

public class A {
    public int a = 1;
    protected int b = 2;
    int c = 3;
}
```

```java title=p2/B.java
package p2;

import p1.A;

public class B extends A {
    void test() {
        // insert code here
    }
}
```

`// insert code here` の位置に記述したとき、コンパイルが成功するコードを選びなさい。

- A. `System.out.println(c);`
- B. `System.out.println(new A().b);`
- C. `System.out.println(new A().c);`
- D. `System.out.println(b);`
- E. `System.out.println(a);`

## 解説
B は A のサブクラスですが、別のパッケージにあります。

- A・C: c は修飾子なし（同じパッケージからだけ）なので、別パッケージの B からは使えません。エラー。
- B: protected の b でも、`new A()` で作った A 型のインスタンスを通すと、別パッケージからは使えません。エラー。
- D: 継承した自分の b として使うのは OK。
- E: public の a はどこからでも使えます。OK。
