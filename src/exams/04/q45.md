次のプログラムをコンパイルしたとき、コンパイルエラーになる行を選びなさい。

```java title=Sub.java
class Base {
    final int MAX = 10;
    final void show() { }
}
public class Sub extends Base {
    void show() { }
    void test() {
        System.out.println(MAX);
    }
}
```

- A. 2 行目
- B. 3 行目
- C. 6 行目
- D. 8 行目
- E. コンパイルエラーは発生しない

## 解説
- 2 行目: final のフィールドを宣言と同時に初期化しています。OK。
- 3 行目: final メソッドの宣言そのものは問題ありません。OK。
- 6 行目: 親の final メソッド show() をオーバーライドしようとしているので**エラー**。
- 8 行目: final 変数を読むだけなので OK（変えようとするとエラー）。

## 検証
@case 正解 C: 6 行目だけがエラー
@stem
@javac-error Sub.java:6

@case 参考: 6 行目を消せば通る
