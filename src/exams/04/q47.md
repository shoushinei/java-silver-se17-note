次のプログラムがあり、カレントディレクトリに Hello.class はありません。

```java title=Hello.java
public class Hello {
    public static void main(String[] args) {
        System.out.println(args.length + ":" + args[0]);
    }
}
```

次のコマンドを実行したときの結果として、正しいものを選びなさい。

```console
> java Hello.java Java SE
```

- A. 「2:Java」と表示される
- B. 「3:Hello.java」と表示される
- C. 「1:Java SE」と表示される
- D. 「2:Hello.java」と表示される
- E. コンパイルしていないため、実行できない

## 解説
`java Hello.java` のように .java のファイル名を渡すと、コンパイルせずにそのまま実行できます（**ソースファイルモード**）。.class を作っていなくても動くので、E は誤りです。

ファイル名 Hello.java は args に入らず、その後ろの `Java` と `SE` が args[0]・args[1] になります。args.length は 2、args[0] は "Java" なので「2:Java」です。

## 検証
@case 正解 A
@stem
@sh java Hello.java Java SE

@end
