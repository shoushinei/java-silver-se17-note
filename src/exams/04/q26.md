次のクラスの `// insert code here` に挿入したとき、コンパイルが成功するコードを選びなさい。

```java title=Calc.java
public class Calc {
    void calc(int a, double b) { }
    // insert code here
}
```

- A. `void calc(double a, int b) { }`
- B. `int calc(int x, double y) { return 0; }`
- C. `void calc(int a) { }`
- D. `private void calc(int a, double b) { }`
- E. `void calc(int b, double a) { }`
- F. `static void calc(int a, double b) { }`

## 解説
同じ名前のメソッドを並べられるのは、**引数の型・数・並び**のどれかが違うときだけです。

- A: (double, int) は (int, double) と並びが違うので OK。
- B: 引数は (int, double) で同じ。戻り値の型と引数名が違うだけなのでエラー。
- C: 引数の数が違うので OK。
- D: アクセス修飾子が違うだけなのでエラー。
- E: 引数名を入れ替えただけで、型の並びは (int, double) のまま。エラー。
- F: static かどうかは区別に使われません。引数が同じなのでエラー。
