次のメソッドの定義のうち、コンパイルが成功するものを選びなさい。

- A. `void m() throws Exception { throw new Exception(); }`
- B. `void m() { throw new Exception(); }`
- C. `void m() throws RuntimeException { throw new Exception(); }`
- D. `void m() { try { throw new Exception(); } finally { } }`
- E. `void m() { throw new RuntimeException(); }`

## 解説
Exception は**検査例外**です。投げるメソッドは、catch で捕まえるか、throws に書いて呼び出し元に任せなければなりません。

- A: throws Exception と書いているので OK。
- B: catch も throws も無いのでエラー。
- C: throws に書いた RuntimeException は Exception の子なので、Exception を任せたことになりません。エラー。
- D: finally は例外を捕まえないので、Exception は外へ出ていきます。エラー。
- E: RuntimeException は**非検査例外**なので、throws を書かなくても投げられます。OK。
