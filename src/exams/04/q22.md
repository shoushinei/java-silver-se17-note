次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Tank {
    private int fuel;

    Tank(int fuel) {
        fuel = fuel * 2;
    }

    int range() {
        int km = 0;
        for (int i = 1; i <= 3; i++) {
            km += fuel + i;
        }
        return km;
    }
}
public class Main {
    public static void main(String[] args) {
        System.out.println(new Tank(5).range());
    }
}
```

- A. 「36」と表示される
- B. 「30」と表示される
- C. 「6」と表示される
- D. 「0」と表示される
- E. コンパイルエラーが発生する

## 解説
コンストラクタの `fuel = fuel * 2;` は、左も右も**引数**の fuel です。引数が 10 になるだけで、フィールドの fuel は既定値の 0 のままです。

range() の中の fuel はフィールド（0）なので、km は (0 + 1) + (0 + 2) + (0 + 3) = 6 です。

A の「36」は、フィールドが 10 になったと考えた場合（11 + 12 + 13）の値です。フィールドに入れるには `this.fuel = fuel * 2;` と書きます。
