次のクラスがあります。

```java title=Child.java
class Parent {
    protected void run() { }
}
public class Child extends Parent {
    // insert code here
}
```

`// insert code here` の位置に記述したとき、コンパイルが成功するコードを選びなさい。

- A. `public void run() { }`
- B. `void run() { }`
- C. `private void run() { }`
- D. `protected void run() { }`
- E. `public int run() { return 0; }`
- F. `public static void run() { }`

## 解説
親の `run()` は protected です。オーバーライドするときは、アクセス修飾子を**同じか、より広く**しなければなりません。広さの順は public ＞ protected ＞ 修飾子なし ＞ private です。

- A: protected → public と広げているので OK。
- B: 修飾子なしは protected より狭いのでエラー。
- C: private はもっと狭いのでエラー。
- D: 同じ protected なので OK。
- E: 引数が同じで戻り値の型だけが違う（void と int）ので、オーバーライドとしてもオーバーロードとしても成り立たずエラー。
- F: 親のインスタンスメソッドを、static メソッドで隠すことはできません。エラー。

## 検証
@case 正解 A
@file Child.java
class Parent { protected void run() { } }
public class Child extends Parent { public void run() { } }
@javac

@case 正解 D
@file Child.java
class Parent { protected void run() { } }
public class Child extends Parent { protected void run() { } }
@javac

@case B は CE
@file Child.java
class Parent { protected void run() { } }
public class Child extends Parent { void run() { } }
@javac-error weaker access

@case C は CE
@file Child.java
class Parent { protected void run() { } }
public class Child extends Parent { private void run() { } }
@javac-error weaker access

@case E は CE
@file Child.java
class Parent { protected void run() { } }
public class Child extends Parent { public int run() { return 0; } }
@javac-error

@case F は CE
@file Child.java
class Parent { protected void run() { } }
public class Child extends Parent { public static void run() { } }
@javac-error overriding method is static
