次の2つのクラスがあります。

```java title=Memo.java
public class Memo {
    private String text = "";

    public Memo add(String s) {
        text += s;
        return this;
    }

    public Memo copy() {
        Memo m = new Memo();
        m.text = text;
        return m;
    }

    @Override
    public String toString() {
        return text;
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Memo a = new Memo();
        Memo b = a.add("x").copy().add("y");
        a.add("z");
        Memo c = b.add("w");
        System.out.println(a + " " + b + " " + c);
    }
}
```

Main をコンパイル、実行したときの結果として、正しいものを選びなさい。

- A. 「xz xy xyw」と表示される
- B. 「xz xyw xyw」と表示される
- C. 「xyzw xyzw xyzw」と表示される
- D. 「x xyw xyw」と表示される
- E. copy の中で、別のインスタンス m の private フィールドに代入しているため、コンパイルエラーが発生する

## 解説
add は自分の text を書き換えて**自分自身（this）**を返します。copy は**新しい Memo**を作って返します。どのインスタンスを指しているかを追います。

| 行 | 処理 | a | もう1つの Memo |
|---|---|---|---|
| 4 | `a.add("x")` は a を書き換えて a を返す | "x" | |
| 4 | `.copy()` で新しい Memo（"x"）を作る | "x" | "x" |
| 4 | `.add("y")` はその新しい Memo を書き換えて返す。これが b | "x" | "xy"（b） |
| 5 | `a.add("z")`。戻り値は使っていないが、a は書き換わる | "xz" | "xy"（b） |
| 6 | `b.add("w")` は b を書き換えて b 自身を返す。c と b は同じインスタンス | "xz" | "xyw"（b と c） |

よって「xz xyw xyw」です。

- A: b.add("w") が新しいインスタンスを返すと考えた誤りです。add は this を返すので、c は b と同じインスタンスです。
- C: copy が同じインスタンスを返すと考えた場合です。copy は new した別のインスタンスを返します。
- D: 5 行目の戻り値を使っていないので a が変わらない、と考えた誤りです。String のメソッドと違い、add は a 自身の text を書き換えています。
- E: copy は Memo クラスの中のメソッドなので、別の Memo インスタンスの private フィールドでも使えます。
