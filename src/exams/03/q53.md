Java のソースファイルについての説明として、正しいものを選びなさい。

- A. 1つのソースファイルには、クラスを1つしか宣言できない
- B. package 文と import 文の両方を書くときは、import 文を先に書く
- C. 1つのソースファイルに2つのクラスを宣言してコンパイルすると、.class ファイルも1つにまとめて作られる
- D. import 文は、クラスの宣言の中（メソッドの前）に書いてもよい
- E. package 文を省略したクラスは、java.lang パッケージに属する
- F. public なクラスを宣言するときは、ソースファイルの名前を「そのクラス名.java」にする

## 解説
- A: 誤り。1つのファイルに複数のクラスを書けます。制限があるのは **public なトップレベルクラスで、1つのファイルに1つまで**です。
- B: 誤り。書く順番は、package 文 → import 文 → クラスの宣言 です。package 文はファイルの先頭（コメントを除く）に1つだけ書きます。
- C: 誤り。.class ファイルは**クラスごとに1つずつ**作られます。A と B を書いた1つのファイルから、A.class と B.class の2つができます。
- D: 誤り。import 文はファイルの先頭部分（package 文の後、クラスの宣言の前）にしか書けません。
- E: 誤り。package 文を省略したクラスは「名前の無いパッケージ」に属します。java.lang は、import を書かなくても自動で使えるパッケージ（String や System など）のことです。
- F: 正しい。`public class Sample` は Sample.java に書きます。別の名前のファイルに書くと、javac でコンパイルエラーになります。

## 検証
@case 正解 F: public クラスの名前とファイル名が違うと CE
@file Other.java
public class Sample {
}
@javac-error should be declared in a file named Sample.java

@case A・C は誤り: 1つのファイルに2つのクラスを書け、別々に実行できる（.class が2つある）
@file Two.java
public class Two {
    public static void main(String[] args) {
        System.out.println("two");
    }
}
class Extra {
    public static void main(String[] args) {
        System.out.println("extra");
    }
}
@javac
@run Two
@stdout
two
@end
@run Extra
@stdout
extra
@end

@case B は誤り: import を package より先に書くと CE
@file app/Main.java
import java.util.List;
package app;
public class Main { }
@javac-error

@case D は誤り: import をクラスの中に書くと CE
@file Main.java
public class Main {
    import java.util.List;
}
@javac-error

@case E は誤り: package の無いクラスは java.lang のクラスではない
@file Hello.java
public class Hello { }
@file Main.java
public class Main {
    java.lang.Hello h;
}
@javac-error cannot find symbol
