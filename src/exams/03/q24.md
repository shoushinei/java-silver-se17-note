メソッドの中に記述したとき、コンパイルが成功するコードを選びなさい。

- A. `var b = 'x';  b += 1;`
- B. `var n = 10;  n = 10L;`
- C. `var d = 1.0f;  d = 1.0;`
- D. `var c = 5L;  c = 5;`
- E. `var e = 'x';  e = e + 1;`
- F. `var s = "a";  s = 'b';`

## 解説
var で宣言した変数の型は、**最初の右辺で決まり、その後は変わりません**。2つ目の文は、決まった型の変数への代入として判定します。

| 選択肢 | var の型 | 2つ目の文 | 判定 |
|---|---|---|---|
| A | char | `+=` は結果を char に暗黙でキャストする | OK（'y' になる） |
| B | int | long の 10L を int に入れる（縮小） | エラー |
| C | float | double の 1.0 を float に入れる（縮小） | エラー |
| D | long | int の 5 を long に入れる（拡大） | OK |
| E | char | `e + 1` は int になり、変数を含むので char に戻せない | エラー |
| F | String | char の 'b' は String に変換されない | エラー |

A と E の違いが要点です。どちらも char に 1 を足していますが、`+=` などの**複合代入には暗黙のキャストが含まれる**ので A は通ります。E の `e + 1` は int の計算結果で、変数 e を含むため（定数式ではないため）、キャストなしでは char に代入できません。

## 検証
@case 正解 A と D
@file T.java
class T {
    void m() {
        var b = 'x';  b += 1;
        var c = 5L;  c = 5;
        System.out.println(b + " " + c);
    }
    public static void main(String[] args) { new T().m(); }
}
@javac
@run T
@stdout
y 5
@end
