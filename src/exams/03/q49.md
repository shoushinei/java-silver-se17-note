  - c2-s12 add(位置, 値) はその位置に割り込ませて後ろをずらす。set(位置, 値) は置き換えて、元の値を返す。remove(Object) は値で探して削除する

次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
import java.util.ArrayList;
import java.util.List;

public class Main {
    public static void main(String[] args) {
        List<String> list = new ArrayList<>();
        list.add("a");
        list.add("b");
        list.add(0, "c");
        String old = list.set(1, "d");
        list.remove("b");
        list.add(old);
        System.out.println(list + " " + list.indexOf("a") + " " + list.size());
    }
}
```

- A. 「[c, d, a] 2 3」と表示される
- B. 「[c, d, d] -1 3」と表示される
- C. 「[c, d, b] -1 3」と表示される
- D. 「[c, d, null] -1 3」と表示される
- E. 実行時に IndexOutOfBoundsException がスローされる

## 解説
| 行 | 処理 | リストの中身 |
|---|---|---|
| 7・8 | "a"、"b" を末尾に追加 | [a, b] |
| 9 | `add(0, "c")`: 位置 0 に**割り込ませ**、後ろを1つずつずらす | [c, a, b] |
| 10 | `set(1, "d")`: 位置 1 の "a" を "d" に置き換え、**元の値 "a" を返す** | [c, d, b]、old は "a" |
| 11 | `remove("b")`: 値が "b" の要素を探して削除 | [c, d] |
| 12 | `add(old)`: "a" を末尾に追加 | [c, d, a] |

indexOf("a") は 2、size() は 3 なので「[c, d, a] 2 3」です。

- B: set が**新しく入れた値**（"d"）を返すと考えた場合です。set の戻り値は、置き換えられる前の値です。
- C: `add(0, "c")` が位置 0 の要素を置き換えると考えた場合です。add は置き換えずに割り込ませます。
- D: set が何も返さない（null）と考えた場合です。
- E: 使っている位置はすべて範囲内です。add(位置, 値) の位置は、0 から size() まで（末尾の次も可）を指定できます。
