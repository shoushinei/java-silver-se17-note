次の2つのクラスがあります。

```java title=Res.java
public class Res implements AutoCloseable {
    private final String name;

    public Res(String name) {
        this.name = name;
        System.out.print("O" + name + " ");
    }

    @Override
    public void close() throws Exception {
        System.out.print("C" + name + " ");
        if (name.equals("B")) {
            throw new Exception("e" + name);
        }
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Res a = new Res("A");
        try (a; Res b = new Res("B")) {
            System.out.print("T ");
        } catch (Exception e) {
            System.out.print(e.getMessage() + " ");
        } finally {
            System.out.print("F");
        }
    }
}
```

Main をコンパイル、実行したときの結果として、正しいものを選びなさい。

- A. 「OA OB T CA CB eB F」と表示される
- B. 「OA OB T CB CA eB F」と表示される
- C. 「OA OB T CB eB F」と表示される
- D. 「OA OB T CB CA F」と表示される
- E. 「OA OB T eB CB CA F」と表示される
- F. try の ( ) に宣言済みの変数 a を書いているため、コンパイルエラーが発生する

## 解説
Java 9 以降は、try の ( ) に**宣言済みの変数**を書けます。条件は、その変数が final か、一度も再代入していない（実質的に final）ことです。a は再代入していないので使えます（F は誤り）。

| 順番 | 処理 | 表示 |
|---|---|---|
| 1 | try より前の `new Res("A")` | OA |
| 2 | ( ) の中の `new Res("B")` | OB |
| 3 | try の本体 | T |
| 4 | 逆の順に閉じる。先に b を閉じ、close の中で例外が発生 | CB |
| 5 | 例外が出ても、**残りのリソース a も必ず閉じる** | CA |
| 6 | すべて閉じてから catch へ。b の close で出た例外のメッセージ | eB |
| 7 | finally | F |

よって「OA OB T CB CA eB F」です。

- A: 閉じる順は、( ) に書いた順の**逆**（b → a）です。
- C: 1つの close で例外が発生しても、閉じる処理は残りのリソースへ続きます。
- D: close で発生した例外も、ふつうの例外と同じく catch に届きます。
- E: catch と finally は、すべてのリソースを閉じたあとに実行されます。
