次のうち、コンパイルが成功するクラスの定義を選びなさい。

- A.
  ```java
  abstract class A {
      private abstract void run();
  }
  ```
- B.
  ```java
  abstract class B {
      static abstract void run();
  }
  ```
- C.
  ```java
  abstract class C {
      abstract final void run();
  }
  ```
- D.
  ```java
  abstract class D {
      protected abstract void run();
      final void stop() { }
  }
  ```
- E.
  ```java
  abstract class E {
      abstract void run() { }
  }
  ```
- F.
  ```java
  final abstract class F {
  }
  ```

## 解説
抽象メソッドは「中身はサブクラスで書いてください」という約束です。サブクラスでオーバーライドできない修飾子とは組み合わせられません。

| 選択肢 | 判定 | 理由 |
|---|---|---|
| A | エラー | private メソッドはサブクラスに受け継がれないので、オーバーライドして中身を書けない |
| B | エラー | static メソッドはオーバーライドされない（隠蔽になるだけ） |
| C | エラー | final メソッドはオーバーライドできない |
| D | OK | protected の抽象メソッドは書ける。抽象クラスに final の具象メソッドを書くのも問題ない |
| E | エラー | 抽象メソッドには本体を書けない。中身が空の `{ }` でも本体あり扱い |
| F | エラー | final クラスは継承できず、abstract クラスは継承されないと使えないので両立しない |

覚え方は「abstract と並べられないのは private・static・final」。どれも「オーバーライドできない」という共通点があります。
