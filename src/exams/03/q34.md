次のインタフェースの `// insert code here` に挿入したとき、コンパイルが成功するコードを選びなさい。

```java title=Shape.java
public interface Shape {
    // insert code here
}
```

- A. `int SIDES = 4;`
- B. `int sides;`
- C. `private double area();`
- D. `static String info() { return "shape"; }`
- E. `default String name();`
- F. `protected void draw();`
- G. `private static String fmt(double d) { return "" + d; }`

## 解説
インタフェースに書けるメンバと、その決まりを整理します。

| 種類 | 暗黙に付く修飾子 | 本体 |
|---|---|---|
| フィールド | public static final | 初期化が必須 |
| 抽象メソッド | public abstract | 書かない |
| default メソッド | public | 必須 |
| static メソッド | public（private も可） | 必須 |
| private メソッド | なし | 必須 |

- A: 定数として OK です。暗黙に public static final になります。
- B: フィールドは final なので、宣言と同時に初期化しなければなりません。エラー。
- C: private のメソッドは、実装クラスから見えないので抽象メソッドにできません。本体が必要です。エラー。
- D: static メソッドは本体付きで書けます。OK。
- E: default メソッドは「実装済みのメソッド」なので本体が必要です。エラー。
- F: インタフェースのメンバに protected は付けられません。エラー。
- G: private static メソッドも本体付きで書けます（ほかの static メソッドや default メソッドから使う部品）。OK。
