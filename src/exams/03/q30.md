次の2つのクラスがあります。

```java title=Wallet.java
public class Wallet {
    private int money;

    public Wallet(int money) {
        this.money = money;
    }

    public void take(Wallet other, int amount) {
        other.money -= amount;
        money += amount;
    }

    public int money() {
        return money;
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Wallet a = new Wallet(100);
        Wallet b = new Wallet(50);
        a.take(b, 30);
        b.take(a, 10);
        System.out.println(a.money() + " " + b.money());
    }
}
```

Main をコンパイル、実行したときの結果として、正しいものを選びなさい。

- A. 「130 20」と表示される
- B. 「120 30」と表示される
- C. 「100 50」と表示される
- D. Wallet.java の 9 行目で、別のインスタンスの private フィールドを使っているため、コンパイルエラーが発生する
- E. フィールド money とメソッド money() の名前が同じため、コンパイルエラーが発生する

## 解説
private の範囲は「**同じクラスのコードの中**」です。「自分のインスタンスだけ」ではありません。take は Wallet クラスの中のメソッドなので、引数で受け取った別の Wallet（other）の private フィールドも読み書きできます（D は誤り）。

| 処理 | a.money | b.money |
|---|---|---|
| 作成 | 100 | 50 |
| `a.take(b, 30)`: b から 30 引き、a に 30 足す | 130 | 20 |
| `b.take(a, 10)`: a から 10 引き、b に 10 足す | 120 | 30 |

よって「120 30」です。

- A: 1回目の take だけを計算した場合の値です。
- C: other は呼び出し元の b（または a）と**同じインスタンス**を指しているので、other.money の変更はそのまま残ります。
- E: フィールドとメソッドは、名前が同じでも区別されます（record のアクセサも、フィールドと同じ名前のメソッドです）。

もし Main の中で `a.money` と書けば、Main は Wallet とは別のクラスなので、そちらはコンパイルエラーになります。
