次のプログラムを、あとに示すコマンドで実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println(args[0] + args[1] + args.length);
        System.out.println(Integer.parseInt(args[0]) + args.length + args[1]);
    }
}
```

```console
> javac Main.java
> java Main 10 20
```

- A. 「32」「32」と表示される
- B. 「302」「1220」と表示される
- C. 「10202」「10220」と表示される
- D. 「Main102」と表示されたあと、NumberFormatException がスローされる
- E. 「10202」「1220」と表示される

## 解説
`java Main 10 20` の args は {"10", "20"} で、args.length は 2 です。クラス名の Main は args に入りません（D は、args[0] がクラス名だと考えた場合の誤りです）。また、引数は数字でも **String** として渡されます。

**3 行目**: `args[0] + args[1] + args.length`

1. "10" + "20" → String 同士なので連結して "1020"
2. "1020" + 2 → String と int なので連結して "10202"

**4 行目**: `Integer.parseInt(args[0]) + args.length + args[1]`

1. parseInt で int の 10 にしてから、10 + 2 → int 同士なので足し算で 12
2. 12 + "20" → int と String なので連結して "1220"

よって「10202」「1220」です。

- A: 引数を数値として足し算したと考えた場合です。args の要素は String です。
- B: 3 行目の "10" + "20" を足し算して 30 にした誤りです。
- C: 4 行目の 10 + 2 を連結して "102" にした誤りです。String が出てくるまでは数値の足し算です。
