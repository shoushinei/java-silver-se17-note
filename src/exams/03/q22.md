次の2つのファイルがあります。

```java title=Account.java
public record Account(String id, int balance) {
    private static int created = 0;

    public Account {
        created++;
        if (balance < 0) {
            throw new IllegalArgumentException();
        }
    }

    public Account deposit(int amount) {
        return new Account(id, balance + amount);
    }

    public static int created() {
        return created;
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Account a = new Account("A1", 100);
        Account b = a.deposit(50);
        a.deposit(30);
        System.out.println(a.balance() + " " + b.balance() + " " + Account.created());
    }
}
```

Main をコンパイル、実行したときの結果として、正しいものを選びなさい。

- A. 「180 180 1」と表示される
- B. 「100 150 3」と表示される
- C. 「100 150 2」と表示される
- D. 「100 150 1」と表示される
- E. record にフィールド created を宣言しているため、コンパイルエラーが発生する

## 解説
record のフィールド（id と balance）は final なので、作ったあとで値を変えられません。そこで deposit は、**足した金額で新しい Account を作って返す**書き方になっています。a 自身は変わりません。

| 行 | 処理 | 作られる record | created |
|---|---|---|---|
| 3 | `new Account("A1", 100)` | a（100） | 1 |
| 4 | `a.deposit(50)` の中の new | b（150） | 2 |
| 5 | `a.deposit(30)` の中の new。戻り値は捨てられる | 名前のない record（130） | 3 |

コンパクトコンストラクタ（`public Account { ... }`）は、**どこで new しても毎回**動きます。deposit の中の new も数えるので、created は 3 です。a の balance は 100 のまま、b は 150 です。よって「100 150 3」です。

- A: deposit が a 自身を書き換えて自分を返すと考えた場合です。record のフィールドは変えられません。
- C・D: main で書いた new だけを数えた誤りです。5 行目の戻り値は使われていませんが、record は作られています。
- E: record に追加できないのは**インスタンス**フィールドだけです。static フィールドは宣言できます。
