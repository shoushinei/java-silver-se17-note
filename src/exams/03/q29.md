次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static String label;

    public static void main(String[] args) {
        String s = label + "!";
        StringBuilder sb = new StringBuilder();
        sb.append(label).append(s.length());
        label += sb;
        System.out.println(label);
    }
}
```

- A. 「1」と表示される
- B. 「null5」と表示される
- C. 5 行目で NullPointerException がスローされる
- D. 7 行目で NullPointerException がスローされる
- E. 「nullnull5」と表示される

## 解説
static フィールド label は初期化していないので、既定値の **null** です。

| 行 | 処理 | 結果 |
|---|---|---|
| 5 | `label + "!"` | null を文字列につなぐと "null" という4文字になる。s は "null!"（長さ 5） |
| 7 | `sb.append(label)` | null の String を append すると "null" が追加される。続けて `append(5)` で sb は "null5" |
| 8 | `label += sb` | `label = label + sb` と同じ。null + "null5" で "nullnull5" |

よって「nullnull5」です。

- A: null を空文字（""）のように扱うと、s は "!"（長さ 1）、label は "1" になります。Java では null は "null" という文字になります。
- B: 8 行目の `label += sb` で、左の label が null であることを見落とした誤りです。null + "null5" なので、先頭にもう1つ "null" が付きます。
- C・D: NullPointerException になるのは、null に対して `label.length()` のように**メソッドを呼んだとき**などです。+ での連結や append に null を渡すことは、例外になりません。
