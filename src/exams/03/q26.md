次の2つのクラスがあります。

```java title=Shop.java
public class Shop {
    static int sold = 0;
    int stock = 10;

    void sell(int sold) {
        stock -= sold;
        Shop.sold += sold;
        sold++;
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Shop a = new Shop();
        Shop b = new Shop();
        a.sell(3);
        b.sell(4);
        System.out.println(Shop.sold + " " + a.sold + " " + (a.stock + b.stock));
    }
}
```

Main をコンパイル、実行したときの結果として、正しいものを選びなさい。

- A. 「7 7 13」と表示される
- B. 「9 9 13」と表示される
- C. 「7 3 13」と表示される
- D. 「7 0 13」と表示される
- E. インスタンス経由で static フィールドを読んでいるため、コンパイルエラーが発生する

## 解説
sell メソッドの引数の名前が、static フィールドと同じ `sold` です。メソッドの中で名前だけで書いた `sold` は、**引数**を指します。

| sell の中の文 | 指しているもの |
|---|---|
| `stock -= sold;` | インスタンスの stock から、引数を引く |
| `Shop.sold += sold;` | 左はクラス名付きなので **static フィールド**、右は引数 |
| `sold++;` | **引数**を 1 増やすだけ（メソッドを抜けると消える） |

- `a.sell(3)`: a の stock は 7、Shop.sold は 3。
- `b.sell(4)`: b の stock は 6、Shop.sold は 7。

最後の行で、`a.sold` は a という変数を通して static フィールドを読んでいるだけなので、Shop.sold と同じ 7 です。`a.stock + b.stock` は括弧の中で先に足し算され 13。よって「7 7 13」です。

- B: `sold++` が static フィールドを増やすと考えた場合です。
- C・D: static フィールドがインスタンスごとにあると考えた誤りです。static フィールドはクラスに1つで、どのインスタンスから読んでも同じ値です。
- E: インスタンス経由で static フィールドを読むのは、推奨されない書き方ですがコンパイルは通ります。
