次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int a = 7, b = 2;
        double x = a / b;
        double y = (double) a / b;
        double z = (double) (a / b);
        float f = a / 2f;
        System.out.println(x + " " + y + " " + z + " " + f);
    }
}
```

- A. 「3.0 3.5 3.0 3.5」と表示される
- B. 「3.5 3.5 3.5 3.5」と表示される
- C. 「3.0 3.5 3.5 3.5」と表示される
- D. 「3 3.5 3 3.5」と表示される
- E. 7 行目で、float の変数に割り算の結果を代入しているため、コンパイルエラーが発生する

## 解説
| 行 | 式 | 計算の流れ | 値 |
|---|---|---|---|
| 4 | `a / b` | int 同士なので 7 / 2 = 3（切り捨て）。それを double に入れる | 3.0 |
| 5 | `(double) a / b` | キャストが先に結びつき、7.0 / 2 → 7.0 / 2.0 | 3.5 |
| 6 | `(double) (a / b)` | 括弧の中の int の割り算 3 が先。それを double にする | 3.0 |
| 7 | `a / 2f` | 2f は float なので、a も float にそろえて 7.0f / 2.0f | 3.5 |

よって「3.0 3.5 3.0 3.5」です。

- 4 行目: 代入先が double でも、割り算そのものは int 同士で行われます。小数点以下が消えたあとで double になるので 3.0 です（B・C は誤り）。
- 5 行目と 6 行目: キャストは / より先に結びつきます。`(double) a / b` は「a を double にしてから割る」、`(double) (a / b)` は「割ってから double にする」です。
- D: double の値を文字列にすると、小数点以下が 0 でも「3.0」のように表示されます。
- E: `a / 2f` は int と float の計算なので、結果は float です。float の変数にそのまま入ります。
