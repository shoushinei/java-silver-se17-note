次のプログラムをコンパイルしたとき、コンパイルエラーになる行を選びなさい。

```java title=Main.java
public class Main {
    static int count = 5;

    public static void main(String[] args) {
        int count = 1;
        for (int i = 0; i < 2; i++) {
            int total = i;
            count += total;
        }
        int i = 10;
        {
            int total = 3;
            int count = 2;
            i += total;
        }
        System.out.println(count + i);
    }
}
```

- A. 5 行目
- B. 7 行目
- C. 10 行目
- D. 12 行目
- E. 13 行目
- F. コンパイルエラーは発生しない

## 解説
ローカル変数が使える範囲（スコープ）は、**宣言した位置から、そのブロック `{ }` の終わりまで**です。範囲が重なっている間は、同じ名前のローカル変数を宣言し直せません。

| 行 | 宣言 | 判定 |
|---|---|---|
| 5 | `int count = 1;` | OK。static フィールドの count と同じ名前だが、フィールドを隠すだけ |
| 7 | `int total = i;` | OK。for のブロックの中だけの変数 |
| 10 | `int i = 10;` | OK。for で宣言した i の範囲は for 文の終わり（9 行目）までで、もう終わっている |
| 12 | `int total = 3;` | OK。7 行目の total の範囲は for のブロックの中で、もう終わっている |
| 13 | `int count = 2;` | **エラー**。5 行目の count の範囲は main の終わりまで続いていて、内側のブロックもその中 |

よって 13 行目だけがエラーです。「内側のブロックなら同じ名前を使える」と考えると、13 行目を見落とします。外側の変数の範囲がまだ続いている内側のブロックでは、同じ名前を宣言できません。逆に、範囲が終わった後なら（10 行目・12 行目）、同じ名前を何度でも使えます。
