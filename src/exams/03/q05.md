次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String key = new String("B");
        switch (key) {
            case "A":
                System.out.print("a");
            case "B":
                System.out.print("b");
            default:
                System.out.print("d");
            case "C":
                System.out.print("c");
                break;
            case "D":
                System.out.print("x");
        }
        System.out.println();
    }
}
```

- A. 「b」と表示される
- B. 「bd」と表示される
- C. 「dc」と表示される
- D. 「bdc」と表示される
- E. 「bdcx」と表示される
- F. default が case の途中に書かれているため、コンパイルエラーが発生する

## 解説
String を switch に渡すと、case の文字列とは **equals で比べます**。`new String("B")` は "B" のリテラルとは別のインスタンスですが、中身が同じなので `case "B":` に一致します。

一致した case から、**break が出てくるまで下へ順に**実行します（フォールスルー）。

1. `case "B":` から始まり「b」
2. break が無いので、下にある `default:` の中へ流れ込み「d」
3. さらに `case "C":` の中へ流れ込み「c」
4. `break;` で switch を抜ける

よって「bdc」です。`case "D":` の「x」は break の後ろなので実行されません（E は誤り）。

- A・B: 一致した case だけ、あるいは次のラベルまでで止まると考えた誤りです。コロン（:）の case は、break まで流れ続けます。
- C: switch が == で比べると考えると、どの case にも一致せず default から始まって「dc」になります。String の switch は equals で比べるので誤りです。
- F: default はどこに書いてもかまいません。途中に書いても、ほかの case に一致しなかったときの入口になるだけです。
