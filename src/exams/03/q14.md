次のプログラムは、12 行目でコンパイルエラーになります。

```java title=Main.java
interface Speaker {
    void speak();
}
class Robot implements Speaker {
    public void speak() { System.out.println("beep"); }
    public void charge() { System.out.println("charging"); }
}
public class Main {
    public static void main(String[] args) {
        Speaker s = new Robot();
        s.speak();
        s.charge();
    }
}
```

「beep」「charging」と表示させるために、12 行目を置き換えるコードとして正しいものを選びなさい。

- A. `(Robot) s.charge();`
- B. `if (s instanceof Robot) s.charge();`
- C. `Robot r = s; r.charge();`
- D. `Robot.charge();`
- E. `((Robot) s).charge();`

## 解説
変数 s の型は Speaker です。呼べるメソッドは**変数の型**で決まるので、実体が Robot でも、Speaker に無い charge() は呼べません。呼ぶには、Robot 型として扱い直す（キャストする）必要があります。

- E: `(Robot) s` を括弧で囲んでから `.charge()` を呼んでいるので、Robot 型として呼べます。正解です。
- A: キャストは `.` より結合が弱いので、`(Robot) (s.charge())` の意味になります。s.charge() の時点でエラーです。
- B: instanceof で確かめても、s の型は Speaker のままです。パターン変数を使って `if (s instanceof Robot r) r.charge();` と書けば OK です。
- C: Speaker 型から Robot 型への代入（親から子の方向）には、キャストが必要です。`Robot r = (Robot) s;` なら OK です。
- D: charge() はインスタンスメソッドなので、クラス名では呼べません。
