次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static String judge(Object o) {
        if (o instanceof Integer i && i > 10) {
            return "big";
        }
        if (o instanceof String s || s.isBlank()) {
            return "text";
        }
        return "other";
    }
    public static void main(String[] args) {
        System.out.println(judge(20) + " " + judge("hi") + " " + judge(5));
    }
}
```

- A. 「big text other」と表示される
- B. 3 行目で、&& の右側でパターン変数 i を使っているため、コンパイルエラーが発生する
- C. 6 行目で、|| の右側でパターン変数 s を使っているため、コンパイルエラーが発生する
- D. 「big other other」と表示される
- E. 実行時に NullPointerException がスローされる

## 解説
パターン変数（`instanceof Integer i` の i）は、**「マッチした」ことが確定している場所でしか使えません**。

- 3 行目の `&&`: 右側が評価されるのは、左側が true（＝o が Integer だった）ときだけです。i は確実に Integer なので使えます。
- 6 行目の `||`: 右側が評価されるのは、左側が **false（＝o が String ではなかった）**ときです。そのとき s には何も入っていないので、使えません。コンパイルエラーになります。

よって 6 行目でコンパイルエラーです。B は、&& の右側なら使えるので誤りです。

もし 6 行目が `if (o instanceof String s && !s.isBlank())` なら、コンパイルが通り「big text other」と表示されます（A はその場合の結果）。

- `o instanceof String s && s.isBlank()`: 使える（右側はマッチしたときだけ評価される）
- `o instanceof String s || s.isBlank()`: 使えない（右側はマッチしなかったときだけ評価される）
- `!(o instanceof String s) || s.isBlank()`: 使える（右側は、! の中がマッチしたときだけ評価される）
