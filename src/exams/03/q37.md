次のプログラムは、コンパイルエラーになります。

```java title=Main.java
class Base {
    private Base() {
        System.out.print("B");
    }
    Base(int x) {
        this();
        System.out.print(x);
    }
}
class Derived extends Base {
    Derived() {
        System.out.print("D");
    }
}
public class Main {
    public static void main(String[] args) {
        new Derived();
    }
}
```

その理由として、正しいものを選びなさい。

- A. Base の引数なしコンストラクタが private なので、Derived のコンストラクタの先頭に入る暗黙の super() から呼び出せないため
- B. Base(int x) の中で、this() を使って private なコンストラクタを呼んでいるため
- C. 引数ありのコンストラクタを持つクラスを継承するときは、子のコンストラクタで必ず super(引数) を書かなければならないため
- D. private なコンストラクタを持つクラスは、継承できないため
- E. Derived のコンストラクタに public が付いていないため

## 解説
Derived() には super(...) も this(...) も書かれていないので、先頭に暗黙の `super();` が入ります。これは Base の**引数なしコンストラクタ** `Base()` を呼びますが、Base() は private なので、Base の外にある Derived からは呼べません。これがエラーの理由です。

- B: this() は同じクラスの中からの呼び出しなので、private でも問題ありません。
- C: 親に引数ありのコンストラクタがあっても、**使える引数なしコンストラクタもあれば**、暗黙の super() で足ります。この問題では、引数なしのものが private で使えないことが原因です。Derived() の先頭に `super(1);` と書けば、コンパイルは通ります。
- D: private 以外のコンストラクタ（ここでは Base(int)）があれば、それを super(...) で呼んで継承できます。
- E: コンストラクタのアクセス修飾子は、この問題とは関係ありません。

    private Base() {
        System.out.print("B");
    }
    Base(int x) {
        this();
        System.out.print(x);
    }
}

        System.out.print("D");
    }

        new Derived();
    }
