次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String s = "banana";
        int i = s.indexOf("an", 2);
        s.replace("a", "o");
        String t = s.substring(i, i + 2);
        int j = s.lastIndexOf('a');
        System.out.println(i + t + j);
    }
}
```

- A. 「1an5」と表示される
- B. 「3on-1」と表示される
- C. 「3ana5」と表示される
- D. 実行時に StringIndexOutOfBoundsException がスローされる
- E. 「3an5」と表示される

## 解説
"banana" の各文字の位置（インデックス）は次のとおりです。

| 位置 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 文字 | b | a | n | a | n | a |

1. `s.indexOf("an", 2)`: 位置 2 から探し始めます。"an" は位置 1 と 3 から始まりますが、1 は探す範囲の外なので **3**。
2. `s.replace("a", "o")`: "bonono" という**新しい文字列を返すだけ**です。戻り値を代入していないので、s は "banana" のままです。
3. `s.substring(3, 5)`: 位置 3 から、位置 5 の**手前**まで（3 と 4）なので "an"。
4. `s.lastIndexOf('a')`: 最後の 'a' の位置で **5**。
5. `i + t + j`: 左から評価します。int の 3 と String の "an" で文字列の連結になり "3an"、続けて 5 をつないで「3an5」。

- A: 第2引数を無視して、最初の "an"（位置 1）を見つけたと考えた誤りです。
- B: replace の結果が s に入ったと考えた場合です（"bonono" には 'a' が無いので lastIndexOf は -1 になります）。
- C: substring の終了位置を含めて数えた誤りです。
- D: 位置 3〜5 は "banana"（長さ 6）の範囲内なので、例外は起きません。
