次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
interface Flyer {
    void fly();
}
class Bird implements Flyer {
    public void fly() { System.out.println("bird"); }
}
class Robot {
    void walk() { System.out.println("robot"); }
}
public class Main {
    public static void main(String[] args) {
        Flyer f = new Bird();
        f.fly();
        Robot r = (Robot) f;
        r.walk();
    }
}
```

- A. 「bird」「robot」と表示される
- B. Robot は Flyer を実装していないため、14 行目でコンパイルエラーが発生する
- C. 「bird」と表示されたあと、NullPointerException がスローされる
- D. 何も表示されずに、ClassCastException がスローされる
- E. 「bird」と表示されたあと、ClassCastException がスローされる

## 解説
14 行目は、インタフェース型 Flyer の変数を、クラス型 Robot にキャストしています。Robot は Flyer を実装していませんが、**コンパイルは通ります**。

コンパイラは「f が指している実体が Robot である可能性があるか」で判断します。Robot は final ではないので、次のようなサブクラスがどこかにあるかもしれません。

```java
class FlyingRobot extends Robot implements Flyer { ... }
```

このクラスのインスタンスなら、Flyer 型の変数にも入り、Robot にもキャストできます。可能性がある以上、コンパイラはキャストを認め、確認は実行時に回します。

実行すると、13 行目で「bird」と表示されたあと、14 行目で実体が Bird（Robot ではない）と分かり、ClassCastException がスローされます。15 行目には進みません。

- B: Robot に `final` が付いていれば、Flyer を実装するサブクラスが作れないので、14 行目がコンパイルエラーになります。この問題の Robot は final ではありません。
- C: f は null ではありません。
- D: 13 行目の f.fly() は、キャストより先に実行されます。
