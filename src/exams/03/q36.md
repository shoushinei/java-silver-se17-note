次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3};
        int i = 0;
        arr[i++] = arr[i] + 10;
        System.out.println(arr[0] + arr[1] + "," + i);
    }
}
```

- A. 「13,1」と表示される
- B. 「14,1」と表示される
- C. 「122,1」と表示される
- D. 「14,0」と表示される
- E. 実行時に ArrayIndexOutOfBoundsException がスローされる

## 解説
5 行目の `arr[i++] = arr[i] + 10;` は、**左から順に**評価されます。

1. 左辺の `arr[i++]`: 添字は i の今の値 **0** に決まり、そのあと i が 1 になる。代入先は arr[0]。
2. 右辺の `arr[i] + 10`: このとき i はもう **1** なので、arr[1] + 10 = 2 + 10 = 12。
3. arr[0] に 12 を代入。配列は {12, 2, 3}、i は 1。

6 行目は、左から `arr[0] + arr[1]` が先に数値として足され 14、そのあと "," と i をつないで「14,1」です。

- A: 右辺を先に計算する（arr[0] + 10 = 11 を arr[0] に入れる）と考えた場合や、添字に増えた後の 1 を使う（arr[1] に 12 を入れる）と考えた場合の値です。どちらも合計は 13 になります。
- C: `arr[0] + arr[1]` は int 同士なので、文字列の連結ではなく足し算です。"," が出てくるまでは数値の計算です。
- D: i++ は文の終わりを待たず、その場で i を増やします。
- E: 使っている添字は 0 と 1 だけなので、範囲内です。
