次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static void run() {
        try {
            System.out.print("T ");
            throw new IllegalStateException();
        } finally {
            System.out.print("F ");
            Integer.parseInt("x");
        }
    }
    public static void main(String[] args) {
        try {
            run();
        } catch (IllegalStateException e) {
            System.out.print("ISE");
        } catch (IllegalArgumentException e) {
            System.out.print("IAE");
        }
    }
}
```

- A. 「T F ISE」と表示される
- B. 「T ISE」と表示される
- C. 「T F ISE IAE」と表示される
- D. 「T F 」と表示されたあと、NumberFormatException がスローされてプログラムが止まる
- E. 「T F IAE」と表示される

## 解説
1. try の中で「T 」を表示し、IllegalStateException を投げます。run には catch が無いので、この例外は呼び出し元へ伝わろうとします。
2. その前に、**finally が必ず実行されます**。「F 」を表示し、`Integer.parseInt("x")` で NumberFormatException が発生します。
3. finally の中で新しい例外が発生すると、**元の IllegalStateException は捨てられ**、NumberFormatException のほうが main へ伝わります。
4. main の catch は上から順に調べます。NumberFormatException は IllegalStateException の子ではないので、1つ目は素通りします。2つ目の IllegalArgumentException は NumberFormatException の**親**なので、ここで捕まえて「IAE」。

よって「T F IAE」です。

- A: 元の IllegalStateException は、finally で発生した例外に置き換えられて消えます。
- B: finally は、例外が呼び出し元へ伝わる前に必ず実行されます。
- C: 1つの例外を捕まえるのは、一致した最初の catch だけです。
- D: NumberFormatException は、main の `catch (IllegalArgumentException e)` で捕まえられます。
