作業ディレクトリの下に、次の2つのファイルがあります。

```java title=src/shop/util/Tax.java
package shop.util;

public class Tax {
    public static int add(int price) {
        return price * 110 / 100;
    }
}
```

```java title=src/shop/Main.java
package shop;

import shop.util.Tax;

public class Main {
    public static void main(String[] args) {
        System.out.println(Tax.add(200));
    }
}
```

作業ディレクトリで次のコマンドを実行し、コンパイルは成功しました。

```console
> javac -d out src/shop/util/Tax.java src/shop/Main.java
```

続けて実行したとき、「220」と表示されるものを選びなさい。

- A. `java out.shop.Main`
- B. `java -cp out/shop Main`
- C. `cd out` を実行してから `java shop.Main`
- D. `cd out/shop` を実行してから `java Main`
- E. `java -cp src shop.Main`

## 解説
`-d out` を付けたので、クラスファイルは package 宣言どおりに out/shop/Main.class と out/shop/util/Tax.class に作られます。

java コマンドは、**-cp で指定した場所（省略したらカレントディレクトリ）を起点に**、クラス名 shop.Main を shop/Main.class というパスに読み替えて探します。

- C: out に移動すれば、-cp を省略してもカレントの out が起点になり、out/shop/Main.class が見つかります。正解です（作業ディレクトリのまま `java -cp out shop.Main` としても同じです）。
- A: クラス名が out.shop.Main になり、そのようなクラスはありません。out はパッケージ名ではありません。
- B・D: shop の中から Main を探すと、Main.class は見つかりますが、中のクラスは package shop の shop.Main なので、名前が合わずに実行できません。
- E: src にあるのは .java のソースだけで、.class はありません。-cp にはクラスファイルの場所を指定します。
