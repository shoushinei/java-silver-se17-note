メソッドの中に `int ○○ = 0;` と書くとき、`○○` の部分に記述してコンパイルが成功する変数名を選びなさい。

- A. `$value`
- B. `_`
- C. `goto`
- D. `String`
- E. `1st`
- F. `record`
- G. `null`

## 解説
| 選択肢 | 判定 | 理由 |
|---|---|---|
| A. `$value` | OK | 1文字目に `$` を使える |
| B. `_` | エラー | Java 9 以降、アンダースコア**1文字だけ**の名前は使えない（`_total` のように続きがあれば OK） |
| C. `goto` | エラー | Java では使われていないが**予約語**として予約されている（`const` も同じ） |
| D. `String` | OK | クラスの名前だが予約語ではないので、変数名にできる（紛らわしいだけで正しい） |
| E. `1st` | エラー | 数字で始まる名前は使えない |
| F. `record` | OK | record クラスを宣言する場所でだけ意味を持つ**文脈依存キーワード**なので、変数名にはできる |
| G. `null` | エラー | `null`・`true`・`false` はリテラルなので使えない |

文脈依存キーワードには、`record` のほかに `var`・`yield`・`sealed`・`permits` などがあります。どれも変数名として使えます（`var` は型の名前には使えません）。「キーワードっぽい名前はすべて使えない」と覚えていると、D と F を外してしまいます。

## 検証
@case 正解 A・D・F
@file T.java
class T {
    void m() {
        int $value = 0;
        int String = 0;
        int record = 0;
    }
}
@javac

@case B は CE
@file T.java
class T { void m() { int _ = 0; } }
@javac-error

@case C は CE
@file T.java
class T { void m() { int goto = 0; } }
@javac-error

@case E は CE
@file T.java
class T { void m() { int 1st = 0; } }
@javac-error

@case G は CE
@file T.java
class T { void m() { int null = 0; } }
@javac-error
