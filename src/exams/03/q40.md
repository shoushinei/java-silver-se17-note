次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Config {
    static String mode = "dev";
    String name = "app";

    static String info() {
        return mode + "!";
    }
}
public class Main {
    public static void main(String[] args) {
        Config c = null;
        System.out.println(c.mode);
        System.out.println(c.info());
        System.out.println(c.name);
    }
}
```

- A. 「dev」「dev!」「app」と表示される
- B. 「dev」「dev!」「null」と表示される
- C. 「dev」「dev!」と表示されたあと、NullPointerException がスローされる
- D. 何も表示されずに、12 行目で NullPointerException がスローされる
- E. null の変数を通して static メンバを使っているため、コンパイルエラーが発生する

## 解説
static のフィールドやメソッドは、インスタンスではなく**クラスに属します**。変数を通して書いても、コンパイラは**変数の型（Config）だけ**を見て、`Config.mode`・`Config.info()` と書いたのと同じものにします。変数の中身は使わないので、null でも例外になりません。

- 12 行目: `c.mode` は `Config.mode` と同じ。「dev」
- 13 行目: `c.info()` は `Config.info()` と同じ。「dev!」
- 14 行目: name は**インスタンスのフィールド**なので、c が指すインスタンスが必要です。c は null なので NullPointerException。

よって C です。

- A・B: インスタンスのフィールドは、インスタンスが無いと読めません。null の変数から読むと "null" と表示されるのではなく、例外になります。
- D: static メンバの使用では、変数の中身が null でも例外になりません。
- E: インスタンス経由で static メンバを使う書き方は、勧められない書き方ですが、コンパイルエラーにはなりません。
