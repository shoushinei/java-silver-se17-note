次のプログラムがあります。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        for (int i = 0; i < 5; i++) {
            if (i % 2 == 0) {
                continue;
            }
            System.out.print(i);
        }
    }
}
```

3〜8 行目を置き換えたとき、同じ結果になるコードを選びなさい。

- A.
  ```java
  int i = -1;
  while (++i < 5) {
      if (i % 2 == 0) {
          continue;
      }
      System.out.print(i);
  }
  ```
- B.
  ```java
  int i = 0;
  while (i < 5) {
      if (i % 2 == 0) {
          continue;
      }
      System.out.print(i);
      i++;
  }
  ```
- C.
  ```java
  for (int i = 0; i < 5; i++) {
      if (i % 2 == 1) {
          continue;
      }
      System.out.print(i);
  }
  ```
- D.
  ```java
  int i = 0;
  do {
      if (i % 2 == 0) {
          continue;
      }
      System.out.print(i);
  } while (++i < 5);
  ```
- E.
  ```java
  int i = 0;
  while (i++ < 5) {
      if (i % 2 == 0) {
          continue;
      }
      System.out.print(i);
  }
  ```

## 解説
元のプログラムは、i が 0〜4 のうち奇数のときだけ表示するので「13」です。for 文の continue は、**更新式 i++ へ飛んでから**条件を調べます。

- A: 正しい。i は -1 から始まり、条件式の `++i` で 0, 1, 2, 3, 4 と増えながら判定されます。i++ を本体に書いていないので、continue しても増やし忘れることがありません。「13」。
- B: 誤り。i が 0 のとき continue で条件式へ戻りますが、本体の最後の `i++` を飛ばすので、i は 0 のまま増えません。**無限ループ**になります。
- C: 誤り。奇数のときに continue するので、偶数の「024」が表示されます。
- D: 正しい。do-while の continue は、**末尾の条件式 `++i < 5` へ飛びます**。i を増やす処理は条件式の中にあるので、飛ばされません。「13」。
- E: 誤り。条件の判定は増やす前の値（0〜4）で行いますが、本体の i は増えた後の 1〜5 です。奇数の 1・3・5 が表示され「135」になります。
