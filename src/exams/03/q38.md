次のクラスの `// insert code here` に挿入したとき、コンパイルが成功するコードを選びなさい。

```java title=Grid.java
public class Grid {
    int[] a, b[];
    int c[], d;

    void test() {
        // insert code here
    }
}
```

- A. `a = b;`
- B. `b[0] = c;`
- C. `d = c;`
- D. `c = new int[2][];`
- E. `a[0] = b[0];`
- F. `b = new int[][] {a, c, d};`

## 解説
配列の [] は、どこに書くかで効く範囲が変わります。

- **型の後ろ**の [] は、その行で宣言する変数**すべて**にかかる
- **変数名の後ろ**の [] は、**その変数だけ**にかかる

| 変数 | 宣言 | 型 |
|---|---|---|
| a | `int[] a` | int[] |
| b | `int[] b[]`（型の [] ＋ 名前の []） | int[][] |
| c | `int c[]` | int[] |
| d | `int d` | int |

- A: int[][] を int[] に入れようとしているのでエラー。
- B: b[0] は2次元配列の1行で int[]、c も int[] なので代入できます。正解です。
- C: int[] を int に入れようとしているのでエラー。
- D: `new int[2][]` は int[][] なので、int[] の c には入りません。エラー。
- E: b[0] は int[]、a[0] は int なのでエラー。
- F: d は int で配列ではないので、int[][] の初期化子に並べられません。エラー。
