次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
sealed interface Shape permits Circle, Square {
    double area();
}
record Circle(double r) implements Shape {
    public double area() {
        return 3 * r * r;
    }
}
record Square(double side) implements Shape {
    public double area() {
        return side * side;
    }
}
final class Triangle implements Shape {
    public double area() {
        return 0.5;
    }
}
public class Main {
    public static void main(String[] args) {
        Shape[] shapes = { new Circle(1), new Square(2) };
        double sum = 0;
        for (Shape s : shapes) {
            sum += s.area();
        }
        System.out.println(sum);
    }
}
```

- A. 「7.0」と表示される
- B. 「7」と表示される
- C. Circle と Square に final・sealed・non-sealed のどれも付いていないため、コンパイルエラーが発生する
- D. Triangle が permits に書かれていないため、コンパイルエラーが発生する
- E. record の area メソッドに public を付けているため、コンパイルエラーが発生する

## 解説
Shape は `permits Circle, Square` と書いた sealed インタフェースです。実装できるのは Circle と Square だけなので、**permits に無い Triangle が implements した時点でコンパイルエラー**です。Triangle を main で使っていなくても、宣言しただけでエラーになります。final を付けても、許可されていないことは変わりません。

- C: sealed の子には final・sealed・non-sealed のどれかが必要ですが、**record は暗黙に final** なので、何も書かなくても条件を満たします。
- E: インタフェースの抽象メソッドは暗黙に public です。実装する側は public にしなければならないので、public は必要です（付けないとエラー）。
- A: Triangle が無ければ、3.0 + 4.0 で「7.0」と表示されます。double の合計なので「7」（B）にはなりません。

計算を追わせておいて、実はコンパイルエラーという作りです。sealed を見たら、まず permits と子の宣言が合っているかを確かめましょう。
