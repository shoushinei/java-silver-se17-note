次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class A {
    A() {
        this("x");
        System.out.print("1");
    }
    A(String s) {
        System.out.print("2");
    }
    {
        System.out.print("3");
    }
}
class B extends A {
    int v = init();
    B() {
        super();
        System.out.print("4");
    }
    int init() {
        System.out.print("5");
        return 0;
    }
    {
        System.out.print("6");
    }
}
public class Main {
    public static void main(String[] args) {
        new B();
    }
}
```

- A. 「3321564」と表示される
- B. 「231564」と表示される
- C. 「321564」と表示される
- D. 「321654」と表示される
- E. 「564321」と表示される

## 解説
インスタンス初期化子（`{ ... }`）とフィールドの初期化式は、**super(...) を呼ぶコンストラクタの中で、super(...) から戻った直後**に実行されます。`this(...)` で始まるコンストラクタでは実行されません。もし実行されたら、同じ初期化が2回動いてしまうからです。

`new B()` の流れを順に追います。

| 順番 | 実行される場所 | 表示 |
|---|---|---|
| 1 | B() の `super()` で A() へ。A() は `this("x")` で A(String) へ | なし |
| 2 | A(String) の先頭の暗黙の super()（Object）から戻り、A のインスタンス初期化子 | 3 |
| 3 | A(String) の本体 | 2 |
| 4 | A() に戻って残りの本体 | 1 |
| 5 | B() に戻り、B のフィールド初期化 `int v = init();`（上から順） | 5 |
| 6 | B のインスタンス初期化子 | 6 |
| 7 | B() の本体 | 4 |

よって「321564」です。

- A: A のインスタンス初期化子を、A() と A(String) の両方で1回ずつ実行した場合の誤りです。this(...) で始まる A() では実行されません。
- B: 初期化子はコンストラクタの**本体より先**に動くので、「2」より「3」が先です。
- D: フィールドの初期化式と初期化ブロックは、**書かれている順**に実行されます。B では `int v = init();` が上にあるので「5」が先です。
- E: 子の初期化は、親のコンストラクタが終わってからです。
