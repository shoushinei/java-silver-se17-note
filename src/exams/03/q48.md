次のプログラムを実行して「P1C」と表示させたい。`// insert code here` の位置に記述するコードとして、正しいものを選びなさい。

```java title=Main.java
class Parent {
    Parent(int n) {
        System.out.print("P" + n);
    }
}
class Child extends Parent {
    Child() {
        // insert code here
        System.out.print("C");
    }
    Child(int n) {
        super(n);
    }
}
public class Main {
    public static void main(String[] args) {
        new Child();
    }
}
```

- A. `this(1);`
- B. `super();`
- C. `super(1);`
- D. `Parent(1);`
- E. `new Parent(1);`
- F. 何も書かない

## 解説
Parent には `Parent(int)` しかありません。Child() の先頭に何も書かないと暗黙の `super();` が入り、存在しない `Parent()` を呼ぼうとしてエラーになります。

- A: 正しい。`this(1)` で Child(int) へ進み、そこで `super(1)` が呼ばれて「P1」、戻って「C」。this(...) を書いたコンストラクタには暗黙の super() が入らないので、エラーにもなりません。
- B: `Parent()` は無いのでエラーです。
- C: 正しい。直接 `Parent(1)` を呼んで「P1」、続けて「C」。
- D: 親のコンストラクタは、名前で呼ぶのではなく `super(...)` で呼びます。`Parent(1)` は「Parent という名前のメソッドの呼び出し」とみなされ、見つからずエラーです。
- E: `new Parent(1)` は別の Parent インスタンスを作る文で、親のコンストラクタの呼び出しにはなりません。Child() の先頭には暗黙の `super();` が入ったままなので、B と同じ理由でエラーです。
- F: 暗黙の `super();` が入るので、B と同じくエラーです。
