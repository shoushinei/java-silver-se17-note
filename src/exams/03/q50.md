メソッドの中に記述したとき、コンパイルが成功するコードを選びなさい。

- A.
  ```java
  for (int i = 0; false; i++) {
      System.out.print(i);
  }
  ```
- B.
  ```java
  int n = 0;
  while (n < 0) {
      n++;
  }
  System.out.print(n);
  ```
- C.
  ```java
  while (1 > 0) {
      System.out.print("x");
  }
  System.out.print("y");
  ```
- D.
  ```java
  do {
      System.out.print("x");
  } while (false);
  System.out.print("y");
  ```
- E.
  ```java
  System.out.print("a");
  throw new IllegalStateException();
  System.out.print("b");
  ```
- F.
  ```java
  for (int i = 0; i < 3; i++) {
      continue;
  }
  System.out.print("end");
  ```

## 解説
コンパイラは「この文が実行される可能性があるか」を調べ、可能性の無い文（到達不能な文）があるとエラーにします。判定に使うのは、**コンパイルの時点で値が決まる定数式**だけです。変数の値は見ません。

- A: エラー。条件が定数の `false` なので、for の本体は1回も実行されず、到達不能です。
- B: OK。`n < 0` は変数を使っているので定数式ではありません。実際には1回も回りませんが、コンパイラは「回るかもしれない」と扱います。
- C: エラー。`1 > 0` はリテラルだけの**定数式**で、値は true に決まります。break の無い無限ループになるので、後ろの「y」の行が到達不能です。
- D: OK。do-while の本体は条件より先に必ず1回実行されるので、条件が false でも問題ありません。ループは終わるので、後ろの文にも届きます。
- E: エラー。throw の直後の文は、絶対に実行されないので到達不能です。
- F: OK。continue の後ろ（ループの中）には文が無いので問題ありません。条件の `i < 3` は定数式ではないので、ループの後ろにも届きます。
