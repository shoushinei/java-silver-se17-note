次のプログラムは、Device クラスでコンパイルエラーになります。

```java title=Main.java
interface Printer {
    default void print() {
        System.out.println("printer");
    }
}
interface Scanner {
    void print();
}
class Device implements Printer, Scanner {
}
public class Main {
    public static void main(String[] args) {
        new Device().print();
    }
}
```

その理由として、正しいものを選びなさい。

- A. Printer の default メソッドが Scanner の print を実装したことになるが、Scanner の print に public が付いていないため
- B. Printer の default メソッドがあっても、Scanner の抽象メソッド print を実装したことにはならないため。Device で print をオーバーライドすれば解決する
- C. default メソッドと同じ名前の抽象メソッドは宣言できないため、Scanner でエラーになる
- D. 2つ以上のインタフェースを同時に implements することはできないため
- E. Device の中で print を呼び出していないため

## 解説
Device は、Printer から default の `print()` を、Scanner から抽象メソッドの `print()` を受け継ぎます。シグネチャが同じでも、**別のインタフェースの default メソッドは、もう一方の抽象メソッドの実装として使われません**。どちらを使うべきかをコンパイラが決めないためです。そのため Device は「Scanner の print を実装していない」とみなされ、コンパイルエラーになります。

直すには、Device で print をオーバーライドします。Printer の処理を使いたければ、`インタフェース名.super.メソッド()` で呼べます。

```java
class Device implements Printer, Scanner {
    @Override
    public void print() {
        Printer.super.print();
    }
}
```

- A: インタフェースのメソッドは、public を書かなくても暗黙に public です。
- C: Printer と Scanner は別々のインタフェースで、それぞれ単独では正しく宣言されています。エラーは、両方を受け継ぐ Device で起きます。
- D: クラスは、いくつでもインタフェースを implements できます。
- E: 抽象メソッドの実装が必要かどうかは、呼び出しているかどうかとは関係ありません。

似た形でも、**親クラス**から受け継いだ public メソッドとインタフェースの default がぶつかる場合は、親クラスのメソッドが優先され、エラーになりません。
