次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Profile.java
public class Profile {
    String name;
    int age;
    boolean active;
    double rate;
    char grade;
    int[] scores = new int[2];

    public static void main(String[] args) {
        Profile p = new Profile();
        System.out.println(p.name + ":" + p.age + ":" + p.active + ":"
                + p.rate + ":" + p.scores[1] + ":" + (p.grade == 0));
    }
}
```

- A. 「:0:false:0.0:0:true」と表示される
- B. 「null:0:false:0.0:0:true」と表示される
- C. 「null:0:false:0:0:true」と表示される
- D. 「null:0:false:0.0:null:true」と表示される
- E. フィールドを初期化していないため、11 行目でコンパイルエラーが発生する

## 解説
**フィールド**は、初期化しなくても型ごとの既定値が自動で入ります（初期化しないと使えないのはローカル変数です。E は誤り）。

| フィールド | 型 | 既定値 | 表示 |
|---|---|---|---|
| name | String（参照型） | null | null |
| age | int | 0 | 0 |
| active | boolean | false | false |
| rate | double | 0.0 | 0.0 |
| scores[1] | int の配列の要素 | 0 | 0 |
| grade | char | '\u0000'（文字コード 0） | `grade == 0` は true |

よって「null:0:false:0.0:0:true」です。

- A: String の既定値は空文字（""）ではなく null です。null を文字列につなぐと "null" と表示されます。
- C: double の値を文字列にすると、0 でも「0.0」と表示されます。
- D: scores 自体は `new int[2]` で作ってあり、その**要素**は int の既定値 0 です。null になるのは、配列を作っていない参照型の変数（`int[] x;` のフィールド）や、参照型の配列の要素です。
- grade: char の既定値は文字コード 0 の文字です。char と int を == で比べると、文字コードの数値で比べるので true になります。
