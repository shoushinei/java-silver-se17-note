次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int i = 0, count = 0;
        while (i++ < 3) {
            int j = i;
            do {
                count++;
            } while (j++ < 2);
        }
        System.out.println(i + " " + count);
    }
}
```

- A. 「3 4」と表示される
- B. 「4 1」と表示される
- C. 「3 3」と表示される
- D. 「4 6」と表示される
- E. 「4 4」と表示される

## 解説
外側の while と内側の do-while を、周ごとに追います。

| 外側の判定 | 本体での i | 内側の do-while | count |
|---|---|---|---|
| 0 < 3 → true（i は 1 に） | 1 | j = 1。count++ → 判定 1 < 2 は true（j は 2 に）→ count++ → 判定 2 < 2 は false | 2 |
| 1 < 3 → true（i は 2 に） | 2 | j = 2。count++ → 判定 2 < 2 は false | 3 |
| 2 < 3 → true（i は 3 に） | 3 | j = 3。count++ → 判定 3 < 2 は false | 4 |
| 3 < 3 → false（**i は 4 に**） | ー | ー | 4 |

よって「4 4」です。ポイントは2つあります。

- **条件式の i++ は、false になった最後の判定でも i を増やします**。ループを抜けたときの i は 3 ではなく 4 です（A・C は誤り）。
- **do-while は、条件が最初から false でも本体を1回実行します**。2周目と3周目でも count が 1 ずつ増えます。B は、内側を while のように先に判定すると考えた場合の値です。
