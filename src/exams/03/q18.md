次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int[][] m = new int[3][];
        m[0] = new int[] {1, 2};
        m[2] = new int[4];
        int total = 0;
        for (int i = 0; i < m.length; i++) {
            total += m[i].length;
            System.out.println(total);
        }
    }
}
```

- A. 「2」「2」「6」と表示される
- B. 「2」と表示されたあと、NullPointerException がスローされる
- C. 「2」と表示されたあと、ArrayIndexOutOfBoundsException がスローされる
- D. 3 行目で2つ目の要素数を省略しているため、コンパイルエラーが発生する
- E. 「2」「6」と表示される

## 解説
`new int[3][]` は、**行を入れる外側の配列（要素数 3）だけ**を作ります。各行は配列型（int[]）の要素なので、既定値の **null** が入っています。

| 要素 | 中身 | length |
|---|---|---|
| m[0] | {1, 2} | 2 |
| m[1] | null（代入していない） | 読めない |
| m[2] | {0, 0, 0, 0} | 4 |

ループの1周目は total が 2 になり「2」と表示します。2周目で `m[1].length` を読もうとしますが、m[1] は null なので **NullPointerException** がスローされます。

- A: null は「長さ 0 の配列」ではありません。null の length を読むと例外です。
- C: m.length は 3 なので、添字の 1 は範囲内です。範囲外ではなく、中身が null なのが原因です。
- D: 2つ目以降の要素数は省略できます（行ごとに長さの違う配列を後から入れられる）。省略できないのは最初の要素数で、`new int[][3]` はエラーです。
- E: for 文は null の行を自動で飛ばしたりしません。
