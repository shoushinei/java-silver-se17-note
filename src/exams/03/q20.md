次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static int zero() {
        System.out.print("Z");
        return 0;
    }
    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        try {
            int r = a[3] / zero();
            System.out.print(r);
        } catch (ArithmeticException e) {
            System.out.print("A");
        } catch (ArrayIndexOutOfBoundsException e) {
            System.out.print("B");
        } finally {
            System.out.print("F");
        }
    }
}
```

- A. 「ZAF」と表示される
- B. 「ZBF」と表示される
- C. 「BF」と表示される
- D. 「AF」と表示される
- E. 「ZABF」と表示される

## 解説
9 行目の `a[3] / zero()` は、0 で割る計算に目が行くように作ってあります。しかし Java の式は**左から順に**評価されます。

1. まず左のオペランド `a[3]` を読みます。a の要素数は 3（使える添字は 0〜2）なので、ここで **ArrayIndexOutOfBoundsException** が発生します。
2. 例外が発生した時点で式の評価は止まるので、右のオペランド `zero()` は**呼ばれません**。「Z」も表示されず、割り算も行われません。
3. `catch (ArrayIndexOutOfBoundsException e)` が捕まえて「B」、最後に finally で「F」。

よって「BF」です。

- A・B: zero() が呼ばれるのは、`a[3]` を読み終わったあとです。その前に例外が発生しています。
- D: 割り算までたどり着かないので、ArithmeticException は発生しません。
- E: 1つの例外を捕まえる catch は、上から最初に一致した1つだけです。
