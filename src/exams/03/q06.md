次の2つのクラスがあります。

```java title=Counter.java
public class Counter {
    private int count;

    public Counter(int count) {
        count = count + 1;
    }

    public void add(int n) {
        int count = this.count + n;
        this.count = count * 2;
    }

    public void reset() {
        int count = 0;
    }

    public int get() {
        return count;
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Counter c = new Counter(5);
        c.add(1);
        c.reset();
        c.add(3);
        System.out.println(c.get());
    }
}
```

Main をコンパイル、実行したときの結果として、正しいものを選びなさい。

- A. 「0」と表示される
- B. 「6」と表示される
- C. 「34」と表示される
- D. 「10」と表示される
- E. 同じ名前の count をフィールドとローカル変数の両方に使っているため、コンパイルエラーが発生する

## 解説
各メソッドの `count` が、フィールドなのか引数・ローカル変数なのかを見分ける問題です。

| 場所 | `count` が指すもの | フィールドの値 |
|---|---|---|
| コンストラクタ `count = count + 1;` | 両方とも**引数**。引数が 6 になるだけ | 0（既定値のまま） |
| `add(1)` | ローカル変数 count = 0 + 1 = 1。`this.count = 1 * 2` | 2 |
| `reset()` | ローカル変数 count を新しく作って 0 を入れるだけ | 2 |
| `add(3)` | ローカル変数 count = 2 + 3 = 5。`this.count = 5 * 2` | 10 |

よって「10」です。フィールドを書き換えているのは、`this.count = ...` と書いた add の2行目だけです。

- B: reset() でフィールドが 0 に戻ると考えた場合の値です（2 → 0 → 6）。
- C: コンストラクタでフィールドが 6 になると考えた場合の値です（6 → 14 → 34）。
- E: フィールドと同じ名前のローカル変数や引数は宣言できます。そのメソッドの中では、名前だけで書くとローカル変数のほうを指す（フィールドを隠す）だけです。
