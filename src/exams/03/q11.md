次のクラスが Vehicle.java に定義されています。

```java title=Vehicle.java
public sealed class Vehicle permits Car, Truck {
}

final class Car extends Vehicle {
}

non-sealed class Truck extends Vehicle {
}
```

Vehicle.java の末尾に追加したとき、コンパイルが成功するクラス宣言を選びなさい。

- A. `class Sports extends Car { }`
- B. `class Van extends Truck { }`
- C. `sealed class Dump extends Truck { }`
- D. `record Kart() extends Truck { }`
- E. `final class Mini extends Truck { }`
- F. `non-sealed class Bus extends Car { }`

## 解説
sealed で継承先を制限しているのは **Vehicle の直接の子（Car と Truck）だけ**です。孫から先は、その子に付けた修飾子で決まります。

- Car は `final` なので、だれも継承できません。A と F はエラーです（F の non-sealed は、そもそも sealed なクラスの子にしか付けられません）。
- Truck は `non-sealed` なので、ふつうのクラスと同じように**自由に継承できます**。B のように修飾子なしでも、E のように final を付けても OK です。
- C: `sealed` を付けたクラスには、許可するサブクラスが少なくとも1つ必要です。Dump を継承するクラスはどこにも無いので、「sealed class must have subclasses」というエラーになります。
- D: record は暗黙に final で、ほかのクラスを `extends` できません（インタフェースの implements はできます）。
