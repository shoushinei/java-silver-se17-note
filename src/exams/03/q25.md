次の2つのファイルがあります。

```java title=lib/Base.java
package lib;

public class Base {
    protected Base() {
    }

    protected void hello() {
        System.out.println("hello");
    }
}
```

```java title=app/Sub.java
package app;

import lib.Base;

public class Sub extends Base {
    public Sub() {
        super();
    }

    void test() {
        hello();
        Base b = new Base();
        this.hello();
        new Sub().hello();
    }
}
```

2つのファイルをコンパイルしたとき、Sub.java でコンパイルエラーになる行を選びなさい。

- A. 7 行目
- B. 11 行目
- C. 12 行目
- D. 13 行目
- E. 14 行目
- F. コンパイルエラーは発生しない

## 解説
Sub は、別のパッケージ（lib）にある Base を継承しています。protected のメンバに届くかどうかは、使い方によって変わります。

| 行 | 書き方 | 判定 |
|---|---|---|
| 7 | `super();` | OK。子のコンストラクタから、親の protected コンストラクタを呼ぶのは許される |
| 11 | `hello();` | OK。自分（Sub 型の this）を通して呼んでいる |
| 12 | `new Base()` | **エラー**。別パッケージから protected のコンストラクタを new で呼ぶことはできない |
| 13 | `this.hello();` | OK。11 行目と同じ |
| 14 | `new Sub().hello();` | OK。別のインスタンスでも、参照の型が Sub（自分の型）なら届く |

protected のコンストラクタは、別のパッケージからは「子のコンストラクタの super(...) として」だけ呼べます。`new Base()` は、子クラスの中に書いても、Base の作成を外から頼むことになるので許されません。
