次のプログラムを実行して「11 true」と表示させたい。`// insert code here` の位置に記述するコードとして、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static int count = 0;

    static boolean t() {
        count += 1;
        return true;
    }

    static boolean f() {
        count += 10;
        return false;
    }

    public static void main(String[] args) {
        // insert code here
        System.out.println(count + " " + r);
    }
}
```

- A. `boolean r = t() || f() && f();`
- B. `boolean r = f() || t() && f();`
- C. `boolean r = t() && f() || t();`
- D. `boolean r = f() && t() || t();`
- E. `boolean r = t() & f() | t();`
- F. `boolean r = f() | t() && t();`

## 解説
押さえる点は2つです。

- **優先順位**: `&` ＞ `|` ＞ `&&` ＞ `||`。`&&` は `||` より先に結びつきます。
- **短絡評価**: `&&` は左が false なら右を評価しません。`||` は左が true なら右を評価しません。`&` と `|` は必ず両方を評価します。

t() は count を 1 増やし、f() は 10 増やします。

括弧を補って、呼ばれる順に追います。

- A: `t() || (f() && f())` → t() が true なので、`||` の右は評価しない。「1 true」
- B: `f() || (t() && f())` → f() → t() → f() の順に呼ばれる。「21 false」
- C: `(t() && f()) || t()` → t() → f() → t()。「12 true」
- D: `(f() && t()) || t()` → f() が false なので `&&` の右の t() は飛ばし、`||` の右の t() を呼ぶ。「11 true」
- E: `(t() & f()) | t()` → `&` と `|` は全部評価するので t() → f() → t()。「12 true」
- F: `(f() | t()) && t()` → `|` は `&&` より先に結びつく。f() → t() → t()。「12 true」

「11」になるのは、f() が1回・t() が1回だけ呼ばれる D です。
