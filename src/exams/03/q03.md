作業ディレクトリの下に、次の3つのファイルがあります。

```java title=shop/model/Item.java
package shop.model;

public class Item {
    public String name() {
        return "model";
    }
}
```

```java title=shop/app/Item.java
package shop.app;

class Item {
    String name() {
        return "app";
    }
}
```

```java title=shop/app/Main.java
package shop.app;

import shop.model.*;

public class Main {
    public static void main(String[] args) {
        Item item = new Item();
        System.out.println(item.name());
    }
}
```

作業ディレクトリで次のコマンドを実行したときの結果として、正しいものを選びなさい。

```console
> javac shop/model/Item.java shop/app/Item.java shop/app/Main.java
> java shop.app.Main
```

- A. 「app」と表示される
- B. 「model」と表示される
- C. Item が2つのパッケージにあってあいまいなため、Main.java でコンパイルエラーが発生する
- D. shop.app.Item が public ではないため、Main.java でコンパイルエラーが発生する
- E. shop.model.Item と同じ名前のクラスを宣言しているため、shop/app/Item.java でコンパイルエラーが発生する

## 解説
Main.java の中の `Item` という名前は、次の強さの順で探されます。

| 強さ | 名前の見つけ方 |
|---|---|
| 1 | そのファイルで宣言したクラスと、名指しの import（`import shop.model.Item;`） |
| 2 | 同じパッケージのクラス |
| 3 | `*` の import（`import shop.model.*;`） |

Main と同じ shop.app パッケージに Item クラスがあるので、2 で見つかります。`import shop.model.*;` で取り込まれる shop.model.Item は、より弱い 3 なので使われません。よって「app」と表示されます。

- B: `import shop.model.Item;` と**名指し**で import していれば、1 の強さになるので「model」と表示されます。`*` の import は、同じパッケージのクラスに負けます。
- C: あいまいでエラーになるのは、**同じ強さ**の候補が2つ見つかったとき（`*` の import どうしで同じ名前があるときなど）です。ここでは強さが違うので、エラーになりません。
- D: 修飾子の無いクラスは同じパッケージから使えます。Main と shop.app.Item は同じ shop.app パッケージです。
- E: 別のパッケージに同じ名前のクラスがあっても問題ありません。パッケージが違えば、完全修飾名（shop.app.Item と shop.model.Item）で区別されます。
