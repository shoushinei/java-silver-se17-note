次の2つのクラスがあります。

```java title=Ticket.java
public class Ticket {
    private String title;
    private int price;

    public Ticket(String title, int price) {
        this.title = title;
        this.price = price;
    }

    public Ticket(String title) {
        this(title, 1000);
    }

    public int price() {
        return price;
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Ticket[] tickets = {
            new Ticket("A"), new Ticket("B", 1500), new Ticket()
        };
        int sum = 0;
        for (Ticket t : tickets) {
            sum += t.price();
        }
        System.out.println(sum);
    }
}
```

Main をコンパイル、実行したときの結果として、正しいものを選びなさい。

- A. 「2500」と表示される
- B. 「3500」と表示される
- C. 実行時に NullPointerException がスローされる
- D. Main.java の 4 行目でコンパイルエラーが発生する
- E. Ticket.java の 11 行目でコンパイルエラーが発生する

## 解説
引数なしのコンストラクタ（デフォルトコンストラクタ）が自動で作られるのは、**クラスにコンストラクタを1つも書かなかったとき**だけです。Ticket には2つのコンストラクタを書いているので、`Ticket()` はありません。Main.java の 4 行目の `new Ticket()` がコンパイルエラーです。

- A: 引数なしのコンストラクタがあって price が既定値の 0 だった場合の合計（1000 + 1500 + 0）です。
- B: `new Ticket()` でも price が 1000 になると考えた場合の合計です。
- C: 配列の要素はすべて new で作っているので null はありません。そもそもコンパイルが通りません。
- E: `this(title, 1000)` は、同じクラスのコンストラクタ `Ticket(String, int)` を呼ぶ正しい書き方です。

計算を追わせておいて、実はコンパイルエラーという作りです。new の引数とコンストラクタの引数の並びが合っているかを、計算より先に確かめましょう。
