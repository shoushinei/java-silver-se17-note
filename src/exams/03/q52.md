次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Score.java
public class Score {
    private int point;
    private static int total;

    void add(int p) {
        point += p;
        total += p;
    }

    static int sum(Score... list) {
        int s = 0;
        for (Score sc : list) {
            s += sc.point;
        }
        return s;
    }

    static void show() {
        System.out.println(point + " " + total);
    }

    public static void main(String[] args) {
        Score a = new Score();
        Score b = new Score();
        a.add(3);
        b.add(4);
        System.out.println(sum(a, b) + " " + total);
        show();
    }
}
```

- A. 「7 7」「0 7」と表示される
- B. 「7 7」「4 7」と表示される
- C. 13 行目で、static メソッドの中でインスタンス変数 point を使っているため、コンパイルエラーが発生する
- D. 19 行目で、static メソッドの中でインスタンス変数 point を使っているため、コンパイルエラーが発生する
- E. 7 行目で、インスタンスメソッドの中で static 変数 total を使っているため、コンパイルエラーが発生する

## 解説
static メソッドは、インスタンスを作らずに呼べるメソッドです。そのため **this が無く**、「どのインスタンスの point か」が決まりません。

| 行 | 場所 | 書き方 | 判定 |
|---|---|---|---|
| 7 | インスタンスメソッド add | `total += p;` | OK。インスタンスメソッドからは static 変数も使える |
| 13 | static メソッド sum | `sc.point` | OK。**インスタンス（sc）を通して**いるので、どの point か決まる |
| 19 | static メソッド show | `point` | **エラー**。名前だけでは、どのインスタンスの point か決まらない |

よって 19 行目でコンパイルエラーです。sum と show はどちらも static メソッドの中で point を使っていますが、インスタンスを通しているかどうかが分かれ目です（C は誤り）。

- A・B: コンパイルが通らないので、実行されません。show を消せば「7 7」と表示されます。
- E: インスタンスメソッドからは、インスタンス変数も static 変数も使えます。
