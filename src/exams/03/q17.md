次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class P {
    String name = "P";
    String getName() {
        return name;
    }
}
class C extends P {
    String name = "C";
    void show() {
        System.out.print(name);
        System.out.print(super.name);
        System.out.print(((P) this).name);
        System.out.print(getName());
        System.out.print(this.name);
    }
}
public class Main {
    public static void main(String[] args) {
        new C().show();
    }
}
```

- A. 「CPPPC」と表示される
- B. 「CPCCC」と表示される
- C. 「CPPCC」と表示される
- D. 「CPCPC」と表示される
- E. 「CCCCC」と表示される
- F. 同じ名前のフィールド name を C で宣言しているため、コンパイルエラーが発生する

## 解説
C のインスタンスの中には、P の name（"P"）と C の name（"C"）の**2つのフィールド**があります。フィールドはオーバーライドされず、子のフィールドが親のフィールドを**隠す**だけです（F は誤り）。どちらを使うかは、実体ではなく**参照の型**でコンパイル時に決まります。

| 行 | 書き方 | 参照の型 | 表示 |
|---|---|---|---|
| 10 | `name` | C（C の中のコード） | C |
| 11 | `super.name` | P（親として見る） | P |
| 12 | `((P) this).name` | P（キャストで P 型の参照にした） | P |
| 13 | `getName()` | getName は P で定義され、C でオーバーライドしていない。P の中の `name` は P のフィールド | P |
| 14 | `this.name` | C | C |

よって「CPPPC」です。

- 12 行目: 実体は C のままですが、フィールドは参照の型で決まるので、P 型にキャストすると P の name が見えます。メソッドならキャストしても実体（C）のものが呼ばれる点と区別しましょう。
- 13 行目: メソッドの呼び出しは実体の型で決まりますが、C は getName をオーバーライドしていないので、P の getName が動きます。その中の `name` は、P のクラスの中で書かれているので P のフィールドです（C のフィールドは見えません）。
- C の選択肢は、getName の中の name まで実体（C）で決まると考えた場合の誤りです。
