次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int[] scores = {72, 85, 64};
        int max;
        for (int s : scores) {
            if (s > 80) {
                max = s;
            }
        }
        System.out.println("max=" + max);
    }
}
```

- A. 「max=85」と表示される
- B. 「max=0」と表示される
- C. 「max=null」と表示される
- D. 10 行目でコンパイルエラーが発生する
- E. 7 行目でコンパイルエラーが発生する

## 解説
ローカル変数 max は、宣言しただけで値が入っていません。ローカル変数には既定値が**入らない**ので、使う前に必ず代入されていなければなりません。

コンパイラは、変数の値を実際に計算せずに「**どの経路を通っても代入済みか**」を調べます。

- for 文は1回も回らないかもしれない（配列が空かもしれない）
- if の条件が一度も true にならないかもしれない

どちらの場合も max に代入されないまま 10 行目に届くので、10 行目の `max` で「初期化されていない可能性がある」というコンパイルエラーになります。実際の配列には 85 があることは、判定に使われません。

- A: 中身を追うと 85 ですが、コンパイルが通りません。
- B・C: 既定値（0 や null）が入るのはフィールドと配列の要素です。ローカル変数には入りません。
- E: 宣言済みの変数への代入なので、7 行目は問題ありません。エラーになるのは、値を**読む**10 行目です。

`int max = 0;` のように宣言と同時に初期化するか、if に else を付けてすべての経路で代入すれば、コンパイルできます。
