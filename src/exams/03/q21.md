次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static int calc(int n) {
        return switch (n) {
            case 1:
            case 2:
                yield n * 10;
            case 3:
                System.out.print("[3]");
            default:
                yield -1;
        };
    }
    public static void main(String[] args) {
        System.out.println(calc(2) + " " + calc(3) + " " + calc(5));
    }
}
```

- A. 「[3]20 -1 -1」と表示される
- B. 「20 [3]-1 -1」と表示される
- C. 「20 -1 -1」と表示される
- D. switch 式でコロン（:）の case を使っているため、コンパイルエラーが発生する
- E. case 3 に yield が無いため、コンパイルエラーが発生する

## 解説
switch 式でも、従来と同じコロン（:）の case を使えます（アローとの混在はできません）。D は誤りです。

**フォールスルーするかどうかは、「文か式か」ではなく「コロンかアローか」で決まります**。コロンの case は、switch 式の中でも次の case へ流れ込み、`yield` に来たところで値を返して抜けます。

- `calc(2)`: `case 2:` から `yield n * 10;` で 20 を返す。
- `calc(3)`: `case 3:` から「[3]」を表示し、yield が無いので `default:` へ流れ込んで `yield -1;`。
- `calc(5)`: どれにも一致しないので `default:` から -1。

E: case 3 の中に yield が無くても、下へ流れた先の default で yield しているので問題ありません。エラーになるのは、yield しないまま switch 式の最後まで流れ切ってしまう場合です。

次に表示の順番です。println は、**引数の文字列を全部作り終えてから**表示します。引数を作る途中、calc(3) を呼んだときに「[3]」が先に画面に出て、そのあと println が「20 -1 -1」を表示します。よって「[3]20 -1 -1」です。

- B: 「[3]」は println より先、calc(3) が呼ばれた瞬間に表示されます。
- C: calc(3) の中の print を見落とした誤りです。
