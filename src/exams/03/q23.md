次の2つのクラスがあります。

```java title=Card.java
public class Card {
    protected int point;
    private final String id;

    public Card(String id) {
        this.id = id;
    }

    public void add(int p) {
        if (p > 0) {
            point += p;
        }
    }

    public final String id() {
        return id;
    }

    @Override
    public String toString() {
        return id + ":" + point;
    }
}
```

```java title=GoldCard.java
public class GoldCard extends Card {
    private int rate = 2;

    public GoldCard(String id) {
        super(id);
    }

    @Override
    public void add(int p) {
        super.add(p * rate);
    }

    public void bonus() {
        add(0);
    }
}
```

これらのクラスについての説明として、正しいものを選びなさい。

- A. GoldCard で id() をオーバーライドすれば、別の id を返すようにできる
- B. `Card c = new GoldCard("G1"); c.add(10);` を実行すると、c の point は 20 になる
- C. GoldCard の bonus() を呼んでも、point は変わらない
- D. GoldCard のメソッドの中から、id フィールドを直接読み書きできる
- E. GoldCard は toString をオーバーライドしていないので、`new GoldCard("G1").toString()` は「GoldCard@1b6d3586」のような文字列を返す
- F. GoldCard のメソッドの中から、point フィールドを直接読み書きできる

## 解説
- A: 誤り。Card の id() は `final` なので、オーバーライドできません。
- B: 正しい。変数の型は Card でも、実体は GoldCard なので GoldCard の add が動きます。`super.add(10 * 2)` で Card の add に 20 が渡り、point は 20 になります。
- C: 正しい。bonus() は `add(0)` を呼びます。GoldCard の add が `super.add(0)` を呼びますが、Card の add は `p > 0` のときだけ足すので、何も変わりません。
- D: 誤り。id は Card の `private` フィールドなので、サブクラスからでも直接は使えません（id() メソッドを通して読むことはできます）。
- E: 誤り。GoldCard は、Card でオーバーライドした toString を受け継いでいます。「G1:0」が返ります。
- F: 正しい。point は `protected` なので、サブクラスの中から直接読み書きできます。
