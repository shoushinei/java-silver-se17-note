次のコードと同じ結果になるコードとして、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String[] names = {"a", "b", "c"};
        for (String n : names) {
            System.out.print(n);
        }
    }
}
```

- A.
  ```java
  for (int i = 0; i <= names.length; i++) {
      System.out.print(names[i]);
  }
  ```
- B.
  ```java
  for (int i = 1; i < names.length; i++) {
      System.out.print(names[i]);
  }
  ```
- C.
  ```java
  for (int i = 0; i < names.length; ) {
      System.out.print(names[i++]);
  }
  ```
- D.
  ```java
  for (int i = 0; ++i < names.length; ) {
      System.out.print(names[i]);
  }
  ```
- E.
  ```java
  for (int i = names.length; i > 0; i--) {
      System.out.print(names[i - 1]);
  }
  ```

## 解説
元のコードは「abc」を表示します。添字 0・1・2 を順に使えば同じになります。

- A: `i <= names.length` なので i が 3 のときも実行され、`names[3]` で ArrayIndexOutOfBoundsException になります（「abc」の後に例外）。
- B: 1 から始まるので「bc」です。
- C: 更新部が空ですが、`names[i++]` で**使ってから** i を増やしています。0・1・2 の順に使われ「abc」です。
- D: 条件の `++i` で**先に増やす**ので、最初に使われるのは 1 です。「bc」になります。
- E: 後ろから回すので「cba」です。

for 文の更新部は空でもよく、ループの中で変数を増やしても構いません。
