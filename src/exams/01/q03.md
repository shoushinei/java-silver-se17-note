次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Res.java
public class Res implements AutoCloseable {
    private final String id;
    public Res(String id) {
        this.id = id;
        System.out.print("open" + id + " ");
    }
    @Override
    public void close() {
        System.out.print("close" + id + " ");
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        try (Res a = new Res("1"); Res b = new Res("2")) {
            System.out.print("body ");
            throw new IllegalStateException();
        } catch (IllegalStateException e) {
            System.out.print("catch ");
        } finally {
            System.out.print("finally");
        }
    }
}
```

- A. 「open1 open2 body catch close2 close1 finally」と表示される
- B. 「open1 open2 body catch finally close1 close2」と表示される
- C. 「open1 open2 body close1 close2 catch finally」と表示される
- D. 「open1 open2 body close2 close1 catch finally」と表示される
- E. close メソッドに throws が無いため、コンパイルエラーが発生する

## 解説
try-with-resources の順序は次のとおりです。

- リソースは**宣言した順に**作られる（open1 → open2）
- try ブロックが終わると（例外で抜けるときも）、リソースは**宣言と逆の順に**閉じられる（close2 → close1）
- **閉じ終わってから** catch ブロック、最後に finally ブロックへ進む

したがって「open1 open2 body close2 close1 catch finally」です。catch の中ではリソースはすでに閉じています。A のように catch の後で閉じると考えるのは誤りです。

E について: `AutoCloseable` の `close()` は `throws Exception` と宣言されていますが、オーバーライドする側は **throws を減らしたり無くしたりしてよい**ので、コンパイルエラーにはなりません。
