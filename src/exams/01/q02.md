次の2つのクラスを確認してください。

```java title=shop/core/Cart.java
package shop.core;

public class Cart {
}
```

```java title=shop/util/Tax.java
package shop.util;

public class Tax {
}
```

これらを使う次のクラスの `// import` の位置に書く import 文として、正しいものを選びなさい。

```java title=app/Checkout.java
package app;
// import

public class Checkout extends Cart {
    public void run() {
        Tax tax = new Tax();
    }
}
```

- A. `import shop.*;`
- B. `import shop.core.Cart;`
- C. `import static shop.util.Tax;`
- D. `import shop.util.*;`
- E. `import static shop.core.*;`
- F. `import shop.core;`

## 解説
`Cart` は `shop.core` パッケージ、`Tax` は `shop.util` パッケージのクラスです。それぞれを取り込む B（クラス単位）と D（パッケージ単位の `*`）が正解です。

- A の `import shop.*;` は、`shop` パッケージ直下のクラスだけを対象にします。**サブパッケージの `shop.core` や `shop.util` は含まれません。** パッケージ名が階層に見えても、import の上では別のパッケージです。
- C と E の `import static` は、クラスの **static メンバ**（static メソッドや static フィールド）を取り込む書き方です。クラスそのものを取り込むことはできません。
- F の `import shop.core;` は、パッケージ名だけを書いていて文法として成り立ちません。パッケージ全体なら `import shop.core.*;` と書きます。

## 検証
@case 正解 B + D ならコンパイルできる
@stem
@file app/Checkout.java
package app;
import shop.core.Cart;
import shop.util.*;

public class Checkout extends Cart {
    public void run() {
        Tax tax = new Tax();
    }
}
@javac

@case A はサブパッケージを含まない（A + D では Cart が見つからない）
@stem
@file app/Checkout.java
package app;
import shop.*;
import shop.util.*;

public class Checkout extends Cart {
    public void run() {
        Tax tax = new Tax();
    }
}
@javac-error cannot find symbol

@case C の import static でクラスは取り込めない
@stem

package app;

import static shop.util.Tax;

    public void run() {
        Tax tax = new Tax();
    }
}
@javac-error

@case E の import static でもクラスは取り込めない

import shop.util.*;

    public void run() {
        Tax tax = new Tax();

@javac-error
