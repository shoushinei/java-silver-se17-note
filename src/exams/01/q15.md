次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Point.java
public class Point {
    private final int x, y;
    public Point(int x, int y) {
        this.x = x;
        this.y = y;
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String p = "ok";
        String q = new StringBuilder("o").append("k").toString();
        Point a = new Point(1, 2);
        Point b = new Point(1, 2);
        Point c = a;

        System.out.print(p == q ? "1" : "2");
        System.out.print(p.equals(q) ? "3" : "4");
        System.out.print(a.equals(b) ? "5" : "6");
        System.out.print(a == c ? "7" : "8");
    }
}
```

- A. 「1357」と表示される
- B. 「2357」と表示される
- C. 「1367」と表示される
- D. 「2367」と表示される
- E. 「2368」と表示される

## 解説
- `p == q`: q は StringBuilder から**実行時に作った文字列**で、プールの "ok" とは別のインスタンスです。中身が同じでも `==` は false で「2」。
- `p.equals(q)`: String の equals は中身を比べるので true で「3」。
- `a.equals(b)`: Point は **equals をオーバーライドしていない**ので、Object の equals（参照の比較）が使われます。別々に new したので false で「6」。
- `a == c`: c は a と同じインスタンスを指すので true で「7」。

「x と y が同じだから a.equals(b) は true」と考えると B を選んでしまいます。中身で比べたいなら、`equals(Object)` をオーバーライドする必要があります。
