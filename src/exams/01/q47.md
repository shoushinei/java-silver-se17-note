次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Base {
    private String tag() { return "base"; }
    public String show() { return tag(); }
}
class Derived extends Base {
    private String tag() { return "derived"; }
    public String show2() { return tag(); }
}

public class Main {
    public static void main(String[] args) {
        Derived d = new Derived();
        System.out.println(d.show() + " " + d.show2());
    }
}
```

- A. 「base derived」と表示される
- B. 「derived derived」と表示される
- C. 「base base」と表示される
- D. Derived で private メソッドを再定義しているため、コンパイルエラーが発生する

## 解説
private メソッドは**継承されません**。Derived の `tag()` は Base の `tag()` をオーバーライドしているのではなく、たまたま同じ名前の**別のメソッド**です。同名で定義すること自体は問題ありません（D は誤り）。

- `d.show()`: show() は Base のメソッドで、その中の `tag()` は Base の private な tag() です。オーバーライドされていないので多態は起きず「base」
- `d.show2()`: Derived の中の `tag()` は Derived の tag() で「derived」

「実体が Derived だから、どちらも derived」と考えると B を選んでしまいます。多態が起きるのは、オーバーライドしたメソッドだけです。
