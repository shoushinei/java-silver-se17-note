次のプログラムを確認してください。

```java title=Animal.java
public class Animal {
}
```

```java title=Dog.java
public class Dog extends Animal {
}
```

```java title=Breeder.java
public interface Breeder {
    Animal breed(int count);
}
```

Breeder インタフェースを実装したクラス（abstract ではない）に記述するメソッドとして、正しいものを選びなさい。

- A.
  ```java
  public Dog breed(int count) {
      return new Dog();
  }
  ```
- B.
  ```java
  public Object breed(int count) {
      return new Animal();
  }
  ```
- C.
  ```java
  Animal breed(int count) {
      return new Animal();
  }
  ```
- D.
  ```java
  public Animal breed(int count) {
      return new Dog();
  }
  ```
- E.
  ```java
  public Dog breed(Integer count) {
      return new Dog();
  }
  ```

## 解説
インタフェースのメソッドを実装する（オーバーライドする）ときの条件は次のとおりです。

- **引数の型と数がまったく同じ**であること
- 戻り値の型は**同じか、そのサブクラス**であること（共変戻り値）
- アクセス修飾子は**狭められない**。インタフェースのメソッドは暗黙に public なので、実装側も public が必要

A は戻り値を Animal のサブクラスの Dog にしています。共変戻り値として認められます。D は戻り値型が同じ Animal で、中身として Dog のインスタンスを返しています。これも問題ありません。

- B の Object は Animal の**親**なので、戻り値を広げることになりエラーです。
- C は public が無いので、アクセスを狭めたことになりエラーです。
- E は引数が `Integer` で、`int` とは別の型です。オーバーライドではなく**別のメソッド（オーバーロード）**になり、`breed(int)` が実装されないままなのでエラーです。
