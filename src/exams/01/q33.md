次のプログラムのコンパイルを成功させる方法として、正しいものを選びなさい。

```java title=Engine.java
public interface Engine {
    void start();
}
```

```java title=Car.java
public abstract class Car /* position 1 */ {
    /* position 2 */
    public void start() { }
    public abstract void stop();
}
```

```java title=Taxi.java
public class Taxi extends Car implements Engine {
    /* position 3 */
}
```

- A. position 3 に `public void start() { }` を記述する
- B. position 3 に `public void stop() { }` を記述する
- C. position 2 に `void stop() { }` を記述する
- D. position 1 に `implements Engine` を記述する

## 解説
Taxi は abstract ではないクラスなので、受け継いだ**すべての abstract メソッドに本体を与える**必要があります。

- Engine の `start()`: 親の Car が `public void start()` を持っているので、それを受け継いだ時点で実装したことになります。
- Car の `stop()`: abstract のままです。これが原因でエラーになっています。

したがって Taxi に `stop()` を書く B で解決します。

- A: start() はすでに実装済みです。stop() が残るので解決しません。
- C: Car に同じシグネチャの stop() が2つ（abstract と本体つき）になり、重複でエラーです。
- D: Car が Engine を実装しても、stop() が残る点は変わりません。
