次のプログラムを確認してください。

```java title=Printer.java
public class Printer {
    public void print(Object o) {
        System.out.print("P-obj ");
    }
}
```

```java title=ColorPrinter.java
public class ColorPrinter extends Printer {
    @Override
    public void print(Object o) {
        System.out.print("C-obj ");
    }
    public void print(String s) {
        System.out.print("C-str ");
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Printer p1 = new Printer();
        Printer p2 = new ColorPrinter();
        ColorPrinter p3 = new ColorPrinter();
        String s = "x";
        // do something
    }
}
```

`// do something` の位置に次の文を書いたときの説明として、正しいものを選びなさい。

- A. `p1.print(s);` を実行すると「P-obj」と表示される
- B. `p2.print(s);` を実行すると「C-str」と表示される
- C. `p2.print(s);` を実行すると「C-obj」と表示される
- D. `p3.print(s);` を実行すると「C-str」と表示される
- E. `p3.print((Object) s);` を実行すると「C-str」と表示される

## 解説
メソッドの呼び出しは2段階で決まります。

1. **コンパイル時**: 変数の型が持っているメソッドの中から、引数の型に最も合う**シグネチャ**（オーバーロード）を選ぶ
2. **実行時**: 選ばれたシグネチャについて、実体のクラスがオーバーライドしていればそちらを実行する

- A: p1 は Printer 型、実体も Printer。`print(Object)` しかないので「P-obj」。正しい。
- B・C: p2 は **Printer 型**なので、コンパイラが見るのは Printer のメソッドだけです。`print(String)` は候補に入らず、`print(Object)` が選ばれます。実行時は実体の ColorPrinter がオーバーライドした `print(Object)` が動くので「C-obj」。B は誤りで C が正しい。
- D: p3 は ColorPrinter 型なので、`print(Object)` と `print(String)` の両方が候補です。引数が String なので、より具体的な `print(String)` が選ばれ「C-str」。正しい。
- E: キャストで引数の型を Object にしたので、コンパイル時に `print(Object)` が選ばれます。実行されるのは ColorPrinter の `print(Object)` で「C-obj」。E は誤り。

「実体が ColorPrinter だから、String を受け取る print が呼ばれる」と考えると B を選んでしまいます。**オーバーロードの選択は実体を見ません。**
