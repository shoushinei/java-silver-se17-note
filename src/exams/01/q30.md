次の2つのクラスがあります。コマンドは util と app の1つ上のディレクトリで実行するものとします。

```java title=util/Tool.java
package util;

public class Tool {
    public static String name() {
        return "tool";
    }
}
```

```java title=app/Main.java
package app;

import util.Tool;

public class Main {
    public static void main(String[] args) {
        System.out.println(Tool.name());
    }
}
```

**両方のクラスファイル（.class）を生成する**コマンドとして、正しいものを選びなさい。

- A. `java app/Main.java`
- B. `javac util/Tool.java`
- C. `javac app/Main.java`
- D. `javac Main.java`
- E. `java -cp . app.Main`

## 解説
javac は、コンパイルするクラスが使っている別のクラスを見つけると、**そのソースも探し出して一緒にコンパイル**します。`javac app/Main.java` を実行すると、Main が import している `util.Tool` のソースを、カレントディレクトリを起点に `util/Tool.java` として見つけ、`util/Tool.class` も作ります。C が正解です。

- A: ソース実行モードです。メモリの中でコンパイルして実行するだけで、**.class ファイルは作りません**。しかも SE 17 では渡した1ファイルしかコンパイルしないので、別ファイルの Tool が見つからずエラーになります。
- B: Tool は何も使っていないので、Tool.class しかできません。
- D: カレントディレクトリに Main.java は無いので、ファイルが見つかりません。
- E: 実行するだけのコマンドです。.class が無ければ実行もできません。

## 検証

@sh java app.Main

@end

@stem

@fails
