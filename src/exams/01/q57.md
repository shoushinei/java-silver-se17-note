次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        char[][] grid = {{'x', 'y'}, {'z'}, {}};
        for (var row : grid) {
            for (char c : row) {
                System.out.print(c);
            }
            System.out.print("|");
        }
    }
}
```

- A. 「xy|z|」と表示される
- B. 「xy|z||」と表示される
- C. 「xyz|」と表示される
- D. 3 行目でコンパイルエラーが発生する
- E. 実行時に ArrayIndexOutOfBoundsException がスローされる

## 解説
grid は3行の2次元配列で、各行の長さは 2・1・0 です。行ごとに長さが違ってもよく、`{}` は**要素が0個の配列**として正しく書けます（D は誤り）。

外側のループは行ごとに回り、`var row` は `char[]` 型になります。

- 1行目: x, y を表示して「|」 → `xy|`
- 2行目: z を表示して「|」 → `z|`
- 3行目: 要素が無いので内側のループは1回も回らず、「|」だけ → `|`

合わせて「xy|z||」です。拡張 for 文は配列の長さの分だけ回るので、添字を超えることはありません（E は誤り）。
