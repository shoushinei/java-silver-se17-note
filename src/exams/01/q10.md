次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Sensor.java
public class Sensor {
    public void report() {
        System.out.print("S");
    }
}
```

```java title=TempSensor.java
public class TempSensor extends Sensor {
    private void calibrate() {
        System.out.print("c");
    }
    @Override
    public void report() {
        calibrate();
        System.out.print("T");
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Object[] items = { new TempSensor(), "x", new Sensor(), 42 };
        for (Object o : items) {
            if (o instanceof Sensor s) {
                s.report();
            }
        }
    }
}
```

- A. 「cTS」と表示される
- B. 「TS」と表示される
- C. 「cTScTS」と表示される
- D. TempSensor の calibrate が private のため、コンパイルエラーが発生する
- E. 実行時に ClassCastException がスローされる

## 解説
`Object[]` には何でも入ります。`o instanceof Sensor s` は、o が Sensor（またはその子）のときだけ true になり、そのときだけ Sensor 型の変数 s が使えます。`"x"` と `42` は Sensor ではないので素通りします。キャストは行わないので、ClassCastException（E）は起きません。

- 1つ目の TempSensor: 実体が TempSensor なので、オーバーライドした `report()` が呼ばれる（多態）。その中で自分の private メソッド `calibrate()` を呼ぶので「c」「T」
- 3つ目の Sensor: 「S」

合わせて「cTS」です。`calibrate()` は private ですが、呼んでいるのは**同じ TempSensor クラスの中**なので問題ありません（D は誤り）。
