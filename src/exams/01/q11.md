次のクラスを確認してください。

```java title=Box.java
public class Box {
    int w, h, d;

    void setW(int w) {
        w = w;
    }
    void setH(int h) {
        this.h = h;
    }
    int getD() {
        return d;
    }
    void resize(int size) {
        int d = size;
        w = h = d;
    }
    void fill(int v) {
        w = h = this.d = v;
    }
}
```

フィールド w・h・d の**3つすべて**を変更するメソッドはどれか。正しいものを選びなさい。

- A. setW メソッド
- B. setH メソッド
- C. getD メソッド
- D. resize メソッド
- E. fill メソッド
- F. どのメソッドも3つすべては変更しない

## 解説
メソッドの中で、フィールドと同じ名前の引数やローカル変数があると、**名前はそちらを指します**。フィールドを指したいときは `this.` を付けます。

- setW: `w = w;` の左右どちらも引数の w です。フィールドは変わりません。
- setH: `this.h` はフィールドなので、h だけが変わります。
- getD: 値を返すだけです。
- resize: `int d = size;` で**ローカル変数 d** を作っています。次の `w = h = d;` の d はこのローカル変数なので、フィールド w と h は変わりますが、フィールド d は変わりません。
- fill: 同名の変数が無いので w と h はフィールドです。`this.d` もフィールドです。代入は右から `this.d = v` → `h = this.d` → `w = h` の順に行われ、**3つすべてが v になります**。

## 検証
@case 正解 E: fill だけが w・h・d をすべて変える

public class Main {
    static String show(Box b) { return b.w + "," + b.h + "," + b.d; }
    public static void main(String[] args) {
        Box a = new Box(); a.setW(5);    System.out.println("setW   " + show(a));
        Box b = new Box(); b.setH(5);    System.out.println("setH   " + show(b));
        Box c = new Box(); c.getD();     System.out.println("getD   " + show(c));
        Box d = new Box(); d.resize(5);  System.out.println("resize " + show(d));
        Box e = new Box(); e.fill(5);    System.out.println("fill   " + show(e));
    }
}
