次のプログラムの `// insert code here` の位置に記述すると**コンパイルエラーになるもの**を選びなさい。

```java title=Item.java
public record Item(String name, int qty) {
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Item a = new Item("pen", 3);
        Item b = new Item("pen", 3);
        // insert code here
    }
}
```

- A. `a.qty = 5;`
- B. `int q = a.getQty();`
- C. `boolean same = a.equals(b);`
- D. `Item c = new Item("cup");`
- E. `String n = a.name();`
- F. `a = new Item("cup", 1);`
- G. `System.out.println(a == b);`

## 解説
record `Item(String name, int qty)` からは、次のものが自動で作られます。

- `private final` のフィールド `name` と `qty`
- 全コンポーネントを受け取るコンストラクタ `Item(String name, int qty)`
- アクセサ `name()` と `qty()`（**get は付かない**）
- 中身で比較する `equals`、`hashCode`、`toString`

これに照らすと次のようになります。

- A: フィールドは private で、しかも final です。外から代入できません。エラー。
- B: アクセサは `qty()` です。`getQty()` というメソッドは存在しません。エラー。
- D: 自動で作られるコンストラクタは2引数だけです。1引数のコンストラクタは無いのでエラー。
- C・E はどちらも自動で作られるメソッドを呼んでいるだけです。
- F: 変数 a 自体は final ではないので、別の Item を代入し直せます。
- G: 参照の比較は書けます（結果は false）。

public class Main {
    public static void main(String[] args) {
        Item a = new Item("pen", 3);
        Item b = new Item("pen", 3);
        boolean same = a.equals(b);
        String n = a.name();
        System.out.println(a == b);
        a = new Item("cup", 1);
        System.out.println(same + " " + n + " " + a);
    }
}
