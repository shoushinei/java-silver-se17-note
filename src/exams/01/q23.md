次のうち、メソッドの定義として**正しくないもの**を選びなさい。

- A. `public void _total() { }`
- B. `public void $sum() { }`
- C. `public void 2nd() { }`
- D. `public void get-name() { }`
- E. `public void 計算() { }`
- F. `public void var() { }`

## 解説
識別子（変数名・メソッド名など）の規則は次のとおりです。

- 1文字目に使えるのは、Unicode の文字（英字・日本語など）、`_`、`$`
- 2文字目以降は、それに加えて数字も使える
- 予約語は使えない

C は数字で始まっているのでエラーです。D のハイフンは識別子に使える文字ではありません（引き算の演算子と区別できなくなります）。

- A の `_total` と B の `$sum` は、先頭の `_` と `$` が使えるので正しい名前です（`_` 単独は不可）。
- E のように日本語も Unicode の文字なので使えます。
- F の `var` は予約語ではない（予約型名）ので、メソッド名に使えます。

## 検証
@case 正解: A・B・E・F はコンパイルできる
@file T.java
class T {
    public void _total() { }
    public void $sum() { }
    public void 計算() { }
    public void var() { }
}
@javac

@case C: 数字で始まる名前はエラー
@file T.java
class T { public void 2nd() { } }
@javac-error

@case D: ハイフンを含む名前はエラー
@file T.java
class T { public void get-name() { } }
@javac-error
