次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String[] inputs = {"10", "x"};
        for (String s : inputs) {
            try {
                int n = Integer.parseInt(s);
                System.out.print(n * 2 + " ");
            } catch (IllegalArgumentException e) {
                System.out.print("IAE ");
            } catch (NumberFormatException e) {
                System.out.print("NFE ");
            } finally {
                System.out.print("F ");
            }
        }
    }
}
```

- A. 「20 F IAE F」と表示される
- B. 「20 F NFE F」と表示される
- C. 「20 IAE F」と表示される
- D. コンパイルエラーが発生する
- E. 「20 F」と表示された後、実行時に例外がスローされる

## 解説
`Integer.parseInt("x")` がスローする **NumberFormatException は IllegalArgumentException のサブクラス**です。

先に `catch (IllegalArgumentException e)` があるので、NumberFormatException はすべてそこで捕まります。後ろの `catch (NumberFormatException e)` には絶対に到達できないため、**コンパイルエラー**になります（「has already been caught」）。

2つの catch の順番を入れ替えれば（サブクラスを先に）コンパイルでき、「20 F NFE F」と表示されます。
