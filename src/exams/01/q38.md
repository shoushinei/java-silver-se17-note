次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Phone.java
public class Phone {
    public void call() {
        System.out.println("call");
    }
}
```

```java title=SmartPhone.java
public class SmartPhone extends Phone {
    public void browse() {
        System.out.println("browse");
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Phone p = new SmartPhone();
        p.call();
        p.browse();
    }
}
```

- A. 「call」「browse」と表示される
- B. 「call」と表示された後、例外がスローされる
- C. コンパイルエラーが発生する
- D. 実行時に ClassCastException がスローされる

## 解説
変数 p の型は Phone です。**コンパイラは変数の型しか見ない**ので、p から呼べるのは Phone に定義されたメソッドだけです。Phone には browse() が無いので、`p.browse()` でコンパイルエラーになります。

実体が SmartPhone であることは、実行するまで分かりません。browse() を呼びたいなら `((SmartPhone) p).browse();` のようにキャストします。
