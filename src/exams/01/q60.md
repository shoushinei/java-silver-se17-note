次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String[] words = new String[3];
        words[1] = "b";
        for (int i = 0; i < words.length; i++) {
            words[i] = words[i] + i;
        }
        for (String w : words) {
            System.out.print(w.length());
        }
    }
}
```

- A. 「121」と表示される
- B. 「020」と表示される
- C. 「525」と表示される
- D. 実行時に NullPointerException がスローされる
- E. コンパイルエラーが発生する

## 解説
`new String[3]` の要素は、すべて **null** で始まります。words[1] だけ "b" を入れています。

6 行目の `words[i] + i` は文字列連結です。**null を + で連結すると "null" という文字列**として扱われ、例外にはなりません。

- words[0]: null + 0 → "null0"（5文字）
- words[1]: "b" + 1 → "b1"（2文字）
- words[2]: null + 2 → "null2"（5文字）

8 行目の時点では、どの要素にも文字列が入っているので、`w.length()` で NullPointerException にはなりません。「525」です。

もし 5〜7 行目のループが無ければ、words[0] が null のまま `w.length()` を呼ぶので NullPointerException になります。
