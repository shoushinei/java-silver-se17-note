次のプログラムはコンパイルエラーになります。その理由として、正しいものを選びなさい。

```java title=Greeter.java
public interface Greeter {
    default void greet() {
        System.out.println("hi");
    }
}
```

```java title=Base.java
public abstract class Base implements Greeter {
    protected void greet() {
        System.out.println("base");
    }
}
```

```java title=Impl.java
public final class Impl extends Base {
}
```

- A. Greeter の default メソッドは暗黙に public なので、Base で protected にしてアクセスを狭めることはできないため
- B. 抽象クラスはインタフェースを実装できないため
- C. Impl が greet() をオーバーライドしていないため
- D. final クラスは抽象クラスを継承できないため

## 解説
インタフェースのメソッドは、default メソッドも含めて**暗黙に public** です。Base の `greet()` はそれをオーバーライドしていますが、protected にしているので**アクセスを狭めた**ことになり、コンパイルエラーです。オーバーライドでは、アクセスを同じか広げることしかできません。

- B: 抽象クラスもインタフェースを実装できます。
- C: Base が greet() に本体を持っているので、Impl がオーバーライドする必要はありません。
- D: final は「このクラスを継承させない」という意味で、final クラスが抽象クラスを継承するのは問題ありません。

Base の greet() を public にすれば、すべてコンパイルできます。
