次のプログラムの 5 行目に挿入したとき、「012345」と表示されるコードとして、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int[][] m = new int[2][3];
        int v = 0;
        // ここに挿入するコード
        for (int[] row : m) {
            for (int x : row) {
                System.out.print(x);
            }
        }
    }
}
```

- A.
  ```java
  for (int i = 0; i < m.length; i++) {
      for (int j = 0; j < m.length; j++) {
          m[i][j] = v++;
      }
  }
  ```
- B.
  ```java
  for (int i = 0; i <= m.length; i++) {
      for (int j = 0; j < m[i].length; j++) {
          m[i][j] = v++;
      }
  }
  ```
- C.
  ```java
  for (int i = 0; i < m.length; i++) {
      for (int j = 0; j < m[i].length; ) {
          m[i][j] = v;
          j++;
          v++;
      }
  }
  ```
- D.
  ```java
  for (int[] row : m) {
      for (int x : row) {
          x = v++;
      }
  }
  ```
- E.
  ```java
  for (int row : m) {
      for (int x : row) {
          x = v++;
      }
  }
  ```

## 解説
m は2行3列で、`m.length` は 2（行数）、`m[i].length` は 3（各行の長さ）です。

- A: 内側の条件が `j < m.length`（2）なので、各行の 0・1 列目しか埋まりません。「010230」です。
- B: 外側が `i <= m.length` なので、i が 2 のとき `m[2]` にアクセスして ArrayIndexOutOfBoundsException です。
- C: 内側の for の更新部は空ですが、本体で `j++` しているので正しく回ります。0〜5 が順に入り「012345」です。正解。
- D: 拡張 for 文の `x` は**要素のコピー**なので、x に代入しても配列の中身は変わりません。「000000」です。
- E: m の要素は `int[]` なので、`int row` では受け取れずコンパイルエラーです。
