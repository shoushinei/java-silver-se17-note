次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=base/Parent.java
package base;

public class Parent {
    public String name = "parent";
    protected Parent() { }
    public String getName() {
        return name;
    }
}
```

```java title=ext/Child.java
package ext;

import base.Parent;

public class Child extends Parent {
    public String name = "child";
    public Child() {
        super();
    }
}
```

```java title=app/Main.java
package app;

import base.Parent;
import ext.Child;

public class Main {
    public static void main(String[] args) {
        Parent p = new Child();
        System.out.println(p.name + " " + p.getName());
    }
}
```

- A. 「parent parent」と表示される
- B. 「child child」と表示される
- C. 「parent child」と表示される
- D. 「child parent」と表示される
- E. Parent のコンストラクタが protected のため、コンパイルエラーが発生する

## 解説
- `p.name`: フィールドはオーバーライドされません。**変数 p の型（Parent）のフィールド**が使われるので「parent」です。
- `p.getName()`: getName() は Parent にしか無いメソッドです。その中の `name` は、Parent クラスの中で書かれているので **Parent の name** を指します。Child の name は Parent の name を隠しているだけで、置き換えてはいないので「parent」です。

合わせて「parent parent」です。

コンストラクタについて: Parent のコンストラクタは protected ですが、別パッケージの子クラス Child が `super()` で呼ぶのは許されます。Main が new しているのは public な `Child()` なので、問題ありません（E は誤り）。

Child の name を返させたいなら、Child で getName() をオーバーライドします。
