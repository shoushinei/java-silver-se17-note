次のプログラムを確認してください。

```java title=Main.java
public class Main {
    static void show(int[]... rows) {
        for (var r : rows) {
            for (var v : r) {
                System.out.print(v);
            }
            System.out.println();
        }
    }

    public static void main(String[] args) {
        show(new int[]{1, 2}, new int[]{3});
    }
}
```

変数 `r` のデータ型として、正しいものを選びなさい。

- A. `int`
- B. `int[]`
- C. `int[][]`
- D. `Object`
- E. var を拡張 for 文に使っているため、コンパイルエラーになる

## 解説
可変長引数 `int[]... rows` の実体は、`int[]` を要素にした配列、つまり `int[][]` です。

拡張 for 文 `for (var r : rows)` の r には、rows の**要素**が1つずつ入ります。`int[][]` の要素は `int[]` なので、var によって r は `int[]` と推論されます。内側の v は int です。

var は拡張 for 文の変数にも使えるので、E は誤りです。このプログラムは「12」「3」を2行に分けて表示します。

## 検証
