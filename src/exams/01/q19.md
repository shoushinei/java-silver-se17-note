クラスの修飾子についての説明として、正しいものを選びなさい。

- A. abstract クラスは、final メソッドを持つことができる
- B. final クラスは、abstract メソッドを持つことができる
- C. sealed クラスのサブクラス（record と enum を除く）は、final・sealed・non-sealed のいずれかを宣言しなければならない
- D. sealed クラスは、final メソッドを持つことができない
- E. final クラスを継承した abstract クラスを宣言できる
- F. abstract クラスは、sealed として宣言することができない
- G. インタフェースは、final として宣言することができる

## 解説
- A: abstract クラスは「未完成のクラス」ですが、完成しているメソッドを持つのは自由です。子にオーバーライドさせたくないメソッドを final にすることもできます。正しい。
- B: final クラスは継承できません。abstract メソッドは子が本体を書くことを前提にしているので、書く子がいない final クラスには置けません。誤り。
- C: sealed クラスの子は、継承をさらに閉じるか（final / sealed）、開くか（non-sealed）を明示する必要があります。正しい。
- D: sealed が制限するのは「どのクラスが継承できるか」だけです。メソッドを final にするのは自由です。誤り。
- E: final クラスは、abstract クラスを含むどんなクラスからも継承できません。誤り。
- F: `abstract sealed class` は書けます。「直接インスタンス化はさせず、許可した子だけに継承させる」という組み合わせは実際によく使われます。誤り。
- G: インタフェースは実装されるためにあるので、final にはできません。誤り。

## 検証
@case 正解 A: abstract クラスは final メソッドを持てる
@file T.java
abstract class T { final void m() { } abstract void n(); }
@javac

@case B: final クラスに abstract メソッドは置けない
@file T.java
final class T { abstract void m(); }
@javac-error

@case 正解 C: 修飾子の無いサブクラスはエラー
@file T.java
sealed class T permits U { }
class U extends T { }
@javac-error

@case D: sealed クラスは final メソッドを持てる
@file T.java
sealed class T permits U { final void m() { } }
final class U extends T { }
@javac

@case E: final クラスは継承できない
@file T.java
final class T { }
abstract class U extends T { }
@javac-error

@case F: abstract sealed は書ける
@file T.java
abstract sealed class T permits U { }
final class U extends T { }
@javac

@case G: final なインタフェースはエラー
@file T.java
final interface T { }
@javac-error
