次の2つのクラスを、calc ディレクトリの1つ上のディレクトリでコンパイル・実行します。

```java title=calc/Add.java
package calc;

public class Add {
    public static int of(int a, int b) {
        return a + b;
    }
}
```

```java title=calc/App.java
package calc;

public class App {
    public static void main(String[] args) {
        System.out.println(Add.of(2, 3));
    }
}
```

「5」と表示させるコマンドの組み合わせとして、正しいものを選びなさい。

- A.
  ```console
  javac -d out calc/Add.java calc/App.java
  java -cp out calc.App
  ```
- B.
  ```console
  javac calc/Add.java calc/App.java
  java -cp out calc.App
  ```
- C.
  ```console
  javac -d out calc/Add.java calc/App.java
  java calc.App
  ```
- D.
  ```console
  javac -d out calc/Add.java calc/App.java
  java -cp out/calc App
  ```
- E.
  ```console
  javac -d out calc/Add.java calc/App.java
  java -cp out calc.App.class
  ```

## 解説
`javac -d out` は .class を `out/` の下に、パッケージの階層ごと書き出します（`out/calc/App.class`）。`java -cp out calc.App` は、`out` を起点に `calc/App.class` を探します。書き出した場所と探す場所が一致するので、A で「5」と表示されます。

- B: -d が無いので .class は `calc/` の中にできます。`out` は存在しないので、クラスが見つかりません。
- C: -cp が無いのでカレントディレクトリの `./calc/App.class` を探しますが、実物は `out/calc/` にあります。
- D: `out/calc` を起点に `App.class` を見つけますが、中のクラスの名前は `calc.App` です。指定した名前 `App` と合わず、NoClassDefFoundError（wrong name）になります。
- E: java に渡すのはクラス名で、`.class` は付けません。
