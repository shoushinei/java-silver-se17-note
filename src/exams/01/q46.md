次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class A {
    A() { System.out.print("a"); }
}
class B extends A {
    B() { System.out.print("b"); }
    B(int x) {
        this();
        System.out.print(x);
    }
}
class C extends B {
    C() {
        super(5);
        System.out.print("c");
    }
}

public class Main {
    public static void main(String[] args) {
        new C();
    }
}
```

- A. 「ab5c」と表示される
- B. 「a5bc」と表示される
- C. 「cb5a」と表示される
- D. 「5abc」と表示される
- E. コンパイルエラーが発生する

## 解説
`new C()` から呼び出しの流れを追います。

1. `C()` の先頭の `super(5)` で、B の `B(int x)` へ
2. `B(int x)` の先頭の `this()` で、同じ B の `B()` へ
3. `B()` の先頭には書かれていないが暗黙の `super()` があり、A の `A()` へ
4. `A()` が「a」を表示して戻る
5. `B()` の本体が「b」を表示して戻る
6. `B(int x)` の残りが「5」を表示して戻る
7. `C()` の残りが「c」を表示する

よって「ab5c」です。コンストラクタは「まず先頭で親（または this() の先）へ行き、戻ってきてから自分の本体を実行する」という順序なので、表示は親から順になります。

`this()` があるコンストラクタには暗黙の `super()` は入りません。super() が入るのは this() の呼び出し先の `B()` です。
