次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String x = new String("sky");
        String y = x.intern();
        String z = "s" + "ky";
        String w = new String("sky").intern();
        System.out.println((x == y) + "," + (y == z) + ","
                + (z == w) + "," + (x == w));
    }
}
```

- A. 「true,true,true,true」と表示される
- B. 「false,false,true,false」と表示される
- C. 「false,true,true,false」と表示される
- D. 「false,true,false,false」と表示される
- E. 「true,true,true,false」と表示される

## 解説
定数プールにある "sky" を「プールの sky」と呼ぶことにします。

- `x`: `new String("sky")` は**必ず新しいオブジェクト**を作ります。プールの sky とは別物です。
- `y`: `x.intern()` は、同じ内容の文字列をプールから探して返します。**プールの sky** です。
- `z`: `"s" + "ky"` はリテラル同士の連結なので、コンパイル時に "sky" という定数になります。**プールの sky** です。
- `w`: new で作った別オブジェクトでも、intern() の戻り値は**プールの sky** です。

`==` は同じオブジェクトかどうかを比べるので、

- `x == y`: 別物 → false
- `y == z`: どちらもプールの sky → true
- `z == w`: どちらもプールの sky → true
- `x == w`: 別物 → false

「false,true,true,false」です。intern() は x 自身を書き換えないので、x は new で作ったオブジェクトのままです。
