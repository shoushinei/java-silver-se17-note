次のプログラムを実行して「10 30 50 」と表示したい。`// insert code here` の位置に入れるコードとして、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int[] nums = {10, 20, 30, 40, 50, 60};
        // insert code here
    }
}
```

- A.
  ```java
  for (int i = 0; i < nums.length; i++) {
      if (i % 2 == 1) System.out.print(nums[i] + " ");
  }
  ```
- B.
  ```java
  for (int i = 0; i < nums.length; i += 2) {
      System.out.print(nums[i] + " ");
  }
  ```
- C.
  ```java
  for (int i = 0; ++i < nums.length; ) {
      if (i % 2 == 0) System.out.print(nums[i] + " ");
  }
  ```
- D.
  ```java
  for (int i = 0; i <= nums.length; i += 2) {
      System.out.print(nums[i] + " ");
  }
  ```
- E.
  ```java
  for (int i = 1; i < nums.length; i += 2) {
      System.out.print(nums[i + 1] + " ");
  }
  ```

## 解説
表示したいのは添字 0・2・4 の値です。

- A: 添字が奇数（1・3・5）のときに表示するので「20 40 60 」です。
- B: 0 から 2 ずつ増やし、0・2・4 で止まります。正解。
- C: 条件の `++i` で先に増やすので、i は 1 から 5 まで動きます。そのうち偶数の 2・4 だけが表示され「30 50 」です。
- D: `i <= nums.length` なので i が 6 のときも実行され、「10 30 50 」を表示した後に ArrayIndexOutOfBoundsException になります。
- E: i は 1・3・5 で、表示するのは `nums[i + 1]`、つまり添字 2・4・6 です。「30 50 」の後に添字 6 で例外になります。
