次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Score.java
public class Score {
    private int total;

    public Score(String... values) {
        for (var v : values) {                  // (1)
            var var = Integer.parseInt(v);      // (2)
            total += var;
        }
    }

    public var getTotal() {                     // (3)
        return total;
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println(new Score("1", "2", "3").getTotal());
    }
}
```

- A. 正しくコンパイルされ、実行すると 6 と表示される
- B. (1) の行でコンパイルエラーが発生する
- C. (2) の行でコンパイルエラーが発生する
- D. (3) の行でコンパイルエラーが発生する
- E. 実行時に NumberFormatException がスローされる

## 解説
`var` が使えるのは、**初期化式のあるローカル変数**（拡張 for 文の変数を含む）だけです。メソッドの戻り値型、引数、フィールドには使えません。

- (1) 拡張 for 文の変数に var は使えます。v は String になります。
- (2) `var var = ...` は一見おかしく見えますが正しい書き方です。var は予約語ではなく「予約型名」なので、**変数名として var を使えます**。
- (3) 戻り値の型に var は書けないので、ここでコンパイルエラーになります。

(3) を `public int getTotal()` にすれば、A のとおり 6 と表示されます。
