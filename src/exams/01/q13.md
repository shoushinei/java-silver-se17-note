次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Shape {
    String name() { return "shape"; }
}
class Circle extends Shape {
    @Override
    String name() { return "circle"; }
}
class Ring extends Circle {
}

public class Main {
    public static void main(String[] args) {
        Shape[] shapes = { new Ring(), new Shape(), new Circle() };
        for (Shape s : shapes) {
            System.out.print(s.name() + " ");
        }
    }
}
```

- A. 「shape shape shape」と表示される
- B. 「circle shape circle」と表示される
- C. 「ring shape circle」と表示される
- D. Ring が name() をオーバーライドしていないため、コンパイルエラーが発生する
- E. 実行時に例外がスローされる

## 解説
配列の要素の型は Shape ですが、呼ばれるのは**実体のクラスのメソッド**です（多態）。

- `new Ring()`: Ring は name() をオーバーライドしていないので、**親の Circle のもの**を受け継いでいます。「circle」
- `new Shape()`: 「shape」
- `new Circle()`: 「circle」

Ring が name() を書かないのは問題ありません。親の Circle に本体があるからです（D は誤り）。「ring」という文字列はどこにも書かれていないので、C はあり得ません。
