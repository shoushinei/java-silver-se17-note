次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String a = "ja" + "va";
        String b = new String("java");
        String c = b.intern();
        String d = "java";
        String e = b;

        if (a == d) System.out.print("P");
        if (b == d) System.out.print("Q");
        if (c == a) System.out.print("R");
        if (e == b) System.out.print("S");
        if (e == c) System.out.print("T");
    }
}
```

- A. 「PRS」と表示される
- B. 「PS」と表示される
- C. 「RS」と表示される
- D. 「PRST」と表示される
- E. 「PQRST」と表示される

## 解説
それぞれの変数が指すインスタンスを整理します。

- `a = "ja" + "va"`: リテラル同士の連結は**コンパイル時に "java" という1つのリテラルになる**（定数式）ので、プールの "java" を指す
- `b = new String("java")`: new なので**プールとは別の新しいインスタンス**
- `c = b.intern()`: プールにある同じ中身のインスタンス、つまりプールの "java"
- `d = "java"`: プールの "java"
- `e = b`: b と同じインスタンス

よって `a == d`（P）、`c == a`（R）、`e == b`（S）が true、`b == d`（Q）と `e == c`（T）は false で「PRS」です。

`b.intern()` は b 自身をプールのものに置き換えるのではなく、**プールのインスタンスを戻り値として返すだけ**です。b と e は new したインスタンスを指したままなので、T は表示されません。
