次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static Integer level;

    public static void main(String[] args) {
        switch (level) {
            case 1 -> System.out.println("low");
            default -> System.out.println("other");
        }
    }
}
```

- A. 「low」と表示される
- B. 「other」と表示される
- C. 「null」と表示される
- D. コンパイルエラーが発生する
- E. 実行時に例外がスローされる

## 解説
`level` は Integer 型の static フィールドで、初期化していないので**既定値の null** です（int なら 0 でした）。

switch は分岐のために、Integer なら裏で `level.intValue()`（アンボクシング）を呼びます。null に対してメソッドを呼ぶことになるので NullPointerException です。

default は「どの case にも一致しなかったとき」の行き先で、**null を受け止める役ではありません**。一致を調べる前の段階で落ちるので、「other」は表示されません（B は誤り）。Integer は switch に使える型なので、コンパイルは通ります（D は誤り）。
