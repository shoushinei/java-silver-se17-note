次のプログラムの `// insert code here` の位置に記述できるコードとして、正しいものを選びなさい。

```java title=Limits.java
public interface Limits {
    int MAX = 10;
    static int MIN = 1;
}
```

```java title=Main.java
public class Main implements Limits {
    public static void main(String[] args) {
        // insert code here
    }
}
```

- A. `MAX++;`
- B. `int x = MIN--;`
- C. `Limits.MAX = 20;`
- D. `int y = MAX * MIN + 1;`
- E. `this.MIN = 0;`

## 解説
インタフェースに書いたフィールドは、何も書かなくても**暗黙に public static final** です。つまりすべて定数で、値を変えることはできません。`MAX` に static を書いていないことや、`MIN` に final を書いていないことは関係ありません。

- A・B: `++` や `--` は値を書き換えるのでエラーです。
- C: クラス名（インタフェース名）を付けても、final への代入はエラーです。
- E: static メソッドの main には this がありません。そもそも this が使えないうえ、MIN も final です。
- D: 値を読むだけなので問題ありません。y は 11 になります。

## 検証
@case 正解 D: 読むだけならよい
@stem
@file Main.java
public class Main implements Limits {
    public static void main(String[] args) {
        int y = MAX * MIN + 1;
        System.out.println(y);
    }
}
@javac
@run Main
@stdout
11
@end

@case A: MAX++ はエラー
@stem
@file Main.java
public class Main implements Limits {
    public static void main(String[] args) {
        MAX++;
    }
}
@javac-error final variable

@case B: MIN-- はエラー（static と書いただけでも final）
@stem
@file Main.java
public class Main implements Limits {
    public static void main(String[] args) {
        int x = MIN--;
    }
}
@javac-error final variable

@case C: インタフェース名を付けても代入できない
@stem
@file Main.java

    public static void main(String[] args) {
        Limits.MAX = 20;
    }
}
@javac-error final variable

    public static void main(String[] args) {

    }
}
