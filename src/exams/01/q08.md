次のうち、コンパイラによってチェックされる例外（検査例外）を選びなさい。

- A. `java.lang.IllegalArgumentException`
- B. `java.io.FileNotFoundException`
- C. `java.lang.NullPointerException`
- D. `java.lang.ArithmeticException`
- E. `java.lang.Exception`
- F. `java.lang.IndexOutOfBoundsException`
- G. `java.lang.Error`

## 解説
検査例外かどうかは、次の1行で判定できます。

**Exception の子孫で、かつ RuntimeException の子孫でないもの**が検査例外です。検査例外は catch するか throws で宣言しないとコンパイルエラーになります。

- B の `FileNotFoundException` は `IOException` の子で、RuntimeException の系統ではないので検査例外です。
- E の `Exception` そのものも検査例外です。`throw new Exception();` と書いたメソッドは throws が必要です。
- A・C・D・F はすべて `RuntimeException` の子孫（非検査例外）です。
- G の `Error` は Exception の系統ではなく、検査の対象外です。

## 検証
@case 正解 B: FileNotFoundException は throws が無いとエラー
@file T.java
class T { void m() { throw new java.io.FileNotFoundException(); } }
@javac-error unreported exception

@case 正解 E: Exception は throws が無いとエラー
@file T.java
class T { void m() { throw new Exception(); } }
@javac-error unreported exception

@case A・C・D・F・G は throws が無くてもコンパイルできる
@file T.java
class T {
    void a() { throw new IllegalArgumentException(); }
    void c() { throw new NullPointerException(); }
    void d() { throw new ArithmeticException(); }
    void f() { throw new IndexOutOfBoundsException(); }
    void g() { throw new Error(); }
}
@javac
