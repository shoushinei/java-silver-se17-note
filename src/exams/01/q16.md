次のコードの switch 文と同じ結果になる switch 式として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int code = Integer.parseInt(args[0]);
        String msg;
        switch (code) {
            case 200: msg = "OK"; break;
            case 301:
            case 302: msg = "Moved"; break;
            case 404: msg = "Not Found"; break;
            default:  msg = "Error";
        }
        System.out.println(msg);
    }
}
```

## 解説
switch 式は値を返す**式**なので、次の規則があります。

- **すべての値を網羅する**必要があります。int のように値の種類が無限にある型では、`default` が必須です。B は default が無いのでエラーです。
- 式を含む文として、**末尾にセミコロンが必要**です。D は `}` の後の `;` が無いのでエラーです。
- アロー（`->`）の右に書けるのは、**式・ブロック（`{ }`）・throw 文**のどれかです。`yield "OK";` は式ではないので、C はエラーです。yield を使うなら `case 200 -> { yield "OK"; }` のようにブロックの中に書くか、コロン形式（`case 200: yield "OK";`）にします。

A は条件をすべて満たし、元の switch 文と同じ結果になります。`case 301, 302` のようにカンマで複数の値を並べられます。

@case 正解 A: 元の switch 文と同じ結果
@file Main.java
public class Main {
    static String before(int code) {
        String msg;
        switch (code) {
            case 200: msg = "OK"; break;
            case 301:
            case 302: msg = "Moved"; break;
            case 404: msg = "Not Found"; break;
            default:  msg = "Error";
        }
        return msg;
    }
    static String after(int code) {
        String msg = switch (code) {
            case 200 -> "OK";
            case 301, 302 -> "Moved";
            case 404 -> "Not Found";
            default -> "Error";
        };
        return msg;
    }
    public static void main(String[] args) {
        for (int c : new int[]{200, 301, 302, 404, 500}) {
            System.out.println(before(c) + " / " + after(c));
        }
    }
}
