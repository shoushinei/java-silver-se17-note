次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class P {
    P() {
        this("p");
        System.out.print("1");
    }
    P(String s) {
        System.out.print(s);
    }
}

class Q extends P {
    Q() {
        this(7);
        System.out.print("2");
    }
    Q(int n) {
        System.out.print(n);
    }
}

public class Main {
    public static void main(String[] args) {
        new Q();
    }
}
```

- A. 「72p1」と表示される
- B. 「7p12」と表示される
- C. 「p172」と表示される
- D. 「p712」と表示される
- E. コンパイルエラーが発生する

## 解説
呼び出しの順に追います。

1. `new Q()` → `Q()` の先頭は `this(7)` なので、`Q(int)` を呼びます。`this(...)` を書いたコンストラクタには暗黙の `super()` は入りません。
2. `Q(int)` の先頭には何も無いので、**暗黙の `super()`** が入り、`P()` を呼びます。
3. `P()` の先頭は `this("p")` なので `P(String)` を呼び、「p」を表示します。
4. `P()` に戻り「1」を表示します。
5. `Q(int)` に戻り「7」を表示します。
6. `Q()` に戻り「2」を表示します。

「p172」です。コンストラクタは、呼び出しを先頭まで**たどり切ってから**、深いほうから順に本体の残りを実行する、と考えると追いやすくなります。
