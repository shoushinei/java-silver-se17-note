次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static int score(char grade) {
        int pts = 0;
        switch (grade) {
            case 'A' -> pts += 3;
            case 'B', 'C' -> pts += 2;
            default -> pts += 1;
        }
        return pts;
    }

    public static void main(String[] args) {
        System.out.println(score('A') + score('C') + score('F'));
    }
}
```

- A. 6 と表示される
- B. 10 と表示される
- C. 「321」と表示される
- D. switch 式ではないのにアロー形式を使っているため、コンパイルエラーが発生する
- E. break が無いため、コンパイルエラーが発生する

## 解説
アロー形式（`->`）は、switch 式だけでなく**値を返さない switch 文でも使えます**（D は誤り）。アロー形式では、一致した case の右側だけが実行され、**下の case へは流れません**。break は不要です（E は誤り）。

- score('A'): 3
- score('C'): `case 'B', 'C'` に一致して 2
- score('F'): どれにも一致せず default で 1

`3 + 2 + 1` は int の足し算なので 6 です。文字列の連結ではないので、C の「321」にはなりません。

コロン形式で break を書かなかったと考えると、'A' で 3 + 2 + 1 = 6、'C' で 2 + 1 = 3、'F' で 1、合計 10（B）になってしまいます。
