次のクラスを確認してください。

```java title=Shape.java
public sealed class Shape permits Circle, Square {
}
```

Shape のサブクラスの宣言として正しいものを選びなさい。なお、各クラスは Shape と同じパッケージの別ファイルに記述するものとする。

- A. `public class Circle extends Shape { }`
- B. `public final class Circle extends Shape { }`
- C. `public non-sealed class Triangle extends Shape { }`
- D. `public abstract class Square extends Shape { }`
- E. `public record Square() extends Shape { }`
- F. `public non-sealed class Square extends Shape { }`

## 解説
sealed クラスのサブクラスには、次の2つの条件があります。

- **permits に名前が書かれていること**。Shape を継承できるのは Circle と Square だけです。C の Triangle は許可されていないのでエラーです。
- **final・sealed・non-sealed のどれかを付けること**。「この先も継承を閉じるのか、開くのか」を明示させるためです。何も付けない A と、abstract だけの D はエラーです。abstract と組み合わせるなら `public abstract non-sealed class Square` のように書きます。

E の record は、暗黙に final ですが**クラスを継承（extends）できない**のでエラーです。record が sealed の階層に入れるのは、sealed **インタフェース**を実装する場合だけです。

B（final）と F（non-sealed）が条件を満たします。
