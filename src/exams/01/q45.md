次のプログラムを確認してください。

```java title=Factory.java
public interface Factory {
    Factory create(String id);
}
```

```java title=Part.java
public class Part implements Factory {
    public Part(String id) { }

    @Override
    public Part create(String id) {
        return new Part(id);
    }
}
```

このプログラムの説明として、正しいものを選びなさい。

- A. Factory を final にすることはできない
- B. Part に abstract を付けると、コンパイルエラーになる
- C. Part に final を付けると、コンパイルエラーになる
- D. Part の create の戻り値型を Object に変えても、コンパイルできる
- E. Part は Factory のサブタイプである
- F. Factory を `public abstract interface Factory` と宣言すると、コンパイルエラーになる

## 解説
- A: インタフェースは実装されるためにあるので、final にはできません。正しい。
- B: Part を abstract にすると、create の中の `new Part(id)` がエラーになります。abstract クラスは、**自分のクラスの中でも** new できません。正しい。
- C: final は継承を禁止するだけです。Part を継承しているクラスは無いので、問題ありません。誤り。
- D: create は Factory の `Factory create(String)` をオーバーライドしています。戻り値は Factory かその子でなければならず、親の Object にはできません。誤り。
- E: Part は Factory を実装しているので、Factory 型の変数に入れられます（サブタイプ）。正しい。
- F: インタフェースは暗黙に abstract です。`abstract` を明示しても冗長なだけで、エラーにはなりません。誤り。

なお、create の戻り値を Part にしているのは、Factory の子の型を返す共変戻り値です。
