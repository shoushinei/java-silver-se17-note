次のプログラムを、あとに示すコマンドで実行したときの結果として、正しいものを選びなさい。

```java title=Label.java
public class Label {
    private String text = "";
    public void setText(String t) {
        text = t;
    }
    public String getText() {
        return text;
    }
    @Override
    public String toString() {
        return getText();
    }
}
```

```java title=BoldLabel.java
public class BoldLabel extends Label {
    @Override
    public void setText(String t) {
        super.setText("*" + t.trim() + "*");
    }
    public void setWords(String[] words) {
        var sb = new StringBuilder();
        for (String w : words) {
            sb.append(w).append('-');
        }
        setText(sb.toString());
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        BoldLabel b = new BoldLabel();
        b.setWords(args);
        System.out.println(b);
    }
}
```

```console
> java Main x y
```

- A. 「*x-y-*」と表示される
- B. 「*x-y*」と表示される
- C. 「x-y-」と表示される
- D. 何も表示されない（空行）
- E. コンパイルエラーが発生する

## 解説
処理を順に追います。

1. `setWords(args)`: args は `{"x", "y"}`。StringBuilder に「x」「-」「y」「-」と追加され、`"x-y-"` になる
2. `setText("x-y-")`: 呼んでいるのは BoldLabel の中なので、**オーバーライドした BoldLabel の setText** が動く
3. `t.trim()` は前後の**空白**だけを取り除く。`-` は空白ではないので残り、`"*x-y-*"` になる
4. `super.setText(...)` で Label の text に `"*x-y-*"` が入る
5. `println(b)` は `toString()` を呼び、toString は getText() を返すので「*x-y-*」

`trim()` が末尾の `-` まで消すと考えると B を選んでしまいます。
