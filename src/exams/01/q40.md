多次元配列の宣言と初期化のコードとして、正しいものを選びなさい。

- A. `int[][] g = {{1}, {2, 3}, {}};`
- B. `int[][][] g = {{1, 2}, {3, 4}};`
- C. `int[][] g = new int[][]{1, 2};`
- D. `int[][] g = new int[][3];`
- E.
  ```java
  int[] row = {7, 8};
  int[][][] cube = new int[2][2][];
  cube[1][0] = row;
  ```
- F. `int[][] g = new int[2];`

## 解説
多次元配列は「配列を要素に持つ配列」です。この見方で1つずつ確かめます。

- A: 2次元の配列に、長さ 1・2・0 の1次元配列を並べています。行ごとに長さが違っても、空の配列 `{}` があっても問題ありません。正しい。
- B: 3次元と宣言しているのに、初期化子は2段しか入れ子になっていません。`1` や `2` が入る場所には `int[]` が必要なのでエラーです。
- C: `new int[][]` の初期化子の中身が `1, 2` で、1段しかありません。`new int[][]{{1, 2}}` なら正しい書き方です。
- D: 生成するときに要素数を省略できるのは**右側（後ろ）の次元だけ**です。最初の次元を省略して後ろだけ書くことはできません。
- E: `new int[2][2][]` は最後の次元を省略した正しい生成です。`cube[1][0]` の型は `int[]` なので、`int[]` の row を代入できます。正しい。
- F: 左辺は2次元、右辺は1次元の配列なので、型が合わずエラーです。

## 検証
@case 正解 A と E
@file Main.java
public class Main {
    public static void main(String[] args) {
        int[][] g = {{1}, {2, 3}, {}};
        int[] row = {7, 8};
        int[][][] cube = new int[2][2][];
        cube[1][0] = row;
        int[][] h = new int[][]{{1, 2}};   // 解説の C の直し方
        System.out.println(g.length + " " + g[2].length + " " + cube[1][0][1] + " " + h[0][1]);
    }
}
