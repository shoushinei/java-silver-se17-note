次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static String label = "field";

    public static void main(String[] args) {
        String label = label + "!";
        System.out.println(label);
    }
}
```

- A. 「field!」と表示される
- B. 「null!」と表示される
- C. 「!」と表示される
- D. コンパイルエラーが発生する
- E. 実行時に例外がスローされる

## 解説
`String label = label + "!";` の右辺の `label` は、フィールドではなく**今まさに宣言しているローカル変数 label** を指します。ローカル変数のスコープは、宣言の途中（初期化式の中）からもう始まっているからです。

そのローカル変数はまだ初期化されていないので、「初期化されていない変数を使った」としてコンパイルエラーになります（`variable label might not have been initialized`）。

フィールドを使いたいなら、`String label = Main.label + "!";` のようにクラス名を付けます。そうすれば「field!」と表示されます。インスタンスフィールドなら `this.label` です。

## 検証
@case 正解 D: 初期化されていないローカル変数を使ったとしてエラー
@stem
@javac-error might not have been initialized

@case 参考: クラス名を付ければフィールドを使える

    public static void main(String[] args) {

    }
}
@javac
@run Main
@stdout

@end
