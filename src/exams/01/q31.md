次のプログラムを確認してください。

```java title=media/Player.java
package media;

public class Player {
    public void play() { }
}
```

```java title=media/audio/Mixer.java
package media.audio;

public class Mixer {
    public void mix(int level) { }
}
```

```java title=studio/Main.java
package studio;
// import

public class Main {
    public static void main(String[] args) {
        new Player().play();
        int level = Integer.parseInt(args[0]);
        new Mixer().mix(level);
    }
}
```

Main クラスの `// import` の位置に入るコードとして、正しいものを選びなさい。

- A.
  ```java
  import media.*;
  ```
- B.
  ```java
  import media.*;
  import media.audio.*;
  ```
- C.
  ```java
  import media.Player;
  import java.lang.Integer;
  ```
- D.
  ```java
  import media.audio.*;
  import java.lang.*;
  ```

## 解説
Main が使っているのは、`media.Player`、`media.audio.Mixer`、`Integer` の3つです。

- `Integer` は `java.lang` パッケージのクラスです。java.lang は**何も書かなくても自動で取り込まれる**ので、import は不要です（書いてもエラーにはなりません）。
- `media.*` で取り込めるのは media パッケージ直下の Player だけです。**サブパッケージの media.audio は含まれません。** Mixer には別の import が必要です。

A は Mixer が無く、C も Mixer が無く、D は Player が無いのでエラーです。両方を取り込んでいる B が正解です。
