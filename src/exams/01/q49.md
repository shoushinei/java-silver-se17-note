次のプログラムを、あとに示すコマンドで実行したときの結果として、正しいものを選びなさい。

```java title=Echo.java
public class Echo {
    public static void main(String[] args) {
        System.out.print(args.length + ":");
        for (String a : args) {
            System.out.print("[" + a + "]");
        }
    }
}
```

```console
> java Echo "a b" c "d"
```

- A. 「3:[a b][c][d]」と表示される
- B. 「4:[a][b][c][d]」と表示される
- C. 「4:["a][b"][c]["d"]」と表示される
- D. 「3:["a b"][c]["d"]」と表示される

## 解説
コマンドライン引数は空白で区切られますが、**ダブルクォートで囲んだ部分は空白を含めて1つの引数**になります。ダブルクォートは区切りの目印で、**引数の中身には含まれません**。

- `"a b"` → `a b`（空白を含む1つ）
- `c` → `c`
- `"d"` → `d`（囲んでも囲まなくても同じ）

したがって引数は3つで、「3:[a b][c][d]」です。
