次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    private char c = 'Z';
    private int n = 9;

    String join(char c, int n) {
        return c + n + "|" + c + n;
    }

    public static void main(String[] args) {
        System.out.println(new Main().join('A', 1));
    }
}
```

- A. 「A1|A1」と表示される
- B. 「66|A1」と表示される
- C. 「Z9|Z9」と表示される
- D. 「B|A1」と表示される
- E. コンパイルエラーが発生する

## 解説
まず、`join` の中の c と n は**引数**を指します。フィールドの 'Z' と 9 は使われません（C は誤り）。

次に `c + n + "|" + c + n` は**左から順に**評価されます。

1. `c + n`: char と int の足し算です。char は数値（'A' は 65）として扱われ、65 + 1 = **66**（int）
2. `66 + "|"`: ここで String が現れるので、以降は文字列連結。"66|"
3. `"66|" + c`: 文字列に char を連結すると文字として付く。"66|A"
4. `"66|A" + n`: "66|A1"

最初の `c + n` を文字列の連結と考えると A を、文字の計算（'A' + 1 = 'B'）と考えると D を選んでしまいます。char 同士や char と int の + は、結果が int になります。
