次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Counter.java
public class Counter {
    static int total;
    int mine;

    Counter() {
        total++;
        mine++;
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Counter a = new Counter();
        Counter b = new Counter();
        a.total += 10;
        System.out.println(a.mine + "," + b.mine + "," + a.total + "," + Counter.total);
    }
}
```

- A. 「1,1,11,2」と表示される
- B. 「1,2,12,12」と表示される
- C. 「1,1,12,12」と表示される
- D. 「2,2,12,12」と表示される
- E. static フィールドを a.total のように参照しているため、コンパイルエラーが発生する

## 解説
`total` は static フィールドなので、**Counter クラスに1つだけ**あり、すべてのインスタンスで共有されます。一方 `mine` はインスタンスごとに別々です。

- new を2回したので、共有の total は 2、a.mine と b.mine はそれぞれ 1
- `a.total += 10` は、変数 a を通して書いていますが、実際には共有の total を書き換えます。total は 12

`a.total` と `Counter.total` は同じ1つの変数なので、どちらも 12 です。static フィールドをインスタンスの変数から参照するのは推奨されない書き方ですが、コンパイルエラーにはなりません（E は誤り）。
