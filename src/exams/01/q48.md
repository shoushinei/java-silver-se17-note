次のうち、メソッドの定義として正しいものを選びなさい。

- A.
  ```java
  public int twice(int x) {
      x * 2;
  }
  ```
- B.
  ```java
  public void log(String m) {
      return m.isEmpty();
  }
  ```
- C.
  ```java
  public String pick(boolean f) {
      if (f) return "y";
  }
  ```
- D.
  ```java
  public long size() {
      return 10;
  }
  ```
- E.
  ```java
  public void stop() {
      return;
  }
  ```
- F.
  ```java
  public char first(String s) {
      return s;
  }
  ```

## 解説
- A: `x * 2;` は計算しているだけで、文として成り立ちません（`not a statement`）。値を返すなら `return x * 2;` と書きます。
- B: 戻り値が void のメソッドは、値を返せません。`return 式;` はエラーです。
- C: f が false のとき、どの return にも到達せずにメソッドが終わってしまいます。戻り値のあるメソッドは、**どの経路でも値を返す**必要があります（`missing return statement`）。
- D: 10 は int ですが、long への**拡大変換**は自動で行われるので返せます。正しい。
- E: void のメソッドで、値を付けない `return;` は書けます。そこでメソッドを終えるという意味です。正しい。
- F: String を char として返すことはできません。

## 検証
