次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Task.java
public interface Task {
    void run();
    void cancel();
}
```

```java title=BaseTask.java
public abstract class BaseTask implements Task {
    public void run() {
        System.out.println("run");
    }
}
```

```java title=PrintTask.java
public class PrintTask extends BaseTask {
    @Override
    public void run() {
        System.out.println("print");
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Task t = new PrintTask();
        t.run();
    }
}
```

- A. 「print」と表示される
- B. 「run」と表示される
- C. BaseTask クラスでコンパイルエラーが発生する
- D. PrintTask クラスでコンパイルエラーが発生する
- E. Task インタフェースでコンパイルエラーが発生する

## 解説
Task には `run()` と `cancel()` の2つの抽象メソッドがあります。

- BaseTask は **abstract クラス**なので、`cancel()` を実装しないまま残しておけます。エラーになりません（C は誤り）。
- PrintTask は abstract ではないので、受け継いだ抽象メソッドを**すべて実装しなければなりません**。`run()` はありますが `cancel()` がありません。PrintTask でコンパイルエラーです。

PrintTask に `public void cancel() { }` を加えれば、A のとおり「print」と表示されます。

## 検証
@case 正解 D: PrintTask で cancel() が未実装
@stem
@javac-error PrintTask is not abstract and does not override abstract method cancel()

@case 参考: cancel() を実装すれば print と表示される
@stem
@file PrintTask.java
public class PrintTask extends BaseTask {
    @Override
    public void run() {
        System.out.println("print");
    }
    public void cancel() { }
}
@javac
@run Main
@stdout
print
@end
