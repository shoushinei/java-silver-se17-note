次のクラスの `load` メソッドから `throws DataException` を取り除くと、コンパイルエラーになります。DataException についての説明として、正しいものを選びなさい。

```java title=Service.java
public class Service {
    public void load(String key) throws DataException {
        if (key.isEmpty()) {
            throw new DataException();
        }
    }
}
```

- A. DataException は RuntimeException のサブクラスではない
- B. DataException は Error のサブクラスである
- C. load を呼び出す側は、DataException を catch するか throws で宣言しなければならない
- D. load の中では、DataException 以外の例外をスローできない
- E. load の中では、DataException のサブクラスの例外をスローできない

## 解説
throws を消すとエラーになるのは、DataException が**検査例外**だからです。検査例外とは「Exception の子孫で、RuntimeException の子孫でないもの」なので、A は正しい説明です。

検査例外を throws で宣言したメソッドを呼ぶ側は、その例外を **catch するか、自分も throws で宣言する**必要があります。C も正しい説明です。

- B: Error のサブクラスは検査の対象外なので、throws を消してもエラーになりません。
- D: throws に書いていない例外でも、RuntimeException の系統ならいつでもスローできます。
- E: throws DataException と宣言していれば、その**サブクラスの例外もスローできます**。

## 検証
@case 正解 A: Exception を継承した例外なら throws を消すとエラー
@file DataException.java
public class DataException extends Exception { }
@file Service.java
public class Service {
    public void load(String key) {
        if (key.isEmpty()) {
            throw new DataException();
        }
    }
}
@javac-error unreported exception

@case 正解 C: 呼び出し側が何もしないとエラー
@stem
@file DataException.java
public class DataException extends Exception { }
@file Main.java
public class Main {
    public static void main(String[] args) {
        new Service().load("");
    }
}
@javac-error unreported exception

@case B: Error の系統なら throws を消してもエラーにならない
@file DataException.java
public class DataException extends Error { }
@file Service.java
public class Service {
    public void load(String key) {
        if (key.isEmpty()) {
            throw new DataException();
        }
    }
}
@javac

@case D と E: 非検査例外やサブクラスの例外もスローできる
@file DataException.java
public class DataException extends Exception { }
@file SubDataException.java
public class SubDataException extends DataException { }
@file Service.java
public class Service {
    public void load(String key) throws DataException {
        if (key.isEmpty()) throw new SubDataException();
        if (key.equals("x")) throw new IllegalStateException();
    }
}
@javac
