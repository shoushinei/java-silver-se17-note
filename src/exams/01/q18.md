次のクラスを確認してください。

```java title=Area.java
public class Area {
    public double area(double w, double h) {
        return w * h;
    }
    // 追加するメソッド
}
```

`// 追加するメソッド` の位置に追加できるメソッドとして、正しいものを選びなさい。

- A. `public double area(double side) { return side * side; }`
- B. `public int area(double w, double h) { return (int) (w * h); }`
- C. `public double area(double h, double w) { return h * w; }`
- D. `private double area(double a, double b) { return a * b; }`
- E. `public double area(int w, int h) { return w * h; }`
- F. `public static double area(double w, double h) { return w * h; }`

## 解説
同じクラスに同じ名前のメソッドを複数書けるのは、**引数の型・数・並び（シグネチャ）が違う**ときだけです。

- A は引数が1つなので、別のシグネチャです。追加できます。
- E は引数の型が `(int, int)` で、`(double, double)` とは別のシグネチャです。追加できます。
- B は戻り値の型だけが違います。**戻り値の型では区別しない**のでエラーです。
- C は引数の**名前**が違うだけです。型の並びは `(double, double)` のままなのでエラーです。
- D はアクセス修飾子だけが違います。これも区別に使われないのでエラーです。
- F は static かどうかだけが違います。これも同じシグネチャとみなされエラーです。
