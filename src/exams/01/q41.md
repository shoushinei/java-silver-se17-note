次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class A {
    int v = 1;
    int get() { return v; }
}
class B extends A {
    int v = 2;
    @Override
    int get() { return v + super.get(); }
}
class C extends B {
    int v = 3;
    @Override
    int get() { return super.v * 10 + super.get(); }
}

public class Main {
    public static void main(String[] args) {
        A x = new C();
        System.out.println(x.get() + " " + x.v);
    }
}
```

- A. 「23 1」と表示される
- B. 「23 3」と表示される
- C. 「33 1」と表示される
- D. 「3 1」と表示される
- E. コンパイルエラーが発生する

## 解説
**メソッドは実体の型で、フィールドは変数の型で**決まる、という違いがポイントです。

`x.get()`: 実体は C なので、C の get() が呼ばれます。

- `super.v` は直接の親 B のフィールド v で 2。× 10 で 20
- `super.get()` は B の get() です。B の中の `v` は B の v で 2、`super.get()` は A の get() で、A の中の v は A の v で 1。よって 2 + 1 = 3
- 合計 20 + 3 = **23**

`x.v`: フィールドはオーバーライドされず、**変数 x の型（A）のフィールド**が使われます。1 です。

同じ名前のフィールドを子で宣言すると、親のフィールドを**隠す**だけで、置き換えるわけではありません。各クラスの中で `v` と書けば、そのクラスの v が使われます。
