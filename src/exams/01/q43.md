次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Walk.java
public interface Walk {
    default String move() {
        return "walk";
    }
}
```

```java title=Swim.java
public interface Swim {
    default String move() {
        return "swim";
    }
}
```

```java title=Duck.java
public class Duck implements Walk, Swim {
    @Override
    public String move() {
        return Walk.super.move() + "+" + Swim.super.move();
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println(new Duck().move());
    }
}
```

- A. 「walk+swim」と表示される
- B. 「walk」と表示される
- C. 「swim」と表示される
- D. 同じ名前の default メソッドを持つインタフェースを2つ実装しているため、コンパイルエラーが発生する
- E. super の前にインタフェース名を書くことはできないため、コンパイルエラーが発生する

## 解説
Walk と Swim は、同じシグネチャの default メソッド `move()` を持っています。両方を実装したクラスは、どちらを使えばよいか決められないので、**自分でオーバーライドしなければなりません**。Duck はオーバーライドしているので、コンパイルは通ります（D は誤り）。オーバーライドしなければエラーでした。

オーバーライドした中から、特定のインタフェースの default メソッドを呼ぶには `インタフェース名.super.メソッド()` と書きます（E は誤り）。ここでは両方を呼んで「walk+swim」を返します。

`super.move()` と書くと、見に行くのは**スーパークラス**（ここでは Object）だけです。Object に move() は無いのでエラーになります。
