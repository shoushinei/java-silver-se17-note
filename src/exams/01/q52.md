次のプログラムを確認してください。

```java title=Account.java
public class Account {
    String owner;
    int balance;

    public Account(String owner, int balance) {
        this.owner = owner;
        this.balance = balance;
    }
}
```

```java title=Savings.java
public class Savings extends Account {
    double rate;

    public Savings(double rate) {
        this.rate = rate;
    }

    public Savings(String owner, int balance, double rate) {
        super(owner, balance);
        this(rate);
    }
}
```

Savings クラスについての説明として、正しいものを選びなさい。

- A. 正しくコンパイルできる
- B. 4 行目のコンストラクタだけがコンパイルエラーになる
- C. 8 行目のコンストラクタだけがコンパイルエラーになる
- D. 4 行目と 8 行目のコンストラクタの両方がコンパイルエラーになる

## 解説
- 4 行目の `Savings(double rate)`: 先頭に super() も this() も書いていないので、**暗黙に `super()`** が入ります。ところが Account には引数なしのコンストラクタがありません。エラーです。
- 8 行目の `Savings(String, int, double)`: `super(...)` と `this(...)` を両方書いています。どちらも**コンストラクタの先頭の文**でなければならないので、両方は書けません。2つ目の `this(rate)` がエラーです。

したがって両方のコンストラクタがエラーになります。

直し方の例: 4 行目を `public Savings(double rate) { this("unknown", 0, rate); }` として、8 行目を `super(owner, balance); this.rate = rate;` にすれば、先頭の呼び出しは1つずつになります。
