次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Tag.java
public class Tag {
    private final String label;
    public Tag(String label) {
        this.label = label;
    }
    @Override
    public String toString() {
        return "#" + label;
    }
}
```

```java title=Main.java
public class Main {
    static Tag[] tags = { new Tag("java"), null, new Tag("sql") };

    public static void main(String[] args) {
        for (Tag t : tags) {
            System.out.print(t + " ");
        }
        System.out.println(tags[1].toString());
    }
}
```

- A. 「#java #sql」と表示される
- B. 「Tag@1b6d3586 null Tag@4554617c」のような形式で表示された後、例外がスローされる
- C. 「#java null #sql 」と表示された後、例外がスローされる
- D. 「#java null #sql null」と表示される
- E. 何も表示されずに例外がスローされる

## 解説
拡張 for 文の中の `t + " "` は文字列連結です。連結は、t が null なら **"null" という文字列**にし、そうでなければ `t.toString()` を呼びます。Tag は toString() をオーバーライドしているので、ハッシュ値の形式（B）にはなりません。

1回目のループで「#java #sql」ではなく「#java null #sql 」と表示されます。null の要素も飛ばされずに "null" として連結されます（A は誤り）。

最後の `tags[1].toString()` は、null に対して**自分でメソッドを呼んでいる**ので NullPointerException です。`println(tags[1])` なら "null" と表示されるだけでしたが、`.toString()` を付けた時点で例外になります（D は誤り）。
