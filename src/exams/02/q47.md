次のインタフェースをコンパイルしたときの結果として、正しいものを選びなさい。

```java title=Formatter.java
public interface Formatter {
    String format(String s);

    default String twice(String s) {
        return join(format(s), format(s));
    }

    static String quote(String s) {
        return join("\"", s) + "\"";
    }

    private String join(String a, String b) {
        return a + b;
    }

    private static String trim(String s) {
        return s.strip();
    }
}
```

- A. 5 行目でコンパイルエラーが発生する
- B. 9 行目でコンパイルエラーが発生する
- C. 12 行目でコンパイルエラーが発生する
- D. 16 行目でコンパイルエラーが発生する
- E. コンパイルエラーは発生しない

## 解説
インタフェースには、SE 9 以降 private メソッドと private static メソッドが書けます（C・D は誤り）。呼び出せる相手は、クラスの static と同じ規則です。

| 呼び出し元 | private（インスタンス） | private static |
|---|---|---|
| default メソッド | ○ | ○ |
| static メソッド | **×** | ○ |

- 5 行目: default メソッドから private の join を呼んでいます。正しい。
- 9 行目: static メソッド quote には this が無いので、インスタンスに属する private の join は呼べません。**コンパイルエラー**です。

join を `private static` にすれば、9 行目もコンパイルできます。「インタフェースの private は内部の共通処理用」という理解に加えて、static かどうかで呼べる相手が変わる点が引っかけです。
