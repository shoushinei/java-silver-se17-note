作業ディレクトリの下に、次のファイルがあります。

```java title=src/Hello.java
package greet;

public class Hello {
    public static void main(String[] args) {
        System.out.println("hi");
    }
}
```

作業ディレクトリで次のコマンドを実行してコンパイルしました。

```console
> javac -d out src/Hello.java
```

この後、プログラムを実行するコマンドとして、正しいものを選びなさい。

- A. `java -cp out greet.Hello`
- B. `java -cp out/greet Hello`
- C. `java -cp src greet.Hello`
- D. `java -cp out/src greet.Hello`
- E. `java -cp out Hello`

## 解説
`-d out` を付けると、javac は **package 宣言に合わせて** `out` の下にディレクトリを作ります。Hello.java は `package greet;` なので、できるのは `out/greet/Hello.class` です。ソースファイルが src の中にあったことは関係ありません（D は、src まで出力先に反映されると考えた誤り）。

実行するときは、次の2つを指定します。

- `-cp`（クラスパス）: パッケージの一番上のディレクトリ（greet）が**入っている場所** → `out`
- クラス名: パッケージ名付きの完全な名前 → `greet.Hello`

- B: -cp にパッケージのディレクトリそのもの（out/greet）を書き、クラス名から greet を外しています。JVM は greet.Hello というクラスを探すので見つかりません。
- C: src には .class がありません。
- E: パッケージ名が無いと、greet.Hello とは別のクラスを探すことになり、見つかりません。
