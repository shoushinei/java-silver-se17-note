次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        final String a = "Ja";
        String b = "Ja";
        String x = a + "va";
        String y = b + "va";
        System.out.println((x == "Java") + " " + (y == "Java") + " "
                + (y.intern() == x));
    }
}
```

- A. 「true true true」と表示される
- B. 「false false true」と表示される
- C. 「false false false」と表示される
- D. 「true false false」と表示される
- E. 「true false true」と表示される

## 解説
違いは、a に `final` が付いているかどうかだけです。

- `x = a + "va"`: a は final で、値がリテラルで決まっているので、`a + "va"` は**定数式**です。コンパイル時に "Java" として計算され、定数プールの "Java" そのものになります。`x == "Java"` は true。
- `y = b + "va"`: b は final ではないので、連結は**実行時**に行われ、新しい String インスタンスが作られます。中身は同じ "Java" でも別のインスタンスなので、`y == "Java"` は false。
- `y.intern()`: 定数プールにある同じ内容の文字列を返します。それは x が指している "Java" と同じなので true。

`equals` ではなく `==` で比べているので、「中身が同じか」ではなく「同じインスタンスか」を追います。
