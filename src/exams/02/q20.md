次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Range.java
public record Range(int lo, int hi) {
    public Range {
        if (lo > hi) {
            int t = lo;
            lo = hi;
            hi = t;
        }
    }

    public int size() {
        return hi - lo;
    }
}
```

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Range r1 = new Range(5, 2);
        Range r2 = new Range(2, 5);
        System.out.println(r1 + " " + r1.size() + " "
                + r1.equals(r2) + " " + (r1 == r2));
    }
}
```

- A. 「Range[lo=5, hi=2] -3 false false」と表示される
- B. 「Range[lo=2, hi=5] 3 true false」と表示される
- C. 「Range[lo=2, hi=5] 3 true true」と表示される
- D. 「Range@1b6d3586 3 true false」のような形で表示される
- E. コンパクトコンストラクタで引数に代入しているため、コンパイルエラーが発生する

## 解説
`public Range { ... }` は、引数リストを省略した**コンパクトコンストラクタ**です。中で書き換えているのは引数 lo と hi で、ブロックの最後に `this.lo = lo; this.hi = hi;` が**自動で**行われます。引数への代入は許されているので、E は誤りです。

`new Range(5, 2)` では lo > hi なので入れ替わり、フィールドは lo = 2、hi = 5 になります。

- `r1`（toString）: record は `Range[lo=2, hi=5]` の形の toString を自動生成します（D は普通のクラスの場合）。
- `r1.size()`: 5 − 2 = 3。record には自分でメソッドを追加できます。
- `r1.equals(r2)`: record の equals は**全コンポーネントの値**を比べます。r2 も lo = 2、hi = 5 なので true。
- `r1 == r2`: 別々に new したインスタンスなので false。
