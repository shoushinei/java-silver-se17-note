次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
interface Speaker {
    default String speak() { return "I"; }
}

class Base {
    public String speak() { return "Base"; }
}

class Child extends Base implements Speaker {
    public String all() {
        return speak() + "-" + Speaker.super.speak() + "-" + super.speak();
    }
}

public class Main {
    public static void main(String[] args) {
        System.out.println(new Child().all());
    }
}
```

- A. 「I-I-Base」と表示される
- B. 「Base-I-Base」と表示される
- C. 「Base-Base-Base」と表示される
- D. speak メソッドが衝突しているため、Child クラスでコンパイルエラーが発生する
- E. Speaker.super の呼び出しでコンパイルエラーが発生する

## 解説
Child は、Base から `speak()` を、Speaker から default の `speak()` を受け継いでいます。この場合は**クラス側（Base）が常に優先**され、衝突エラーにはなりません（D は誤り）。2つのインタフェースの default 同士の衝突とは違います。

- `speak()`: Child 自身は speak を持たないので、優先される Base の speak() → "Base"。
- `Speaker.super.speak()`: Child は Speaker を**直接** implements しているので、名指しで Speaker の default を呼べます → "I"（E は誤り）。
- `super.speak()`: スーパークラス Base の speak() → "Base"。

`super.` はスーパークラスだけを、`Speaker.super.` は名指ししたインタフェースだけを見に行く、と使い分けます。
