次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        byte b = 10;
        b += 300;
        short s = 10;
        s *= 1000;
        System.out.println(b + " " + s);
    }
}
```

- A. 「310 10000」と表示される
- B. 「54 10000」と表示される
- C. 「54 -25536」と表示される
- D. 4 行目でコンパイルエラーが発生する
- E. 6 行目でコンパイルエラーが発生する

## 解説
`b += 300` は `b = (byte)(b + 300)` と同じ意味で、**複合代入演算子には縮小キャストが組み込まれている**のでコンパイルは通ります（`b = b + 300` と書けばエラー）。

計算結果の 310 は byte の範囲（-128〜127）を超えます。縮小キャストでは下位 8 ビットだけが残るので、310 − 256 = **54** になります。

`s *= 1000` も同じくキャストが入りますが、10000 は short の範囲（〜32767）に収まるので、そのまま **10000** です。

「コンパイルエラー」を選ばせる引っかけと、「範囲外なら例外」という誤解の両方に注意してください。整数の桁あふれは例外になりません。
