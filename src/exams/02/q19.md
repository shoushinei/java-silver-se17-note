次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int i = 3;
        do {
            System.out.print(i);
        } while (i-- > 1);

        int j = 0;
        while (j++ < 3);
        {
            System.out.print(" " + i + " " + j);
        }
    }
}
```

- A. 「321 1 3」と表示される
- B. 「3210 -1 4」と表示される
- C. 「321 0 4」と表示される
- D. 「321 0 1 0 2 0 3」と表示される
- E. コンパイルエラーが発生する

## 解説
**do-while**: 本体を先に実行してから条件を調べます。`i-- > 1` は「今の i と 1 を比べてから、i を 1 減らす」です。

| 表示 | 条件 `i-- > 1` | その後の i |
|---|---|---|
| 3 | 3 > 1 → true | 2 |
| 2 | 2 > 1 → true | 1 |
| 1 | 1 > 1 → false | 0 |

「321」と表示し、ループを抜けたとき i は **0** です。比べた後にも減るので、1 ではありません（A は誤り）。

**while**: 9 行目の `while (j++ < 3);` は、末尾のセミコロンが**空の本体**です。つまり「j++ < 3 が false になるまで何もしない」ループです。j が 0・1・2 のときは true、3 のとき false で終わり、最後の比較の後にも増えるので j は **4** です。

10〜12 行目の `{ }` はループとは無関係な、ただのブロックで、1回だけ実行されます（D は、ブロックをループの本体だと誤解した場合）。セミコロンだけの文は正しい文なので、コンパイルエラーにもなりません。
