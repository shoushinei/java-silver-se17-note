次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int[][] a = { {1, 2}, {3} };
        int[][] b = a.clone();
        b[1] = new int[]{9};
        b[0][1] = 8;
        a[0] = new int[]{5, 6};
        System.out.println(a[0][1] + " " + a[1][0] + " "
                + b[0][1] + " " + b[1][0]);
    }
}
```

- A. 「8 3 8 9」と表示される
- B. 「6 9 8 9」と表示される
- C. 「6 3 8 9」と表示される
- D. 「6 3 6 9」と表示される
- E. 「2 3 8 9」と表示される

## 解説
`a.clone()` で新しくできるのは**外側の箱だけ**で、2つの行 `{1, 2}` と `{3}` は a と b で共有されます。1行ずつ追います。

| 行 | 操作 | a | b |
|---|---|---|---|
| 4 | `b = a.clone()` | {1,2} {3} | 同じ2つの行を共有 |
| 5 | `b[1] = new int[]{9}` | {1,2} {3} | b の1行目だけ {9} に付け替え |
| 6 | `b[0][1] = 8` | **{1,8}** {3} | {1,8} {9}（0行目は共有なので両方変わる） |
| 7 | `a[0] = new int[]{5, 6}` | {5,6} {3} | {1,8} {9}（a の0行目だけ付け替え） |

- `a[0][1]` は付け替えた {5,6} の 6。
- `a[1][0]` は b 側だけ付け替えたので、元の {3} の 3。
- `b[0][1]` は、a 側が付け替えても b は元の行 {1,8} を指したままなので 8。
- `b[1][0]` は 9。

「6 3 8 9」です。**添字1つの代入（付け替え）は、その配列だけの話**で、付け替えた後はもう行を共有していない、というのがポイントです（D は7行目で b も変わると考えた誤り）。
