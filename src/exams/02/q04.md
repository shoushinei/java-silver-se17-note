次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Base {
    static { System.out.print("1"); }
    { System.out.print("2"); }
    Base() { System.out.print("3"); }
}

class Sub extends Base {
    static { System.out.print("4"); }
    { System.out.print("5"); }
    Sub() { System.out.print("6"); }
}

public class Main {
    public static void main(String[] args) {
        new Sub();
        System.out.print("|");
        new Sub();
    }
}
```

- A. 「123456|123456」と表示される
- B. 「142356|142356」と表示される
- C. 「412356|2356」と表示される
- D. 「142356|2356」と表示される
- E. 「124356|2356」と表示される

## 解説
順番は2段階で考えます。

1. **クラスの準備（1回だけ）**: Sub を初めて使うとき、親から順にクラスが読み込まれ、static 初期化子が動きます。Base の「1」→ Sub の「4」。
2. **インスタンスの生成（new のたび）**: 親の部分から作られます。各クラスの中では「インスタンス初期化子 → コンストラクタの本体」の順です。Base の「2」「3」→ Sub の「5」「6」。

1回目の `new Sub()` は「142356」です。2回目はクラスの準備が済んでいるので static 初期化子は動かず、「2356」だけです。

- A: static 初期化子を、インスタンスごとの処理の中に混ぜています。
- B: static 初期化子を2回動かしています。
- C: 子の static を親より先にしています。
- E: 親のインスタンス部分（2・3）より先に、子の static（4）が来るわけではありません。static はインスタンスの処理より前にまとめて済みます。
