次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Item.java
public class Item {
    static int count;
    int id;

    Item() {
        id = ++count;
    }

    public static void main(String[] args) {
        Item a = new Item();
        Item b = new Item();
        b.count = 10;
        Item c = new Item();
        System.out.println(a.id + " " + b.id + " " + c.id + " " + a.count);
    }
}
```

- A. 「1 2 3 3」と表示される
- B. 「1 2 3 10」と表示される
- C. 「1 2 11 10」と表示される
- D. インスタンス経由で static フィールドに代入しているため、コンパイルエラーが発生する
- E. 「1 2 11 11」と表示される

## 解説
count は static なので、**クラスに1つだけ**あり、すべてのインスタンスで共有されます。id はインスタンスごとにあります。

| 処理 | count | id |
|---|---|---|
| `a = new Item()` | 1 | a.id = 1 |
| `b = new Item()` | 2 | b.id = 2 |
| `b.count = 10` | 10 | （b 経由でも、変わるのは共有の count） |
| `c = new Item()` | 11 | c.id = 11 |

`a.count` も同じ count を読むので 11 です。「b.count は b だけのもの」と考えると B や C を選んでしまいます。

static フィールドをインスタンス経由で使うのは推奨されませんが、コンパイルエラーにはなりません（D は誤り）。`Item.count` と書いたのと同じ意味です。
