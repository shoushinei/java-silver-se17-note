次のうち、クラス App に記述したとき、`java App` コマンドでプログラムを起動できる main メソッドの宣言を選びなさい。

- A. `public static void main(String... args) { }`
- B. `static public void main(String args[]) { }`
- C. `public void main(String[] args) { }`
- D. `public static int main(String[] args) { return 0; }`
- E. `public static void main(String args) { }`
- F. `private static void main(String[] args) { }`

## 解説
起動に使われる main は、**public・static・戻り値 void・引数は String の配列1つ**です。この条件を満たしていれば、次の違いは問題になりません。

- A: 可変長引数 `String...` は、中身が String の配列なので使えます。正しい。
- B: `static public` のように修飾子の順番は自由です。`String args[]` のように角括弧を変数名の後ろに書いても同じ意味です。正しい。

次のものは、**コンパイルは通りますが起動できません**（main という名前の、ただのメソッドとして扱われます）。

- C: static が無い。
- D: 戻り値が int。
- E: 引数が String 1つで、配列ではない。
- F: private。

「コンパイルできるか」と「起動できるか」は別の問題です。どちらを問われているかを先に確かめます。

## 検証
@case 正解 A: 起動できる
@file App.java
public class App {
    public static void main(String... args) { System.out.println("A"); }
}
@javac
@run App
@stdout
A
@end

@case 正解 B: 起動できる
@file App.java
public class App {
    static public void main(String args[]) { System.out.println("B"); }
}
@javac
@run App
@stdout
B
@end

@case C はコンパイルできるが、Java 17 では起動できない
@only-jdk 17
@file App.java
public class App {
    public void main(String[] args) { }
}
@javac
@sh java -cp out App
@fails

@case D はコンパイルできるが、Java 17 では起動できない
@only-jdk 17

@javac

@fails
