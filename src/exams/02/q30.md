次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String s = "";
        for (int n : new int[]{2, 3, 1}) {
            switch (n) {
                case 1:
                    s += "1";
                default:
                    s += "d";
                case 2:
                    s += "2";
                    break;
                case 4:
                    s += "4";
            }
            s += "|";
        }
        System.out.println(s);
    }
}
```

- A. 「2|d|1|」と表示される
- B. 「2|d2|1|」と表示される
- C. 「2|d24|1d24|」と表示される
- D. default が最後に書かれていないため、コンパイルエラーが発生する
- E. 「2|d2|1d2|」と表示される

## 解説
switch 文は、一致した case（一致が無ければ default）の位置から**下へ順に**実行し、break で止まります。default の位置はどこでも構いません（D は誤り）。

| n | 入口 | 実行される部分 | 追加される文字 |
|---|---|---|---|
| 2 | case 2 | "2" → break | `2|` |
| 3 | 一致なし → default | "d" → case 2 の "2" → break | `d2|` |
| 1 | case 1 | "1" → default の "d" → case 2 の "2" → break | `1d2|` |

default が途中にあっても、「一致しなかったときの入口」になるだけで、そこから下へ流れるのは同じです。case 4 は break の後にあるので、どの n でも実行されません（C は誤り）。
