次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
interface Greeter {
    String name();
    default String greet() {
        return "Hi, " + name();
    }
}

abstract class Base implements Greeter {
    public String name() { return "Base"; }
    public abstract String tag();
}

class Impl extends Base {
    public String name() { return "Impl"; }
    public String tag() { return greet() + "!"; }
}

public class Main {
    public static void main(String[] args) {
        Greeter g = new Impl();
        Base b = new Impl();
        System.out.println(g.greet() + " / " + b.tag());
    }
}
```

- A. 「Hi, Impl / Hi, Impl!」と表示される
- B. 「Hi, Base / Hi, Base!」と表示される
- C. 「Hi, Base / Hi, Impl!」と表示される
- D. Base クラスが greet メソッドを実装していないため、コンパイルエラーが発生する
- E. Impl クラスが greet メソッドを実装していないため、コンパイルエラーが発生する

## 解説
greet() は Greeter の default メソッドで、中で `name()` を呼んでいます。この `name()` も普通のメソッド呼び出しなので、**実体のクラス**のものが動きます。

- `g.greet()`: 実体は Impl です。greet() は Greeter の default がそのまま使われ、中の `name()` は Impl の "Impl" が選ばれます。「Hi, Impl」。
- `b.tag()`: Impl の tag() が動き、greet() → Impl の name() で「Hi, Impl!」。

Base が name() を実装していても、Impl がさらにオーバーライドしているので、Base の "Base" は使われません（B・C は誤り）。

default メソッドは実装済みなので、Base も Impl も greet() を書く必要はありません（D・E は誤り）。「インタフェースに骨組み（greet）を置き、中身（name）を実装クラスに任せる」という、抽象クラスのテンプレートと同じ形です。
