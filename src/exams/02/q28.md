次のクラスの `// insert code here` に挿入したとき、コンパイルが成功するコードを選びなさい。

```java title=Counter.java
public class Counter {
    private int count;
    private static int total;

    public static void reset() {
        // insert code here
    }
}
```

- A. `count = 0;`
- B. `this.count = 0;`
- C. `new Counter().count = 0;`
- D. `total = 0;`
- E. `Counter.count = 0;`
- F. `super.toString();`

## 解説
reset() は static メソッドなので、特定のインスタンスに属していません。そのため `this`（自分のインスタンス）がありません。

- A: `count` はインスタンスのフィールドです。`this.count` の省略形なので、this の無い static メソッドでは使えません。エラー。
- B: this そのものが使えません。エラー。
- C: `new Counter()` で作ったインスタンスを通して count を使っています。count は private ですが、同じクラスの中なので使えます。正しい。
- D: total は static フィールドなので、static メソッドから直接使えます。正しい。
- E: `クラス名.フィールド名` の形で使えるのは static フィールドだけです。エラー。
- F: super も this と同じくインスタンスを前提にするので、static メソッドでは使えません。エラー。

「static からはインスタンスのメンバが使えない」は正確には「**インスタンスを指定せずには**使えない」です。C のように、インスタンスを用意すれば使えます。

## 検証
@case 正解 C と D
@file Counter.java
public class Counter {
    private int count;
    private static int total;

    public static void reset() {
        new Counter().count = 0;
        total = 0;
    }
}
@javac

@case A は CE
@file Counter.java
public class Counter {
    private int count;
    public static void reset() {
        count = 0;
    }
}
@javac-error non-static variable count cannot be referenced from a static context

@case B は CE
@file Counter.java
public class Counter {
    private int count;
    public static void reset() {
        this.count = 0;
    }
}
@javac-error

@case E は CE
@file Counter.java
public class Counter {
    private int count;
    public static void reset() {
        Counter.count = 0;
    }
}
@javac-error

@case F は CE
@file Counter.java
public class Counter {
    public static void reset() {
        super.toString();
    }
}
@javac-error
