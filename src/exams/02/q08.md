次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static int first() {
        int x = 1;
        try {
            return x;
        } finally {
            x = 2;
        }
    }

    static int second() {
        try {
            throw new RuntimeException();
        } finally {
            return 3;
        }
    }

    static int third() {
        int[] a = {1};
        try {
            return a[0];
        } finally {
            a[0] = 9;
        }
    }

    public static void main(String[] args) {
        System.out.println(first() + " " + second() + " " + third());
    }
}
```

- A. 「2 3 9」と表示される
- B. 「1 3 9」と表示される
- C. 「2 3 1」と表示される
- D. 実行時に RuntimeException がスローされる
- E. 「1 3 1」と表示される

## 解説
- `first()`: `return x;` の時点で、返す値 **1** が決まって保存されます。その後 finally で x を 2 にしても、保存済みの戻り値は変わりません。1。
- `second()`: try で例外が発生しますが、finally の中に `return 3;` があります。**finally の return は、進行中の例外を捨てて**メソッドを正常に終わらせます。3。例外は外に出ません（D は誤り）。
- `third()`: `return a[0];` で返す値は、その時点の要素の値 **1** です。finally で配列の中身を 9 に変えても、すでに取り出した int の値は変わりません。1。

結果は「1 3 1」です。third() で「配列は参照型だから 9 になる」と考えさせる引っかけに注意してください。返しているのは配列ではなく、要素の int の値です。
