次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        outer:
        for (int i = 1; i <= 3; i++) {
            for (int j = 1; j <= 3; j++) {
                if (j == i) continue outer;
                if (i + j > 4) break outer;
                System.out.print(i + "" + j + " ");
            }
        }
        System.out.println("end");
    }
}
```

- A. 「12 13 21 31 end」と表示される
- B. 「21 31 end」と表示される
- C. 「21 31 32 end」と表示される
- D. 「21 end」と表示される
- E. 「end」と表示される

## 解説
`continue outer` は内側のループを打ち切り、**外側のループの次の周**へ進みます。`break outer` は**外側のループごと**抜けます。

| i | j | 判定 | 結果 |
|---|---|---|---|
| 1 | 1 | j == i | continue outer → i = 2 へ |
| 2 | 1 | 2+1 = 3 は 4 以下 | 「21 」 |
| 2 | 2 | j == i | continue outer → i = 3 へ |
| 3 | 1 | 3+1 = 4 は 4 以下 | 「31 」 |
| 3 | 2 | 3+2 = 5 > 4 | break outer → ループを抜ける |

最後に「end」を表示して「21 31 end」です。

- A: ラベルを無視して、continue と break が内側のループだけに効くと考えた場合の結果です。
- C: i = 3, j = 2 で `break outer` が働くことを見落とし、「32 」まで表示した誤りです（その次の j = 3 は j == i なので continue outer）。
