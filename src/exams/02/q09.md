次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String s = " \t Java \n";
        System.out.print(s.isEmpty() + " ");
        System.out.print(s.isBlank() + " ");
        System.out.print(s.strip().length() + " ");
        System.out.print("  ".isBlank() + " ");
        System.out.println("".isEmpty());
    }
}
```

- A. 「false false 4 true true」と表示される
- B. 「false true 4 true true」と表示される
- C. 「false false 9 true true」と表示される
- D. 「true false 4 false true」と表示される
- E. 「false false 6 true true」と表示される

## 解説
| メソッド | true になる条件 |
|---|---|
| `isEmpty()` | 長さが 0 |
| `isBlank()` | 空か、空白文字（スペース・タブ・改行など）だけ |

- `s.isEmpty()`: s の長さは 9 なので false。
- `s.isBlank()`: 「Java」を含むので false（B は、空白が多いことに引っ張られた誤り）。
- `s.strip()`: 前後の空白・タブ・改行をすべて除いて "Java"。長さ 4。
- `"  ".isBlank()`: スペースだけなので true。長さは 2 なので isEmpty() なら false です。
- `"".isEmpty()`: 長さ 0 なので true。

`strip()` は元の文字列を変えず、新しい文字列を返します。ここでは戻り値に対して `length()` を呼んでいるので 4 です。
