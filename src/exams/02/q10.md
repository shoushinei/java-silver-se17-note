次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Point.java
public class Point {
    int x, y;

    Point(int x, int y) {
        x = x;
        this.y = y;
    }

    Point(int v) {
        this(v, v);
        x++;
    }

    public static void main(String[] args) {
        Point p = new Point(5);
        System.out.println(p.x + "," + p.y);
    }
}
```

- A. 「5,5」と表示される
- B. 「6,5」と表示される
- C. 「0,5」と表示される
- D. 「1,5」と表示される
- E. コンパイルエラーが発生する

## 解説
`new Point(5)` は `Point(int v)` を呼び、その先頭の `this(v, v)` で `Point(int x, int y)` に進みます。

- 5 行目 `x = x;`: 引数 x が同名のフィールドを隠しているので、**引数に引数を代入しているだけ**です。フィールド x は既定値の 0 のまま。
- 6 行目 `this.y = y;`: フィールド y は 5 になります。

`Point(int v)` に戻り、11 行目の `x++` を実行します。このコンストラクタには x という名前の引数もローカル変数も無いので、**x はフィールド**を指します。0 が 1 になります。

「1,5」です。5 行目に引っ張られて A や B を選ばせる問題です。同じ `x` という文字でも、どのコンストラクタの中にあるかで指すものが変わります。
