次のプログラムの先頭（`// imports` の位置）に記述したとき、コンパイルが成功するものを選びなさい。

```java title=Main.java
// imports

public class Main {
    public static void main(String[] args) {
        List<String> names = new ArrayList<>();
        names.add("a");
        System.out.println(names);
    }
}
```

- A.
  ```java
  import java.util.*;
  import java.awt.*;
  ```
- B.
  ```java
  import java.util.*;
  import java.awt.*;
  import java.util.List;
  ```
- C.
  ```java
  import java.util.List;
  import java.util.ArrayList;
  ```
- D.
  ```java
  import java.util.List;
  import java.awt.List;
  import java.util.ArrayList;
  ```
- E.
  ```java
  import java.awt.*;
  import java.util.ArrayList;
  ```

## 解説
`List` という名前のクラスは、`java.util.List`（コレクション）と `java.awt.List`（画面部品）の2つがあります。

- A: `*` でどちらのパッケージも読み込んでいるので、`List` と書いた時点で**どちらのことかあいまい**になりエラーです。
- B: `import java.util.List;` のような**単一型インポートは `*` より優先**されるので、List は java.util.List に決まります。ArrayList は java.util.* から見つかります。正しい。
- C: 必要な2つを名指ししています。正しい。
- D: 同じ名前 List を、単一型インポートで2つ指定すると、import 文の時点でエラーです。
- E: List は java.awt.List になります。java.awt.List はジェネリクスのクラスではないので `List<String>` と書けず、ArrayList も代入できません。エラー。

`*` を2つ並べても、それだけではエラーになりません。**あいまいな名前を実際に使ったときに**エラーになる点がポイントです（A で List を使わなければコンパイルは通ります）。
