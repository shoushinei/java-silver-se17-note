次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static void m(Object o)     { System.out.print("Object "); }
    static void m(String s)     { System.out.print("String "); }
    static void m(Integer... v) { System.out.print("Varargs "); }

    public static void main(String[] args) {
        m("A");
        m(10);
        m();
        m(10, 20);
    }
}
```

- A. 「String Varargs Varargs Varargs」と表示される
- B. 「Object Object Varargs Varargs」と表示される
- C. 8 行目の呼び出しがあいまいなため、コンパイルエラーが発生する
- D. 「String Object Varargs Varargs」と表示される
- E. 「String Object Object Varargs」と表示される

## 解説
- `m("A")`: String 版と Object 版の両方に渡せますが、String は Object の子で**より具体的**なので String 版です。
- `m(10)`: int をそのまま受け取れる m は無いので、次の段階でボクシングを試します。10 → Integer にすれば、Integer は Object の子なので **Object 版**に渡せます。ここで決まるので、可変長引数（Integer...）までは進みません。可変長引数は最後の段階なので、Object 版と比べられることもなく、あいまいにもなりません（A・C は誤り）。
- `m()`: 引数 0 個で呼べるのは可変長引数だけです。
- `m(10, 20)`: 引数 2 個で呼べるのも可変長引数だけです。

「Integer... のほうが Integer に近いから m(10) は Varargs」と考えさせる引っかけです。可変長引数は、ほかの候補が1つも使えないときにだけ選ばれます。
