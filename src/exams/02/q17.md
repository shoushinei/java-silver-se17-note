次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Integer> list = new ArrayList<>(List.of(10, 20, 30, 1));
        list.remove(1);
        list.remove(Integer.valueOf(1));
        list.remove(Integer.valueOf(99));
        System.out.println(list);
    }
}
```

- A. 「[20, 30]」と表示される
- B. 「[10, 20, 30]」と表示される
- C. 「[30, 1]」と表示される
- D. 実行時に例外がスローされる
- E. 「[10, 30]」と表示される

## 解説
`List<Integer>` の remove には2つのオーバーロードがあります。

| 呼び出し | 選ばれるメソッド | 意味 |
|---|---|---|
| `remove(1)` | `remove(int index)` | **位置** 1 の要素を削除 |
| `remove(Integer.valueOf(1))` | `remove(Object o)` | **値が 1** の要素を削除 |

- 6 行目: int の 1 を渡すと、ボクシングの要らない `remove(int)` が選ばれます。位置 1 の 20 が消えて [10, 30, 1]。
- 7 行目: Integer を渡しているので `remove(Object)` です。値 1 が消えて [10, 30]。
- 8 行目: 値 99 は無いので、何もせず false を返すだけです。例外にはなりません（D は誤り）。

`List.of(...)` 自体は変更できませんが、それを `new ArrayList<>(...)` に渡して作ったリストは普通の ArrayList なので、削除できます。
