次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class Parent {
    Parent() {
        System.out.print("P:");
        show();
    }
    void show() {
        System.out.print("parent ");
    }
}

class Child extends Parent {
    private String msg = "hello";
    private int count = 5;
    Child() {
        System.out.print("C:");
        show();
    }
    @Override
    void show() {
        System.out.print(msg + count + " ");
    }
}

public class Main {
    public static void main(String[] args) {
        new Child();
    }
}
```

- A. 「P:parent C:hello5 」と表示される
- B. 「P:hello5 C:hello5 」と表示される
- C. 「P:null0 C:hello5 」と表示される
- D. 「C:hello5 P:parent 」と表示される
- E. 実行時に NullPointerException がスローされる

## 解説
`new Child()` の流れを順に追います。

1. Child のコンストラクタの先頭には暗黙の `super()` があるので、まず Parent のコンストラクタが動き「P:」を表示します。
2. Parent のコンストラクタの中の `show()` は、**実体（Child）の show()** が呼ばれます。オーバーライドは、親のコンストラクタの中からの呼び出しでも実体で決まるからです（A は誤り）。
3. ところがこの時点では、Child のフィールド初期化子（`msg = "hello"` と `count = 5`）は**まだ実行されていません**。フィールドの初期化子は `super()` から戻った後に実行されるからです。msg は既定値の null、count は 0 なので「null0 」。
4. super() から戻ると msg と count に値が入り、Child のコンストラクタ本体で「C:」と「hello5 」を表示します。

null を文字列連結しても例外にはならず "null" になるので、E も誤りです。
