次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Object[] data = { "ab", 12, "xyz", null, 'q' };
        int total = 0;
        for (Object o : data) {
            if (!(o instanceof String s)) {
                continue;
            }
            total += s.length();
        }
        System.out.println(total);
    }
}
```

- A. 「6」と表示される
- B. 「5」と表示される
- C. 実行時に NullPointerException がスローされる
- D. 9 行目で、if 文の外にあるパターン変数 s を使っているため、コンパイルエラーが発生する
- E. 「0」と表示される

## 解説
6 行目は「o が String **でなければ** continue」です。つまり 9 行目に到達するのは、o が String のときだけです。コンパイラはこれを見抜いて、**if 文の後ろでも s を使えるように**します（D は誤り）。

- "ab" → String なので 9 行目へ。total = 2。
- 12 → Integer なので continue。
- "xyz" → total = 5。
- null → `null instanceof String` は false なので continue。例外にはなりません（C は誤り）。
- 'q' → Character なので continue（A は、文字も String として数えた誤り）。

合計は 5 です。

パターン変数が使える範囲は「そこでは必ず型が合っている」と言える場所です。`if (o instanceof String s) { ... } else { ここでは使えない }` とは逆向きになる点が、この問題の引っかけです。
