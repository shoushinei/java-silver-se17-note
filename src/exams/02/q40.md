次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
abstract class Shape {
    abstract double area();
}

class Circle extends Shape {
    double r = 1;
    double area() { return 3.14 * r * r; }
}

class Square extends Shape {
    double s = 2;
    double area() { return s * s; }
}

public class Main {
    public static void main(String[] args) {
        Shape[] shapes = { new Square(), new Circle() };
        for (Shape sh : shapes) {
            System.out.print(sh.area() + " ");
            Square sq = (Square) sh;
            System.out.print(sq.s + " ");
        }
    }
}
```

- A. 「4.0 2.0 3.14 2.0 」と表示される
- B. 「4.0 2.0 」と表示された後、ClassCastException がスローされる
- C. 20 行目でコンパイルエラーが発生する
- D. Shape が抽象クラスのため、17 行目でコンパイルエラーが発生する
- E. 「4.0 2.0 3.14 」と表示された後、ClassCastException がスローされる

## 解説
- 17 行目: 抽象クラスは new できませんが、**配列の型**としては使えます。中身は Square と Circle のインスタンスです（D は誤り）。
- 20 行目: Shape から子の Square へのキャストは、「実体が Square かもしれない」のでコンパイルは通ります（C は誤り）。

1 周目は Square なので、面積「4.0 」とキャスト後の s「2.0 」を表示します。

2 周目は Circle です。まず面積「3.14 」を表示し（B は、この表示を飛ばした誤り）、次のキャストで実体が Square ではないので **ClassCastException** になります。

キャストが安全かどうかはコンパイラには分からず、実行時に実体を確かめて初めて失敗します。`if (sh instanceof Square sq)` と書けば、例外を避けられます。
