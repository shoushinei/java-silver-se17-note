次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int i = 2;
        i = i++ + ++i;
        int j = i-- - --i;
        System.out.println(i + " " + j);
    }
}
```

- A. 「6 2」と表示される
- B. 「5 1」と表示される
- C. 「4 0」と表示される
- D. 「4 2」と表示される
- E. 「7 3」と表示される

## 解説
演算子の左側から順に、そのときの値を書き出していきます。

**4 行目** `i = i++ + ++i;`（i は 2 から）

| 項 | 使われる値 | その後の i |
|---|---|---|
| `i++` | 2 | 3 |
| `++i` | 4 | 4 |

2 + 4 = 6 を i に代入するので、i は **6** です（途中で 4 になった値は上書きされます）。

**5 行目** `int j = i-- - --i;`（i は 6 から）

| 項 | 使われる値 | その後の i |
|---|---|---|
| `i--` | 6 | 5 |
| `--i` | 4 | 4 |

j = 6 − 4 = **2**、i は **4** です。

「4 2」です。A は、5 行目で i が減ったことを見落とした誤りです。
