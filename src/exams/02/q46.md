次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static void work() {
        try {
            throw new IllegalStateException("t");
        } catch (RuntimeException e) {
            System.out.print("catch:" + e.getMessage() + " ");
            throw new IllegalArgumentException("c");
        } finally {
            System.out.print("finally ");
        }
    }

    public static void main(String[] args) {
        try {
            work();
        } catch (IllegalArgumentException e) {
            System.out.print("main:" + e.getMessage());
        }
    }
}
```

- A. 「catch:t main:c finally 」と表示される
- B. 「catch:t finally main:t」と表示される
- C. 「catch:t finally 」と表示された後、例外がスローされてプログラムが終了する
- D. 「catch:t finally main:c」と表示される
- E. work メソッドが throws を宣言していないため、コンパイルエラーが発生する

## 解説
1. try で IllegalStateException("t") が発生し、`catch (RuntimeException e)` が捕まえます（IllegalStateException は RuntimeException の子）。「catch:t 」。
2. catch の中で新しい IllegalArgumentException("c") を投げます。この例外は、同じ try 文の catch では捕まえられません。
3. work() を抜ける**前に finally が実行され**「finally 」。
4. 例外は main に伝わり、`catch (IllegalArgumentException e)` が捕まえて「main:c」。

- A: finally は、例外が呼び出し元へ伝わる前に実行されます。
- B: main に届くのは、後から投げた "c" の例外です。最初の "t" は catch で処理済みです。
- C: main の catch が捕まえるので、プログラムは異常終了しません。
- E: どちらも RuntimeException の子（非検査例外）なので、throws は不要です。
