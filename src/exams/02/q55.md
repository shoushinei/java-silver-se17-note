次のクラスをコンパイルしたとき、コンパイルエラーになる行を選びなさい。

```java title=Config.java
public class Config {
    static final int MAX;
    final int[] values = {1, 2};
    final String name;

    static {
        MAX = 10;
    }

    Config(String name) {
        this.name = name;
    }

    final void update(final int n) {
        values[0] = n;
        values = new int[]{n};
        n = 0;
        MAX = n;
    }
}
```

- A. 2 行目
- B. 7 行目
- C. 15 行目
- D. 16 行目
- E. 17 行目
- F. 18 行目

## 解説
| 行 | 内容 | 判定 |
|---|---|---|
| 2 | 初期値の無い static final | ○ static 初期化子で代入するなら書ける |
| 7 | static 初期化子で MAX に1回だけ代入 | ○ |
| 11 | コンストラクタで final の name に1回だけ代入 | ○ |
| 14 | final メソッド、final 引数 | ○ final メソッドは「オーバーライドできない」だけ |
| 15 | final の配列の**中身**を変更 | ○ 固定されるのは参照（矢印）だけ |
| 16 | final の values 自体に別の配列を代入 | **×** 再代入 |
| 17 | final の引数 n に代入 | **×** 再代入 |
| 18 | static final の MAX に、static 初期化子の外で代入 | **×** |

final は「一度決めたら変えられない」ですが、**何が固定されるか**は種類で違います。参照型の final は矢印が固定されるだけで、指す先の中身は変えられます（15 行目）。

2 行目のように初期値の無い final（ブランク final）は、static なら static 初期化子、インスタンスならコンストラクタで、**必ず1回だけ**代入します。
