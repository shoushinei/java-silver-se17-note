次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static void change(String s, StringBuilder sb, int n, int[] arr) {
        s += "!";
        sb.append("!");
        sb = new StringBuilder("X");
        n++;
        arr[0]++;
        arr = new int[]{100};
    }

    public static void main(String[] args) {
        String s = "a";
        StringBuilder sb = new StringBuilder("b");
        int n = 1;
        int[] arr = {1};
        change(s, sb, n, arr);
        System.out.println(s + " " + sb + " " + n + " " + arr[0]);
    }
}
```

- A. 「a b! 1 2」と表示される
- B. 「a b 1 1」と表示される
- C. 「a! b! 2 100」と表示される
- D. 「a X 1 100」と表示される
- E. 「a! X 2 2」と表示される

## 解説
Java の引数はすべて**値渡し**です。参照型の場合は「指す先（矢印）」がコピーされます。

| 引数 | メソッドの中でしたこと | 呼び出し元への影響 |
|---|---|---|
| `s` | `s += "!"` で新しい String を作り、引数の s を差し替えた | なし → "a" |
| `sb` | `append` で**指す先の中身**を変えた後、引数の sb を差し替えた | 中身の変更だけ伝わる → "b!" |
| `n` | 基本データ型の値のコピーを増やした | なし → 1 |
| `arr` | `arr[0]++` で**指す先の中身**を変えた後、引数の arr を差し替えた | 中身の変更だけ伝わる → 2 |

String は不変なので、`+=` は元の文字列を書き換えず、新しい String を作って**メソッドの中の変数 s** に入れ直すだけです。呼び出し元の s は "a" のままです。

「差し替える前に中身を変えたか」がポイントです。sb と arr は、差し替える前に中身を変えているので、その変更が残ります。
