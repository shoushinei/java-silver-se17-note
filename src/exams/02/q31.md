次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        String t = """
            A
              B
            C""";
        String u = """
            x \
            y
            """;
        System.out.println(t.length() + " " + u.length());
    }
}
```

- A. 「9 5」と表示される
- B. 「8 4」と表示される
- C. 「7 4」と表示される
- D. 「7 3」と表示される
- E. コンパイルエラーが発生する

## 解説
**t**: 各行に共通するインデント（A と C の行の先頭の空白）が取り除かれます。B の行は2文字多く字下げされているので、その2文字は残ります。閉じる `"""` が C と同じ行にあるので、最後に改行は付きません。

```console
A↵
  B↵
C
```

文字数は A（1）+ 改行（1）+ 空白2と B（3）+ 改行（1）+ C（1）= **7**。

**u**: 行末の `\` は「ここで改行しない」という意味で、次の行とつながります。`\` の前の空白は行末の空白ではないので残ります。閉じる `"""` が独立した行にあるので、y の後ろに改行が付きます。

```console
x y↵
```

x・空白・y・改行で **4** です。
