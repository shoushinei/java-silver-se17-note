次の record の `// insert code here` に挿入したとき、コンパイルが成功するコードを選びなさい。

```java title=Book.java
public record Book(String title, int price) {
    // insert code here
}
```

- A. `private int stock;`
- B. `static int count = 0;`
- C. `public Book() { }`
- D. `public String title() { return title.toUpperCase(); }`
- E. `public long price() { return price; }`
- F. `void setPrice(int price) { this.price = price; }`

## 解説
- A: record には**インスタンスフィールドを追加できません**。フィールドはコンポーネント（title と price）だけです。エラー。
- B: static フィールドは追加できます。正しい。
- C: コンポーネントと違う引数のコンストラクタも書けますが、先頭で `this("無題", 0);` のように**正規コンストラクタを呼ぶ**必要があります。何も呼ばない C はエラー。
- D: アクセサ `title()` は、戻り値の型と引数が同じなら自分で書き直せます。正しい。
- E: アクセサ `price()` の戻り値はコンポーネントと同じ int でなければならず、long にはできません。エラー。
- F: record のフィールドは private final なので、代入できません。エラー。

「record は何も追加できない」ではなく、「**インスタンスの状態を増やしたり変えたりすることだけができない**」と覚えると、選択肢を切り分けやすくなります。
