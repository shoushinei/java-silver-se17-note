メソッドの中に記述したとき、コンパイルが成功する宣言を選びなさい。

- A. `int a = 0b1_0;`
- B. `long b = 1_000L;`
- C. `int c = _100;`
- D. `float d = 1.5;`
- E. `int e = 0x1F_;`
- F. `double f = 1_0.5_0;`
- G. `int g = 08;`

## 解説
数値リテラルの `_` は、**数字と数字の間**にだけ書けます。

- A: 2進数の 10（10進で 2）。`1_0` は数字の間なので正しい。
- B: L は long のリテラル。`1_000` も正しい。
- C: 先頭が `_` だと数値ではなく**識別子**（変数名）として読まれます。_100 という変数は無いのでエラー。
- D: 小数のリテラルは double です。float に入れるには `1.5f` と書きます。エラー。
- E: 最後の `_` は数字と数字の間ではないのでエラー。
- F: `1_0.5_0` は 10.50。小数点の左右とも、_ は数字の間にあるので正しい。
- G: 先頭が 0 の数は **8進数**として読まれ、8 は8進数では使えない数字なのでエラー。

`_` を書けない場所は、先頭・末尾・小数点の直前直後・`0x` や `0b` の直後・`L` や `F` の直前です。
