次のプログラムの `// insert code here` に挿入したとき、コンパイルが成功するものを選びなさい。

```java title=Main.java
// insert code here

public class Main {
    public static void main(String[] args) {
        System.out.println(max(3, 7) + " " + PI);
    }
}
```

- A. `import static java.lang.Math;`
- B. `import java.lang.Math.*;`
- C. `import static java.lang.Math.*;`
- D. `import static java.lang.Math.max;`
- E. `static import java.lang.Math.*;`

## 解説
`max` と `PI` は、どちらも Math クラスの **static メンバ**です。クラス名を付けずに使うには `import static` が必要です。

- A: `import static` の後には、クラスではなく**メンバ**（または `*`）を書きます。クラスで止めるとエラーです。
- B: static の付かない `import java.lang.Math.*;` は、Math の中の**型**（ネストしたクラス）を読み込む書き方です。文としては正しいですが、max や PI は読み込まれず、使った所でエラーになります。
- C: Math の static メンバをすべて読み込みます。正しい。
- D: max だけを読み込んでいるので、PI が見つからずエラーです。
- E: 語順は `import static` です。`static import` とは書けません。
