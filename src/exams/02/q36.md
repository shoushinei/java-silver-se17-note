次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        System.out.print(-7 / 2 + " ");
        System.out.print(-7 % 2 + " ");
        System.out.print(7 % -2 + " ");
        System.out.print(7 / 2 * 2.0 + " ");
        System.out.println(7 / 2.0 * 2);
    }
}
```

- A. 「-4 1 -1 7.0 7.0」と表示される
- B. 「-3 1 -1 6.0 7.0」と表示される
- C. 「-3 -1 1 7.0 7.0」と表示される
- D. 「-3 -1 1 6.0 7.0」と表示される
- E. 「-4 -1 1 6.0 7.0」と表示される

## 解説
- `-7 / 2`: int 同士の割り算は、小数点以下を**0 に近い方へ切り捨て**ます。-3.5 → **-3**（-4 ではありません）。
- `-7 % 2`: 余りの符号は**左オペランド**に従います。-7 = 2 × (-3) + (-1) なので **-1**。
- `7 % -2`: 左の 7 が正なので余りも正で **1**。
- `7 / 2 * 2.0`: 左から順に計算します。まず `7 / 2` が int 同士で 3、それに 2.0 を掛けて **6.0**。
- `7 / 2.0 * 2`: `7 / 2.0` は片方が double なので 3.5、それに 2 を掛けて **7.0**。

`7 / 2 * 2.0` の結果は、2.0 が式にあっても、先に計算される `7 / 2` の時点では int 同士なので切り捨てが起きます。「double が1つでもあれば最初から小数で計算する」わけではない点が引っかけです。
