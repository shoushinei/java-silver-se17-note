次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static String grade(int score) {
        return switch (score / 10) {
            case 10, 9 -> "A";
            case 8 -> "B";
            case 7, 6 -> {
                String s = "C";
                yield s;
            }
        };
    }

    public static void main(String[] args) {
        System.out.println(grade(95) + grade(70));
    }
}
```

- A. 「AC」と表示される
- B. 「AB」と表示される
- C. 「A」と表示された後、実行時に例外がスローされる
- D. コンパイルエラーが発生する
- E. 「A」と表示される

## 解説
switch **式**は、値を必ず1つ返さなければならないので、**すべての入力値を網羅**している必要があります。`score / 10` は int で、10・9・8・7・6 以外の値（5 や -1 など）も取り得ます。default が無いので、「網羅していない」というコンパイルエラーになります。

`case 7, 6 -> { ... yield s; }` のように、ブロックの中で `yield` を使って値を返す書き方は正しいので、エラーの原因ではありません。

`default -> "D";` を加えれば、「AC」と表示されます（grade(95) は 9 → "A"、grade(70) は 7 → "C"）。

switch **文**（値を返さない）なら default が無くても問題ありません。式か文かを最初に見分けることが大切です。
