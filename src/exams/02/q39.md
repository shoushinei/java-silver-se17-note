次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        StringBuilder sb = new StringBuilder("abc");
        sb.insert(1, sb.length()).reverse().deleteCharAt(0);
        StringBuilder other = new StringBuilder(sb);
        System.out.println(sb + " " + sb.equals(other) + " "
                + sb.toString().equals(other.toString()));
    }
}
```

- A. 「b3a false true」と表示される
- B. 「b3a true true」と表示される
- C. 「a3b false true」と表示される
- D. 「cb3 false true」と表示される
- E. コンパイルエラーが発生する

## 解説
StringBuilder の insert・reverse・deleteCharAt は、**同じオブジェクトを書き換えて、そのオブジェクト自身を返す**ので、つなげて呼べます。

| 呼び出し | sb の中身 |
|---|---|
| 最初 | abc |
| `insert(1, sb.length())` | 位置 1 に 3 を挿入 → a3bc |
| `reverse()` | cb3a |
| `deleteCharAt(0)` | 位置 0 の c を削除 → b3a |

`insert` の第2引数には int も渡せます（文字列にして挿入される）。`sb.length()` は insert の前に評価されるので 3 です。

- `sb.equals(other)`: StringBuilder は equals をオーバーライドしていないので、Object の equals（**同じインスタンスか**）で比べられます。other は `new` で作った別のオブジェクトなので false。
- `toString()` どうしの equals: String の equals は中身を比べるので true。

StringBuilder の中身を比べたいときは、toString してから比べます。
