メソッドの中に記述したとき、コンパイルが成功するコードを選びなさい。

- A. `for (int i = 0, j = 10; i < j; i++, j--) { }`
- B. `for (int i = 0, int j = 10; i < j; i++) { }`
- C. `for (int i = 0; ; i++) { if (i > 3) break; }`
- D. `while (false) { System.out.println("x"); }`
- E. `for (int i = 0; i < 3; i++) { break; System.out.println(i); }`

## 解説
- A: 初期化部では、**同じ型**の変数をカンマで複数宣言できます。更新部もカンマで複数書けます。正しい。
- B: 型を2回書く（`int i = 0, int j = 10`）ことはできません。エラー。
- C: 条件を省略すると true とみなされる無限ループですが、中に break があるので問題ありません。正しい。
- D: 条件が**定数の false** なので、本体は絶対に実行されません。コンパイラはこれを「到達できない文」としてエラーにします。
- E: `break;` の直後の文には絶対に到達できないのでエラーです（`continue;` や `return;` の直後も同じ）。

D の引っかけとして、`if (false) { ... }` はエラーにならない点も押さえておきます。if は、デバッグ用のコードを一時的に止める用途のために、例外的に許されています。

## 検証
