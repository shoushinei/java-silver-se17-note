次のプログラムをコンパイルしたとき、コンパイルエラーになる行を選びなさい。

```java title=Main.java
class Animal { void eat() { } }
class Dog extends Animal { void bark() { } }

public class Main {
    public static void main(String[] args) {
        Animal a = new Dog();
        ((Dog) a).bark();
        (Dog) a.bark();
        Runnable r = (Runnable) a;
        a.eat();
        a.bark();
    }
}
```

- A. 7 行目
- B. 8 行目
- C. 9 行目
- D. 10 行目
- E. 11 行目

## 解説
- 7 行目: `((Dog) a)` で a を Dog として扱ってから `.bark()` を呼んでいます。正しい。
- 8 行目: キャストは `.`（メソッド呼び出し）より**結合が弱い**ので、`(Dog) (a.bark())` と解釈されます。まず Animal 型の a に bark() が無いのでエラーです。そもそも「キャストするだけの式」は文として書けません。
- 9 行目: Animal は final ではないので、「Animal の子のどれかが Runnable を実装しているかもしれない」とコンパイラは判断し、インタフェースへのキャストを**許します**。実際には Dog は Runnable ではないので、実行すれば ClassCastException になりますが、コンパイルエラーではありません。
- 10 行目: eat() は Animal にあるので正しい。
- 11 行目: 変数 a の型は Animal で、bark() は Animal にありません。実体が Dog でもエラーです。

8 行目のように、子のメソッドを呼ぶには **キャストした式全体を括弧で囲む**必要があります。
