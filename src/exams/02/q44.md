次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        String[] arr = {"x", "y", "z"};
        List<String> list = Arrays.asList(arr);
        list.set(0, "X");
        arr[2] = "Z";
        System.out.print(list + " " + arr[0] + " ");
        list.add("w");
        System.out.println(list);
    }
}
```

- A. 「[X, y, Z] X [X, y, Z, w]」と表示される
- B. 「[X, y, z] x 」と表示された後、UnsupportedOperationException がスローされる
- C. 「[X, y, Z] X 」と表示された後、UnsupportedOperationException がスローされる
- D. 「[X, y, z] x [X, y, z, w]」と表示される
- E. 何も表示されずに、UnsupportedOperationException がスローされる

## 解説
`Arrays.asList(arr)` は、配列をコピーせず**そのまま包んだ**リストを返します。リストと配列は同じ中身を共有します。

- 7 行目 `list.set(0, "X")`: 中身の書き換えは許されています。共有している arr[0] も "X" になります。
- 8 行目 `arr[2] = "Z"`: 配列を書き換えると、リストから見ても "Z" になります。
- 9 行目: 「[X, y, Z] X 」と表示されます（B・D は、共有していないと考えた誤り）。
- 10 行目 `list.add("w")`: 配列の長さは変えられないので、要素を増やす操作は **UnsupportedOperationException** です（A は誤り）。

| 作り方 | set | add / remove |
|---|---|---|
| `List.of(...)` | × | × |
| `Arrays.asList(...)` | ○（元の配列も変わる） | × |
| `new ArrayList<>(...)` | ○ | ○ |
