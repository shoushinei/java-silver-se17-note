次の3つのファイルがあります。

```java title=lib/Helper.java
package lib;

class Helper {
    public static String hello() {
        return "hello";
    }
}
```

```java title=lib/Api.java
package lib;

public class Api {
    public static String call() {
        return Helper.hello();
    }
}
```

```java title=app/Main.java
package app;

import lib.Api;
import lib.Helper;

public class Main {
    public static void main(String[] args) {
        System.out.println(Api.call() + " " + Helper.hello());
    }
}
```

これらをコンパイル、実行したときの結果として、正しいものを選びなさい。

- A. 「hello hello」と表示される
- B. Api クラスでコンパイルエラーが発生する
- C. Main クラスでコンパイルエラーが発生する
- D. 「hello」と表示された後、実行時に例外がスローされる
- E. Helper クラスでコンパイルエラーが発生する

## 解説
Helper クラスには `public` が付いていないので、**lib パッケージの中からしか見えません**。

- Api は同じ lib パッケージなので、Helper を使えます（B は誤り）。
- Main は app パッケージなので、Helper という型そのものが見えません。`import lib.Helper;` の時点で「Helper は public ではないので、パッケージの外からアクセスできない」というコンパイルエラーになります。
- Helper の中で hello() に public を付けても、クラスが見えないので意味がありません。**クラスのアクセスが先に判定され、メンバのアクセスはその後**です。修飾子なしのクラスに public メソッドを書くこと自体はエラーではありません（E は誤り）。

Main から `Helper.hello()` の部分を消せば、`Api.call()` 経由で「hello」と表示できます。外に見せたくないクラスを、public なクラスの窓口越しに使わせる、というよくある形です。
