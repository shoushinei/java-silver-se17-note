次のコードを確認してください。

```java title=Util.java
public interface Util {
    static int twice(int x) {
        return x * 2;
    }
    default int triple(int x) {
        return x * 3;
    }
}
```

```java title=Tool.java
public class Tool implements Util { }
```

別のクラスの main メソッドに記述したとき、コンパイルが成功するコードを選びなさい。

- A. `int a = Util.twice(2);`
- B. `int b = Tool.twice(2);`
- C. `int c = new Tool().twice(2);`
- D. `int d = new Tool().triple(2);`
- E. `int e = Util.triple(2);`
- F. `int f = Tool.triple(2);`

## 解説
| | static メソッド `twice` | default メソッド `triple` |
|---|---|---|
| 実装クラスに継承されるか | **されない** | される |
| 呼び方 | `インタフェース名.twice()` だけ | インスタンス経由 |

- A: static メソッドはインタフェース名で呼びます。正しい。
- B・C: インタフェースの static メソッドは Tool に**継承されない**ので、Tool.twice も、Tool のインスタンス経由の twice も存在しません。エラー。
- D: default メソッドは継承されるので、Tool のインスタンスから呼べます。正しい。
- E・F: triple はインスタンスメソッドなので、型の名前では呼べません。エラー。

クラスの static メソッドなら、子クラス名やインスタンス経由でも呼べます（推奨はされない）。インタフェースの static メソッドだけは例外で、C のような呼び方ができないのが引っかけです。
