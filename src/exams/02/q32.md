次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Object[] items = { 1, "2", 3.0, '4', 5L, true, null };
        int count = 0;
        for (Object o : items) {
            if (o instanceof Number n && n.intValue() > 0) {
                count++;
            }
        }
        System.out.println(count);
    }
}
```

- A. 「4」と表示される
- B. 「5」と表示される
- C. 実行時に NullPointerException がスローされる
- D. 「3」と表示される
- E. Object の配列に基本データ型の値を入れているため、コンパイルエラーが発生する

## 解説
配列の初期化で、基本データ型の値はそれぞれのラッパークラスに**ボクシング**されて入ります（E は誤り）。

| 要素 | 実際の型 | Number か |
|---|---|---|
| `1` | Integer | ○ |
| `"2"` | String | × |
| `3.0` | Double | ○ |
| `'4'` | Character | **×** |
| `5L` | Long | ○ |
| `true` | Boolean | × |
| `null` | — | × |

Number の子は、6つの数値のラッパー（Byte・Short・Integer・Long・Float・Double）だけです。**Character は数字の文字を入れていても Number ではありません**（A は、'4' を数えた誤り）。

`null instanceof Number` は、例外にならず false になります。`&&` の右側の `n.intValue()` は、左が true のときしか評価されないので、null で呼ばれることもありません（C は誤り）。

Number に当てはまる 3 つとも intValue() が正なので、count は 3 です。
