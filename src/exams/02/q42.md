次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    static String f(Object o)   { return "O"; }
    static String f(Object[] a) { return "A"; }
    static String f(long v)     { return "L"; }

    public static void main(String[] args) {
        System.out.println(f(new int[3]) + f(new Integer[3]) + f(5)
                + f(new int[2][2]) + f(5.0));
    }
}
```

- A. 「OALAO」と表示される
- B. 「OALOO」と表示される
- C. 「AALAO」と表示される
- D. 「AALAL」と表示される
- E. f(5.0) の呼び出しがあいまいなため、コンパイルエラーが発生する

## 解説
配列も「型」として親子関係で判定します。

| 引数 | 型 | 選ばれる f | 理由 |
|---|---|---|---|
| `new int[3]` | int[] | O | int は Object ではないので、int[] は Object[] の子ではない。配列はすべて Object の子 |
| `new Integer[3]` | Integer[] | A | Integer は Object の子なので、Integer[] は Object[] の子。Object より具体的 |
| `5` | int | L | int → long の拡大変換（ボクシングより先） |
| `new int[2][2]` | int[][] | A | 要素の int[] は Object なので、int[][] は Object[] の子 |
| `5.0` | double | O | double → long は縮小なので不可。ボクシングで Double → Object |

「int[] は数字の配列だから Object[]（A）」と考えさせるのが1つ目の引っかけで、「2次元なら int[] と同じく O」と考えさせるのが4つ目の引っかけです。f(5.0) は候補が Object 版しか残らないので、あいまいにはなりません（E は誤り）。
