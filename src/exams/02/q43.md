次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class A {
    String v() { return "A" + tag(); }
    String tag() { return "a"; }
}

class B extends A {
    String v() { return "B" + super.v(); }
}

class C extends B {
    String tag() { return "c"; }
}

public class Main {
    public static void main(String[] args) {
        A x = new C();
        B y = new B();
        System.out.println(x.v() + " " + y.v());
    }
}
```

- A. 「BAa BAa」と表示される
- B. 「BAc BAa」と表示される
- C. 「CBAc BAa」と表示される
- D. 「Ac Aa」と表示される
- E. 「BAc BAc」と表示される

## 解説
**x.v()**（実体は C）

1. C は v() をオーバーライドしていないので、B から受け継いだ v() が動きます → "B" + super.v()。
2. `super.v()` は A の v() です → "A" + tag()。
3. この `tag()` は **this.tag()** のことで、this の実体は C です。C の tag() が動いて "c"。

合わせて "BAc"。super.v() で A のメソッドに入っても、その中の呼び出しは実体（C）で決まるのがポイントです（A は、tag() も A のものが呼ばれると考えた誤り）。

**y.v()**（実体は B）

B の v() → "B" + A の v() → "A" + tag()。B は tag() をオーバーライドしていないので A の "a"。合わせて "BAa"。

C は、C 自身が v() を持っていると考えた誤りです。
