次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int x = 5;
        boolean r = x > 3 || ++x > 5 && x++ < 10;
        System.out.println(r + " " + x);

        int y = 5;
        boolean s = y < 3 && ++y > 5 || y++ < 10;
        System.out.println(s + " " + y);
    }
}
```

- A.
  ```console
  true 5
  true 6
  ```
- B.
  ```console
  true 7
  true 6
  ```
- C.
  ```console
  true 6
  true 7
  ```
- D.
  ```console
  true 5
  false 5
  ```
- E. コンパイルエラーが発生する

## 解説
`&&` は `||` より優先順位が高いので、まず `&&` の部分がまとまります。

- 4 行目: `x > 3 || (++x > 5 && x++ < 10)` です。左の `x > 3` が true なので、`||` の右側は**丸ごと評価されません**。`++x` も `x++` も実行されず、x は 5 のままです。「true 5」。
- 8 行目: `(y < 3 && ++y > 5) || y++ < 10` です。`y < 3` が false なので `&&` の右（`++y`）は実行されず、括弧全体は false。次に `||` の右の `y++ < 10` を評価します。5 < 10 で true、その後 y は 6 になります。「true 6」。

左から順に全部を評価して x を 7 にしてしまう（B）のが典型的な誤りです。短絡で飛ばされた部分にある `++` は、なかったことになります。
