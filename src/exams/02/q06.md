メソッドの中に記述したとき、コンパイルが成功する宣言を選びなさい。

- A. `var a = (String) null;`
- B. `var b = null;`
- C. `var c = {1, 2};`
- D. `var d = 'x' + 1;`
- E. `var e, f = 1;`
- F. `var g;`

## 解説
`var` は、右辺から**型を1つに決められる**ときだけ使えます。

- A: `(String) null` は String 型の式なので、a は String 型になります。正しい。
- B: `null` だけでは型が決まりません。エラー。
- C: `{1, 2}` という配列の初期化子は、それだけでは何の配列か決まりません。`var c = new int[]{1, 2};` なら書けます。エラー。
- D: `'x' + 1` は char と int の演算なので結果は int（121）。d は int 型です。正しい。
- E: var は1つの文で複数の変数を宣言できません。エラー。
- F: 初期化が無いと型を推論できません。エラー。

A は「null だから var は使えない」と早合点させる選択肢です。キャストが付いていれば、式の型は決まっています。
