次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
class P {
    String name = "P";
    static String kind() { return "sP"; }
    String type() { return "iP"; }
}

class C extends P {
    String name = "C";
    static String kind() { return "sC"; }
    String type() { return "iC"; }
}

public class Main {
    public static void main(String[] args) {
        P p = new C();
        C c = (C) p;
        System.out.println(p.name + p.kind() + p.type() + " "
                + c.name + c.kind() + c.type());
    }
}
```

- A. 「CsCiC CsCiC」と表示される
- B. 「PsPiC CsCiC」と表示される
- C. 「PsPiP CsCiC」と表示される
- D. 「PsCiC CsCiC」と表示される
- E. インスタンス経由で static メソッドを呼んでいるため、コンパイルエラーが発生する

## 解説
p と c は同じインスタンス（実体は C）を指していますが、何が使われるかは種類によって違います。

| 種類 | 何で決まるか | p（P 型） | c（C 型） |
|---|---|---|---|
| フィールド `name` | 変数の型（宣言型） | P の "P" | C の "C" |
| static メソッド `kind()` | 変数の型（宣言型） | P の "sP" | C の "sC" |
| インスタンスメソッド `type()` | 実体の型 | C の "iC" | C の "iC" |

子で同名のフィールドや static メソッドを書くと、親のものを**隠す**だけで、置き換えはしません（隠蔽）。オーバーライドされるのはインスタンスメソッドだけです。

static メソッドを `p.kind()` のようにインスタンス経由で呼ぶのは推奨されませんが、コンパイルは通ります（E は誤り）。このときも、実体ではなく変数の型でどのメソッドかが決まります。
