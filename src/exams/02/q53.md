次のプログラムを確認してください。

```java title=base/Shape.java
package base;

public class Shape {
    String label() {
        return "shape";
    }

    public String describe() {
        return "I am " + label();
    }
}
```

```java title=app/Circle.java
package app;

import base.Shape;

public class Circle extends Shape {
    @Override
    String label() {
        return "circle";
    }
}
```

```java title=app/Main.java
package app;

public class Main {
    public static void main(String[] args) {
        System.out.println(new Circle().describe());
    }
}
```

これらをコンパイル、実行したときの結果として、正しいものを選びなさい。

- A. 「I am circle」と表示される
- B. 「I am shape」と表示される
- C. Circle クラスでコンパイルエラーが発生する
- D. Shape クラスでコンパイルエラーが発生する
- E. 実行時に例外がスローされる

## 解説
Shape の `label()` には修飾子が無いので、**base パッケージの中からしか見えません**。app パッケージの Circle からは、label() はそもそも見えないので、オーバーライドできません。

Circle の `label()` は、名前が同じだけの**別のメソッド**です。そこに `@Override` が付いているので、「オーバーライドになっていない」というコンパイルエラーになります。

もし `@Override` が無ければコンパイルは通りますが、describe() の中の `label()` は Shape の label() のままなので、「I am shape」と表示されます（B は @Override が無い場合の結果）。「子で同じ名前のメソッドを書けば必ず置き換わる」と考えると A を選んでしまいます。

Shape の label() を `protected` か `public` にすれば、正しいオーバーライドになり「I am circle」と表示されます。
