次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        var list = new ArrayList<>();
        list.add("Java");
        list.add(17);
        for (var e : list) {
            System.out.print(e + " ");
        }
        String first = list.get(0);
        System.out.println(first);
    }
}
```

- A. 「Java 17 Java」と表示される
- B. 「Java 17 」と表示された後、ClassCastException がスローされる
- C. 7 行目でコンパイルエラーが発生する
- D. 11 行目でコンパイルエラーが発生する
- E. 5 行目でコンパイルエラーが発生する

## 解説
`var list = new ArrayList<>();` では、左辺にも右辺にも要素の型の手がかりがありません。この場合、ダイヤモンド `<>` は **Object** と推論され、list は `ArrayList<Object>` 型になります。5 行目はエラーではありません。

- 6・7 行目: 要素は Object なので、String も Integer（17 のボクシング）も add できます。
- 8 行目: `var e` は Object 型です。println に渡すと toString が呼ばれるので、表示はできます。
- 11 行目: `list.get(0)` の型は **Object** です。中身が "Java" でも、Object を String 型の変数に代入するにはキャストが必要なので、**コンパイルエラー**になります。

コンパイルエラーがあるので、実行されることはありません（A・B は誤り）。`String first = (String) list.get(0);` とキャストすれば、「Java 17 Java」と表示されます。

`var` と `<>` を同時に使うと、どちらも相手から型を推論しようとして、結局 Object になる、と覚えておきます。
