次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        int n = 0;
        StringBuilder sb = new StringBuilder();
        while (n < 8) {
            switch (n % 3) {
                case 0:
                    n += 2;
                    break;
                case 1:
                    n++;
                    continue;
                default:
                    n *= 2;
            }
            sb.append(n).append(" ");
        }
        System.out.println(sb);
    }
}
```

- A. 「2 4 10 」と表示される
- B. 「2 4 5 10 」と表示される
- C. 「2 」と表示される
- D. 「2 4 」と表示される
- E. switch の中で continue を使っているため、コンパイルエラーが発生する

## 解説
ポイントは2つです。

- `break`（9 行目）は **switch だけ**を抜けます。while は続き、16 行目の append が実行されます（C は、while まで抜けると考えた誤り）。
- `continue`（12 行目）は switch には関係なく、**while の次の周**へ進みます。16 行目の append は飛ばされます。ループの中の switch なら continue は書けます（E は誤り）。

| n（周の始め） | n % 3 | 処理 | append |
|---|---|---|---|
| 0 | 0 | n = 2、break | 「2 」 |
| 2 | 2 | default: n = 4 | 「4 」 |
| 4 | 1 | n = 5、continue | しない |
| 5 | 2 | default: n = 10 | 「10 」 |
| 10 | — | 10 < 8 が false で終了 | |

「2 4 10 」です。continue で append が飛ばされるので、5 は表示されません（B は誤り）。
