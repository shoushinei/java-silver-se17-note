次のプログラムをコンパイル、実行したときの結果として、正しいものを選びなさい。

```java title=Main.java
public class Main {
    public static void main(String[] args) {
        Integer a = 127, b = 127;
        Integer c = 128, d = 128;
        Long e = 127L;
        System.out.print((a == b) + " ");
        System.out.print((c == d) + " ");
        System.out.print(c.equals(d) + " ");
        System.out.print(a.equals(e) + " ");
        System.out.println(e == 127);
    }
}
```

- A. 「true false true false true」と表示される
- B. 「true false true true true」と表示される
- C. 「true true true true true」と表示される
- D. 「true false true false false」と表示される
- E. 10 行目で Long と int を比べているため、コンパイルエラーが発生する

## 解説
- `a == b`: 127 はキャッシュの範囲（-128〜127）なので、ボクシングで**同じ Integer インスタンス**が使われます。true。
- `c == d`: 128 は範囲外なので、別々のインスタンスが作られます。`==` は参照の比較なので false。
- `c.equals(d)`: 中身の比較なので true。
- `a.equals(e)`: Integer の equals は、**引数も Integer のときだけ** true になり得ます。e は Long なので、値が同じ 127 でも false です（B は誤り）。
- `e == 127`: 片方が基本データ型なので、e が**アンボクシング**されて long の 127 と int の 127 の比較になります。値が同じなので true。コンパイルエラーにはなりません（E は誤り）。

Integer と Long はどちらも Number の子ですが、互いに兄弟で、equals では別物として扱われます。
