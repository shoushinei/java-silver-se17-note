HOW TO USE

はじめての方へ

このサイトの使い方を、実際の画面を動かしながら1歩ずつ説明します。右の画面は本物のページです（説明用に開いているので、ここで操作しても受験記録は保存されません）。「次へ」か → キーで進みます。

    この画面を別のタブで開く ↗
    画面を読み込んでいます…

    もっと詳しく

    • キーボード ── 教材では / で検索窓へ、Esc で検索を解除。模擬試験では ← → で前後の問題、A〜H で選択、M で見直しマーク。
    • スマホ ── 教材の目次は左上の「目次」から、模擬試験の問題一覧は「問題一覧」から開きます。画面の上のバーに、いま読んでいる章と論点が出ます。
    • 記録の保存先 ── 受験記録・メモ・続きの位置は、このブラウザの中だけに保存されます（このサイトについて）。
