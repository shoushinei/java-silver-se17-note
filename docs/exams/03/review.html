3A(String) の本体2
4A() に戻って残りの本体1
5B() に戻り、B のフィールド初期化 int v = init();（上から順）5

7B() の本体4

正解：D

String を switch に渡すと、case の文字列とは equals で比べます。new String("B") は "B" のリテラルとは別のインスタンスですが、中身が同じなので case "B": に一致します。

一致した case から、break が出てくるまで下へ順に実行します（フォールスルー）。

1. case "B": から始まり「b」2. break が無いので、下にある default: の中へ流れ込み「d」3. さらに case "C": の中へ流れ込み「c」4. break; で switch を抜ける

よって「bdc」です。case "D": の「x」は break の後ろなので実行されません（E は誤り）。

  • A・B: 一致した case だけ、あるいは次のラベルまでで止まると考えた誤りです。コロン（:）の case は、break まで流れ続けます。
  • C: switch が == で比べると考えると、どの case にも一致せず default から始まって「dc」になります。String の switch は equals で比べるので誤りです。
  • F: default はどこに書いてもかまいません。途中に書いても、ほかの case に一致しなかったときの入口になるだけです。

統合ノートで確認する

  • 第2章 07「Stringの不変性」 ── new String で作った文字列は == では別物でも、equals では等しい

  • D: close で発生した例外も、ふつうの例外と同じく catch に届きます。
